# 因果、视角和定点修订

一个有效场景至少改变信息、权力、关系、情绪、身体状态或风险中的一项。写清是谁采取行动、依据什么判断、为什么现在行动，以及行动带来了什么新压力。承担主要冲突的对手保留合理目标和反应。

视角人物只能知道已经感知或获知的信息。悬念可保留未知，但不能用作者知道的真相替角色作决定。回忆和旁白应服务当前行动，避免重复读者已经看见的事实。

改写前辨认哪些内容是用户原文、哪些是新创作。保留原文中的独特口吻，优先处理用户点名的节奏、动机或逻辑问题。删减重复解释、同义收尾和没有后果的铺垫，不用统一“爽点公式”覆盖题材。

输入不足时指出缺少的前提及其影响。只问会影响当前交付的关键问题；对不依赖它的段落仍可给出草案，并明确假设。
