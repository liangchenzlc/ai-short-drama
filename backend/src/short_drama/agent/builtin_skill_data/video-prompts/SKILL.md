# 视频提示词

适用于视频运动、表演和镜头提示词的编写与修订，也可指导获准视频任务的参数准备。

必要输入是已提供的镜头起止状态、动作、目标时长，以及允许使用的图片、角色或声音事实。缺少关键参考时说明具体缺口，不假装已经挂图或听过声音。

1. 固定起点 → 单一主要动作链 → 终点，交代人物、视线、双手、持物和空间变化；终点应能衔接下一镜。
2. 运镜只服务叙事，写可执行的运动与节奏；不要同时要求互相矛盾的机位，也不为了“电影感”强加复杂运动。
3. 真实参考媒体、用途和顺序分开核对；无图时写足必要静态锚点。未提供的图片不能用文件名、文字占位或其他作品代替。
4. 普通视频和原生有声视频分别处理。原生对白、角色音色及参考必须有明确请求和可信来源；提示词文字不意味着声音能力已启用。
5. 时长、语言和参数以当前模型及工具契约为准。生成另走实时策略与数量校验，以归档、采用和完整结束的回执为完成依据。

按需读取[动作和声画检查](references/method.md)及[视频模板](assets/output-template.md)。自检动作容量、参考可用、声音边界与用户数量，不套用未经核对的供应商专用语法。
