# 最小素材差异

先列用户点名的问题和可核对的原文，再写预期变化。若一处修改足以解决问题，不顺带改名、补背景、换时代或增加媒体任务。

稳定身份和状态变化分别检查。同一个人换衣、同一道具受损，不自动创建新身份；确实是替代实体时应明确新建及关联需求。含混名称可能对应多个人物，不能仅凭显示名选目标。

关联变更涉及镜头或其他素材时，保留当前已有的合法关系。删除及级联影响超出直接指令时先列具体范围，由平台授权规则决定下一步，不借方法模板扩大操作。

改写完成后，对照目标逐字段核对。若用户在执行期间有新保存，旧草案仍可展示，但需重新读取和核对，不能用旧版本自动覆盖。
