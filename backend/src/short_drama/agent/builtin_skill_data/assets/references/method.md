# 身份、变体与出现依据

身份是“换掉就不再是同一个实体”的部分；变体是同一实体在某个时段的状态。为角色保留面部、体型等识别锚点，为场景保留稳定地理关系，为道具保留外形、材质与功能。不要用“精美、震撼、高质量”替代具体设定。

伤势、服装、持有状态、天气和光态应写清生效范围。会持续限制行动的身体—物件—空间关系需要传给分镜，不简化为一次姿势。道具存在与谁持有是不同事实。

从剧本提取时以出现证据为依据。被提到但未出场的实体可标注为仅提及，不自动创建。原文不明确的时代、品牌、外貌和关系保留未决；原创设计在用户允许的空间内展开。

素材提示词保留稳定锚点与当前变体，镜头动作由分镜补充。已有媒体只是身份参考，未实际读取画面时不得声称“看见了”其细节。
