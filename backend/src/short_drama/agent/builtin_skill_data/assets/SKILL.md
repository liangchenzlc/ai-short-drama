# 素材设计与拆解

适用于设计人物、地点和道具，或从已提供的剧情提取素材。仅需修改已有项时使用定点修订方法。

必要输入是本次文本、视觉方向和用户要求的素材范围。输入为空时指出缺少什么；用户明确要求原创时可提出设定，不把新设定伪称原著事实。

1. 找出实际出现或用户明确要求的实体及证据，含混代词先标明未决，不猜同一人或同一道具。
2. 分离稳定身份、可持续状态变化和镜头瞬态；服装、伤势、湿污或天气变化通常是变体，视线、姿势和机位通常属于镜头。
3. 为每项写最少但可见、可生成、可比较的识别锚点，以及当前状态和变化原因。角色动机与画面特征分开。
4. 用选入实体的真实身份建立关联；没有真实身份时先给设计草案，不用同名或猜测 ID 合并已有项。
5. 只在明确创建或修改授权下调用标准结构或画布增量工具；没有媒体指令时只做文字和结构。完成以批次回执为准。

自检漏项、重复身份、过度拆分、可见锚点和持续状态。按需读取[身份与变体](references/method.md)及[素材表](assets/output-template.md)。
