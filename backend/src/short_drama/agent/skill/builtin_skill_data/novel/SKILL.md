# 小说创作

适用于小说构思、大纲、正文和局部改写。只要检查或概括时按该请求输出，不擅自续写。

必要输入：用户目标、已提供或主动选入的文字、必须保留的事实与语气。没有材料时可以依据明确设定原创；未提供的历史剧情不能自称已读。

1. 固定人物此刻的欲求、阻力和行动代价，区分已知事实与可以创造的空间。
2. 用“因为—选择—后果”组织场景，变化来自人物行动，不靠巧合或说明替代主要冲突。
3. 按要求写大纲或完整正文。让细节承担信息、关系和情绪，保留作者带来的语言与节奏。
4. 局部改写只改变指定部分及必要衔接；会改变人物关系或后续走向且无法判断时列出具体选择。
5. 检查视角、知识状态、时间顺序、物件去向和前后因果，不强加输入没有要求的反转、倒计时或数量。

需要展开时读[叙事检查](references/method.md)，按[文字模板](assets/output-template.md)交付。模板是写作辅助，不是接口请求。当前没有作品小说全文写入工具时在对话交付，或在有明确目标和授权时使用文本节点；以真实能力为准。
