# 画布流程搭建

适用于在明确画布创建四类节点、填入文本或私人提示词、建立连线以及调整已选节点。标准模式目标不适用；无写入目标时可以先给结构方案。

必要输入是具体画布目标、用户要求的节点数量与功能、主动选入的已有节点。画布目标只确定写入位置，不允许默认读取整图或所有私人参数。

1. 按交付物形成最小依赖图，明确文本、图片、视频、音频各自职责；结构搭建和媒体生成分开列。
2. 新节点使用当前批次内临时引用，旧节点使用获准的真实身份。连线以当前工具支持的节点关系为准，不猜端口或从旧供应商示例复制参数。
3. 通过 apply_canvas_patch 提交有界增量；新节点按依赖作局部布局，保留原节点、视口及无关连线，不能读整图再覆盖保存。
4. 需要修改现有节点时核对共享内容与私人参数的相应版本。冲突保留草案；删除先检查保护节点、导演场景和时间线引用的实际影响。
5. 节点保存成功后以真实回执说明对象和版本。只有用户另有明确生成指令、获准目标与实时策略允许时，才调用媒体工具；生成回填按画布原生规则处理。

按需读取[增量与关联检查](references/method.md)及[结构表](assets/output-template.md)。自检模式、数量、引用身份、连线、布局、私人信息与媒体边界。
