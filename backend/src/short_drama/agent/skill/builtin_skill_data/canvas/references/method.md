# 画布增量检查

同一批新建节点之间使用该批声明的引用关联。已有节点只能来自主动选入或本任务可读回执，名称相似、当前页面正显示和用户切页都不能增加读取范围。

文本节点承载文字，图片、视频、音频节点承载对应媒体及原生生成设置。创建一个“视频节点”仅建立结构，不代表已经调用模型。媒体数量按真实目标与平台预算计入，不借多个节点绕开总量限制。

画布结构和私人生成参数分别保护版本。移动节点不自动取得其私人提示词；本任务成果读取也不能借内部差异查看后来人工改写的正文。读取目录只说明身份，必要内容另按工具读取。

新增节点只作局部安排，避免遮挡当前依赖，并保留原视口。删除和断连按平台注册规则检查引用影响，禁止通过整图替换绕过保护。重复请求复用原回执，失败整批回滚。

来源：本项目画布增量工具与服务端契约；不包含上游执行脚本、全图保存或第三方接口。
