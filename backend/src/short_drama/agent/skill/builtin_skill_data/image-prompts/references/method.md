# 图片的控制范围

人物图优先固定面部、体型、发型和本次服装；场景图优先固定空间、入口和可见地标；道具图优先固定外形、尺度、材质与功能状态。稳定识别锚点和当前变体分开，避免多项相互矛盾的描述。

参考图的作用需要具体：身份参考不自动控制背景和姿势，构图参考不自动替换人物，风格参考不应带入无关文字或标识。只读取用户主动选入或本任务完整回执可取的图片，不搜索未授权图位。

静帧写可同时发生的状态。若需要“转身并走出门”，单帧应选动作的确定瞬间，运动过程留给视频。画面文字写准确内容及可读条件，不用“加些字”替代。

保留有作用的限制，去掉没有验证作用的形容词。没有实际生成时交付提示词；生成受理、归档和采用分别依据平台回执。
