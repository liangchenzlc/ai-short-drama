# 图片提示词

适用于编写、精简或修改图片提示词，也可指导获准图片生成前的内容准备。

必要输入是这张图的用途、主体、必须保留的身份与状态，以及允许参考的真实媒体。输入不足时指出具体缺口；用户允许原创时可设计，不能冒称来自已读原图。

1. 先写主体、稳定识别锚点和用途，再写当前变体、构图与视角、光线、材质、背景和禁止项。
2. 每张参考只控制明确范围，如人物身份、服装或构图。需要判断画面时先按获准身份读取真实图片，名称或图片目录不能证明内容。
3. 一张图只包含能同时满足的静态状态。多视图或状态对照须说明版面，不把完整动作链塞进单帧。
4. 提示词语言服从用户和当前模型要求，不默认转换英文；正文可直接复制，去掉占位符、内部路径、流程说明与质量词堆叠。
5. 若用户明确要求生成，另核对真实目标、模型能力、数量和实时策略，通过平台注册工具执行；成功后遵循真实采用回执，不插入旧候选采用流程。

自检身份与变体、视角、光线、文字要求和参考边界。按需读取[视觉组织](references/method.md)及[提示词模板](assets/output-template.md)。
