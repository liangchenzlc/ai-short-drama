# 分镜规划

适用于拆解剧情、设计镜头与关联素材，或分析拍摄和剪辑可行性。仅分析时不创建卡片。

必要输入是本次剧情范围、人物与空间关系、用户数量和时长要求。输入不足时说明依赖；用户要求固定镜头数时遵守，不因模板改变数量。

1. 为每个镜头确定观众必须接收的信息及其不可替代作用，再选择景别、机位和动作。
2. 写清开场状态、单一主要动作和结束状态。延续人物位置、视线、持物、伤势及道具状态，切换轴线需有可理解依据。
3. 根据对白、动作和停顿估计时长，保持模型和当前工具允许的参数；估算不等于实测。
4. 只关联已选入或本任务真实回执中的素材。无真实身份时可列待关联名称，不猜 ID。
5. 用户明确要求搭建后调用标准分镜批次或画布增量工具。生成媒体另按明确请求和实时策略执行，不能因有图片栏就启动生成。

自检镜头职责、数量、时长容纳、画面文字、声画关系和接续状态。需要细化时读[镜头与连续性](references/method.md)及[分镜表](assets/output-template.md)。
