# 镜头职责与状态交接

每镜先回答“观众现在必须看见什么”，避免为丰富景别重复相同信息。特写可承载关键物件和反应，全景可交代空间，选择应服务剧情，而不是固定循环。

镜头开场沿用上镜退出状态：人物在何处、朝向哪里、什么东西由哪只手持有、动作已经进行到哪里。镜头切换不能让物件瞬移、伤势消失或角色突然知道未获知的信息。

同一镜头优先一个主要动作链。对白、可读文字和动作同时发生时检查观众能否接收；必要时重分配职责，不能在用户固定镜头数之外擅自加镜。时长以真实动作、表演和平台参数范围为依据。

需要生成时，先确定输入图片或已结算媒体是否被主动授权引用。画面起点、运动终点和下一镜必须一致；无媒体请求时，镜头表只形成文本和结构。
