# 素材定点修订

适用于用户明确要求修改已选素材的描述、提示词或关联。只有名称且无法确定身份时先消歧。

必要输入是目标真实身份、已读取的保存版本、用户指定变化和应保留的内容。缺少正文时通过获准读取工具取选入范围；不能因需要背景而扫描其他素材。

1. 区分身份改变、状态变体和单次姿势，明确哪些字段确实需要改动。
2. 保留无关文字、识别锚点、私人参数和真实关联；只给出最小差异。
3. 对会影响后续镜头的服装、伤势、道具状态和空间变化说明影响，不自动扩展修改到未选对象。
4. 明确授权后按当前版本调用结构工具。版本变化保留草案，主动刷新或询问如何合并，不能重试覆盖新编辑。
5. 根据回执说明已保存字段与未执行内容；修改提示词不意味着图片已重生成、已采用或旧媒体已删除。

按需使用[修订核对](references/method.md)及[差异表](assets/output-template.md)。自检目标、范围、保留项和保存版本。
