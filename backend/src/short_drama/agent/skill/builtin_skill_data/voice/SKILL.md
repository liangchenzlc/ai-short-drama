# 配音与声音规划

适用于写台词、设计角色声音、规划情绪和声音结构，也可准备用户明确要求的配音任务。

必要输入是准确台词、真实说话人、语言与用户要求；讨论声音设计可先使用文字。声音描述、真实音色和某一句表演必须分开，不混为已生成样音。

1. 固定角色较稳定的音区、音色质感、口音和停顿习惯；一句话的情绪、音量和重音归入表演，不写成永久身份。
2. 台词以用户提供或获准读取的保存内容为准，专名发音、画内／画外和静默分开标记。不能因需要配音而自动读取其他角色或整部剧本。
3. 形成逐句表：说话人、准确文本、情绪／表演、时序和真实音色来源。缺少来源时标为待选，不能编造 voice ID。
4. 写入台词、生成角色音色、标准声音台词配音及原生有声视频是不同操作，按用户具体要求和当前能力分别走平台注册工具。
5. 生成前核对实时音频／视频策略和数量，受理不明沿用原请求；成功以实际归档和采用回执为准，不悄悄切收费模型或重发。

按需读取[身份与表演](references/method.md)及[声音表](assets/output-template.md)。自检身份、文本、数量、授权、时序和完成依据。
