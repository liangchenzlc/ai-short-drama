# 声音身份与单句表演

判断声音特征是否属于身份：角色安静说一句无关紧要的话时，这个特征是否仍在。音区、口音和习惯可属于身份；奔跑后的气息、愤怒时的音量或一次压低嗓音属于当场表演。

参考音频可控制音色，不自动带入背景声、原台词或一次情绪。只知道媒体身份或文字说明，不能声称已经试听。没有音频理解工具或真实试听依据时，如实说明判断来自文字与元数据。

区分四种交付：台词文字保存只证明文字；角色音色任务产出样音并采用声音身份；逐句配音以保存的声音台词和真实音色为源；原生有声视频还需要真实镜头、角色和对白来源。一个环节成功不能替代其他环节。

专名、多音字和语言要求明确记录。时序依据实际音频长度或用户时长安排，估算不冒充检测结果。声音设计不默认获得克隆或扩展读取范围。
