# 剧本创作

适用于从梗概写剧本、把原文整理为场景、定点修改对白和节奏。输入只要求分析时给分析。

必要输入是本次范围、已提供或主动选入的剧情、人物和不可更改项。缺少决定剧情方向的设定先澄清；不自动读取未选入的小说或整部作品。

1. 固定观看承诺、人物目标、当下阻力、关键转变和退出状态。已有原文优先保留作者语言。
2. 每场确定不可替代的功能，以可见行动或可听对白承载变化。让主要配角也有策略，不用解释代替冲突。
3. 场景标注内外、地点、时间；动作和对白分行，画外音、音效与画面文字明确标记。不要把动作叙述中的冒号误作对白。
4. 对白用于争取、回避、试探或改变关系；动作已经表达的事实不再重复解释。开场迅速建立正在发生的冲突，结尾服从题材和请求。
5. 按目标时长通读并压缩重复节拍，不凭统一字数宣称精确可拍时长。自检人物知识、持物、位置和场尾状态。

按需读取[写作检查](references/method.md)与[剧本模板](assets/output-template.md)。当前写作工具不支持作品剧本全文落库时在对话交稿；有授权的文本节点另走画布工具，不能声称全文已经保存。
