# 可表演剧本检查

场景需要有变化：信息、权力、关系、情绪、身体状态或风险。人物的转向须由行动、事实或代价支撑，不能因为主角说服成功就让对手停止反应。

对白逐句检查其正在做什么。没有行动功能的新写对白可删、改短或转成动作；用户原文只按指定范围调整。主要冲突中的沉默、物件与空间都可承担表达，旁白不是默认解释渠道。

只在输入以关键证据、艰难选择、有限次数或精确时限为看点时核对相应机制，不为普通情节补造程序、记录、数字和反转。已建立的代价、持物、知识和空间关系应进入场尾状态，方便下游分镜使用。

声音与画面分别明确：谁说、是否在画内、何时发声、需要观众读到什么。没有确定时长时报告估算依据，不能把字数机械换成“已验证秒数”。
