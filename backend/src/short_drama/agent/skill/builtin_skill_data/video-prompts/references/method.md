# 运动、参考与声音

动作链须有连续状态。起点是“杯子在桌上”，终点是“杯子已递到对方手中”时，应交代谁拾起、移动和交接，而不是只写“发生激烈对话”。关键物件不应因切换描述而消失或换手。

时长容纳动作、对白和必要停顿。多项关键动作挤在一段时，先检查删减或拆分是否符合用户镜头数与段数；不擅自增加生成数量。运镜、主体运动和背景变化应彼此可成立。

图生视频的参考需是真实、获准且可供当前工具读取的媒体。文字构图计划和图片提示词不是已有图片；目录身份也不等于已看过画面。需要判断真实起点时使用获准图片读取工具。

对白明确说话人、准确文本、发声时序和音色来源。普通无声或非原生视频不能因模板有声音一栏而升级，原生有声的能力与授权需独立核对。已有视频的轨道和实测时长只能由真实媒体检查或回执证明。
