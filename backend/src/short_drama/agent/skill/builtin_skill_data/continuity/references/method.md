# 可证明的连续性差异

人物：面部与体型锚点是否稳定，服装、伤势与湿污变化是否有依据。道具：是否存在、由谁持有、哪只手持有、开合或损伤状态，不能把所有权等同于当前持有。

空间：人物站位、入口、视线、运动方向和轴线是否可接续。动作：上镜终点是否成为下镜起点，关键物件是否在未交代时瞬移。知识：人物是否提前知道只对观众或其他角色揭示的信息。

声音：角色音色身份、发声人、台词和声源位置是否与已提供来源一致。风格：按已确定的时代、色光、材质和镜头语言检查，允许用户明确要求的变化，不用主观偏好制造问题。

问题等级依据实际影响：阻断理解或执行的确定矛盾优先；局部体验差异其次；证据不足的疑点单列待核对。给出预期修订结果，避免“缺乏电影感、AI 味重”之类无法验收的结论。
