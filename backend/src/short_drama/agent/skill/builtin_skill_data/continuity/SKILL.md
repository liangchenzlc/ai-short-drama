# 连续性检查

适用于核对人物、服装、伤势、道具、位置、动作、知识、声音或视觉风格的前后差异。只检查获准可见范围。

必要输入是待比较的两个以上状态，或待审内容及明确设定。只有单个片段时仍可检查内部矛盾，但不能声称已验证全作品一致。

1. 写清实际检查范围和未读取范围，区分确定事实、允许变化与未知信息。
2. 对每处差异给出真实主体或片段位置、必要短引文、冲突状态和影响。先判断是否存在剧情建立的合理变化，不将变体误报为换身份。
3. 持物、左右手、轴线、视线、空间和动作按起止状态比较；角色知识只来自已建立的信息；风格检查依据已给方向，不强推统一审美。
4. 未实际读取的图片或声音只按文本与元数据说明限制，不自称看过画面或试听。资料不足时指出需补充的具体输入。
5. 提出能解决问题的最小修订。用户只要审查时交付差异；明确要求修改且有真实目标、版本和授权时才调用结构工具，不自动重生成媒体。

自检每个问题是否有依据、是否混淆未知与错误、修改是否超范围。按需读取[连续性清单](references/method.md)及[差异报告](assets/output-template.md)。
