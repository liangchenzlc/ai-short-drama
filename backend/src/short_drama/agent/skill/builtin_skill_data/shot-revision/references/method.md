# 镜头局部影响

修改画面职责前先确认用户是否只要求润色文字。不要把表达优化升级成新剧情，也不要把镜头移动当成可以改动全部节点布局或分镜排序的授权。

动作变化要核对开场、过程、终点。若原镜头结尾为“关门”，后镜却从开门开始，应指出已有依据和差异；如果后镜未选入，只能提示需要核对，不能声称已查完整连续性。

替换角色或道具关联前确认真实身份与本次授权。相似名称、旧回复中的内部差异和后来的私人提示词都不能代替可访问的当前选入信息。

保存成功只证明结构变更。已有图片、视频或声音可能需要用户另外决定是否重做；没有对应请求时保留。版本冲突不能自动换请求身份覆盖用户最新保存。
