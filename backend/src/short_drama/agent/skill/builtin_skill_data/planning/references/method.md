# 依赖与范围检查

将请求分成“内容已知”“用户要求”“尚不确定”三部分，不把推测写成作品事实。保持用户当前明确要求高于方法默认偏好，手动指定的方法高于自动补充。

先解决真正阻塞执行的依赖：没有目标可先讨论；没有剧情可先整理问题；没有媒体请求可先搭结构。不要为了补齐计划表去读取未选正文、引入新角色、增加镜头、调用收费生成或修改全局开关。

每步的完成依据应与操作对应：草稿形成只证明文本可审阅；结构保存需批次回执；生成受理只有任务身份；生成、归档及采用全部结束后才能称该媒体工具完成。受理不明保留原身份核对。

若数量或目标有多种解释，列出具体差别并询问；不以最宽解释执行。无需将正常工具调用逐次变成人工审批。
