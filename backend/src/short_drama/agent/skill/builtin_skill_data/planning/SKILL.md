# 创作任务规划

适用于梳理目标、拆解复杂请求、决定先后顺序。简单闲聊直接回答，无需制定流程。

必要输入是用户要交付什么、已有材料和明确限制。缺少会改变执行范围的信息时具体询问；只缺非必要风格细节时给出合理选项，继续能完成的部分。

1. 用一两句固定目标、必须和禁止项、数量、参考主体、写入目标及媒体要求；这些信息分别记录，选了参考不等于允许改写。
2. 按依赖形成最少步骤，每步说明输入、可核对结果和完成依据，不展示隐藏推理。
3. 讨论交付文本；搭建只创建获准卡片或节点；生成必须另有明确请求及允许的实时策略。不开启用户没有要求的下一阶段。
4. 执行前核对目标和工具；能力缺失时说明可完成的文本方案，不编造已保存、已生成或已采用。
5. 根据实际回执更新完成情况；补充约束沿用原任务，改向和停止在平台工具边界生效。

按需使用[依赖检查](references/method.md)和[计划模板](assets/output-template.md)。自检所有步骤是否必要、数量是否准确、参考和目标是否混淆、结论是否有回执支持。
