# 产品范围与创作流程

AI短剧工作台面向个人创作者与项目协作者，帮助完成故事改编、素材准备、分镜制作与成片导出。账号必须验证邮箱；项目主人通过绑定账号或指定邮箱的邀请加入协作者。成员使用各自模型配置，个人素材导入为独立副本，项目产出在成员离开后保留。业务数据保存于服务端数据库和 MinIO。首期不含独立团队空间或实时编辑。

## 项目工作区模式

创建项目时选择“标准模式”或“无限画布模式”，默认标准模式，创建后固定。标准模式沿用下文分集流程；无限画布跳转同源独立构建的 BeefTV 编辑器，初始创建一个主画布，数据模型允许多个画布。布局、菜单、操作及结果回填以源固定版本为基准，最终目标和范围见[一比一迁移方案](../docs/plans/2026-10-05-beeftv-infinite-canvas-migration.md)。

无限画布独立子包仅保留具体画布编辑器，BeefTV 首页、源项目库/详情、资产/任务管理、模型设置、外部 Agent 及整站导航已物理删除。项目、资产、模型配置和任务统一使用当前工作台入口；旧画布库和其他整站深链转到宿主项目列表。“返回工作台”和“模型配置”在作品与个人偏好保存成功后才离开，冲突保留当前草稿。画布内的媒体选择和生成记录继续保留原功能，AI 创作助手与标准分集页共用，不提供独立整站管理页。

当前已接通创建、基础图保存、历史、账号隔离及基本生成准入/回填链路；完整生成协议与参数、媒体加工及全部导入导出仍未验收，不能标记为完整可用。无限画布生成继续按源行为自动回填，标准模式生成继续采用候选审核规则；助手按最新需求统一为项目纯对话，不修改画布或执行创作任务。私人任务参数、生成草稿、未绑定产物与对话不随画布作品共享。

无限画布文字节点可通过 Chat Completions 引用已保存的项目图片，按本人保存的模型图片能力校验并
保持源引用顺序。未声明视觉能力不自动启用；保存的非流模型使用非流请求。正文沿原生成回填及
草稿恢复流程，其他文字多模态协议、思考和工具分别实施。宿主保存的运行配置在新任务准入时派生执行缓存，
旧任务使用原冻结配置。完整验收仍以阶段实施记录为准。

模型配置统一到宿主 `/ai_config`，旧无限画布设置链接转到宿主；画布只保留模型选择、个人默认与生成参数。运行 profile、API Key、第二密钥和自定义请求头由宿主管理，秘密服务端加密，读取只返回存在标记。离开画布前等待个人偏好与作品保存回执，冲突保留当前草稿；宿主通过已校验的画布返回地址提供返回入口。模型测试创建本人的独立异步任务，收到实际模型响应后才成功，可在创作历史中查看结果；不为了测试创建项目或节点。原协议目录元数据已迁入，未实现的 Python 执行协议仍明确标记不可用。完整运行能力与一比一对照继续按实施记录核验。

BeefAPI 保留官方渠道与原连接、重连、钱包操作。设备授权由服务端 scheduler 继续处理，关闭页面不会停止；API Key 加密保存，浏览器只能读取脱敏状态。官方地址与模型目录由服务端提供，成员各自授权和维护私人 headers；断开不会删除手工渠道。同次授权的目录刷新保留用户模型选择，存在未保存草稿或版本冲突时不会自动覆盖。按固定源实际调用，余额保持 unknown，目录或连接核验返回 401/403 才标记失效；完整正式企业登录仍须验收。

无限画布视频增加 OpenAI Videos、NewAPI Channel 2 与官方 BeefAPI Seedance 协议。Channel 2 本地参考沿用原 HTTPS 替换弹窗，受理前失败不创建任务；刷新沿用同一任务，成功结果按源直接绑定并播放。模型默认参数和参考媒体元信息在服务端冻结，未知收费提交保持待核对状态、阻止重新提交。当前原视频 UI 与受控供应商链路验证不代表完整协议、全部媒体工具或收费模型验收。

## AI 创作助手与作品生成

分集详情页保留左侧流程、中央作品与右侧模型和生成设置，取消创作方式切换。四个阶段均在顶部保存状态左侧提供“AI 创作助手”，默认关闭。桌面打开助手临时收起生成设置，关闭后恢复原输入；窄屏采用右侧抽屉。素材与镜头始终进入原编辑功能，需要编辑区域时收起助手，对话和草稿保留。

标准与无限画布共用同一套助手前端和 `/assistant` 接口。助手只提供问答、分析和建议，支持复制回复；生成、提取和修改作品使用原入口。服务端固定纯对话用途并禁止工具调用，Skill 不能取得创作执行权限。对话按本人和项目归属，切换分集、阶段、素材、镜头或同项目画布不自动更换对话，也不创建对象专属会话。

助手对话、已有创作候选和生成历史仅本人可见，明确采用后的作品按项目权限共享。任务中心、媒体库、声音与成片历史按作者隔离，项目成员不能查看他人的生成参数、模型、错误或过程记录。原创作对话保留为“历史创作记录”，消息只读，已有任务、计划与候选仍可按原权限、来源版本及许可继续处理，不拼接到新聊天。“采用并继续”只继续该历史记录明确关联的运行，可能产生后续费用。

助手沿用画布的标题栏、新对话与历史图标、消息气泡、安全 Markdown、自适应输入、左下模型和圆形发送按钮。保留图片、文本、视频、音频附件、资产引用以及个人 Skill 管理，发送时冻结版本。当前作品显示为可移除的引用标签，其他作品可用 `@` 引用；不带作品引用时可进行普通问答。模型和凭据统一由工作台模型配置管理，不要求工具能力验证，附件不兼容明确反馈。

引用作品发送前等待正文及相关编辑保存回执；失败、409 冲突或等待期间的新修改保留草稿并阻止发送。服务端校验权限与来源版本并冻结上下文，切页不改变已受理消息。Enter 发送、Shift+Enter 换行，中文输入法组合期间不提交。关闭面板不停止服务端回复，刷新可恢复消息、运行与草稿；受理不明时复用原请求和幂等键核对，不自动再次调用模型。

助手复用既有 Agent 启用配置和独立 Worker，需要账号认证与显式数据库迁移。旧 `mode=agent` 链接转换为助手入口，包含旧对话 ID 的链接进入历史创作记录，解析后清除模式与对象会话参数。新链接使用助手显隐、项目当前对话和可选历史记录；素材与分镜编辑另以 `asset`、`shot` 保留稳定选择，旧非创作对话的对象深链兼容转换，不创建对象对话。既有供应商证据见[验收记录](../docs/agent-verification.md)，不代表本次共用助手或其他模型已经真实验收。

本次设计与验收状态见[流程精细化方案](../docs/plans/2026-10-03-episode-workflow-refinement.md)；启用、关闭与 unknown 处理见 [Agent 部署](../docs/agent-deployment.md)，接口与私有/共享边界见 [API 说明](../docs/api/README.md#agent-创作与私有候选)。

## 页面与核心流程

1. **项目管理**：搜索和分页查看项目卡片，点击进入项目；详情左侧三个图标分区分别显示剧集信息、项目资源库、共同创作。剧集信息与分集列表上下排列，分集使用固定尺寸封面卡片，三点菜单提供编辑和删除；无封面时显示默认封面，首镜头采用图片后作为封面。协作者列表独立显示，邀请按钮打开生成邀请链接的弹窗。新项目不自动创建示例内容。
2. **小说改编**：本集小说与剧本定稿在中央两个标签页编辑，停顿后自动保存。支持 UTF-8/GB18030 的 TXT 导入（最多 1 MiB），导入前确认替换正文。右侧生成设置提供文本模型、本集画幅、视觉风格及改编要求；生成剧本按钮与生成记录图标同行，提交后持续加载并禁止重复点击；候选在生成记录弹窗预览、采用。可直接手写剧本，确认后用于提取和分镜生成；修改确认稿会取消确认。
3. **素材准备**：工具栏“从剧本提取素材”位于“从项目库添加”左侧，打开模型、要求与逐项审核弹窗。中央以卡片展示分集素材，点击名称在右侧编辑完整素材；助手打开时恢复原编辑区域，对话保留。图片独立预览，菜单保留编辑、共享到项目和从本集删除；个人和项目素材仍使用详情抽屉。切换素材须核对未保存内容，离开分集或引用作品发送前等待素材保存，失败保留草稿。可保存多张参考图，生成候选后明确采用。
4. **分镜制作**：响应式卡片网格展示当前采用图片、镜号、时长、最多两行的脚本和独立的图片与视频状态；无图镜头显示占位。“新增分镜 / 提取分镜 / 历史记录”同行排列，批量选择须先进入“批量操作”。点击卡片选择镜头，右侧“镜头信息 / 分镜图 / 分镜视频”标签编辑脚本、时长、分类素材关联及制作媒体，支持前后镜头切换；选择镜头恢复编辑区域但不更换助手对话。分镜阶段不提供“声音制作”按钮。提取弹窗提供文本模型、平均镜头时长和要求，生成提交后持续加载并禁止重复点击。历史弹窗只读取本人记录，整批追加或替换；历史与当前镜头均按 20 条滚动加载。图片生成记录在独立弹窗核对。

5. **成片合成与导出**：从已采用的分镜视频建立独立草稿，在单视频时间轴上追加、排序、分割、裁剪、删除和静音片段，编辑自动保存。统一以 30 fps 定位和逐帧预览，拖动片段两端或使用快捷键逐帧裁剪；轨道显示连续缩略图、裁剪时间反馈及排序落点，缩放围绕播放位置。支持当前编辑会话内最多 100 步撤销/重做。大播放器支持整条轨道顺播、全屏、后台 360p 合成预览及实际导出成片播放。声音、字幕及配乐入口位于成片标题下方，在同一工作区展开编辑；离开流程前保存声音草稿，版本冲突保留输入并阻止离开。正式导出为 720p/1080p MP4，支持取消、失败重试、下载及设为当前成片；合成使用提交时的快照，结果展示对应的只读轨道。

分集实际导航为小说改编、素材准备、分镜制作、成片合成与导出四步，流程栏可收起。步骤编号只表达顺序；已保存、已确认、当前采用是不同状态。

成片工作台支持专注剪辑：临时收起分集标题、创作流程和步骤导航，退出后恢复原布局。素材区可折叠；桌面可拖动分隔条或使用方向键调整播放器和轨道高度，偏好保存在本机。片段属性区及重置布局入口已移除；静音和恢复完整位于剪辑工具栏。刷新默认退出专注模式，窄屏仍采用自然堆叠布局。

成片预览优先使用后台生成的播放代理；素材区使用代表缩略图，轨道按保留的来源时间显示连续采样缩略图。每个来源最多采样 24 帧，生成前或加载失败时回退到代表图；正式导出读取原视频，实际时长由后台检测。已有草稿打开时自动补齐预览素材，不同步或覆盖剪辑决定。分镜来源更新仍需要明确同步，保留已有顺序、分割和裁剪，已删除片段不会重新加入，新分镜追加到末尾；替换源视频过短时需重新裁剪。保存失败或版本冲突保留本页编辑，可下载草稿、重试保存或确认后重新载入；重新载入、同步来源及离开编辑会话会清空撤销历史。

分镜图片操作区按需展开，展示关联素材及去重后的已确认参考图数量。生成前保存并核对最新分镜上下文；其他窗口改动时先刷新核对，不覆盖草稿。模型不支持参考图时不能静默丢图。任务历史和候选分页加载，可查看任务详情并按服务端许可安全恢复；受理结果不明时先核对记录，避免重复计费。

采用历史分镜图保留其原生成布局、画幅和分辨率，不用当前编辑设置改写历史元数据，也不改变下一次生成设置。旧来源需要明确确认，确认仍不能绕过当前图片、分镜版本和上下文的并发校验。

## 素材与媒体

| 概念 | 用途 |
| --- | --- |
| 素材 | 角色、场景或道具的名称、描述、提示词和当前确认图片 |
| 素材库 | 个人库独立；导入项目时复制素材和物理文件；同一项目与其分集可引用同一本体 |
| 图片候选 | 生成、上传或选择的待核对图片，未确认时不改变素材当前图片 |
| 媒体资产库 | AI生成的图片/视频；桌面每行四张媒体卡片，仅展示画面与左下名称，点击核对详情，无筛选和刷新入口 |

素材提取只使用文本模型，不生成图片。素材详情可选择图片模型及可选参数，一次生成1–4张候选；先保存素材，再使用服务端冻结的内容生成。生成会读取持久化参考图片，不自动引用当前采用图片或继承入口项目风格。素材和分镜各最多保存 16 张输入参考图；模型不支持时明确拒绝。移除仅解除关联，历史请求仍保留原文件。上传支持PNG/JPEG/WebP，最大20 MiB、4000万像素。

同一项目内引用的素材共享已采用作品，生成历史与候选始终只对生成者开放；跨范围复制不带入原生成历史、个人模型配置或音色绑定。离开详情后任务继续，重新打开从服务端恢复。生成完成不改变当前图片；采用时校验版本，共享素材需确认影响范围。素材内容改变后，旧候选仍保留，采用需明确核对；仅改选图片不会让同批其他候选失效。

## 通用AI能力

任务中心新建图片任务时，参考图片可从图片资产库选择或多选上传本地图片，合计最多 16 张。上传支持 PNG/JPEG/WebP，单张最多 20 MiB、4000 万像素；成功后显示预览并自动加入本次任务，上传期间禁止提交。上传文件作为输入媒体保存，不创建生成任务或生成资产；移除仅解除本次表单引用。

AI配置统一使用 `/ai_config`，标准模式和无限画布共用本人模型；旧 `/ai` 与 `/canvas-app/settings` 链接兼容跳转。按文本、图片、视频、音频分组，每条配置一个模型，各类型可设默认；编辑表单在启用开关旁提供默认配置选择。高级配置补充 API 格式、调用协议、参考资源根、能力与默认参数、第二密钥和自定义请求头；高级配置可明确清空。Key 和请求头值提交服务端加密保存，浏览器只读取存在标记，不持久化秘密。

模型目录探测不调用生成、不自动保存配置；没有目录接口时可手动填写模型名。独立模型测试与 BeefAPI 企业连接在宿主提供；测试成功仅代表本次返回，未接通协议明确拒绝。托管模型可维护名称、启停和删除，企业地址、模型身份与授权凭据由服务端维护。画布只选择模型、保存个人默认和生成参数，原节点及重试按稳定 ID/旧别名恢复；进入模型配置前等待偏好和作品保存，失败或冲突保留草稿。宿主“返回画布”只接受具体同源画布路径。

任务中心按任务 ID 与“项目 / 集 / 用途”识别来源；已完成任务可跳转至对应创作页面，通用图片/视频跳资产库，通用文本可查看结果。失败任务直接显示完整原因，并在服务端允许时恢复或重试；列表不提供更多筛选、刷新或详情按钮。生成请求可能产生费用，不能把未知受理结果当作免费重试。任务离开页面后仍在后台执行。

右上角账号入口打开独立 `/account` 页面，维护账号信息、安全设置与退出登录；返回按钮回到进入前的站内页面。素材侧栏仅保留素材库入口，角色、场景、道具在素材页内切换。

模型兼容受协议、参数和账户能力限制；“能获取模型列表”不等于“已验证生成可用”。

## 保存与恢复

- 项目、分集、小说/剧本、三层素材库、分镜、任务和采用结果持久化到服务端。
- 项目设置显式保存；正文自动保存，候选采用与确认独立提交。
- 网络失败先核实服务端状态；版本冲突保留草稿，允许下载后人工合并，不自动覆盖。
- 账号模式仅读取本人命名空间下的浏览器草稿。未归属旧稿只在受控兼容模式提供预览或下载，不自动导入任何账号。
- 模型选择按账号保存到服务端。清理浏览器数据不会删除作品或模型偏好，但会丢失尚未保存的本地草稿。
- 生成结果保留候选。源内容修改后旧分镜图可能过期，需核对后再采用。

- 分镜视频的批量、首尾帧和多素材图片参考；单张分镜图生视频及候选采用已接入分镜制作页面。
- 宫格图切格、配音、字幕、配乐、多轨时间线、转场和变速。
- 独立团队空间、只读访客、所有者转让、实时编辑、评论与任务分配。

分镜视频入口在选中镜头的“分镜视频”标签：已采用分镜图自动作为全能参考图，支持单图、四宫格、五宫格及九宫格。参考图不强制用作视频首帧，成片不复制宫格排版，视频画幅沿用分集设置。默认提示词来自分镜，用户可编辑；系统提示词在后台参与生成，页面不展示。视频时长可独立调整，默认沿用分镜时长，范围受模型能力约束；调整视频时长不会修改分镜脚本时长或使分镜图过期。提示词、清晰度和视频时长自动保存，生成前等待保存完成。候选支持播放与采用，离开页面后任务继续，来源改变后提示核对。

后续可扩展声音、字幕和批量制作。
