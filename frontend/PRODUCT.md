# 产品范围与创作流程

> 2026-10-28：旧 Agent 入口链接仅打开当前项目助手，不再携带已失效的历史对话参数；现行助手布局及操作不变。下文关于该参数恢复历史记录的描述为历史记录。

本项目仅支持桌面浏览器，最低内容视口宽度为 **1280 CSS px**，以浏览器实际内容区域计。新增和修改页面无需手机、平板或触屏专属布局、原型及验收；保留桌面窗口变化、组件内部排布、键盘可访问性、降低动效与正常滚动。低于最低宽度沿用桌面最小宽度并允许溢出，不增加设备识别或访问拦截。9:16 等媒体内容比例与输出能力继续保留。

Skill 管理统一在独立 `/skills` 页面，位于侧栏资产库下方。只接受 Markdown／ZIP 导入与完整包更新；文件统一通过目录树和只读源码区域查看，复用 Ant Design DirectoryTree／Splitter 与 CodeMirror 6。卡片只显示名称、用途、模式和启停，标签保留但不展示，不再记录触发方式。适用模式为通用／创作／画布三段单选，新导入默认通用；脚本整包拒绝，历史脚本仅兼容读取。内置原件可查看、启停及导出。AI 配置不再承载 Skill 管理，旧链接替换跳转；版本冲突保留导入包，受理不明保留原请求核对，旧账号草稿提供下载和明确清除出口。V3 助手已接入按需检索／加载、任务级冻结版本和资料分段读取；ThoughtChain 显示方法来源、版本、用途、缺少能力及实际参与步骤。输入区提供可搜索、加载更多和直接多选的 Skill 列表，输入 `/` 可按真实身份和版本选择同名方法，Enter 确认后在输入框内显示可移除的高亮块，不把命令文字放进正文，显式清空也能跨刷新恢复；原任务旧版需明确操作才升级。九类能力已适配为 12 个独立内置包，并显式发布到当前业务库，历史资料受版本引用保护，维护见[内置方法](../docs/instruction/内置创作方法维护.md)。自由文本的广义语义消歧与真实模型效果仍待验证，测试替身通过不代表真实模型验收。

AI短剧工作台面向个人创作者，帮助完成故事改编、素材生成、分镜制作与成片导出。账号必须验证邮箱，作品、私人模型与个人画风保存在服务端数据库和 MinIO。项目协作、邀请、项目素材库和全局素材库已作为废案移除。当前作品的素材生成与媒体资产库继续保留。

## 项目工作区模式

创建时选择“创作模式”或“无限画布模式”，默认创作模式，创建后固定；接口值仍为 `standard` / `infinite_canvas`。创建请求仅包含名称和模式，名称去除首尾空白后为 1–120 字符。创作模式只保留一层 Project，没有 Episode、隐藏分集或占位 ID。创建完成直接进入 `/projects/:id/source`；正文、素材、分镜、声音与成片直接归属当前作品。

创作模式沿用“剧本创作 / 资产生成 / 分镜制作 / 成片合成”四阶段，路径为 `/projects/:id/:stage`，无阶段时默认 `source`。没有项目资料页、梗概/画幅/风格设置或分集列表；剧本页只展示一篇连续正文，小说和大纲专属链已退役。旧分集、素材库与协作深链显示停用说明。

无限画布使用同源独立构建的 BeefTV 编辑器，保留自己的 Project → Canvas 所有权以及多画布、素材、角色节点、个人画风、复制、ZIP、保存与回收功能。删除绑定标准来源项目、分集目录、来源画风和共享角色目录；分镜角色直接使用本画布的 `nodeId/name/definition`，复制时重映射节点引用。桌面布局与其他操作以固定源版本为依据，移动端适配按当前桌面支持范围退役，现行边界见[画布迁移边界](../docs/instruction/画布迁移边界.md)，原范围见[一比一迁移方案](../docs/plans/2026-10/2026-10-05-BeefTV无限画布一比一迁移方案.md)。

无限画布独立子包仅保留具体画布编辑器，BeefTV 首页、源项目库/详情、资产/任务管理、模型设置、外部 Agent 及整站导航已物理删除。项目、媒体资产和模型配置统一使用宿主入口，任务进度在各创作场景内反馈；旧画布库和其他整站深链转到宿主项目列表。“返回工作台”和“模型配置”在作品与个人偏好保存成功后才离开，冲突保留当前草稿。画布内的媒体选择和生成记录继续保留原功能，AI 创作助手与创作模式页面共用，不提供独立整站管理页。

宿主项目管理页提供“画布导入导出”：导出所选无限画布项目的全部已保存画布与引用媒体，ZIP导入为本人新作品；未确认的导入保留原请求，核对后选择原ZIP继续。

项目卡片点击后在新浏览器标签页打开，列表保留；名称、最近打开日期与三点更多菜单位于同一行。删除项目须明确确认，删除后项目及其创作内容不可访问，已受理任务不会自动取消。素材与分镜卡片也通过更多菜单删除，素材仍受分镜引用保护；分镜删除校验镜头及列表版本，删除成功后选中邻近镜头，已有关联的成片草稿保留并提示来源变化。

画布导演台暂处于“正在开发”阶段：新增与右键菜单中的导演台禁用，底部 `TV Director` 快捷入口隐藏，已有导演节点保留内容但不能打开工作台。恢复开放前不提供新建或打开导演台的入口。

当前已接通创建、基础图保存、历史、账号隔离及基本生成准入/回填链路；完整生成协议与参数、媒体加工及全部导入导出仍未验收，不能标记为完整可用。无限画布生成继续按源行为自动回填，创作模式素材图与分镜图生成后直接保存，默认第一张为主图；标准分镜视频成功归档后自动成为镜头视频。剧本工作台的选区改写直接更新当前正文；素材提取、分镜结构与 Agent 文本候选保留明确采用。助手已转为项目会话与逻辑任务，当前开放的工具范围见下文；完整创作执行仍在实施。私人任务参数、生成草稿、未绑定产物与对话仅本人可见。

## AI 创作助手与作品生成

创作模式页面使用左侧40px满高图标导航与占满剩余高度的创作工作区。四个阶段均在顶部保存状态右侧提供“AI 创作助手”，默认关闭。桌面打开助手增加独立右列，默认 380px，可拖动左边界或使用方向键、Home／End 在 320–560px 内调节，实际最大宽度受编辑区可用空间限制；宽度按账号保存在本机。主面板让出空间，选择素材、镜头和展开设置保持助手打开。助手统一使用桌面停靠栏，可与生成设置同时打开并保留各自输入。剧本正文在实际剩余区域内居中，窄容器自动减小内距，没有目录和对应抽屉；打开改写要求时保留助手。素材与分镜为“左列表 / 预览和设置主面板 / 助手”；成片沿用既有内部布局。

标准与无限画布共用同一套助手前端和 `/assistant` 接口，以项目为 V3 会话主体，账号仍限定私人访问。在哪个项目聊天，创建或修改成果就保存到哪个项目；模式只区分创作工作区和画布工作区。同项目切阶段或画布可继续原会话，跨项目分别恢复会话和草稿；已受理任务保持原项目及原画布目标。新任务自动使用当前项目的保存目标与创作设定，不自动加入小说、剧本或整图正文；标准助手已移除“引用当前剧本”入口，新消息不绑定正文或选区，并解除旧任务的剧本绑定。回复期间发送按钮切换为停止图标，输入草稿继续保留；停止后直接发送新的要求，保留原任务的目标、引用、附件和方法，由消息表达补充或改变方向，不再提供“补充当前任务”提示及独立停止／继续按钮。新消息受理后才继续回复，任务完成后下一条消息自动开始新任务，输入区展示当前任务目标，可明确开始新任务并保留本次引用、附件、方法及文字。当前已接入目标、主动主体、操作回执、本任务成果读取、自动记忆、有界标准／画布结构批次、标准图片／普通及原生有声分镜视频／角色音色／声音台词配音和画布媒体生成及 ThoughtChain；标准素材／分镜、画布节点／连线、旧声音文本及实际已采用媒体的明确批次撤销已接入；多批次反序撤销、Skill 广义语义消歧及真实模型验收仍在实施，原生成和编辑入口继续可用。

标准批次按真实用户的直接创建、修改、关联、排序或删除指令执行，不因选入参考资料而自动修改。一次提交内的素材、分镜与原生对白文本共同成功或共同回滚；额外关联删除先显示影响范围。回执成果卡显示实际对象、创建／修改／删除状态、保存版本和批次，可打开真实素材／分镜；已删除对象保留操作记录。重复调用复用原效果，旧快照不能覆盖后来编辑。对白沿用原生功能开关和角色关联规则，只保存文本，不生成声音。当前授权识别为有界直接表达，具体示例和限制见[助手 API](../docs/api/assistant.md)。

画布结构批次可创建文本、图片、视频和音频节点，填写正文／私人提示词、调整已选节点及合法连线；搭建时不生成媒体。新增节点按依赖局部布局，保留原节点与视口；错误整批回滚，重复调用返回原回执。私人参数与共享节点分别核对版本，来源已变需主动刷新。删除保护节点、导演场景及时间线引用。节点成果卡显示真实名称、创建／修改／删除状态、保存／参数版本和批次，并通过原生入口定位；已删除项无链接。助手可按回执读取本任务新建节点的保存快照，不能借内部差异读取旧节点或后来人工修改。真实模型执行、媒体工具及完整原生运行对照仍需独立验收。

标准图片组可按选入范围读取冻结目录、图位及历史媒体身份；单图位不会展开其他图位或私人提示词。明确要求换主图后，助手核对真实图片及三类版本，复用原生采用规则，也可恢复明确选入的历史组。轨迹卡显示“已设为主图”、保存／主图／图位版本与来源链接；重复调用只返回原回执，后来人工编辑需主动刷新。目录身份不表示已经读过图片，换主图不启动媒体生成。

需要分析图片画面时，助手可按目录指定一张图位图片，或按本任务完整结算回执读取真实标准／画布图片。平台校验受管文件后在下一段模型输入发送实际图片，轨迹显示“读取指定图片”并保留准确媒体身份回执；只拿到目录身份不能声称已经看过画面。移除、刷新、删除或失权会阻止后续读取，不自动换成新图；未选入的其他图位及后来私人参数仍不可读。真实多模态模型的理解质量单独验收。

明确要求“为已选分镜生成一段视频”后，助手可生成普通分镜视频（不启用原生对白／音色），每目标一段，沿用已保存参数。当前主图须主动选入或来自本任务已结算图片；旧正文、私人提示词和未选入角色不自动进入请求。原生归档检查真实视频轨道、尺寸与时长，成功后自动采用并保留旧视频；人工编辑、删除、主图或当前视频变化时保留产物并提示冲突。段数计入视频上限，停止／改向／删除等待生成与采用完整结束。成果卡显示“已自动采用”和段数，可定位分镜视频面板。有声生成使用单独的明确指令和可信对白／音色来源；真实供应商验收独立记录。

明确要求“为已选角色生成一个音色：要求”后，助手可使用本人音频模型生成并自动采用角色音色，每目标一个，计入音频上限。素材版本与音色版本分别保护，后来人工修改或删除时保留生成样音并提示冲突。供应商只收到本次声音描述和试音文本；原生功能开关、有效样音和完整采用规则继续适用。成果卡显示独立音色版本、数量和试听入口，在局部弹窗读取该次生成的原样音，避免播放后来更换的当前音色；读取失败可重新读取，来源失效不提供试听或定位。停止／改向／删除等待完整生成及采用。浏览器测试验证控件和身份匹配，真实音频供应商及实际播放尚未验收。

明确选入声音草稿中已保存的“声音台词”，再要求“为已选台词生成配音”，助手按真实台词标识使用该条已保存的正文、音色及模型，每条一个结果，计入音频上限。选入分镜不自动扩大为台词引用，目录不展示未选正文。声音文档与画面时间线分别保护；生成成功后通过原生采用更新对白轨、保留稳定片段和旧候选，人工修改产生冲突时保留产物。停止／改向／删除等待完整归档与采用；成果卡恢复真实任务、声音版本及状态，来源链接打开成片声音面板并定位该台词，不猜测已删除来源。当前不通过此生成工具编辑声音文本、字幕、画面或导出；真实配音供应商与内容质量验收独立记录。

标准结构工具支持“创建两条台词”“修改已选台词的音色”“编辑本任务台词的正文”等明确指令，仅增量保存台词正文、角色、音色或配音模型。原生声音文档保留字幕、时间、音轨和已有音频，声音／画面双版本保护后续人工编辑；没有成片草稿时先保存原生草稿。台词成果卡显示已创建／已修改、双版本和来源，保存文本不显示为已生成配音。本任务新建台词可按回执读取保存快照，再明确要求“为本任务台词生成配音”。

明确要求“为已选分镜生成一段有声视频”后，助手使用已保存的原生声音模式、已确认对白及可信角色音色；每个说话角色须主动选入或为本任务可信成果，仅选分镜不自动读取未选角色。当前主图与视频设置继续沿用普通视频规则。生成只附带获准对白和样音，外发前变化阻止提交，已外发后变化保留视频并提示采用冲突。对白镜头缺音轨或静音时保留候选并拒绝采用，已确认无对白的镜头允许无音轨。结果卡沿用视频定位和数量；技术检查通过不代表台词准确、音色还原或真实供应商验收。

明确要求“为已选素材生成图片”或“为已选分镜各生成两张图片”后，助手可生成标准图片，每目标默认一张、最多四张。AI 配置 → 创作助手保存本人媒体总开关，默认开启且保留已有关闭设置；开启仍需本次明确授权、可用图片模型和足够数量上限。完整批次从生成到回填都保持在任务过程中，停止／改向／删除等待本批次全部结果明确。有效图片按稳定序号自动采用，其他结果及旧主图保留在图片组；冲突不覆盖人工编辑。部分失败暂停，下一条明确要求可继续处理，保留已有成果和数量记录；结果不明保留原请求待核实。成果卡显示已生成／请求数量、采用状态、真实图片组和回执。数据库与浏览器自动测试不代表真实供应商验收。

创作设定和阶段摘要由后台自动维护，用户无需操作记忆管理、抽取冲突、维护状态或记忆清理选项，前端不显示相应按钮、弹窗和内部工具轨迹。后台继续通过来源版本、水位、预算及权限校验抽取和读取，失效来源不得恢复旧事实。

项目设定自动限定在会话所属项目内。后台原有记忆 API 与显式工具为兼容保留；前端不提供记忆设置或管理入口，也不以用户管理记忆作为创作前置步骤。

画布媒体沿节点已保存设置执行，图片每目标默认一张、最多四张，视频／音频每目标一段。提示词和参考图只使用本次获准内容，原节点私人正文、未选邻居不自动进入生成。标准和画布均可显式使用本任务完整结算的真实图片作后续参考；跨任务、伪造产物及失效来源被拒绝，图片身份不代表已读取图片内容。工具等待原生归档、私人素材交付和主输出回填；其他输出保留在私人任务及素材。人工编辑、删除、任务替换时保留产物并提示冲突，失效节点不提供来源链接。图片、视频和音频分别显示正确数量单位，停止／改向／删除同样等待完整媒体边界。数据库、受控供应商与浏览器验证不代表真实供应商或画布完整一比一验收。

项目会话列表支持新建、搜索、改名与永久删除，不提供归档、分支或回收站。删除只做普通永久删除确认，不预览记忆或提供清理选择；当前工具完整结束后才删除，会话摘要、会话记忆和附件引用按后台规则清理，作品成果保留。未确认的删除请求按账号、项目保存，刷新核对复用原请求；旧请求继续保持原体原键。物理原文／媒体清理与备份保留分别处理，不把页面不可见描述为全部备份已擦除。

标准助手成果批次提供撤销预览，逐项列出安全项、冲突原因及必须同时选择的关联项，只有明确选择才执行。支持标准素材／分镜结构、关联、排序、原生对白、旧声音文本，以及画布节点／连线逆向，保护后续人工编辑、引用及媒体变化；行版本前进，原操作回执保留。画布核对共享图和私人参数版本，只合并选中差异；声音文本保护声音／成片双版本和多轨数据。选择与原请求按账号会话持久保存，受理不明跨刷新用原体原键核对，409 后明确采用新预览。历史修订与撤销同时有待核对请求时，可分别核对原请求；新发送仍冻结。成果卡持久显示已撤销状态，已删除对象不再显示旧链接；停止和改向保留成果，已发生的生成费用不退回。图片／视频／音色／台词配音与画布媒体绑定可恢复前一采用状态，保留新产物和生成历史；完整结算失败批次中的实际采用项也可单独核对。首次音色撤销保留新版本，成果卡隐藏该批次旧试听入口。共享画布原生界面保持原交互边界。

用户消息只展示正文和所附引用，不显示编辑、重新回答或修订记录操作；助手回复保留复制及已有修订记录。旧版本留下的修订草稿和待核对请求仍可恢复，防止移除入口后丢失未确认的操作；版本冲突保留输入，修订仍不能扩大成业务执行。新的补充或方向调整直接发送新消息。

助手对话、文本候选、私人媒体历史及任务历史仅本人可见；素材图、分镜图的完整图片组和成功回填的分镜视频按本人作品权限保留，其他作品在明确采用后写入作品。任务中心、媒体库、声音与成片历史按作者隔离，项目成员不能查看他人的生成参数、模型、错误或过程记录。原创作对话保留为“历史创作记录”，消息只读，已有任务、计划与候选仍可按原权限、来源版本及许可继续处理，不拼接到新聊天。“采用并继续”只继续该历史记录明确关联的运行，可能产生后续费用。

标准与画布助手统一使用 Ant Design X 的消息气泡、输入、建议与会话列表组件，消息正文为 13px；两端分别使用桌面右侧面板，并适配各自主题与宽度。可移除作品引用、附件放在输入框上方，Skill 高亮块放在 Sender 边框内顶部，输入贴底。模型旁依次是添加图标和 Skill 图标，发送靠右；添加菜单包含“图片”“文本”“从当前画布选择”“从资产库选择”，创作模式禁用当前画布项并提示“仅画布模式可用”。Skill 图标及 `/ → 浏览全部 Skill` 打开同一锚定列表，搜索全部内置／个人方法、加载更多、多选即生效，最多 8 项，保留冻结版本和不可用原因，不使用选择弹窗。“附件与技能”展开行及“对话仅你可见”说明已移除。已有附件、方法移除、失败重试和原请求核对继续可用，发送时冻结版本。作品可用 `@` 引用，键盘选择引用不发送消息；不带作品引用时可进行普通问答。模型和凭据统一由工作台模型配置管理，附件不兼容明确反馈。

引用作品发送前等待正文及相关编辑保存回执；失败、409 冲突或等待期间的新修改保留草稿并阻止发送。服务端校验权限与来源版本并冻结上下文，切页不改变已受理消息。Enter 发送、Shift+Enter 换行，中文输入法组合期间不提交。关闭面板不停止服务端回复，刷新可恢复消息、运行与草稿；受理不明时复用原请求和幂等键核对，不自动再次调用模型。

输入区不再提供“管理任务引用”入口或目录弹窗，通过 `@`、选入当前主体或画布节点添加引用。已选引用显示实际版本和来源链接；有新版本时保留原快照，可在引用标签主动刷新或移除，变更随下一条消息在工具边界生效，停止后发送新要求时一并继续。跨页引用草稿按账号与会话保存，任务输入变化先核对；受理不明仍使用原选择水位、原体及原键。新任务不继承引用，保存目标与项目设定自动来自所属项目。

任务附件可独立保留或移除，显示待移除状态；变更不删除原上传记录，停止后再次发送新要求并继续回复时应用。移除和新增按整个任务的累计附件数量与文本大小校验，发送前复核可用性。主体“查看来源”打开真实素材、分镜、指定图片组／图位或原画布节点；浏览图片不改变主图，画布只调整视图和选择。来源失效明确反馈。

任务设置及其弹窗已移除。新创作任务自动保存到会话所属项目，新画布任务还绑定发起时的当前画布；后台自动读取同项目设定。切页不修改已受理目标，前端不允许跨项目设置写入目标或手动切换记忆范围。生成数量沿用现有默认规则与执行上限。

## 页面与核心流程

1. **作品管理**：搜索和分页查看作品卡片。新建创作模式后直接进入剧本创作，卡片同样直接打开四阶段工作区；顶栏作品名称可原位编辑，Enter 或失焦保存，版本冲突保留本机名称并提供下载与核对恢复。没有项目资料、分集、共享协作和旧素材库入口。新作品不自动创建示例内容。
2. **剧本创作**：标题为“剧本”，下方“故事设定 / 剧本正文”横向标签保持各自编辑会话。编辑区最大960px，正文与两侧同为近黑背景（#181818），正文在剩余高度内连续滚动，不解析场次目录。故事设定为一句话卖点、故事梗概、故事类型、人物小传四个输入框，以稍浅灰色（#202020）填充，与编辑区区分，聚焦保持同色且不出现边框；使用独立版本自动保存，不修改正文版本、不自动读取旧大纲。正文保留串行保存、中文输入法、快捷键撤销／重做与选区AI改写。页面移除“让助手起草剧本”和“最近变更”按钮，AI创作助手由顶部进入。标题移除导入／导出，底部不显示固定字数或撤销行。选字后可点击“AI 改写”或按Ctrl/Cmd+K，核对选区、要求和模型；仅参考选区及前后文，成功精确替换，可单步撤销。任务期间正文只读，进度与停止放在标题行，离开继续、刷新恢复。小说、大纲及专属兼容 API 已删除；AI创作助手沿用原入口。
3. **资产生成**：左侧标题“资产库”，右侧图标切换列表／宫格并提供Tooltip，按账号记忆偏好；分类、搜索、选中对象和分页不受切换影响。列表行高45px，32px缩略图在左、标题在右，悬停或键盘焦点显示更多；宫格沿用卡片并移除角色／场景／道具类型角标。底部固定45px满宽“＋ 创建”，主页面移除从剧本提取入口，历史记录仍可查看。首次进入且未指定素材时预览第一张可见卡片，显式素材链接及当前选择优先；已有创建中、失败或待核对的草稿时继续恢复该草稿，桌面生成设置默认打开，可手动收起。新增立即追加并选中空白本机草稿，不弹创建窗口；全部分类下类型为空，其他分类沿用当前类型。名称和类型补齐后自动创建服务端素材，原位替换临时卡片；受理不明保留原创建请求核对，名称或类型缺失时不能生成。主面板内左侧预览图片，右侧同排编辑名称和类型、直接编辑描述并自动保存；对象标题栏提供生成记录、更多操作与设置开合，有主图的状态为“已生图”，图片/素材类型重复横栏移除，生成设置为主面板内可收起的桌面栏。参考图在提示词上方，空态也使用加号块添加图片；输入`@`可通过缩略图列表引用已添加的图片，选中显示行内标签。编号按共享图在前、私人图在后去重排列，删除图片时同步更新提示词引用及编号。提示词框填满剩余设置空间；底部同排提供紧凑图片模型、紧邻模型的生成选项和靠右的发送按钮，张数在生成选项内选择。新结果按 1／2／4 张固定图位进入中央预览，默认第一张主图并更新卡片封面，多张可直接设主图；预览不常驻数量及刷新栏，生成记录仍可刷新，图片读取失败可就近重试。上传、媒体资产库选择与移除保留在当前作品素材操作中；素材提取保留核对流程，不提供跨库导入或共享。
4. **分镜制作**：左侧标题“分镜表”，列表／宫格切换及45px底部“＋ 创建”与资产库一致；列表为缩略图与镜头名称，宫格保留当前媒体、镜号、脚本时长及名称与景别。无名称显示“未命名镜头”，无景别留空。保留名称搜索和随“分镜图 / 分镜视频”切换的待制作筛选，主页面移除提取与重新提取，生成记录仍可查看和采用历史候选。首次进入且没有明确选择或待恢复编辑时，静默预览第一张可见卡片，桌面生成设置默认打开，可手动收起。新增在末尾追加空白镜头并选中，不弹创建窗口；名称可为空，不阻止图片或视频生成。主面板在镜头标题栏内提供紧凑的图／视频分段切换，共用名称和脚本表单，独立名称不取自或改写脚本；对象标题栏提供前后镜头、媒体生成记录、更多与设置开合。批量操作与排序可从“分镜生成记录”底部进入，按 20 条滚动加载继续保留。景别、运镜、脚本时长与画面布局不在设置区编辑，未显示的既有值仍保留。图、视频分别保存本人提示词、模型和参数，使用紧凑模型菜单和紧邻模型的生成选项；提示词框填满设置余高。图、视频均不在预览标题栏展示状态标签；视频不展示采用工具栏。视频播放器占满预览区剩余宽高、画面保持原比例；只以当前主图为参考，没有主图时明确阻止视频生成，提交时核对当前主图、分镜版本和上下文。已保存作品不会因后续参数修改失效。生成记录按需打开，分镜提取结果仍需逐项核对或明确整批追加、替换；图片生成后直接保存为共享图片组、默认第一张主图；视频成功归档时自动确定为镜头视频，更新成片可读取的来源，失败时保留旧视频。旧任务晚到、来源变化、撤权或镜头移除不能覆盖当前作品，历史仅供播放核对。分镜阶段不提供“声音制作”按钮。

5. **成片合成与导出**：从当前确定的分镜视频建立独立草稿，一条连续画面轨配合原声、对白、字幕、配乐、音效五类辅助轨。支持当前作品、媒体资产库及本地视频／图片入轨，独立音频作为对白、配乐或音效添加；追加、替换、排序、分割、裁剪、删除、静音及构图共同自动保存。画面以 30 fps 定位、逐帧预览并删除合拢；辅助轨用整数毫秒，可锁定、静音、关联镜头或固定作品时间位置。原声、对白、字幕、音效默认随镜头，配乐默认固定位置；循环配乐分割保持连续。轨道保留缩略图、真实波形、吸附及缩放，最多 100 步组合撤销／重做。大播放器使用同一声音时钟同步预览画面、声音与字幕，支持全屏、构图拖动、安全区、后台 360p 合成预览及实际成片播放。右侧设置按需收起，检查器统一使用桌面内联栏，保留中央预览和轨道的内部滚动。字幕可校对、分割／合并、偏移、按标点断句、调整样式及导入／导出 SRT；识别默认本地 Whisper，云端必须主动选择，先预览后明确应用。多段配乐与音效支持裁剪、循环、音量、淡入淡出、人声压低和真实响度分析。旧配音入口继续生成、试听及明确采用，采用后进入对白轨。画面与声音版本同时校验，冲突保留整份草稿；离开流程时保存队列继续。导出弹窗集中选择 720p/1080p 与 auto/16:9/9:16 输出画幅；默认 auto 从有效分镜或首个有效媒体决定，预览与结果使用实际输出尺寸，不继承项目画幅，先保存再冻结快照，支持取消、失败重试、下载及明确设为当前成片。此次不新增导出前检查步骤。

创作模式导航固定在左侧，占40px宽与完整视口高度；四个图标依次为剧本创作、资产生成、分镜制作、成片预览，悬停和键盘焦点显示文字提示，当前阶段可辨认。60px头部保留返回列表、可原位编辑的作品名称、保存状态及助手入口。作品名称、正文、故事设定、素材和分镜会话一同参与保存屏障；409保留输入，核对前不覆盖服务端。成片内部布局及功能保持原样。

成片工作台支持专注剪辑：临时收起作品标题、创作流程和步骤导航，退出后恢复原布局。素材区可折叠；桌面可拖动分隔条或使用方向键调整播放器和轨道高度，偏好保存在本机，多轨高度为 280–360px。画面／声音／字幕属性进入右侧可收起设置；静音在剪辑工具栏及各轨道，前移、后移及恢复完整进入更多菜单。刷新默认退出专注模式；生成和编辑设置使用桌面侧栏，普通侧栏不锁住页面焦点，手动收起后可从入口重新打开。恢复不保存签名地址，可按媒体 ID 补齐较老素材；短视频替换先确认裁剪，取消保留原片段。功能及部署边界见[成片编辑器维护说明](../docs/instruction/标准成片编辑器维护说明.md)。

成片预览优先使用后台生成的播放代理；素材区使用代表缩略图，轨道按保留的来源时间显示连续采样缩略图。每个来源最多采样 24 帧，生成前或加载失败时回退到代表图；正式导出读取原视频，实际时长由后台检测。已有草稿打开时自动补齐预览素材，不同步或覆盖剪辑决定。分镜来源更新仍需要明确同步，保留已有顺序、分割和裁剪，已删除片段不会重新加入，新分镜追加到末尾；替换源视频过短时需重新裁剪。保存失败或版本冲突保留本页编辑，可下载输入、重试保存或在版本详情选择重新载入，替换前保留本机副本；重新载入、同步来源及离开剪辑页面会清空撤销历史。

分镜图片设置可按需收起，参考图位于提示词上方，空态与已有图共用加号块。提示词支持`@`缩略图菜单及行内标签，编号按关联素材主图、共享参考图、私人参考图的实际提交顺序去重排列；移除或替换私人参考时同步更新引用和编号，提示词与参考图一次保存。已有共享来源与本人参考图分别管理、提交时去重校验。生成前等待作品及私人参数保存并核对最新分镜上下文；其他窗口改动时先核对，不覆盖草稿。模型不支持参考图时不能静默丢图。任务历史和图片组分页加载，可查看任务详情并按服务端许可安全恢复；受理结果不明时保留原幂等键，只核对既有请求，避免重复计费。

素材及分镜的“比例与分辨率”打开生成选项浮层，提供关闭按钮；Escape 关闭浮层后回到入口，底层桌面设置继续打开。七个比例中 2:3、3:2 暂不可用，其余选项按实际模型能力启用。图片提供 1K／2K／4K 与模型默认，以及“选择张数”的 1／2／4 张选项；视频在同一浮层提供比例、480p／720p／1080p 与模型默认、时长，时长按模型支持档位选择，未提供档位时使用 1–3600 秒整数输入。图片比例也可恢复模型默认，个人草稿保留该选择。

将历史分镜图设为主图时保留图片的原生成布局、画幅和分辨率，不改变下一次生成设置；写入前校验图片、主图和分镜版本。手动设置主图表达使用该图作为当前内容参考的决定。

## 素材与媒体

| 概念 | 用途 |
| --- | --- |
| 素材 | 角色、场景或道具的名称、描述、提示词和当前确认图片 |
| 作品素材 | 当前作品直接拥有的角色、场景和道具；无全局库、项目库导入与共享 |
| 图片组与主图 | 素材图、分镜图的完整作品组；生成直接保存，默认第一张主图，可逐图处理或改设主图 |
| 主页媒体资产库 | 本人 AI 生成的图片/视频/音频；按工作台与媒体类型筛选、名称搜索、创建时间倒序，桌面六列、每页 24 项，点击直接预览 |

主页资产库默认进入 `/media-library/all`，上层为“生成历史 / 创作模式 / 画布模式”，“生成历史”包含全部模式；下层以按钮展示“全部 / 图片 / 视频 / 音频”，32px 高的名称搜索框紧邻媒体按钮并同行排列，总数靠右。工作台、媒体类型与名称可组合筛选，条件变化回到第一页并关闭预览；刷新和浏览器前进后退保留 URL 中的条件。搜索只匹配资产名称，不匹配提示词；中文输入完成后查询。同一创建时间按资产 ID 倒序稳定分页。

卡片保持 4:3 比例与左下名称，六列下宽高较原四列约缩小三成，长名称截断并保留完整提示。图片采用画布同款大图预览，支持缩放、旋转及拖动；视频居中播放，音频居中试听，关闭立即停止并恢复触发卡片的键盘焦点。预览不提供右侧详情、重命名、采用或任务跳转；签名地址过期可重新读取详情。资产库不收录手动上传；无项目来源的本人历史生成只计入“生成历史”。

素材提取只使用文本模型，不生成图片。素材详情可选择图片模型及可选参数，创作模式界面一次生成 1／2／4 张图片；先保存素材，再使用服务端冻结的内容生成。生成会读取持久化参考图片，不自动引用当前采用图片或继承入口项目风格。素材和分镜各最多保存 16 张输入参考图；模型不支持时明确拒绝。移除仅解除关联，历史请求仍保留原文件。上传支持PNG/JPEG/WebP，最大20 MiB、4000万像素。

本人可读取素材图与分镜图的完整图片组及原图历史；任务、提示词、模型配置与图片处理记录仅本人可见。离开详情后任务继续，重新打开从服务端恢复。尚无图片组时素材和分镜预览仅显示“还没有生成图片”，无视频时显示“还没有生成视频”，读取失败提供独立重试入口；已有作品时改张数仍保留当前组，提交新生成后切换为新组占位。各图按输出序号回填，缺图不挤占其他图位，预览不常驻数量及刷新栏。手动选主图立即保存，迟到结果不覆盖选择。素材或分镜内容已变化时仍保留结果，自动主图更新停止；核对后可将图片设为主图。

每张图片的工具栏在桌面悬停或键盘聚焦时显示。支持预览、下载、上传替换、自由裁切、画笔／矩形／文字标注、插值尺寸调整（长边 4096 像素）、最多 25 张的宫格切分，以及局部重绘、表情、质感、多角度、打光、复制提示词、看图反推和加入私人参考图。单图处理替换原图位并保留原图历史，不改变其他图位及下次生成参数；切分产生新组、第一张为主图，旧组保留。AI 工具按实际模型能力启用；反推当前接入声明视觉能力的 OpenAI Chat／Responses 协议。全景及视频处理工具不在本次图片工具范围。

## 通用AI能力

> 2026-10-28：独立任务管理及其通用新建任务表单已退役，导航和其他页面不再跳转任务中心，旧 `/tasks/*` 地址替换跳转到 `/projects`。后台生成、轮询与创作场景内必要的生成反馈继续保留。

创作场景仍可从图片资产库选择或上传本地参考图；上传文件作为输入媒体保存，不创建生成资产，移除仅解除当前引用。具体数量、格式和大小限制沿用对应场景合同。

AI配置统一使用 `/ai_config`，创作模式和无限画布共用本人模型；旧 `/ai` 与 `/canvas-app/settings` 链接兼容跳转。按文本、图片、视频、音频分组，每条配置一个模型，各类型可设默认；编辑表单在启用开关旁提供默认配置选择。高级配置补充 API 格式、调用协议、参考资源根、能力与默认参数、第二密钥和自定义请求头；高级配置可明确清空。Key 和请求头值提交服务端加密保存，浏览器只读取存在标记，不持久化秘密。

“创作助手”标签提供一个账号级“允许生成图片、视频、音频”总开关，缺少设置默认开启，已保存的关闭不因升级恢复。显式保存，冲突和保存结果不明保留本次选择，先读取最新状态后核对；切换模型标签保留未保存的选择。开关不授权新任务，也不影响讨论、提示词或结构搭建。标准图片和画布媒体已接通受理、派发、数量预占及原生采用／回填；各模式、媒体类型和真实供应商的验收边界分别记录，不能从开关页面推定完整生成能力。

画布音频已接通 `openai-audio` 同步二进制和 `async-audio` 原任务轮询/content；
生成前保存来源，成功后由原消费者直接回填，归档失败只恢复已生成的原结果。
原界面生成、播放、键盘进度、关闭窗口后的仅cookies任务恢复及unknown无重试切片已验证，
两协议MP3/WAV/Opus/AAC/FLAC已验证真实播放；PCM保留原字节和未知时长，
原播放器无法解码时显示错误并禁用进度，不自动转封装。
后端HTTP/MySQL/MinIO为受控供应商，不代表收费模型、声音质量或完整一比一验收。

模型目录探测不调用生成、不自动保存配置；没有目录接口时可手动填写模型名。独立模型测试在宿主提供；测试成功仅代表本次返回，未接通协议明确拒绝。模型名称、启停和删除由本人维护；地址、模型身份与凭据按宿主配置管理。画布只选择模型、保存个人默认和生成参数，原节点及重试按稳定 ID/旧别名恢复；进入模型配置前等待偏好和作品保存，失败或冲突保留草稿。宿主“返回画布”只接受具体同源画布路径。

生成请求可能产生费用，不能把未知受理结果当作免费重试。已受理任务离开页面后仍在后台执行，进度、失败原因与服务端允许的恢复操作由原创作场景承接。

右上角账号入口打开独立 `/account` 页面，维护账号信息、安全设置与退出登录；返回按钮回到进入前的站内页面。导航不再提供全局素材库入口；角色、场景和道具在当前作品的资产生成阶段切换。

模型兼容受协议、参数和账户能力限制；“能获取模型列表”不等于“已验证生成可用”。

## 标准创作反馈

标准创作的错误与警告统一使用不占页面空间的公共 Message；正常能力核对、读取设置只显示原控件 loading，自动保存成功保持安静。冲突、受理不明及恢复操作保留在原有详情入口，关闭提示不清除问题或输入；必要确认和原数据区域三态继续保留。具体分类和开发规则见 [标准创作流程反馈规则](../docs/design/创作反馈规则.md)。

## 保存与恢复

- 作品、故事设定、剧本、当前素材、分镜、声音、成片、任务和采用结果持久化到服务端；不存在分集与跨层素材关联。
- 作品名称原位保存；当前剧本保存和新写作任务成功即生效，无草稿或确认入口。素材提取、分镜结构及 Agent 候选仍须明确采用；图片生成直接保存，切换主图即时提交；分镜视频成功归档后自动确定。
- 创作模式的素材名称、类型、描述与镜头名称、脚本使用串行自动保存；不兼容的类型转换明确拒绝并保留输入。
- 素材图、分镜图、分镜视频的个人生成草稿按本人、作品、稳定对象和用途分别保存到服务端，包括模型、提示词、可见参数和个人参考图；仅本人可见，也不覆盖作品描述、脚本或生成默认设置。生成前等待相应草稿保存，失败或冲突保留本机输入，只阻止依赖它的提交，不阻止应用内切换。小说改编草稿用途已删除。
- 顶部仅保留一个按需展开的固定尺寸保存图标，通过可访问名称、悬浮说明与详情表达保存中及异常计数；空白初始参数不提示草稿，尚未补齐的新素材只在本机保留，创建受理不明继续保留原卡片和原请求。
- 网络失败先核实服务端状态；版本冲突保留双方内容，允许下载后人工合并，不自动覆盖。会话按账号及实际资源保留，四步、素材、镜头与图/视频标签立即切换；仅内存且无法持久保留的输入才触发刷新或关闭标签页的浏览器保护。
- 账号模式仅读取本人命名空间下的浏览器草稿。未归属旧稿只在受控兼容模式提供预览或下载，不自动导入任何账号。
- 模型选择按账号保存到服务端。清理浏览器数据不会删除作品或模型偏好，但会丢失尚未保存的本地草稿。
- 素材图和分镜图保存为图片组，默认第一张为主图；来源内容修改后提示核对。新写作文本直接回写，素材／分镜结构与 Agent 候选保留采用流程，分镜视频在来源校验通过后自动回填。

## 尚未实现

- 跨素材批量生成。
- 分镜视频的批量、首尾帧和多素材图片参考；单张分镜图生视频及成功自动确定已接入分镜制作页面。
- 多视频叠层、转场、变速和词级字幕对齐；已有声音多轨、配音、字幕及配乐不属于此限制。
- 协作与旧素材库已退役；不作为当前待开发功能。

分镜视频入口在选中镜头标题栏的“分镜视频”分段切换：当前分镜主图自动作为全能参考图，支持单图、四宫格、五宫格及九宫格。参考图不强制用作视频首帧，成片不复制宫格排版，视频画幅未指定时使用模型默认值，不继承作品级默认值。默认提示词来自分镜，用户可在本人草稿中编辑；系统提示词在后台参与生成，页面不展示。视频时长可独立调整，默认沿用分镜时长，范围受模型能力约束；提示词、清晰度和视频时长与分镜图参数分别自动保存，生成前等待保存完成。修改私人视频参数不会修改作品镜头脚本时长、默认设置或主图。成功归档后由后端自动确定镜头视频，页面刷新当前作品；历史视频仅播放，离开页面后已受理任务继续。并发任务按提交顺序保护，较早任务晚到不覆盖较新成功结果；来源改变后的结果保留历史，不覆盖作品。既有成片草稿仍需“同步分镜视频”，不自动改写剪辑决定。

后续可扩展多视频叠层、转场、变速及更多批量制作能力。

## 创作可靠性与恢复

剧本页已移除“最近变更”和“让助手起草剧本”按钮。AI替换、整篇导入、助手采用及恢复的服务端前后快照和兼容API继续保留。历史助手剧本修改仍先显示前后差异与范围，经明确采用才写入；旧版本建议不能覆盖当前正文，过期后在剧本正文中核对修改。“引用当前剧本”按钮、自动正文／选区绑定及草稿引用开关已移除；普通聊天无需等待正文保存，显式素材引用仍执行原保存与版本校验。

运行中鼠标或键盘均可补充完整输入，在下一步骤生效；停止和暂停后普通消息续跑。当前任务目标与开始新任务可见。明确拒绝清理待确认但保留输入，受理不明使用原键核对。最小主体引用草稿恢复前重新检查版本，失效引用不可静默发送。助手写入或撤销后业务区同步，脏稿保留并进入冲突。

分镜历史候选从生成记录查看和采用，主页面不再提供提取入口；最新导出与当前采用分开播放和下载。资产、分镜图及视频的生成阻断原因与可执行恢复动作放在按钮旁。左侧40px桌面四阶段图标导航始终可见。
