# 产品范围与创作流程

AI短剧工作台面向个人创作者与项目协作者，帮助完成故事改编、素材准备、分镜制作与成片导出。账号必须验证邮箱；项目主人通过绑定账号或指定邮箱的邀请加入协作者。成员使用各自模型配置，个人素材导入为独立副本，项目产出在成员离开后保留。业务数据保存于服务端数据库和 MinIO。首期不含独立团队空间或实时编辑。

## 两种创作模式

小说改编、素材准备和分镜制作采用左侧流程、中央作品、右侧 AI 创作的布局。提示词设置与 Agent 对话共用右侧区域，模式切换位于 AI 创作框左上角，窄屏通过“作品 / AI 创作”切换。成片阶段只显示流程和成片工作区。旧链接默认进入提示词模式；Agent 链接保留 `mode=agent` 与当前对话。这三个创作阶段首次进入 Agent 模式时自动创建独立会话，返回阶段沿用其会话；创建失败时保留同一幂等请求，不自动重发。切换模式或阶段不会停止已发出的任务。

| 模式 | 使用方式与适合的工作 | 优势与代价 |
| --- | --- | --- |
| 提示词创作 | 在当前小说、素材或镜头入口选择模型和参数，提交明确的一项生成要求 | 操作直接，单项任务的输入和范围清楚；连续修改、多阶段工作需要用户逐步组织 |
| Agent 创作 | 围绕本集作品持续对话，先讨论方向，或明确生成候选；多步骤任务先核对计划再批准 | 可保留上下文、分解任务并调用现有创作流程；需要额外审查计划，可能发生多次模型调用，耗时与费用受执行范围影响 |

Agent 对话仅本人可见，候选与已采用作品按项目权限共享。讨论不授权制作；明确的单项任务可以直接执行，多步骤任务按批准的对象、来源版本、模型和数量执行，修改范围或付费重试需要新授权。所有输出先作为候选，采用仍遵守小说替换、脚本选择与确认分离、提取逐项审核、分镜追加/替换及共享媒体影响检查。采用不会自动继续对话；“采用并继续”只继续当前明确关联的运行，可能产生后续费用。

指定媒体任务按图片/视频、素材名称或镜头摘要、本人媒体模型、本次参数与数量依次选择，不需要手填内部 ID。参数默认沿用当前对象，明确覆盖仅作用于新候选，保留手动编辑器设置。协作文本模型负责理解与计划，图片/视频模型负责执行生成，分别选择与校验。新镜头尚无已采用图片时，先生成并采用图片，再提出视频任务；采用后参考图改变需要新计划审核或新的明确单项授权，原计划不会自动换用新图。发送前先保存当前作品；失败或版本冲突保留草稿并阻止新请求。Enter 换行，Ctrl/Cmd+Enter 发送；窄屏在作品和对话之间切换。

Agent 默认开启，运行需要账号认证、显式迁移和独立 Worker；执行开关可显式关闭，旧链接仍默认进入提示词模式。首版使用单协调 Agent 与内置版本化 Skills，覆盖文本、素材、分镜及图片/视频；时间线、音频和导出编排继续使用现有工作台。工具能力须由用户明确验证，一次验证最多两次可能计费的文本请求；打开页面不会自动验证或生成。所选配置已完成真实文本、图片与视频验收，结果见[验收记录](../docs/agent-verification.md)；该证据限于所选供应商配置，本地自动测试仍不能替代其他模型的实际兼容性验证。本次真实视频请求限定 480p/5 秒，实际归档尺寸与时长分别记录；产品参数仍默认沿用对象并遵守模型约束。

设计与验收状态以[实施契约](../docs/plans/2026-10-02-agent-mode-implementation.md)为准；启用、关闭与 unknown 处理见 [Agent 部署](../docs/agent-deployment.md)，接口与私有/共享边界见 [API 说明](../docs/api/README.md#agent-创作与共享候选)。

## 页面与核心流程

1. **项目管理**：搜索和分页查看项目卡片，点击进入项目；详情左侧三个图标分区分别显示剧集信息、项目资源库、共同创作。剧集信息与分集列表上下排列，分集使用固定尺寸封面卡片，三点菜单提供编辑和删除；无封面时显示默认封面，首镜头采用图片后作为封面。协作者列表独立显示，邀请按钮打开生成邀请链接的弹窗。新项目不自动创建示例内容。
2. **小说改编**：本集小说与剧本定稿在中央两个标签页编辑，停顿后自动保存。支持 UTF-8/GB18030 的 TXT 导入（最多 1 MiB），导入前确认替换正文。右侧提示词创作区提供文本模型、本集画幅、视觉风格及改编要求；候选在生成记录弹窗预览、采用。可直接手写剧本，确认后用于提取和分镜生成；修改确认稿会取消确认。
3. **素材准备**：右侧填写已确认剧本的素材提取要求，按叙事作用审核候选；图片提示词通过名称旁的图标浮层查看和编辑。分集素材在中央编辑信息、右侧生成图片；个人和项目素材仍使用详情抽屉。切换素材须核对未保存内容，离开分集或 Agent 发送前会等待素材保存，失败保留草稿。可保存多张参考图，生成候选后明确采用。
4. **分镜制作**：右侧提供文本/生图模型、平均镜头时长和要求，选择镜头后在同一区域生成图片和视频。中央编辑脚本和分类素材关联。生成记录弹窗只展示镜号与脚本，整批追加或替换；历史与当前镜头均按 20 条滚动加载。图片生成记录在独立弹窗核对。

5. **成片合成与导出**：从已采用的分镜视频建立独立草稿，在单视频时间轴上追加、排序、分割、裁剪、删除和静音片段，编辑自动保存。统一以 30 fps 定位和逐帧预览，拖动片段两端或使用快捷键逐帧裁剪；轨道显示连续缩略图、裁剪时间反馈及排序落点，缩放围绕播放位置。支持当前编辑会话内最多 100 步撤销/重做。大播放器支持整条轨道顺播、全屏、后台 360p 合成预览及实际导出成片播放。声音、字幕及配乐入口位于成片标题下方，在同一工作区展开编辑；离开流程前保存声音草稿，版本冲突保留输入并阻止离开。正式导出为 720p/1080p MP4，支持取消、失败重试、下载及设为当前成片；合成使用提交时的快照，结果展示对应的只读轨道。

分集实际导航为小说改编、素材准备、分镜制作、成片合成与导出四步，流程栏可收起。步骤编号只表达顺序；已保存、已确认、当前采用是不同状态。

成片工作台支持专注剪辑：临时收起分集标题、创作流程和步骤导航，退出后恢复原布局。素材区可折叠；桌面可拖动分隔条或使用方向键调整播放器和轨道高度，偏好保存在本机。片段属性区及重置布局入口已移除；静音和恢复完整位于剪辑工具栏。刷新默认退出专注模式，窄屏仍采用自然堆叠布局。

成片预览优先使用后台生成的播放代理；素材区使用代表缩略图，轨道按保留的来源时间显示连续采样缩略图。每个来源最多采样 24 帧，生成前或加载失败时回退到代表图；正式导出读取原视频，实际时长由后台检测。已有草稿打开时自动补齐预览素材，不同步或覆盖剪辑决定。分镜来源更新仍需要明确同步，保留已有顺序、分割和裁剪，已删除片段不会重新加入，新分镜追加到末尾；替换源视频过短时需重新裁剪。保存失败或版本冲突保留本页编辑，可下载草稿、重试保存或确认后重新载入；重新载入、同步来源及离开编辑会话会清空撤销历史。

分镜图片操作区按需展开，展示关联素材及去重后的已确认参考图数量。生成前保存并核对最新分镜上下文；其他窗口改动时先刷新核对，不覆盖草稿。模型不支持参考图时不能静默丢图。任务历史和候选分页加载，可查看任务详情并按服务端许可安全恢复；受理结果不明时先核对记录，避免重复计费。

采用历史分镜图保留其原生成布局、画幅和分辨率，不用当前编辑设置改写历史元数据，也不改变下一次生成设置。旧来源需要明确确认，确认仍不能绕过当前图片、分镜版本和上下文的并发校验。

## 素材与媒体

| 概念 | 用途 |
| --- | --- |
| 素材 | 角色、场景或道具的名称、描述、提示词和当前确认图片 |
| 素材库 | 个人库独立；导入项目时复制素材和物理文件；同一项目与其分集可引用同一本体 |
| 图片候选 | 生成、上传或选择的待核对图片，未确认时不改变素材当前图片 |
| 媒体资产库 | AI生成的图片/视频；桌面每行四张媒体卡片，仅展示画面与左下名称，点击核对详情，无筛选和刷新入口 |

素材提取只使用文本模型，不生成图片。素材详情可选择图片模型及可选参数，一次生成1–4张候选；先保存素材，再使用服务端冻结的内容生成。生成会读取持久化参考图片，不自动引用当前采用图片或继承入口项目风格。素材和分镜各最多保存 16 张输入参考图；模型不支持时明确拒绝。移除仅解除关联，历史请求仍保留原文件。上传支持PNG/JPEG/WebP，最大20 MiB、4000万像素。

同一项目内引用的素材共享生成历史；跨范围复制不带入原生成历史、个人模型配置或音色绑定。离开详情后任务继续，重新打开从服务端恢复。生成完成不改变当前图片；采用时校验版本，共享素材需确认影响范围。素材内容改变后，旧候选仍保留，采用需明确核对；仅改选图片不会让同批其他候选失效。

## 通用AI能力

任务中心新建图片任务时，参考图片可从图片资产库选择或多选上传本地图片，合计最多 16 张。上传支持 PNG/JPEG/WebP，单张最多 20 MiB、4000 万像素；成功后显示预览并自动加入本次任务，上传期间禁止提交。上传文件作为输入媒体保存，不创建生成任务或生成资产；移除仅解除本次表单引用。

AI配置页面使用 `/ai_config`，旧 `/ai` 链接兼容跳转。按文本、图片、视频分组，每条配置一个模型，各类型可设默认；编辑表单在启用开关旁提供默认配置选择。模型与服务地址分列显示。Key提交至服务端加密保存，浏览器不持久化。模型目录探测不调用生成、不自动保存配置；没有目录接口时可手动填写模型名。

任务中心按任务 ID 与“项目 / 集 / 用途”识别来源；已完成任务可跳转至对应创作页面，通用图片/视频跳资产库，通用文本可查看结果。失败任务直接显示完整原因，并在服务端允许时恢复或重试；列表不提供更多筛选、刷新或详情按钮。生成请求可能产生费用，不能把未知受理结果当作免费重试。任务离开页面后仍在后台执行。

右上角账号入口打开独立 `/account` 页面，维护账号信息、安全设置与退出登录；返回按钮回到进入前的站内页面。素材侧栏仅保留素材库入口，角色、场景、道具在素材页内切换。

模型兼容受协议、参数和账户能力限制；“能获取模型列表”不等于“已验证生成可用”。

## 保存与恢复

- 项目、分集、小说/剧本、三层素材库、分镜、任务和采用结果持久化到服务端。
- 项目设置显式保存；正文自动保存，候选采用与确认独立提交。
- 网络失败先核实服务端状态；版本冲突保留草稿，允许下载后人工合并，不自动覆盖。
- 账号模式仅读取本人命名空间下的浏览器草稿。未归属旧稿只在受控兼容模式提供预览或下载，不自动导入任何账号。
- 模型选择按账号保存到服务端。清理浏览器数据不会删除作品或模型偏好，但会丢失尚未保存的本地草稿。
- 生成结果保留候选。源内容修改后旧分镜图可能过期，需核对后再采用。

## 尚未实现

- 素材多视图及跨素材批量生成。
- 分镜视频的批量、首尾帧和多素材图片参考；单张分镜图生视频及候选采用已接入分镜制作页面。
- 宫格图切格、配音、字幕、配乐、多轨时间线、转场和变速。
- 独立团队空间、只读访客、所有者转让、实时编辑、评论与任务分配。

分镜视频入口在选中镜头的“分镜视频”标签：已采用分镜图自动作为全能参考图，支持单图、四宫格、五宫格及九宫格。参考图不强制用作视频首帧，成片不复制宫格排版，视频画幅沿用分集设置。默认提示词来自分镜，用户可编辑；系统提示词在后台参与生成，页面不展示。视频时长可独立调整，默认沿用分镜时长，范围受模型能力约束；调整视频时长不会修改分镜脚本时长或使分镜图过期。提示词、清晰度和视频时长自动保存，生成前等待保存完成。候选支持播放与采用，离开页面后任务继续，来源改变后提示核对。

后续可扩展声音、字幕和批量制作。
