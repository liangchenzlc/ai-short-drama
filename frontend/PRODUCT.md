# 产品范围与创作流程

AI短剧工作台面向个人创作者，帮助完成故事改编、素材准备和分镜画面制作。当前单用户运行，无登录、团队空间或权限管理。业务数据保存于服务端数据库和MinIO，不以浏览器演示数据作为真实生成结果。

## 页面与核心流程

1. **项目管理**：搜索和分页查看项目，新建或返回已有项目；项目详情维护名称、梗概、风格、画幅及分集。新项目不自动创建示例内容。
2. **小说改编**：输入小说，自动保存；选择文本模型与补充要求，生成剧本候选。可跳过小说直接手写剧本。
3. **剧本定稿**：编辑当前稿，明确确认后用于素材提取或分镜生成。切换候选前先保存当前稿；修改确认稿会取消确认。
4. **素材准备**：从已确认剧本提取角色、场景、道具，按叙事作用与原文依据审核候选；可编辑、部分创建或复用已有素材。可在素材详情生成图片、上传图片或从资产库选择，预览候选后明确采用。
5. **分镜制作**：根据已确认剧本与素材生成分镜候选，预览时长、原文依据和叙事节拍后追加或替换；可手动编辑、排序、关联素材与归档。使用关联素材参考图生成图片，预览后采用。

分集实际导航为小说改编、剧本定稿、素材准备、分镜制作四步。步骤编号只表达顺序；已保存、已确认、当前采用是不同状态。

分镜图片操作区按需展开，展示关联素材及去重后的已确认参考图数量。生成前保存并核对最新分镜上下文；其他窗口改动时先刷新核对，不覆盖草稿。模型不支持参考图时不能静默丢图。任务历史和候选分页加载，可查看任务详情并按服务端许可安全恢复；受理结果不明时先核对记录，避免重复计费。

采用历史分镜图保留其原生成布局、画幅和分辨率，不用当前编辑设置改写历史元数据，也不改变下一次生成设置。旧来源需要明确确认，确认仍不能绕过当前图片、分镜版本和上下文的并发校验。

## 素材与媒体

| 概念 | 用途 |
| --- | --- |
| 素材 | 角色、场景或道具的名称、描述、提示词和当前确认图片 |
| 素材库 | 全局/项目/分集对素材本体的引用；共享修改会影响多个引用 |
| 图片候选 | 生成、上传或选择的待核对图片，未确认时不改变素材当前图片 |
| 媒体资产库 | AI生成的图片/视频及来源，不等同于角色素材库 |

素材提取只使用文本模型，不生成图片。素材详情可选择图片模型、补充要求及可选参数，一次生成1–4张候选；先保存素材，再使用服务端冻结的内容生成。默认不自动引用当前图片，不自动继承入口项目的风格。上传支持PNG/JPEG/WebP，最大20 MiB、4000万像素。

同一素材在不同库中共享生成历史。离开详情后任务继续，重新打开从服务端恢复。生成完成不改变当前图片；采用时校验版本，共享素材需确认影响范围。素材内容改变后，旧候选仍保留，采用需明确核对；仅改选图片不会让同批其他候选失效。

## 通用AI能力

AI配置按文本、图片、视频分组；每条配置一个模型，各类型可设默认。Key提交至服务端加密保存，浏览器不持久化。模型目录探测不调用生成、不自动保存配置；没有目录接口时可手动填写模型名。

任务中心可发起通用文本/图片/视频生成、查看结果与调用状态，并在允许时取消、恢复或重试。生成请求可能产生费用；错误后的可恢复性由后端决定，不能把未知受理结果当作免费重试。任务离开页面后仍在后台执行。

模型兼容受协议、参数和账户能力限制；“能获取模型列表”不等于“已验证生成可用”。

## 保存与恢复

- 项目、分集、小说/剧本、三层素材库、分镜、任务和采用结果持久化到服务端。
- 项目设置显式保存；正文自动保存，候选采用与确认独立提交。
- 网络失败先核实服务端状态；版本冲突保留草稿，允许下载后人工合并，不自动覆盖。
- 已有浏览器正文可预览并显式导入；旧素材/制作快照可下载，旧演示组件不再作为创作入口。
- 模型选择仍是浏览器偏好。清理浏览器数据不会删除服务端作品，但会丢失未导出的旧稿及偏好。
- 生成结果保留候选。源内容修改后旧分镜图可能过期，需核对后再采用。
