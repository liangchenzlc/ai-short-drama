# 成片合成与导出设计约定

## 范围与方向

第四步，Operate 模式。面向整理分镜、剪辑整集并导出 MP4 的创作者。继承 [DESIGN.md](../DESIGN.md) 的冷黑、中性灰、近白主操作和中文工作台字体；不改变项目主色。一条连续画面轨配合原声、对白、字幕、配乐、音效五类辅助轨，不新增多视频叠层、转场、变速或导出前检查。

## Direction contract

- **THESIS**：画面与轨道占据工作区，工具紧凑排列；设置按需展开，任务提示不改变预览或时间轴尺寸。
- **OWN-WORLD**：复用现有主题 token、线性图标和细边框，区域间距 8px，设置内距 10px。预览保持深色承托，视频等比显示。
- **STORY**：从分镜视频或已有素材建立草稿，在同一时钟下编排画面、试听声音、校对字幕，最后导出或查看历史。
- **FIRST VIEWPORT**：顶部一行成片摘要与图标入口；左侧素材、中央播放器、下方多轨；编辑设置按需在右侧打开，导出参数在原弹窗内。
- **FORM**：采用用户确认的修改清单，没有另选视觉世界；常用工具直达，低频操作进入一级更多菜单。
- **FINISH**：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 布局与控件

标准工作区填满剩余视口高度，素材、设置及轨道内部滚动。桌面素材栏通常为 184px，较窄桌面为 160px；新设置展开时为 280px，素材栏收至 168px。默认播放器利用剩余高度，显式调整的播放器和轨道高度继续保存为本机偏好。多轨最小 280px、最大 360px，旧单轨及结果回看保留原高度边界；播放器高度调整及素材显隐保持原有编辑会话。

顶部组合画幅、片段数、总时长和声音、同步、历史、专注剪辑、导出入口。撤销、重做、分割、删除、静音使用图标按钮并保留可访问名称、悬浮说明及焦点；前移、后移、恢复完整在更多片段操作中。所有图标按钮悬浮不改变尺寸、不隐藏图标。桌面图标操作通常 30px，手机主要操作 44px。

素材卡为缩略图、名称或镜号、时长与加号组成的紧凑条目，完整名称／脚本通过标题提示查看。视频与图片可拖入画面轨，也可在素材弹窗中添加或替换；音频在对应类别入轨。替换过短视频时先在弹窗确认裁剪，取消不改变原片段。剪辑预览与成片回看在播放器标题行用双分段按钮切换；合成预览保留直接入口。两种播放器共用图标控制，包含播放、逐帧、时间码、预览静音及全屏；实际成片额外提供版本说明、刷新地址及下载。预览静音只影响试听，不修改导出片段静音设置。

多轨共用播放头、缩放和吸附，画面保留真实缩略图、选中描边与裁剪把手，声音显示真实来源波形、字幕显示紧凑文本块。每轨直接提供锁定和静音，空轨可折叠。原声、对白、字幕、音效默认关联镜头，配乐默认固定整集位置，可从设置解除或重建关联。画面删除自动合拢，关联片段随镜头重排／分割／裁剪；循环声音保持偏移。动态反馈覆盖在原轨道内，不追加文档流高度；快捷键位于帮助浮层。

剪辑预览由统一 AudioContext 时钟驱动画面、独立音轨和字幕，视频元素静音，避免重复声音。跳转、切换来源或等待音频解码时冻结时钟，后台标签暂停。构图支持适应／填充、缩放、位置和直接拖动；安全区仅为预览辅助，不进入导出。

## 声音、字幕与配乐

标准多轨使用右侧可收起设置，按画面、声音、字幕组织属性，内距 10px、组距 8px；打开、收起和切换专注模式保留草稿。1200px 及以下使用宽度最多 360px 的统一 Dialog，背景不可交互，支持焦点循环、Escape 与关闭后返回原入口；下拉和反馈详情先于底层设置处理 Escape。

设置标题固定，正文独立滚动。声音提供音量、真实响度增益、起止、循环、淡入淡出及人声压低配乐；素材通过统一弹窗接入。字幕以紧凑行编辑，输入即时进入保存会话，时间以秒显示至三位小数，提交为整数毫秒；分割／合并、整体偏移、按标点断句、SRT 和样式按需展开，不常驻大量说明。

字幕识别使用独立 Dialog，默认本地 Whisper，云端模型须主动选择。先显示识别结果并允许导出 SRT，明确应用才替换识别范围的字幕，保留撤销；结果过期保留两份内容。本人任务记录与核实入口位于弹窗内，进度只更新原按钮和任务记录，不挤压工作台。按标点断句和跨镜头分段使用字符比例估计时间，不表达词级对齐。

旧配音面板保留生成、试听和明确采用，采用后进入对白轨。打开前保存组合草稿并关闭新设置，面板编辑期间锁住底层工作台；关闭前完成保存并刷新。旧面板窄屏仍沿原局部操作层规则，新增字幕／配乐编辑统一在多轨设置完成。声音和画面原子保存、双版本冲突及本机恢复均保留整份输入。

## 导出、记录与同步

导出入口位于顶部，处理中在原按钮显示进度；阶段、取消与恢复操作通过公共反馈详情查看，不挤压工作区。导出弹窗汇总片段、时长、画幅、MP4 格式与 720p/1080p 清晰度；清晰度修改先保存，之后使用最新版本冻结导出快照。旧分镜来源仍需明确核对。

导出记录使用紧凑行，播放和下载直达，设为当前成片在更多操作中。当前成片继续明确选择，不新增自动采用。同步弹窗列出镜头新增、替换和移除，保留对旧裁剪的影响说明。

## 状态与验证边界

报错、警告、受理不明、恢复、冲突和任务详情统一遵守 [反馈规则](../../docs/design/创作反馈规则.md)。准备过程使用原控件 loading，播放器自身缓冲或播放失败仍在原视频区域表达。关闭提示不能清除草稿或原幂等请求。

浏览器测试使用 API 测试替身及本机合成视频，只证明界面布局和指定交互；不代表真实模型、真实服务端导出或 FFmpeg 验收。
