# 成片合成与导出设计约定

## Scope / mode
第四步，Operate 模式。个人创作者整理已采用分镜视频，裁剪、连播，导出整集。继承 DESIGN.md，不改变前三步视觉。

## Content / action
真实片段缩略图和播放器是主体。主要动作是“导出成片”；排序、纳入、裁剪和原声设置自动保存。来源更新需核对，历史成片需明确采用。读写状态从服务端取得。导出区在编辑区下方正常排布，避免遮挡裁剪操作和预览说明。

## Direction / tokens
采用已确认的左序列、右预览布局。背景 #f4f7f7，工作表面 #ffffff，文字 #203235，次级文字 #5d7073，强调 #087f75，预览底色 #152726。字体继承 Segoe UI/PingFang SC/Microsoft YaHei，14px 正文，12px 辅助，页面标题桌面 24px、手机 22px，分区标题 15px。左对齐，数值使用等宽数字而非等宽字体。这些为成片页局部规格，通用主题仍以 DESIGN.md 和 src/app/theme.ts 为准。

## First viewport
标题和保存状态在顶部。左侧片段序列约占 30%，右侧预览与当前片段编辑占 70%。导出栏在编辑区及已有成片/运行状态之后占据正常文档流，距前一区域 28px，不悬浮覆盖内容。不用统计卡片，纳入数和总时长只占一行。

```text
成片合成与导出              成片草稿已保存  导出记录
画幅 / 片段数                         同步分镜视频
┌ 镜头序列 ───────┬ 视频预览 ────────────────────┐
│ 缩略图 / 镜号   │                              │
│ 开关 / 时长     │          当前片段            │
│ 顺序 / 状态     │                              │
│                ├ 裁剪范围 / 原声 / 连续预览 ──┤
└────────────────┴──────────────────────────────┘
N 个片段 / 总时长        导出清晰度    导出成片
```

## Signature interaction / states
选中序列片段后预览和裁剪控件联动；播放时可把播放位置设为裁剪起止点。范围轨显示保留范围。拖动和上下移动有相同保存语义。缺图、探测中、失效、冲突、排队、处理、成功、失败均用就近文字和操作，不只用颜色。

## Responsive / build path
Code-led，seed 为用户已确认的实施计划。760px 及以下播放器优先、序列随后，输入和底部操作可换行，键盘移动与拖动等价。序列内部滚动，桌面最高 660px、手机最高 430px。无装饰动画。首轮桌面和手机统一截图检查，修复后最多复核一次。不生成产品插画，以用户视频作为视觉焦点。
