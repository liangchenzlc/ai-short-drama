# 成片合成与导出设计约定

## Scope / mode

第四步，Operate 模式。个人创作者整理已采用分镜视频，在单视频时间轴上剪辑、连播并导出整集。继承 [DESIGN.md](../DESIGN.md) 的浅色、青绿视觉系统；这是既有界面的扩展。产品范围见 [PRODUCT.md](../PRODUCT.md)。多轨、字幕、配音、配乐、转场和变速不在当前范围。

## Content / action

大播放器和真实视频缩略图是主体，主要动作是“导出成片”。素材区支持重复添加已采用的分镜视频；时间轴支持分割、删除、排序、裁剪和静音，编辑自动保存。来源更新需明确同步，历史成片需明确采用。保存、任务及采用状态从服务端取得，导出区在正常文档流内位于编辑区之后。

“剪辑预览”按当前轨道顺播；“合成预览”在后台生成 360p MP4；“导出成片”播放实际导出的 MP4。两种合成结果都在大播放器内查看，并显示提交时冻结的只读轨道。草稿发生变化时就近标明版本差异，切回“剪辑预览”继续编辑。

## Direction / tokens

背景、白色表面、深青绿强调色、字体与控件继承通用主题，以 [theme.ts](../src/app/theme.ts) 和 DESIGN.md 为准。播放器使用深色承托视频，外围保持浅色；青绿用于当前模式、选中片段和裁剪把手。时间码使用等宽数字，片段标签在真实缩略图上用深色底衬保证可读性。焦点有可见轮廓；错误、静音、选中与保存状态同时提供文字或语义标记。

## First viewport

标题、保存状态和导出记录在顶部，随后显示画幅、片段数及同步入口。桌面左侧为窄幅分镜视频素材，右侧为大播放器及播放控制；整个工作区下方依次放剪辑工具和单视频时间轴。没有片段属性区，静音与恢复完整在工具栏内操作。分镜素材始终按分镜编号的数值升序排列，不随轨道调整顺序；成片剪辑顺序以轨道为准。

轨道选中片段显示覆盖在缩略图上方的 3px 青绿色边框与白色内描边，标签增加“已选中”文字并加深底色，裁剪把手保持高亮。选中样式不改变片段尺寸，边框不拦截点击或拖动。

```text
成片合成与导出                     保存状态  导出记录
画幅 / 片段数                         同步分镜视频
┌ 分镜视频素材 ──┬ 剪辑预览 / 导出成片       合成预览 ┐
│ 缩略图 / 时长  │                                  │
│ 镜号 / 添加    │             大播放器             │
│ 分镜脚本摘要   ├ 上一帧 / 播放 / 下一帧 / 全屏 ─────┤
└────────────────┴──────────────────────────────────┘
撤销 / 重做 / 分割 / 删除 / 排序 / 静音 / 恢复完整 / 定位
视频轨道 / 片段数 / 总时长 / 30 fps       适应全部 / 缩放
┌ 时间刻度与播放头 ──────────────────────────────────┐
│ 片段 01 │ 片段 02 │ 片段 03 │ …                    │
└───────────────────────────────────────────────────┘
任务状态 / 当前成片（存在时）
N 个片段 / 总时长                导出清晰度  导出成片
```

桌面素材栏宽 190px，1000px 及以下缩为 150px；素材列表内部滚动，高度跟随播放器。普通模式的播放器默认随视口在 280–380px 之间调整，专注模式默认 240–460px，视频等比完整展示。时间轴支持自身横向滚动、缩放和“适应全部”。导出栏与前一区域保持 28px 间距，不覆盖播放器或裁剪操作。

标题栏的「专注剪辑」临时隐藏外围分集标题、流程栏和步骤导航，保持原有流程栏折叠偏好；专注模式的标题栏固定在滚动区域顶部，保留保存状态、退出和导出记录。按 Esc 或点击退出恢复普通布局；弹窗、输入框、下拉框及视频全屏内的 Esc 不同时退出专注模式。面板上方仅提供「收起/展开素材」，不提供属性面板和重置布局。开关面板和切换模式保持播放器挂载与播放位置。

桌面播放器下方及时间轴下方的分隔条支持指针拖动、上下方向键（20px）、Home/End（最小/最大）。播放器可调整为 200px 至视口高度的 72%（最大 760px），轨道为 152–360px；分隔条有焦点轮廓、可访问名称、当前值和作用区域。面板开关和显式设置的高度保存在本机 `short-drama:assembly-layout:v1`，存储不可用时仍可正常操作。专注模式不持久化；窄屏不显示分隔条，播放器恢复自然比例、轨道恢复 152px，桌面偏好仍保留。

## Signature interaction / states

- **统一时间**：剪辑与播放使用全局 30 fps 时间坐标，时间码为“分:秒:帧”；数字输入以秒显示并对齐到帧。双 video 元素预加载相邻片段，仅当前可见播放器输出声音，片段边界按轨道顺序切换。
- **剪辑操作**：点击轨道片段联动选择和定位；拖动片段时标出插入线并说明目标位置，也可用前移/后移按钮。拖动两端时实时显示来源入点、出点和保留时长，越界时提示，至少保留一帧；松开后提交一次剪辑。键盘 Alt + 左右方向键逐帧改变出点，加 Shift 改变入点；分割共用同一个帧边界。素材可拖入相应位置或点击添加到末尾，同一来源可多次添加，最多 300 个片段。删除只移除轨道片段。
- **缩放与刻度**：滑块及加减按钮围绕可见播放头缩放；播放头原先不可见时将其带回视口中部。「适应全部」缩放完整轨道并返回轨道起点。刻度间距随缩放变化，细刻度显示帧数，避免长片段概览及逐帧放大时标签挤叠。
- **播放与定位**：支持逐帧、播放/暂停、全屏、点击刻度、拖动播放头和输入秒数定位；播放时轨道随播放头滚动。双播放器顺播仍可能遇到网络缓冲；就近显示准备画面、播放失败与刷新视频入口，不承诺无缝播放。
- **撤销与保存**：片段编辑在当前会话中保留最多 100 步撤销/重做，撤销本身也自动保存；同步来源、重新载入和会话结束清空历史。停止编辑约 650ms 后保存，离开前等待保存。失败或版本冲突暂停保存并保留本页编辑，提供下载草稿、重试保存和确认重新载入，不自动覆盖服务端版本。
- **合成结果**：合成预览和正式导出使用提交快照，后台工作期间可继续编辑。结果模式锁定片段编辑并显示冻结轨道，可定位播放和下载 MP4；回到剪辑模式后编辑当前草稿。导出清晰度为 720p/1080p，采用成片是独立确认操作。
- **媒体与异常**：剪辑预览优先使用 360p、30 fps 播放代理，正式导出读取原视频。素材使用代表图，轨道使用最多 24 帧的采样缩略图拼图，按裁剪后的来源时间选帧；仅绘制可见范围内的缩略图格，每片段最多 32 格，不额外启动视频解码器。未生成或加载失败时回退到代表图。已有草稿打开时通过幂等初始化补齐预览素材，不同步来源、不覆盖编辑。缺视频、检测中、不可用、裁剪超界、任务失败和旧来源均就近说明；旧来源继续使用需明确核对。

编辑区支持 S 分割、Delete/Backspace 删除、Ctrl/⌘ Z 撤销、Ctrl/⌘ Shift Z 或 Ctrl/⌘ Y 重做；输入控件内不触发剪辑快捷键。轨道片段可键盘聚焦并用 Enter/Space 定位，Alt 组合键为裁剪提供逐帧替代操作。

## Responsive / build path

760px 及以下按播放器、剪辑工具、时间轴、分镜素材顺序排列。播放控制和工具栏换行；素材区变为可横向滚动的缩略图列表，片段宽 128px。横向视频按 16:9 展示，竖向视频保留独立高度。全屏将播放器与控制栏一起展开，保留播放和逐帧操作。无装饰动画，以用户视频为视觉焦点。

实现依据为 `AssemblyPlayer.tsx`、`AssemblyTimeline.tsx`、`AssemblyFilmstrip.tsx`、`timeline-view.ts`、`AssemblyWorkbench.tsx`、`assembly-editing.ts`、`useAssembly.ts`、`AssemblyStage.tsx` 与 `assembly.css`。本轮桌面与窄屏截图为仓库根目录 `.impeccable/review/timeline-readability-desktop.png`、`timeline-readability-mobile.png`；这些截图使用 FFmpeg 合成测试素材，只作为布局证据，播放、保存及导出行为需由对应功能验收单独证明。
