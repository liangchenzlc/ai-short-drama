# 网页还原方案与实施记录

目标：以 ai-video-integration/frontend/src 当前实现为视觉依据，在独立 React + Vite + TypeScript 工程中还原网站。

保留原有蓝白配色（#f5f8fc、#edf4fc、#20334d、#1677ff）、微软雅黑/Segoe UI 字体、侧栏、项目卡片、弹窗、剧集信息、素材库、AI 设置及分集制作页面。

实现步骤：
1. 迁移可独立运行的 React 展示组件和 CSS，使用标准 Vite 入口。
2. 重写项目管理为 localStorage 数据；预置三个演示项目、剧集和素材。
3. 移除 Electron、IPC、服务状态管理、后端接口和自定义媒体协议。媒体导入使用浏览器文件选择与 IndexedDB。
4. 保留原有演示生成与确认交互；AI 配置仅展示，密钥不保存、不请求服务。
5. 类型检查、生产构建、浏览器核对项目/剧集/素材/配置交互与移动布局。

网站仅包含前端代码；不会读取或更改原项目的数据。
