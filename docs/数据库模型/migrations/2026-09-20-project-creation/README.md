# 项目创建接口迁移

新数据库直接执行已更新的 `../../schema.mysql8.sql`，不再包含项目目标时长。

存量数据库需要先选定业务库，备份需要保留的旧目标时长，再执行
`001_remove_project_target.sql`。脚本删除 `projects.target_ms` 及
`ck_projects_target`，不影响镜头视频参数或媒体实际时长；支持重复执行。
MySQL DDL 隐式提交，删除的旧时长不能通过事务回滚恢复。

发布时先暂停旧版本项目写入，执行迁移并确认末尾两项计数均为 0，再启用新后端。
新后端不再写入旧库中必填且无默认值的 `target_ms`，所以必须完成迁移后使用创建接口。
应用启动不会自动迁移数据库。本次仅提供脚本，不自动执行存量业务库变更。
