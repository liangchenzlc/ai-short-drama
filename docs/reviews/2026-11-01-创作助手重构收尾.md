## 已实施

- 单一通用助手使用 LangChain `create_agent`、LangGraph checkpoint／interrupt 完成模型和工具循环；项目提供会话、上下文、权限、预算、持久化与业务执行，完成由主模型判断。
- 工具按问答、媒体生成、画布、标准创作、沙箱、Skill、委派等子包拆分，统一 registry／contracts／scope／LangChain 绑定；Skill 按目录、正文和资源渐进披露。
- 用户可设置提示词、工具与 Skill 范围、预算及媒体授权；问答和媒体结果支持持久等待、恢复及停止。同步子任务隔离执行，在主会话查看轨迹，永久不提供独立子会话聊天。
- OpenSandbox + Docker 支持 Python、Node.js、联网与 pip／npm；前端可展开具体工具目标、Skill 名称／版本、实际模型思考、子任务及沙箱输出。
- 对外 MCP 仅提供业务工具，复用真实账号权限和业务回执；设置页创建具名令牌，可选有效期与 IP 白名单，支持删除。永久不通过 MCP 委托整个助手；外部工具接入／测试／启停设置页仅保留设计，本次不实现。
