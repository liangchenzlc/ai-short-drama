## 验证限制

统一 dev 场景未通过：在本机开发启动后，宿主代理 `/canvas-app/` 请求超时，部分轮次宿主 `/projects` 也冷启动超时。有／无品牌插件对照均可复现代理超时，而直连画布 HTML 与宿主 HTML 可返回 200；关闭时 Vite `dep-scan` 扫描到前端 HTML fixtures 与画布，并输出 `The server is being restarted or closed. Request is outdated`。本次未修改开发代理、依赖扫描策略或放宽测试超时。

端口占用清理用例早轮通过，最终与 preview 一起复测时在 `frontends.test.mjs` 的启动标记断言失败：大量关闭日志占满测试保留的末尾 32 KiB，`标准模式：` 标记不在保留输出中。退出码和占用错误断言已通过，后续端口关闭及独立服务存活断言在该轮未执行；不将该轮列为通过。生产 preview 随后单独运行通过。

未调用真实 SMTP 或模型供应商；邮件仅替换网络传输，MCP 使用进程内 HTTP，未做 MySQL／TCP 集成验收。未实际构建 wheel 检查包内容：本机 PATH 无 `uv`，现有虚拟环境无 `hatchling`，未为此增加依赖。浏览器用例覆盖本次品牌显示范围，未替代其他业务端到端验收。
