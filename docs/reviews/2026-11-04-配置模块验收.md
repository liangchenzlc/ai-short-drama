# 配置模块实施与验收

关联[实施方案](../plans/2026-11/2026-11-03-配置模块实施方案.md)、[定稿](../design/2026-11-03-配置模块定稿与后端改造清单.md)及[官方媒体合同](../design/2026-11-03-官方媒体接口契约.md)。本记录只覆盖本轮配置改造，不将工作区原有 Agent 轨迹、上下文与方法包变更计入本轮交付。

## 已落地范围

- 主导航改为「配置」，保留工作台壳；模型、助手三页、MCP 使用统一左导航及右内容区。文本／媒体分组与媒体标签均可深链，编辑和测试使用图标。
- 模型弹窗由服务端 options 驱动，文本只有自动识别、Chat Completions、Responses、Claude Messages。密钥直接输入或删除，获取模型复用原位下拉；输入聚焦无描边。创建以原 key 核对，未切换接口的编辑保留原协议与隐藏参数。
- 助手统一部分 PATCH 与版本；文字 600ms、开关立即串行同步，无额外保存按钮。工作台开启后才显示媒体总开关，关闭仍允许只读分析引用。设置和记忆同步队列按账号挂载，切换主导航或关闭记忆抽屉不丢未同步草稿。
- 长期记忆归账号，主体、来源、修订、遗忘规则不关联作品／对话；关闭保留数据并停止 Agent 读写、注入及提炼，重开不补抽。管理支持搜索、分页、版本化编辑与删除；删除对话不删除记忆。
- MCP 独立令牌页面、六列表格、无项目选择，按账号当前项目权限动态判断。创建幂等、密钥只返回一次，结果未知按原创建 key 核对；撤销／过期阻止后续外发，已外发继续归档为候选，自动采用前再次检查来源令牌。
- 删除用户运行额度、默认／本任务媒体数量及旧策略 HTTP 接口；保留实际用量、原生生成记录、内部 Run 预算及系统并发保护。
- 图片以策略、注册表和适配器复用五个协议族，仅退役 RunningHub 图片。补齐 Gemini、Grok 图片及 MiniMax H3、Kling 4 视频，原视频／音频协议及工作流执行保留。Wan3 缺完整契约，未按旧合同猜测接入；Midjourney 暂缓。

## 迁移与服务

已备份真实开发库，在随机隔离库恢复并预演后，执行[配置与账号记忆迁移](../database/migrations/2026-11-03-settings-module/README.md)。原4条局部记忆备份后移出在线库，没有提升为账号偏好；有效旧令牌和 RunningHub 图片配置均为0。121张表的完整 SQL 已重新生成并通过核对。

原 API、text／image／video／render／agent Worker 和 scheduler 已同版恢复，启动日志未发现异常。迁移前已有 Run 保留原 Task、收据及检查点，服务恢复后进入待用户输入；未人为重发旧请求，也未为了验证新建媒体生成。原先未运行的 audio Worker 未额外启动。

## 边界与未执行项

- 本轮没有主动发起真实收费媒体生成验收。协议和数据库测试不能证明账号模型权限、真实内容质量、生产网络或供应商实时可用性；既有任务的正常恢复不计作本轮供应商验收。
- GPT Image、Grok 继续复用已有协议；本轮没有核实其全部最新型号。Google 使用官方 SDK 合同，MiniMax／Kling／方舟的准确型号与端点依据记录在官方媒体合同中。
- Wan3 未取得完整请求／返回合同，未开放；旧已支持万相保留。Midjourney 按已确定方向等待官方 API 或合作文档。
- Kling 4 官方采用单 API Key，早期原型中的 AK/SK 假设不适用于该接口；本轮普通表单按官方合同显示一个密钥字段，不套旧 JWT。
- 本轮不提交 commit，不覆盖或回滚其他任务的未提交改动。
