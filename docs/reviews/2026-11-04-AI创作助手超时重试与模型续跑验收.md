# AI 创作助手超时重试与模型续跑验收

本记录限定于连接／响应超时、重复失败提示、失败后切换模型和 DeepSeek 工具选择兼容性。工作区既有工具说明拆分、会话标题和其他界面改动保留，不计作本次交付。

## 已实施行为

- Agent 使用可取消的异步 HTTP。DNS、TCP、TLS 共用连接期限，首次30秒，仅未发送请求字节的连接超时可重试5次，期限依次60／90／120／150／180秒。SDK与HTTP库不另行重试。
- 连接成功后、发送HTTP头前持久准入；未发送的连接尝试不创建Turn、不消耗调用或输出预留。停止取消当前连接，不进入下一次尝试。
- 响应默认120秒无有效正文、思考或工具参数进展即失败，不重发。HTTP头、心跳和空工具参数帧不续期；已发送的不明结果保留账本与输出预留。
- 重试状态持久保存并经公开Run投影恢复。界面仅显示“连接超时，正在重试 1/5”，不显示本次连接等待秒数。删除前端重复失败段落，保留后端会话失败消息。
- 错误暂停、预算暂停和停止且控制／操作结算后可切换模型；同Task新建Run，旧Run和成果保留。受理不明须明确确认；Worker失联和在途停止由统一结算读取账本事实，避免漏记。前端从当前及历史Run查找所选Task的最新Run，确认和所选模型随原幂等请求保存。
- 显式DeepSeek provider或精确官方域名启用适配，custom官方地址也生效；任意自定义地址不按模型名推断。Chat／Responses的强制工具选择关闭thinking，冲突单独分类。请求头统一大小写，避免重复Content-Type；非JSON错误体不保存正文，明确HTTP拒绝保持准确分类。

不新增数据库表、迁移或依赖。维护说明、API和环境示例已同步。
