本次清理覆盖 39 个 CSS 文件：删除 222 条小屏或触屏专用媒体规则，将 11 条桌面规则提升为默认，简化 3 条组合规则。画布处理 98 处工具类或 JSX 呈现，其中 94 处提升桌面类、4 处删除手机专用元素。没有引入依赖、设备识别、访问拦截页或新的布局框架；本任务没有修改后端业务、接口或数据库。

## 保留项与残留核对

| 保留项 | 理由 |
| --- | --- |
| 14 条宽度媒体规则 | 均为 1280px 及以上的桌面窗口档位，涉及侧栏、列表、面板和大屏排布 |
| 1 条高度媒体规则 | 处理较矮桌面窗口的内部滚动与操作可达性，不引入手机布局 |
| 14 条容器查询、实际容器 ResizeObserver | 助手和设置同时打开后，桌面编辑容器仍可能很窄；用于正文内距、预览与列表排布 |
| 55 条降低动效规则、2 条精确指针悬浮规则 | 保留无障碍偏好与桌面鼠标悬浮能力 |
| visualViewport、DPR、Pointer Events | 用于通用浮层边界、清晰度和画布输入；无限画布的多指输入不产生独立移动页面 |
| 2xl 工具类及 sm／md／lg 尺寸键 | 前者是有效桌面宽度档位，后者是组件尺寸或语言名映射，不是响应式布局类 |
| 9:16、图片缩放尺寸及小节点夹具 | 属于媒体内容、输出与画布对象尺寸，不是浏览器设备适配 |

源码未残留 `isMobile`、`hasTouch`、`useBreakpoint`、手机安全区或触屏专属布局分支。测试中的手机／平板视口及设备上下文已迁出；保存、冲突、附件、权限、焦点与恢复断言保留在桌面用例中，没有新增 skip。历史原型、第三方资产及既有验收数据没有为消除搜索命中而改写。
