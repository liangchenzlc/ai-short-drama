# 成片合成与导出验收

交付第四步：独立成片草稿、排序、包含/排除、非破坏性裁剪、静音、顺序预览、明确同步分镜视频、后台导出、取消、重试、下载及设为当前成片。

前端按现有浅色与青绿色界面延伸。桌面以视频预览为主、左侧镜头序列；手机先预览后列表。导出栏保留独立布局空间，不遮挡编辑控件。自动保存串行提交，离开页面和导出前等待保存；冲突保留本页编辑并提供草稿备份。

数据库总文件 `docs/数据库模型/schema.mysql8.sql` 覆盖全部 24 张表，包括之前的分镜视频字段，以及新增的 3 张合成表和 `media_files.video_metadata`。ORM、完整建库 SQL 和增量迁移同步。已执行本地增量升级，数据保留。独立 MySQL 随机测试库从全量 SQL 创建，结束后删除测试库。

验证结果：

- 后端单元测试 462 项通过，API 测试 43 项通过。
- 集成组 106 项通过，2 项按环境配置跳过。完整组初跑发现旧回收站视频恢复和后续视频迁移链问题，修复后对应 5 项复验通过。
- 前端 111 项测试通过，TypeScript 与 Vite 生产构建通过；仍有既有大包体提示。
- 真实 FFmpeg 验证横屏 720p、竖屏 1080p、音轨标准化、静音片段、裁剪拼接和运行中取消。
- HTTP/MySQL/实际编码联测覆盖：检测真实时长、版本冲突、冻结导出、模拟上传失败、复用已编码文件重试、重复 Worker 消息、下载、采用与跨项目拒绝。
- Playwright 桌面 1440 和手机 390 视口，覆盖排序、裁剪、静音、保存屏障、导出记录、采用与保存冲突恢复；使用明确标记的 FFmpeg 测试素材和 API 替身，没有调用付费模型。浏览器 Vite 热更新 WebSocket 被本地网络检查阻止，页面 HTTP 与交互正常；409 为主动注入的冲突验收。
- Impeccable 独立复核提出的导出栏遮挡、四步持久文档两项修复均已评分 resolved，最终 disposition 为 ship，仅覆盖这些修复项。文档交接已完成。detector 已调用一次，退出 0 但没有输出报告，因此不声称 detector 检查通过。
- 本地 API、数据库、MinIO 健康检查为 200；成片 GET 接口为 200。已启动独立 render Worker。

部署需 FFmpeg；优先配置 ffprobe，缺少时可使用 FFmpeg 读取容器信息并解码首帧。便携工具只保存在忽略目录中，不随源码提交。后台合成进度按准备、片段编码、拼接和上传阶段更新。此版不含配音、字幕、音乐、多轨剪辑、变速或转场。
