# 分镜视频全能参考模式修正

用户明确：单图、四宫格、五宫格等分镜图是全能参考图，不应被强制作为视频首帧。本次修正替代首次实施的单首帧限制。

## 结果

- 分镜视频使用 `reference_media_id` 绑定当前已采用分镜图，支持 single/four/five/nine 排版；保留图片过期和并发版本检查。
- 服务端生成 `input.reference_media_ids`，ModelHub multipart 上传原图并发送 `functionMode=omni_reference`。不会把宫格转换成首帧输入，也不自动拆格。
- 输出 `ratio` 使用分集画幅，与宫格整图的宽高比独立。时长与清晰度仍取已保存设置，不增加操作步骤。
- 系统提示词与默认用户提示词升级为 `shot-video-v2`：从参考图理解人物、道具、场景、动作与运镜；不冻结整张宫格为第一帧，不把宫格边框、编号或排版复制到成片。用户已保存的自定义提示词保留。
- 页面使用「全能参考图」及相应说明，只支持首帧输入的模型不能通过参考图能力检查。
- `shot-video-context-v2` 包含全能参考语义；历史任务保留原快照，旧首帧视频与当前模式不同会提示来源过期。无需额外数据库迁移，历史 `first_frame_media_id` 列保留首帧含义，新全能参考任务不填该列。
