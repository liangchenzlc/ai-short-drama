## 已实施范围

Task1–11 与后续 Task13–31 已有实施和独立审查记录。本次续作未修改生产代码，核对后的功能包括：

- LangChain `create_agent` 与 LangGraph 接管模型、工具循环、checkpoint、interrupt 和恢复；主模型判断完成，旧强制 reviewer 与自研完成循环退役。
- 工具按业务子包拆分，外层统一 registry、contracts、scope 和 LangChain 绑定；内部助手与对外 MCP 共用业务能力。
- 单一通用助手保留会话、上下文、自定义提示词、动态设置与媒体授权开关；Skill 按目录、正文、资源渐进披露，并按执行范围隔离冻结版本和来源。
- `ask_user` 与业务生成等待持久化；同步子任务支持隔离和并发，统一在主会话展示，不提供子会话聊天。
- OpenSandbox + Docker 提供 Python、Node.js、公网访问及 pip/npm，工作区资源显式导入、物化和归档。
- 前端展示具体工具与 Skill 目标、参数、结果、问答、子任务、沙箱日志和真实可用思考，支持刷新、分页和 SSE 补读。
- MCP 长期只开放工作台业务工具；账号设置支持具名令牌、可选有效期、IP 白名单和删除。外部工具连接管理页仅保留设计，不在本次实施范围。
