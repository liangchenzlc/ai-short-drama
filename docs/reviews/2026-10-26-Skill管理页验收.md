## 完成范围

独立 `/skills` 已接入侧栏，支持我的／内置来源、名称与用途搜索、启停及模式筛选。卡片仅保留名称、用途、适用模式与启停；不展示标签、触发方式或文件数量。通用／创作／画布为三段式单选，新增默认通用，更新保留当前模式和启停状态。

Skill 通过 Markdown 或 ZIP 导入，更新使用完整包替换，移除文件需确认。标签不提供填写入口，更新缺省保留原值，显式空数组清空。脚本、`scripts/` 目录和未知格式导致整包拒绝；预览及正式写入均检查文件、路径、引用、体积与模式兼容性，兼容直传和复制接口也受同一限制。

详情、导入及更新共用只读文件浏览器，复用 Ant Design `DirectoryTree`／`Splitter` 和 `@uiw/react-codemirror`（CodeMirror 6），没有自行实现代码编辑器。默认打开 SKILL.md 正文，支持目录展开、文本行号、复制、图片、逐文件滚动位置、版本缓存、取消旧请求和局部重试；只读区域禁止输入、剪切、粘贴和拖入修改。窄屏切换目录与文件。

前后端契约、ORM 及运行时不再记录或按 `invocation_mode` 筛选，继续按启停、模式和兼容性判断可用性。历史任务的冻结版本、资源及实际激活来源审计保持原样。不兼容方法可停用，停用后前后端均拒绝重新启用。

AI 配置页的 Skill 页签、管理、编辑、资料组件及专属样式已删除，保留模型分类与助手设置。旧 `/ai_config?section=skills` 使用替换历史记录跳转；助手选择器统一进入 `/skills`。旧草稿与含退役字段的受理记录提供原记录下载和明确清除，不删字段后重发；恢复数据按账号隔离。
