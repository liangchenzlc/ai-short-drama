## 审查与视觉检查

前后端独立审查已修复以下实际发现，并覆盖相应回归：

- 新建对话的创建回执曾短暂挂载输入区，随后详情读取再次重挂载；现详情加载完成后才开放输入。延迟详情响应下确认无提前输入区、仅一次上下文初始化，首条草稿在折叠和窄屏切换后保留。
- 附件恢复未完成或失败时阻止发送；结果不明的上传和引用保留原请求与幂等键。
- Skill 保存及上传按钮保持稳定可访问名称；未保存的 Skill 编辑提供放弃确认；关闭模型设置仍保留指定媒体任务状态。
- 素材编辑在窄屏关闭后恢复卡片焦点；图片和三点菜单不触发卡片编辑；候选失权后清空内容并拒绝晚响应恢复。
- 实际超过 120 秒的引用音频不再依赖可能缺失或错误的时长元数据，也不静默截取。
- 新媒体附件先写入父媒体记录，再写入附件外键，仍处于同一事务。
- 视频和对白音频采用后的发布标记不再被同事务的重复读取抹掉；重复采用路径同样持久化。协作者可读取作品，仍无法读取作者的候选和私有首帧来源。

已实际截图并目视检查 1440、1024、390 三种宽度下的 Agent 对话、素材卡片、右侧素材编辑、分镜卡片。浏览器回归检查页面无横向溢出，窄屏输入工具和发送可达。截图保存在被 Git 忽略的 `frontend/.runtime/refinement-visual/`。
