- 无指定付费模型与费用上限，真实模型视觉验收不执行；将其归档为外部验收边界，不阻塞本地实现、验证和推送。

## 已交付功能

- 关联素材展示确认状态及去重后的参考图片数量；未确认素材仅参与文字上下文。
- 单镜操作锁、先保存再核对、上下文/版本/图片/参数变化提醒，晚到响应不能覆盖另一分集的草稿。
- 分集级解析实际默认图片模型和能力，明确不支持参考图时阻止提交，不悄悄丢图或降参。
- 图片区按需展开、历史/候选分页、活动任务追踪、任务详情和已有安全恢复入口。
- 手动刷新续期所有已加载候选页的链接；自动轮询仍只刷新首页，避免全历史扫描。
- 历史候选保留真实生成参数，确认旧来源仍使用同一组目标并发令牌，不改下次生成设置。
- 网络受理未知时保留保护；每次 HTTP 提交拥有独立 owner，旧请求的晚到回执不得清除新请求的保护或幂等键。
