# 创作工作台前端预览验收

日期：2026-11-06

范围：独立开发预览及其复用的前端视图；不包含成片预览节点页面。

## 验收结果

- 单集默认一个分集；增加分集后显示顶部选择器，剧本和分镜按集切换，资产由全剧共享。
- 资产与分镜左栏沿用原有卡片、筛选、创建、删除及列表／宫格切换；中间单卡、宫格、列表的切换与左栏独立。
- 资产单卡左侧编辑资料、右侧查看图片和编辑提示词；支持图片组、对比、主图选择及失败图片重试，查看图片不会自动更改主图。
- 分镜单卡左侧编辑信息和生成分镜图，右侧预览视频并编辑提示词；关联角色和场景的主图默认选为视频参考，可以移除；分镜图需由用户明确选入。可分别模拟直接生成视频和带分镜图生成视频。
- 宫格和列表支持跨视图保留勾选；切集清理镜头勾选。101 项模拟任务按 100＋1 分批，展示批次记录，失败项可单独重试。
- 批量生成只处理当前筛选范围内的已选项，筛选外的勾选保留但不提交；参考图超限的镜头在视频批量预检中跳过并提示原因。
- 关联角色或场景暂时缺图时保留默认参考选择，补图后自动显示，用户移除后不恢复。删除资产或调整关联时清理并重新对应图片提示词引用；单次、批量和跨批次补图后引用仍指向原资产。
- 已人工走通单集写作、增加第二集、生成概要、编辑共享资产及标签、两集镜头、两种视频路径和批量生成；演示请求拦截未发现真实业务 API 或外部服务调用。
