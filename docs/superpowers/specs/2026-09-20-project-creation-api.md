# 项目与分集创建接口

项目组织整部短剧，分集承载小说、剧本、素材和分镜。项目目标时长已移除；
镜头视频生成参数与媒体实际时长继续由各自模型管理。

## HTTP 契约

`POST /api/v1/projects`：必填 `name`（trim 后 1–120 字符）、`aspect`
（16:9 / 9:16）；可选 `synopsis`（默认空，最多 2000 字符）、`style`
（默认空，最多 255 字符）。服务端生成雪花 ID、UTC 审计时间和最近打开时间，
操作人为空。返回 201 和完整 ProjectRead，不创建示例分集或素材。

`POST /api/v1/projects/{project_id}/episodes`：必填 `title`（trim 后 1–255
字符）；可选 `synopsis`（默认空，最多 500 字符）、`aspect`、`style`
（最多 255 字符）。省略画幅/风格则复制项目值，显式空风格表示不设风格，
显式 null 不合法。路径是唯一归属来源，客户端不能指定 position。
返回 201 和完整 EpisodeRead。

所有请求拒绝未知字段、客户端 ID、审计字段和目标时长。所有 ID 输出为十进制
字符串，时间输出为 UTC ISO 8601（Z）。错误沿用 error.code/message/fields：
422 参数错误，404 项目不存在，409 并发或约束冲突，503 数据库不可用。

## 事务与并发

分集创建在一个服务事务内锁定项目行，使用当前读查询该项目最大的 position，
加一后写入（首集为 1），超过 unsigned INT 上限返回 409。
项目行锁与已有更新、删除、重排服务使用相同锁序，唯一索引提供最终约束。
position 允许空隙，界面集号按排序后的序号展示。

画幅/风格复制后独立修改。增加分集不刷新项目 updated_at，不初始化小说、
剧本、素材或生成任务。小说首次保存时才创建。
服务拥有事务，DAO 仅查询、写入及 flush；失败全部回滚。

名称允许重复，普通 POST 不承诺幂等；客户端提交中禁用按钮，不自动重试创建。
超时后先查询结果，后续如需幂等保障另增持久化幂等键。

## 实施边界

已开放完整项目、分集增删改查及记录项目最近打开时间接口，网页对应管理页面
均使用服务端数据；移除自动示例分集初始化，采用服务端字符串 ID，分集标题上限为 255。
项目列表支持搜索、分页、分集数量和继续创作；项目详情显式保存，分集弹窗支持编辑与删除。
分集详情包含按排序计算的 episode_number，position 有空隙时仍连续显示集号。
后端所有分集接口校验路径中的 project_id，防止跨项目读取、更新或删除。
删除保留外键 RESTRICT 行为，关联内容尚未清理时返回 409。
项目资源库及分集内小说、剧本、素材、分镜制作内容仍属于本地演示，界面明确标注。
旧浏览器项目不自动导入，用户已确认目标时长迁移执行完成。
