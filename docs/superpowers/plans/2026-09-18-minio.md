# MinIO Infrastructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reusable MinIO infrastructure backed by the user's existing image/video buckets.

**Architecture:** API → StorageService → MinioStorage adapter. Config and lifecycle reuse existing Settings and FastAPI lifespan; database metadata is untouched.

**Tech Stack:** Python 3.12, uv, FastAPI, official minio SDK, urllib3.

**Spec:** docs/superpowers/specs/2026-09-18-minio-design.md

## Global Constraints

- No local MinIO; use existing cloud buckets, no bucket creation or policy changes.
- Credentials only in .env; no secrets in logs, tests or docs.
- Snowflake object identity, stable minio:// locator, temporary signed URLs only returned on request.
- Stream downloads release the response and connection on every exit.
- No public business upload routes or database mutations in this phase.
