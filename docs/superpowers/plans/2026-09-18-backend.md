# Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Deliver an independently runnable backend with 17 domain models, validated DAO/service operations and test endpoints.

**Architecture:** api → service → dao; SQLAlchemy domain objects and independent Pydantic schemas. Service owns transaction and invariant enforcement; DAO never commits.

**Tech Stack:** Python 3.12+, uv, FastAPI, SQLAlchemy 2.x, PyMySQL, Pydantic v2, cryptography, pytest, Ruff.

**Spec:** `docs/superpowers/specs/2026-09-18-backend-design.md`

## Global Constraints

- MySQL 8.0.21+; existing schema is authoritative; no automatic production DDL.
- Preserve api/service/dao layers and all 17 tables.
- Generated columns are read-only; JSON identifiers are decimal strings; normal writes use UTC audit timestamps.
- No existing Git repository: work in the newly created backend folder, no commit/worktree operations.
- No SQLite substitution for MySQL integration verification.
