# 分集小说与剧本持久化验收

日期：2026-09-21。功能分支：`feat/episode-writing`。

## 已实现

- 五个分集写作接口：读取、小说保存、当前剧本保存、选择已有剧本、确认剧本。
- `episodes.editing_script_id` 和 `content_version` 增量迁移；服务层校验同分集归属，分集行锁与版本检查保护写入。
- 小说/剧本内部 CRUD 与已有剧本生成入库也更新编辑版本；编辑已确认稿会取消该稿确认。
- 前端 1 秒自动保存、共享串行队列、请求期间的新输入保留、网络结果核对、冲突暂停、离开页面保护。
- 明确的浏览器旧稿预览/导入、草稿下载、服务端版本加载；没有调用真实模型。
- 素材和分镜演示只在内存中使用当前正文，不将服务端正文写回覆盖旧浏览器稿。

## 本机部署
