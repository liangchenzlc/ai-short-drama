# 工作台读取与加载性能

> 本页是 2026-10-13 的性能测量与修复记录，撰写时项目仍有分集结构。2026-10-21 起分集、成员与跨库共享已移除，文中涉及分集阶段、成员状态的描述只作历史背景；当前结构见[创作模式维护说明](创作模式维护说明.md)。

> 2026-10-27 起项目仅支持内容视口宽度 ≥1280 CSS px 的桌面浏览器。下文 390px 等尺寸保留为历史测量记录，不再作为现行布局或验收要求；后续矩阵见[按功能执行测试](按功能执行测试.md)。

本次以 `8c99584` 为修改前基准，测量项目、分集、素材、任务、媒体、AI 配置和 Agent 的主要读取路径。主要瓶颈是权限 SQL 表达式重复构造、列表逐项查询关联数据，以及项目详情提前加载所有分集编辑器。

## 实现与保护范围

- 后端复用有界的权限 SQL 表达式，仍由数据库检查当前项目归属和归档状态；不缓存权限判定或业务数据。
- 项目最近打开时间、任务调用历史与来源名称、Agent 最新运行与待审核工具、候选剧本预览改为页内批量查询。原生有声分镜与成片源复用页内对白、角色声音和媒体查询，保留单镜头严格校验及上下文哈希。
- 已确认无写入副作用的读取路径取消项目、分集和媒体写锁。保存、确认、采用、生成、成片初始化以及会修改状态的批量任务查询保持原有锁和版本检查。
- 前端按当前项目子页、分集阶段加载组件；当前页面代码在认证和数据请求期间预载，避免新增串行等待。组件在挂载期间保持类型稳定。正文、素材首次访问后保留编辑状态；分镜和成片沿用原有阶段生命周期。
- 模型配置目录按账号、服务类型共享请求，支持分页、取消、重试及配置变更和窗口聚焦失效。串行自动保存、409 草稿、候选明确采用和导航屏障继续有效。
- 成片流程隐藏右侧 AI 栏；提示词与 Agent 切换控件仍位于 AI 栏左上角。

没有新增依赖、数据库表或索引，也没有修改业务数据库结构。

## 复现

后端在 `backend/` 执行，已有虚拟环境也可用 `.venv/Scripts/python.exe` 替代 `uv run python`：

```powershell
uv run python scripts/benchmark_reads.py --docker-container ai-short-drama-mysql-1 --profile all --samples 7 --warmups 3 --native-samples 3 --native-large-samples 1 --native-warmups 0 --output .runtime/backend-reads.json
```

Docker 模式先检查显式指定容器的本机端口与 Settings 一致，只对本次随机 `short_drama_<uuid>_test` 库临时授权，结束时独立撤权和删除。没有 Docker 时可提供具有 CREATE/DROP 权限的 `TEST_DATABASE_URL`，协议为 `mysql+pymysql`，数据库名以 `_test` 结尾；脚本仍新建随机库。不要使用业务库作为测试库。

对照旧版本时，在另一个目录检出 `8c99584`，向同一脚本提供 `--source-root <旧目录>/backend/src`。应用导入发生在该参数生效后，不会误用当前源码。报告保留原始样本、SQL、响应长度与业务哈希，正常退出后 `isolated_database_dropped` 才置为 `true`；中途异常应核查隔离库是否已清理。

前端在 `frontend/` 构建，并在一个终端保持预览：

```powershell
npm run build
npm run preview -- --port 4180 --strictPort
```

另一个终端执行：

```powershell
$env:PLAYWRIGHT_PRODUCTION_URL = 'http://127.0.0.1:4180'
$env:PERFORMANCE_API_LATENCY_MS = '250'
$env:PERFORMANCE_PHASE = 'after'
npm run test:performance
```

可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装的 Chromium。报告输出到 `.runtime/performance/<phase>/`，包括各页面可用时间、请求时间线、JS 文件大小和浏览器错误；预览必须对应当前 `dist/`，避免把另一版本的页面与本地文件大小混算。对照旧版本时使用相同 fixture、延迟、视口和可用条件；冷开单次结果不称为 P50。

真实 MySQL 回归可继续使用开发指南中的 `scripts/run_integration.py`。应用账号没有 CREATE DATABASE 权限而本机有已核实的 MySQL 容器时，隔离管理入口为：

```powershell
$testTemp = '.runtime/pytest-integration-' + [Guid]::NewGuid().ToString('N')
uv run python scripts/benchmark_database.py --docker-container ai-short-drama-mysql-1 -- tests/integration -q -p no:cacheprovider --basetemp $testTemp
```

新增物理锁回归在持有项目或分集 `FOR UPDATE` 锁时读取正文、分集详情、分镜和成片，要求锁释放前返回已提交内容；独立写入仍等待锁，版本变化后返回 409。权限 SQL、批量列表、原生上下文、版本新鲜度和隔离管理异常路径也有专项回归。浏览器回归覆盖未访问阶段不读取、正文创作要求保留、共享模型目录、认证前仅预载代码，以及原有编辑和 Agent 导航保护。
