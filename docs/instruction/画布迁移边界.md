# 无限画布迁移边界

只在对 `frontend/canvas/` 及其宿主接入做改动时适用。2026-10-21 的单层创作、来源解绑与共享退役调整以[创作模式维护说明](创作模式维护说明.md)为准。

- 用户原先要求画布原生布局、交互、操作和功能一比一保留 BeefTV 固定版本。2026-10-27 用户明确调整支持范围：画布与宿主统一仅支持内容视口宽度 ≥1280 CSS px 的桌面浏览器，删除手机／平板布局、助手抽屉、移动工具栏和触屏尺寸分支。该调整仅替代原移动端保留与验收要求，其余桌面功能、视觉、数据及生成行为仍按原边界维护。保留桌面窗口、容器排布、面板调宽、Pointer Events、键盘操作、降低动效与媒体比例。
- `frontend/canvas/` 作为独立子包保留自己的 `package.json`、锁文件、HTML、React root、Provider、CSS、字体、组件和交互实现；宿主统一安装、启动、构建与预览入口。按用户 2026-10-06 的调整，共同声明但版本不同的直接依赖采用宿主依赖版本，源独有依赖继续独立锁定，并处理其兼容依赖；不为画布升级或替换标准前端依赖。依赖对齐后的视觉和行为仍需对照，不能沿用旧版本验收结果作为本次证明。数据库与服务边界接入当前 Python/MySQL/MinIO，源 HTTP 请求复用宿主客户端。
- 无限画布生成回填与助手图操作以源既有直接应用/提议确认为准，不插入创作模式的候选采用步骤。这是用户一比一要求的限定例外；私人参数、任务、凭据、生成历史及对话仍按本人隔离，画布作品按所有者独占的项目权限访问。
- 只有全部布局、操作、媒体、生成、助手与真实运行对照通过后才能声明完整迁移。阶段完成、哈希检查、构建或 API 夹具测试不等于一比一验收；源已禁用的入口保持源状态。
