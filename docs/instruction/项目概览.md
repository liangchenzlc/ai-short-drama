# 项目概览

2026-10-30 正式执行链：Worker 调用 `agent/runtime/executor.py::AgentRuntime.execute`，一次投递完成或恢复完整图；`runtime/agent.py` 是唯一 `create_agent` 工厂，`runtime/lease.py` 管心跳与取消，`runtime/checkpointer.py` 保存图步骤。`runtime/context.py` 定义可信上下文与范围状态，`runtime/middleware.py` 组织公开中间件，`context/graph.py` 装配输入与 Skill；`runtime/model_ledger.py` 管父 Run 预算。`service/assistant/execution/tools.py` 登记及逐工具结算，`interruptions.py` 收尾中断，`results.py` 冻结新 Run 可继承的明确成果身份。设置位于 `api/v1/assistant/settings/preferences.py` 及对应 schemas／service／dao。

AI 短剧工作台：剧本 → 素材 → 分镜 → 成片，配合项目 AI 创作助手与独立无限画布。业务数据以 MySQL 和 MinIO 为准，后端依赖方向是 API → Service → DAO → ORM。

统一轨迹入口为 `agent/runtime/events.py`，展示契约在 `schemas/assistant/operations/trace.py`；`service/assistant/tasks/trace.py` 与 `dao/assistant/execution/trace.py` 复用 AgentEvent 提供有界回看、冻结版本详情与授权归档，路由在 `api/v1/assistant/conversations/trace.py`。前端共用唯一 `types/assistant/trace.ts` 与 `features/assistant/runtime/assistant-trace.ts`，主会话已接具体目标轨迹、子任务展开、日志滚动与冻结详情，刷新和分页继续复用同一投影。

## 当前产品边界

- 账号：邮箱证明注册、登录、重置密码及个人配置；项目仅所有者访问。
- 创作模式：项目直接拥有剧本、故事设定、素材、分镜与成片。剧本支持连续编辑、自动保存和选区改写；素材、镜头与声音保持明确采用及版本校验。
- AI 创作助手：按项目管理会话与任务，支持引用、附件、Skill、补充、停止、续跑、执行轨迹与待答问题。侧栏配置统一管理模型、助手通用权限、账号级长期记忆、个性化指令和独立 MCP 令牌；文字及开关自动保存。用户媒体数量与运行额度已移除，内部预算和实际用量保留。
- 无限画布：独立子包，内部交互与目录保留，宿主接入集中到集成桥。
- 生成任务：RabbitMQ + Celery 按模态执行；任务详情、批量生成与恢复反馈保留在创作场景。
- 主页资产库：本人生成的图片、视频、音频，支持筛选、搜索、分页及预览。
- Skill：独立页面管理内置与个人方法包、导入更新、启停及只读资源预览，见 [Skill API](../api/skills.md)。

已退役：分集、小说／大纲创作链、旧 scope 0–2 会话入口、独立任务中心、成员邀请、跨库共享及 BeefAPI 连接。现行私有候选与明确采用链继续维护。

助手工具由 `agent/tools/{projects,standard,canvas,media_generation,ask_user,resources,skill,memory,context,sandbox,delegation}` 内各文件导出 SPEC，`registry.py` 显式汇总45项能力；业务参数位于 `schemas/assistant/operations`，事务内处理器位于 `service/assistant/operations`。12项业务能力使用 `workbench__` 并可外放MCP，其中4项目录读取仅对MCP可见，内部助手仍为原41项；33项内部能力包括 `runtime__`、7项上游原生代码／文件工具和原生 `task` 工厂元数据，目录不保留旧别名。`task` 的真实对象仅由 `runtime/agent.py` 的 SubAgentMiddleware 提供，子图不装委派中间件；`runtime__ask_user` 与 `runtime__wait_generation` 是真实持久 interrupt 工具。`agent/context/delegation.py` 解析明确交接，`service/assistant/execution/scope.py` 将可信父调用关联到持久子 scope。`agent/sandbox/workspace.py` 管 scope 容器和持久绑定，`backend.py` 复用官方 backend 并接入输出／取消，`resources.py` 管授权交接；scope 查询沿现有 Service／DAO。委派、代码、等待、Skill、记忆及内部资源读取不外放MCP，图片业务读取按独立授权开放，见 [MCP API](../api/mcp.md)。

`core/identity.py` 区分基础业务身份与浏览器会话身份；`service/assistant/operations/invocation.py` 负责可信项目／主体范围和业务幂等回执，DAO 与 ORM 同目录映射。内部执行范围和外部业务入口共用这条业务边界，外部业务调用不创建助手会话或运行记录。

## 数据与运行时

- MySQL 8.0.21+，当前完整结构 121 张表，见[完整 SQL](../database/schema/schema.mysql8.sql)。本轮测试业务数据清理与三张退役表删除见[本轮增量](../database/migrations/2026-10-28-source-restructure/README.md)。
- MinIO 存放私有媒体与方法资源；本轮数据库清理不删除桶对象。签名链接默认五分钟。
- API 及 scheduler、text、image、video、audio、render、agent 八个角色，见[开发运行与验证](开发运行与验证.md)。
- 前端两包由宿主统一安装与构建，宿主路径别名为 @host/。

保存、权限及异步数据流见[系统架构与数据流](系统架构与数据流.md)；测试分级见[按功能执行测试](按功能执行测试.md)。
