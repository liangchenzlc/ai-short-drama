# 项目概览

AI 短剧工作台：从小说／剧本到素材、分镜、成片的创作流水线，加 Agent 创作助手与独立的无限画布子包。业务数据以 MySQL 和 MinIO 为准，后端分层 API → Service → DAO → ORM。

本文只给"有什么、代码在哪"，具体规则见[系统架构与数据流](系统架构与数据流.md)、[实现约定](实现约定.md)与[接口约定](../api/README.md)。

## 当前产品边界

- **账号与归属**：邮箱验证码注册与登录（`auth.py`）。项目由所有者独占，没有成员、邀请和跨库共享。
- **创作模式**（内部标识 `workspace_mode=standard`）：单层项目，流程为小说／剧本 → 素材 → 分镜 → 成片。分集已删除，作品直接属于项目。
- **无限画布**：作为独立子包保留原有交互，见[画布迁移边界](画布迁移边界.md)。
- **Agent 创作助手**：全局助手与创作工具，12 个内置方法包，见[内置创作方法维护](内置创作方法维护.md)。
- **生成任务**：RabbitMQ + Celery 异步执行，按模态分队列；模型配置与凭据按用户隔离。

明确不提供：分集、三层素材库与跨库共享、成员／邀请、旧 BeefAPI 连接。

### 接口分组

`auth`、`projects`、`project_writing`、`assets`、`project_storyboard`、`project_generation`、`project_assembly`、`project_sound`、`ai_generations`、`generation_batches`、`generation_references`、`image_groups`、`media_library`、`personal_resources`、`native_voice`、`user_creation_drafts`、`ai_model_configs`、`agent`、`assistant`、`assistant_memory`、`agent_artifacts`，以及 12 个 `canvas_*` 模块与 `canvases`。逐条契约见[接口约定](../api/README.md)。

## 数据与运行时

- MySQL 8.0.21+，当前完整建表 117 张，脚本为 [`schema.mysql8.sql`](../database/schema/schema.mysql8.sql)；旧库升级走 [`migrations/`](../database/migrations/README.md)。
- MinIO 存放素材、候选、成片与内置方法资源包；私有桶，签名链接默认 5 分钟。
- RabbitMQ + Celery：`scheduler`、`text`、`image`、`video`、`audio`、`render`、`agent` 七类进程，启动方式见[开发运行与验证](开发运行与验证.md)。
- 前端两包（`frontend`、`frontend/canvas`）统一由宿主安装、启动、构建与预览。
