# 项目概览

AI 短剧工作台：从小说／剧本到素材、分镜、成片的创作流水线，加 Agent 创作助手与独立的无限画布子包。业务数据以 MySQL 和 MinIO 为准，后端分层 API → Service → DAO → ORM。

本文只给"有什么、代码在哪"，具体规则见[系统架构与数据流](系统架构与数据流.md)、[实现约定](实现约定.md)与[接口约定](../api/README.md)。

## 当前产品边界

- **账号与归属**：邮箱验证码注册与登录（`auth.py`）。项目由所有者独占，没有成员、邀请和跨库共享。
- **创作模式**（内部标识 `workspace_mode=standard`）：单层项目，流程为小说／剧本 → 素材 → 分镜 → 成片。分集已删除，作品直接属于项目。
- **无限画布**：作为独立子包保留原有交互，见[画布迁移边界](画布迁移边界.md)。
- **Agent 创作助手**：按项目恢复会话与保存目标，创作模式和画布共用输入及 Skill 列表，新任务使用 LangGraph／LangChain、自主 function calling 和按需资源水合，支持 `/` 方法高亮块；新任务支持边界停止及普通消息续跑，旧任务保留原控制，12 个内置方法包，见[内置创作方法维护](内置创作方法维护.md)。
- **生成任务**：RabbitMQ + Celery 异步执行，按模态分队列；模型配置与凭据按用户隔离。独立任务管理已退役，进度与恢复反馈在原创作场景内保留。
- **主页资产库**：本人 AI 图片、视频、音频，按工作台与媒体分类、名称搜索，六列分页与直接预览，不收录手动上传。

明确不提供：分集、三层素材库与跨库共享、成员／邀请、旧 BeefAPI 连接。

Skill 由独立 `/skills` 页面管理：导入、完整包更新、个人启停和目录树只读预览在 `features/skills`，AI 配置旧视图已删除。创建回执核对使用 `/agent/skills/requests/{key}`，契约见 [Skill API](../api/agent.md#内置与个人-skill-管理)。

## 代码地图

| 层 | 位置 | 说明 |
| --- | --- | --- |
| 前端入口 | `frontend/src/app` | 路由、主题、全局样式 |
| 前端页面 | `frontend/src/pages` | `projects`、`assets`、`media-library`、`skills`、`ai-config` |
| 前端业务 | `frontend/src/features` | `projects`、`assets`、`generations`、`image-tools`、`media-library`、`agents`、`ai-assistant`、`skills`、`ai-config`、`auth` |
| 前端接口 | `frontend/src/api` | 统一 HTTP 客户端、请求模块与 DTO |
| 画布子包 | `frontend/canvas` | 自己的 `package.json`、HTML 入口与交互实现，宿主统一安装与构建 |
| 后端路由 | `backend/src/short_drama/api/v1` | 34 个路由模块统一挂在 `/api/v1`，`router.py` 汇总，`test.py` 为测试路由 |
| 后端契约 | `backend/src/short_drama/schemas` | Pydantic 请求／响应模型 |
| 业务层 | `backend/src/short_drama/service` | 业务规则与事务边界 |
| 数据访问 | `backend/src/short_drama/dao`、`domain` | DAO 不自行提交；`domain` 是 SQLAlchemy ORM |
| 模型与提示词 | `backend/src/short_drama/ai` | 适配器、提示词模板（`ai/prompts/<场景>/system.md`）、网关与流式 |
| Agent | `backend/src/short_drama/agent` | `harness` 执行图、`resources` 水合、`context` 装配、`tools` 自主工具、`skill` 方法及 `memory` 五层记忆 |
| 异步任务 | `backend/src/short_drama/tasks` | Celery 任务与渲染、媒体处理 |
| 基础设施 | `backend/src/short_drama/db`、`storage`、`core` | 权限、数据库会话、MinIO、配置与加密 |

当前共享入口：资源范围及画布父校验在 `db/resource_scope.py`、`db/canvas_scope.py`、`db/canvas_resource_scope.py`；时间与方法目录常量在 `core/time.py`、`core/skill_catalog.py`；画布文档转换和 JSON 摘要在 `utils/`。`service/task_runtime_service.py` 持有任务租约与业务联动，DAO 保留 SQL。Agent 的权限、执行围栏、工具契约、来源快照与原生上下文分别有单向依赖模块，详细入口见[代码索引](代码索引.md)。

前端模型配置请求保持在 `api/modules`，DTO 位于 `api/types`；表单与目录转换由 `features/ai-config/config-api.ts` 组合。通用预加载组件通过加载函数与路由组合，不导入业务 API。

> 2026-10-28：`pages/tasks` 及任务中心专用新建表单已删除，旧 `/tasks/*` 地址回到项目列表；`features/generations` 保留创作区复用的任务详情和批量生成。主页资产库由 `pages/media-library/MediaLibraryPage.tsx` 组合筛选与分页，`features/media-library/AssetPreview.tsx` 仅负责预览；列表经 `api/modules/media-library.ts`、`api/v1/media_library.py`、`MediaAssetService` 与 `MediaAssetDAO.history` 查询。

剧本节点由 `pages/projects/episode/SourceStage.tsx` 组合 `features/projects/NovelScriptGeneration.tsx` 与 `script-desk/`：`ScriptDesk` 负责剧本双标签与任务状态，`StorySettingsEditor` 复用资源会话保存四项故事设定，`ScriptSceneEditor` 负责连续编辑与撤销，`ScriptRewriteDialog` 负责范围摘要及要求层，`script-selection.ts` 负责选区几何和字数；`writing-session.ts` 继续管理正文及兼容小说／大纲的串行保存。后端入口为 `project_writing.py`、`project_writing_service.py`、`project_writing_dao.py`，故事设定模型为 `project_story_settings.py`，历史大纲模型为 `project_story_outline.py`；三个 AI 场景统一由 `writing_generation_service.py` 冻结来源及原子回写，提示词在 `ai/prompts/story_outline/`、`script_generate/`、`script_rewrite/`。本页仅提供选区改写，小说／大纲目录和整篇生成入口已移除；历史数据及兼容 API 保留，原 Quill 编辑器与独立 ScriptStage 已退役。

### 接口分组

`auth`、`projects`、`project_writing`、`assets`、`project_storyboard`、`project_generation`、`project_assembly`、`project_sound`、`ai_generations`、`generation_batches`、`generation_references`、`image_groups`、`media_library`、`personal_resources`、`native_voice`、`user_creation_drafts`、`ai_model_configs`、`agent`、`assistant`、`agent_artifacts`，以及 12 个 `canvas_*` 模块与 `canvases`。逐条契约见[接口约定](../api/README.md)。

`project_writing` 提供独立story-settings读取／保存、大纲兼容保存、写作活动任务投影和 script-revisions 摘要／详情／恢复，`ai_generations` 新增大纲／正文生成与局部改写来源，详见[剧本工作台契约](../api/writing-workspace.md)。

## 数据与运行时

- MySQL 8.0.21+，当前完整建表 122 张，脚本为 [`schema.mysql8.sql`](../database/schema/schema.mysql8.sql)；旧库升级走 [`migrations/`](../database/migrations/README.md)。
- MinIO 存放素材、候选、成片与内置方法资源包；私有桶，签名链接默认 5 分钟。
- RabbitMQ + Celery：`scheduler`、`text`、`image`、`video`、`audio`、`render`、`agent` 七类进程，启动方式见[开发运行与验证](开发运行与验证.md)。
- 前端两包（`frontend`、`frontend/canvas`）统一由宿主安装、启动、构建与预览。
