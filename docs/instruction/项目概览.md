# 项目概览

AI 短剧工作台：剧本 → 素材 → 分镜 → 成片，配合项目 AI 创作助手与独立无限画布。业务数据以 MySQL 和 MinIO 为准，后端依赖方向是 API → Service → DAO → ORM。

## 当前产品边界

- 账号：邮箱证明注册、登录、重置密码及个人配置；项目仅所有者访问。
- 创作模式：项目直接拥有剧本、故事设定、素材、分镜与成片。剧本支持连续编辑、自动保存和选区改写；素材、镜头与声音保持明确采用及版本校验。
- AI 创作助手：按项目管理会话与任务，支持引用、附件、Skill、任务补充、停止、续跑、生成成果与明确采用。新任务使用 Harness；仍有效的 V3 旧引擎控制链保留。
- 无限画布：独立子包，内部交互与目录保留，宿主接入集中到集成桥。
- 生成任务：RabbitMQ + Celery 按模态执行；任务详情、批量生成与恢复反馈保留在创作场景。
- 主页资产库：本人生成的图片、视频、音频，支持筛选、搜索、分页及预览。
- Skill：独立页面管理内置与个人方法包、导入更新、启停及只读资源预览，见 [Skill API](../api/skills.md)。

已退役：分集、小说／大纲创作链、旧 scope 0–2 会话入口、独立任务中心、成员邀请、跨库共享及 BeefAPI 连接。现行私有候选与明确采用链继续维护。

## 代码地图

| 层 | 位置 | 组织方式 |
| --- | --- | --- |
| 应用壳 | `frontend/src/app` | router、providers、layouts、styles |
| 页面 | `frontend/src/pages` | projects/list、projects/workspace、creation 四阶段、identity、ai-config、skills、media-library；页面目录以 index.tsx 为入口 |
| 业务功能 | `frontend/src/features` | creation、assistant、projects、identity、generations、ai-config、skills、media、canvas-integration；模块内继续按能力划分 |
| 请求 | `frontend/src/api` | 唯一 http.ts，其余按业务／具体功能组织 |
| 类型 | `frontend/src/types` | DTO、Props、状态及会话类型按业务／功能集中管理 |
| 公共能力 | `frontend/src/shared` | ui、async、navigation、media；不依赖业务 API 与功能模块 |
| 画布集成 | `frontend/src/integrations/canvas` | assistant、contracts、session、image-tools，屏蔽宿主内部布局 |
| 画布子包 | `frontend/canvas` | 宿主统一安装、启动与构建，内部结构见[画布迁移边界](画布迁移边界.md) |
| HTTP／注入 | `backend/src/short_drama/api/v1`、`api/dependencies` | 按业务及功能组织；router.py 聚合，不写业务规则 |
| 后端业务层 | `backend/src/short_drama/service` | 按业务／功能划分，Service 管事务，复杂能力再拆生命周期 |
| 数据访问与模型 | `backend/src/short_drama/dao`、`domain` | 同业务目录；DAO 不提交，domain 是 ORM 结构来源 |
| 请求响应契约 | `backend/src/short_drama/schemas` | Pydantic，按业务与功能细分 |
| 模型调用 | `backend/src/short_drama/ai` | adapters 按模态／协议、gateway 按传输／能力、prompts 按场景 |
| 助手执行 | `backend/src/short_drama/agent` | harness、runtime、gateway、context、resources、tools、task、memory、skill |
| 后台任务 | `backend/src/short_drama/tasks` | assistant、generations、canvas、identity、rendering、runtime；显式 Celery 任务名保持稳定 |
| 基础设施 | `backend/src/short_drama/db`、`storage`、`core` | access／scope、会话、MinIO、配置、日志与异常 |

完整目录、拆分理由和搬迁查询方式见[目录与职责维护](目录与职责维护.md)；关键调用链见[代码索引](代码索引.md)。

## 数据与运行时

- MySQL 8.0.21+，当前完整结构 119 张表，见[完整 SQL](../database/schema/schema.mysql8.sql)。本轮测试业务数据清理与三张退役表删除见[本轮增量](../database/migrations/2026-10-28-source-restructure/README.md)。
- MinIO 存放私有媒体与方法资源；本轮数据库清理不删除桶对象。签名链接默认五分钟。
- API 及 scheduler、text、image、video、audio、render、agent 八个角色，见[开发运行与验证](开发运行与验证.md)。
- 前端两包由宿主统一安装与构建，宿主路径别名为 @host/。

保存、权限及异步数据流见[系统架构与数据流](系统架构与数据流.md)；测试分级见[按功能执行测试](按功能执行测试.md)。
