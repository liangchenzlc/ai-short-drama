# 创作模式维护说明

## 产品与接口

创作模式内部继续使用 `workspace_mode=standard`，无限画布使用 `infinite_canvas`。项目就是一部作品，新建仅填写名称和模式，成功后直接进入剧本创作、资产生成、分镜制作、成片预览四阶段。不存在分集或隐藏分集。名称允许重复，去除首尾空格后为 1–120 字符；模式创建后不可修改。

工作台保留项目名称原位编辑、阶段导航、保存状态、助手和返回列表。Enter 或失焦保存名称，Escape 取消；版本冲突保留输入。项目梗概、项目画幅、项目风格和手动归档均已取消，创建与读取不再包含这些字段。

项目卡片在新浏览器标签页打开，名称、最近打开日期及三点更多按钮同行；更多菜单提供删除项目。删除前确认，使用 `row_version` 核验，409 后保留窗口并要求重新核对、再次确认。素材与分镜卡片同样提供更多菜单删除，先保存相关编辑及私人生成参数；被分镜引用的素材不能删除。分镜删除同时校验行版本与列表版本，保留历史媒体、已有成片片段及已受理任务，迟到结果不能恢复镜头。项目和分镜使用现有软删除字段，无需数据库结构迁移。

项目、全局及个人角色／场景／道具素材库、跨库共享、成员与邀请不再提供。流程内素材直接属于项目，继续保留角色、场景、道具、图片组、分镜关联、上传和私人参考图。媒体资产库、本人媒体复制和画布自身资产功能保留。两种模式的项目均由所有者独占。

画布不再绑定创作项目，不读取其小说、章节、角色目录或画风。自身 `workspaceProjectId`、普通角色节点、私人画风、上传、绘图、时间线和生成保留。旧包若携带退役来源绑定，应明确拒绝导入，避免恢复已取消的业务关系。

| 对象 | 接口前缀／存储 |
| --- | --- |
| 项目创建 | `POST /api/v1/projects`，仅 `name/workspace_mode` |
| 项目改名 | `PATCH /api/v1/projects/{id}`，`name/row_version` |
| 项目删除 | `DELETE /api/v1/projects/{id}?row_version=版本`，成功 204 |
| 创作内容 | `/api/v1/projects/{id}/...`，沿用写作、分镜、声音、成片操作后缀 |
| 故事设定 | `project_story_settings`，独立`row_version`及四个字符串字段 |
| 小说／大纲／剧本 | `project_novels` / `project_story_outlines` / `project_scripts` |
| 成片／任务 | `project_assemblies` / `project_assembly_clips` / `project_render_jobs` |
| 私人草稿 | `(user_id, project_id, object_id, purpose)`；小说对象为项目 ID |

正文、分镜、任务、快照、Agent、生成回填和恢复均以项目为归属。项目拥有 `editing_script_id/content_version/storyboard_version`；对外 ID 与版本仍为十进制字符串。自动保存、409 保稿、幂等受理核对和私人数据隔离继续生效。

## 剧本编辑与阶段名称

`TopStepNav` 现为左侧固定40px满高图标导航，依次进入剧本创作、资产生成、分镜制作、成片预览，Tooltip说明名称；原source/assets/storyboard/assembly路径及数据归属不变。资产侧栏为“资产库”、分镜侧栏为“分镜表”，以ResourceViewToggle统一双视图；列表行与底部创建均高45px。主页面不再提供素材／分镜提取入口，历史生成结果、恢复和采用保留。

`ScriptDesk` 标题为“剧本”，提供故事设定和剧本正文双标签，最大宽960px，编辑区与两侧统一同色。StorySettingsEditor的四个输入框使用独立ResourceEditingSession，经story-settings接口保存；版本、恢复和保存状态与正文隔离，不把旧大纲当作故事梗概。ScriptSceneEditor继续使用单个textarea与连续同度量文字层，保留前言、场头、空白、跨场选区、中文输入法和会话撤销。隐藏标签、切换阶段及展开助手保持编辑器挂载；当前标签内容内部滚动，去掉固定字数／撤销行。

> **2026-10-28 界面调整：** 剧本页已移除“让助手起草剧本”和“最近变更”按钮及专属前端代码；下段关于标题保留“最近变更”的说明为历史实现。服务端变更快照及兼容API继续保留。

非空剧本保存即发布并保持内部唯一确认，清空正文不回退旧稿。选中文字点击“AI 改写”或按Ctrl/Cmd+K，核对范围、摘要、要求及实际文本模型；先保存正文，再冻结Unicode码点区间，服务端只参考选区及前后各2000码点，成功精确替换，一次撤销还原。标题保留最近变更，移除TXT导入和导出；历史导入快照与兼容API仍保留。格式工具栏、右侧创作栏、候选比较和采用／确认入口继续不展示。

写作任务复用通用文本队列，改写期间整篇正文只读，进度和停止位于标题行；离开不取消，刷新恢复活动任务。故事设定不受正文任务锁影响，仍须通过自己的版本校验。受理不明保留原体原键，失败、迟到或取消不覆盖正文；409保留本机输入。AI创作助手沿用原入口及能力。接口见[剧本工作台](../api/writing-workspace.md)，本次仅新增[故事设定表](../database/migrations/2026-10-28-story-settings/README.md)，不迁移旧业务数据。

## 项目助手与输入区

`CreativeAssistantPanel` 以账号和项目为会话范围，项目内四阶段共用会话选择；跨项目分别恢复。`EpisodeCreationWorkspace` 统一使用桌面停靠助手，最低内容视口宽度为 1280 CSS px。助手默认 380px，可拖动左边界在 320–560px 调节，实际最大值为容器扣除 640px 编辑空间及间距；方向键每次 16px，Home／End 到边界。`creation:assistant-width` 通过账号 storage 保存本机偏好；不再按设备或视口切换抽屉，助手与生成设置可以同时打开。

模型旁依次是添加、Skill 图标。添加菜单只列图片、文本、当前画布和资产库；创作模式显示但禁用当前画布项，提示“仅画布模式可用”。`AssistantSkillPicker` 是锚定列表内容，支持搜索、加载更多、最多 8 项多选，`/ → 浏览全部 Skill` 共用；`/名称` 支持方向键及 Enter 确认，选择后移除命令文字，在 Sender 内显示可移除高亮块；不要恢复旧选择弹窗或把维护表单放回输入区。

任务设置、管理任务引用和记忆管理按钮及弹窗、“独立新任务”下拉框均已移除，隐私说明和附件展开行亦不显示。用户消息下不显示编辑、重新回答或修订操作。回复期间 Sender 的发送按钮切换为停止图标；底部不再显示运行控制行、“补充当前任务”及独立继续按钮，等待回复的三个点按顺序渐变，降低动效偏好下静止显示。停止后直接发送新要求，保留原任务目标、引用、附件和方法，新消息可表达补充或改变方向；完成后自动开始新任务。已选引用仍能主动刷新、移除及定位来源，已选附件与方法仍能移除；上传重试、原请求核对、停止／继续／排队及草稿恢复须保留。后台自动记忆和摘要继续执行，前端过滤内部记忆操作轨迹。

停止后的新消息先经普通消息入口保存，继续意图及发起时的 `control_seq` 随 `AssistantPendingSend.resume` 冻结。消息受理后以其 `message_id` 发起 resume，复用原消息，不产生“继续任务”气泡；恢复控制在原记录清理前保持可核对，确定的 4xx 拒绝清除本次继续记录，其他标签页的新停止不能被旧继续覆盖。

新任务自动绑定当前项目保存目标及项目设定，画布另绑定发起时的当前画布；已有任务的补充保持原目标。绑定与权限由 `AssistantTaskService` 在幂等回执查询后校验，前端切页不得改写原请求。历史未绑定项目的 V3 保留原身份，不自动归到当前项目。接口和增量见[助手 API](../api/assistant.md)、[项目会话迁移](../database/migrations/2026-10-22-project-assistant/README.md)。

## 成片输出尺寸

成片导出设置接受 `auto/16:9/9:16`，默认 `auto`，两种保存入口均携带 `aspect`。自动模式按实际输出顺序选择首个参与导出的分镜视频，无分镜视频时选择首个导入视频；完全没有视频时使用 16:9。排除的片段不参与选择。

宽高来自服务端媒体探测，包含旋转和像素宽高比修正。自动模式保留方形、4:3 等真实比例，720p／1080p 分别将短边设为 720／1080 并取偶数，合成预览短边为 360。视频尚未探测完成时等待，探测失败显示错误，不猜测比例。显式选择不受同步、探测或排序覆盖。

受理导出时冻结 `output_width/output_height/output_source`；Worker 使用同一快照渲染。预览按相同比例缩小。默认等比补边，用户选择 cover 才裁切。普通保存与原子多轨保存保持同样契约。

## 离线切换与恢复

本次允许清空两种模式的业务测试数据，不迁移旧作品。保留账号与会话、注册／找回密码证明及邮件、模型配置、模型偏好、渠道映射、账号级画布偏好、个人 Skill 和个人画风。

个人画风若引用将被清理的项目媒体，按用户分别复制为私人媒体，并更新快照和引用；不同用户不共用新媒体身份。备份包含完整数据库、引用对象、摘要、执行 DDL 和保留数据校验。备份可能含凭据密文或私人内容，只能保存在本机忽略目录。

在 `backend/` 执行；数据库账号需能创建、删除隔离测试库及修改当前业务库。脚本只从当前工作目录 `.env` 取设置，不自动切换其他库。以下目录替换为本次独立备份目录，`--database` 必须与配置完全匹配。

```powershell
uv run python scripts/creation_mode_reset.py plan
uv run python scripts/creation_mode_reset.py backup --directory ../.runtime/creation-mode/database-backup --database short_drama --offline
uv run python scripts/creation_mode_reset.py rehearse --directory ../.runtime/creation-mode/database-backup --database short_drama --offline
uv run python scripts/creation_mode_reset.py apply --directory ../.runtime/creation-mode/database-backup --database short_drama --offline
```

执行顺序：停止新增提交，核清在途与受理不明任务，停止 API、scheduler 和全部 Worker，再备份。受理不明的付费请求不自动重发。先成功恢复到随机 `_test_creation_*` 库并重建、核对保护数据与外键，才允许重建原库。备份后原库有任何变化即拒绝切换。脚本拒绝未声明的额外业务表。

切换后所有服务使用同一个新的 `GENERATION_QUEUE_NAMESPACE`，各角色仍使用不同 Snowflake worker ID。旧命名空间保留到验收，禁止直接清空 RabbitMQ 实例。代码、完整 SQL、锁文件及本机配置与原 `ENCRYPTION_KEY` 需一起备份。确认同版服务正常后，`prune` 仅删除备份清单中已不被当前数据库引用的旧对象，不清空 bucket。

```powershell
uv run python scripts/creation_mode_reset.py prune --directory ../.runtime/creation-mode/database-backup --database short_drama --offline
```

DDL 不能事务回滚。失败时保持服务停止，使用 `restore` 恢复同点数据库与对象，并恢复同点代码、配置和旧队列命名空间后启动；只回退代码不构成恢复。

```powershell
uv run python scripts/creation_mode_reset.py restore --directory ../.runtime/creation-mode/database-backup --database short_drama --offline
```

实际切换结果、验证及限制记录在[本次迁移记录](../database/migrations/2026-10-21-creation-mode/README.md)。历史协作和分集迁移仅供旧版本维护，不可叠加到本版新库。
