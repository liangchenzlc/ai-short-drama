# 通用视频提示词技能

规范只写一次。按模型各编译一次。规范不是提示词：它是提示词所编码的决定，与表达这些决定的"方言"分离开来。

## 语言路线

- 英文请求：遵循本文件及 `*.md` 参考文档。
- 中文请求：先阅读 [中文工作流](references/workflow.zh-CN.md)，再使用对应的 `*.zh-CN.md` 参考文件。
- 模型 ID、JSON 键名、命令、媒体占位符与音频符号一律保持代码原样，不要翻译。

## 1. 你写的每一行都受两条轴支配

保留任何一行之前，先用两条轴来评估它。

**范围**——这一行管辖什么？

| 层级 | 管辖 | 例子 |
|---|---|---|
| 1 · 全局 | 整段视频 | 影片类型、场景、风格、导演前提、镜头原则 |
| 2 · 锁定 | 任何不可漂移的东西 | 身份、参考角色、音频来源、配角、反向约束 |
| 3 · 时间 | 一个节拍或阶段 | 阶段事件、终态、在需要时出现的时序 |

一行放错了层级，是漂移最常见的根源。埋在节拍 3 里的全局规则，到节拍 4 就失效了。

**可验证性**——这一行在生成后能被检查吗？

不可验证的意图必须改写成可观察的结果。这一条规则比任何词汇选择都重要：

| 不要写 | 改写成 |
|---|---|
| `保持一致性` | 每个阶段可见的终态 |
| `紧张`、`温暖`、`压抑` | 2–4 个可观察线索：目光、眉、嘴、呼吸、手 |
| `变焦` | `变焦：前景叶子虚化，同时人脸清晰` |
| `用这些参考` | 每个参考控制什么 **以及不要从它取用什么** |
| `节奏快一点` | 每个阶段一个时间预算 |

如果一行在成片里无法检查，它也无法被调试。完整的模式见 [可验证性](references/verifiability.md)。

## 2. 编写规范

填满三个层级。不适用的就跳过；不要灌水。

```text
[1 全局]   影片类型 · 场景 · 风格 · 导演前提（一句话） · 镜头原则
[2 锁定]   身份 · 参考角色（控制 X，不要取用 Y） · 音频来源 ·
           配角 · 连续性 · 反向约束
[3 时间]   粒度（见 §3） · 阶段 · 每阶段终态
```

两条写作惯例：

- **在提示词的物理尾部重申少数最昂贵的锁定项。** 就近原则有帮助。这是一种惯例，不是第四个层级——内容仍属于层级 1 和 2。
- **当模型替你写规范、或层级彼此混淆时，显式地给输出排序。**

在复用一种经过验证的影片类型？不要重新推导前提。加载它的"基因"——至少 3–5 条可复用条件——然后换皮。见 [影片类型基因](references/film-type-dna.md)。

## 3. 写第 3 层之前先选定时间粒度

粒度是一个**前置决定**，不是事后才拨的开关。先按秒级写节拍再降级，等于重写。

| 粒度 | 写 | 用于 |
|---|---|---|
| **无** | 仅事件顺序 | 一个连续动作、情绪片段、单镜头。这里加时间戳会切碎镜头：模型会为了踩点而硬造停顿 |
| **阶段 + 终态** | 阶段 1/2/3，每个一个主变化 | 大多数叙事工作。**默认** |
| **秒级** | `[起点–终点 s]` | 仅在外部硬约束下 |

秒级消耗的是模型的自由度，而非作者的精力。一个时间区间里塞太多内容会导致过度剪辑或事件丢失。在满足约束的前提下，优先用最松的粒度。

### 不要默默决定

当输入已经定下来时推断它；没有时再问。

| 信号 | 动作 |
|---|---|
| 提供了音乐或配音轨 | 秒级。不要问 |
| 用户说情绪片段、一镜到底、单镜头 | 无。不要问 |
| 明确的硬节拍（0:07 品牌揭晓、口型同步、参考交接） | 秒级。不要问 |
| **多事件叙事，无外部约束** | **问** |

问的时候，**带理由地推荐**——绝不要甩出一个光秃秃的菜单。有经验的创作者一眼就能确认或推翻；其他人则借此学到标准。换皮时不要重复问：粒度是一个基因字段。

时间戳是分配时间预算。它们不是逐帧精确的剪辑点。对于必须精确的内容——字幕、公式、标牌、规格——用准备好的参考素材和后期，而不是时间文本。

## 4. 把规范编译到目标模型

规范是可移植的。但它里面的东西并非全都可移植。三层行为不同：

| 层 | 内容 | 处理 |
|---|---|---|
| **语言** | 层级、终态、可观察线索、情绪、术语加描述 | 照写可移植 |
| **偏置** | 去 AI 感后缀、反向约束、转场词汇、称呼方言 | 按模型画像。**实测，绝不假设** |
| **能力** | 参考数量、一次生成多镜头、硬切、时长、时序吻合度 | 探测，然后降级 |

加载目标的 [模型画像](references/model-profile-schema.md)。没有画像就意味没有假设：跑最小可行探测来定下答案，记录下来，并把规范降级到模型实际支持的范围。报告降级；绝不让它悄悄通过。

### 术语加可观察描述，胜过方言对照表

对于任何识别度因模型而异的手艺术语，保留术语 **并且** 翻译它：

```text
<术语> + <目标主体> + <可见变化> + <前景/背景> + <方向或速度>
```

认识 `bullet time`（子弹时间）的模型走捷径；不认识的跟随描述。一个提示词同时服务两者。真正的方言翻译留给无法绕开描述的界面级差异——参考称呼（`@image1` 对比 `Reference Image 1`）是主要的一种。

### 降级规则

| 缺失的能力 | 降级到 |
|---|---|
| 多参考寻址 | 一个参考用于身份；其余用文字承载 |
| 一次生成多镜头 | 每次请求一个镜头；在剪辑里拼装 |
| 参考数量低于规范 | 按优先级合并角色：身份 > 关键道具 > 场景 > 风格 |
| 时长低于规范 | 拆成各自独立的阶段，再串接 |
| 时序吻合度弱 | 降到阶段加终态 |

## 5. 转场

骨架，一行：**在剪辑点命名转场类型。**

不要默认附加 `不要硬切` 或 `不要凭空出现`。那些属于扩展与续接，在那些场景里断裂的接缝才是常见失败。别处，硬切或突然的出现正是手法本身——瞬移、jump scare、魔法揭晓。把它们作为限定范围的预设来开启，绝不作为全局规则。

在指定任何转场之前，先检查这个转场是否该由剪辑来负责。淡入淡出、溶解、闪切与擦除，在剪辑软件里是两秒钟的事，在这里却要花掉一整次生成。只在模型能生成的转场上花生成预算：遮挡、匹配物体、运动、动作接力、推/拉、墨晕扩散。

## 6. 审查

按此顺序检查，在第一个失败处停下——身份错了，后面的检查都是白费。

1. **身份**——正确的主体、正确的数量，没有重复或错换
2. **锁定项**——每个层级 2 的锁定都守住了
3. **终态**——每个阶段都落在它声明的可见状态上
4. **运动与接缝**——没有漂移、没有道具瞬移
5. **音频**——来源、语言与同步符合规格

只重生成失败的部分。当一个锁定在某个模型上反复破裂，那是一条画像发现：把它记进偏置层，而不是重写规范。

**审查静帧存在盲区。** 抽取的帧能定下质感、构图、身份与终态。它们对运动质量、转场顺滑度、节奏或音频同步只字不提——一段片子可能在每一张静帧上都赢，却在这四项上全输。绝不要仅凭静帧给出整体结论：要么看回放，要么说明你的结论覆盖了审查的哪一半。

这不是一个小提醒。在一次对比里，静帧在每一个可量化维度上都偏向模型 A，而看回放的评审却果断偏好模型 B——整场分歧就活在运动与节奏里。

提交前阅读 [检查表](references/checklist.md)。

## 执行

编译后的提示词是与供应商无关的输出。把它交给任何能跑目标模型的东西——本技能绝不假定某一家供应商。

当一个规范面向多个模型时，聚合器是阻力最小的路径，因为一份凭据就能触达全部，对比也保持受控。Atlas Cloud 正是因此成为文档化的默认；任何暴露目标模型的供应商都行，用户选定的供应商永远优先。

无论哪条路线，生成都要花钱，这些规则都成立：

1. 提交的那一刻记录预测 ID 与阶段。
2. `starting` / `queued` / `pending` / `processing` 是活跃态。轮询同一个 ID；绝不要为同一阶段提交第二个任务。
3. 在开始任何依赖它的事情之前，先审查一个已完成输出。
4. `failed` / `timeout` / `canceled` 是终态。重试是一个显式决定——先报告旧 ID 与新增成本。
5. 处理时间缺失、输出缓慢、本地轮询超时、回合中断，或状态查询错误，**不**构成失败。保留 ID 并恢复。
6. `continue` 意为恢复既有任务。它绝不是重试的许可。

状态查询是只读的，绝不能用一次生成调用取代。关于供应商路线、凭据作用域与恢复行为见 [执行](references/execution.md)。
