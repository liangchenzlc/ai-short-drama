# 诊断：五类 AI 味与对应手段

写提示词之前必须先定位。定位错了，加多少词都没用——**用提示词去修结构缺陷，或者用重绘去修渲染残留，都是白干。**

## 一、先分清「可以提示词修的」和「修不了的」

| 类型 | 典型症状 | 提示词能修吗 | 手段 |
| --- | --- | --- | --- |
| A 皮肤响应 | 塑料、蜡像、磨皮、全脸均匀反光、毛孔被抹平 | 能 | 皮肤段提示词 |
| B 光与空间 | 人脸和背景不是一套光、贴片感、阴影方向不一致 | 部分能 | 光段提示词 + 局部重绘 |
| C 材质 | 衣料像色块、无织纹、发丝成块、饰品穿模 | 能 | 材质段提示词 |
| D 渲染残留 | 全画面同等锐利、HDR 感、噪点全无、边缘光晕 | 部分能 | 提示词弱化 + 可选后处理 |
| E 结构缺陷 | 手指多/粘、牙齿连成条、耳朵变形、瞳孔不圆 | **不能** | 局部重绘或弃图 |

> 依据：`photorealistic-skill/references/defects.md` 把缺陷分成 People / Scene / Finish 三组，并明确"Fix"列里结构类走 inpaint、渲染类走 degrade，两者不能互换。

## 二、A 类：皮肤响应（90% 的"塑料感"在这里）

### 判定
100% 放大看三个位置：
1. **鼻翼**：有没有毛孔。没有 → 磨皮。
2. **额头**：是不是一片均匀高光。是 → 油光/蜡感。
3. **面颊与脖子交界**：色号是否一致且连续。断层 → 磨皮+贴片。

### 三种典型状态

| 状态 | 特征 | 提示词方向 |
| --- | --- | --- |
| **磨皮型** | 皮肤像磨砂、无毛孔、边缘发虚 | 恢复区域性微细节，按对焦衰减 |
| **蜡像型** | 有反光但反光均匀铺满全脸 | 把反光收成"有边界的小高光"，只落在朝光面 |
| **噪点型** | 毛孔像平铺的噪点、全脸一样密 | 减密度、按区域分配（颊柔鼻清） |

### 关键原则（这条最容易做错）

**不要用"脏"来制造真实。** 加雀斑、加痘印、加统一颗粒、加深皱纹，得到的是另一种假。
上游明确禁止：`Do not manufacture realism with dirt, darkness, coarse pores, uniform grain, random color patches, or exaggerated facial lines.`

正确的三件事：
1. 低频肤色干净连续
2. 高光有边界、只出现在朝光面
3. 微细节按区域/对焦/光照分配，不全脸均质

> 依据：xxg-portrait-rebuild-light「Apply Optical Skin Realism」三条信号定义。

## 三、B 类：光与空间（贴片感）

### 判定
遮住背景只看人物剪影，再放开：
- 人物主光方向 ≠ 背景光源方向 → 贴片
- 人物色温恒定（不管环境冷暖） → 贴片
- 地面/墙面颜色没有反到下颌、鼻翼、衣料暗部 → 贴片

### 处理顺序
**先判断是否在 L1 范围内。** 用户只说"去 AI 味"时，光向是锁死的，只能优化"光的响应"，不能改"光的方向"：

| 允许（L1） | 不允许（需用户明确要求，属 L3） |
| --- | --- |
| 让高光贴合现有光源方向 | 把正面光改成侧光 |
| 补一点环境反光到下颌 | 新增轮廓光 |
| 统一人物与背景的色温关系 | 整体换色调（黄昏/冷调） |

> 依据：xxg-portrait-rebuild-light 在 `texture-only` 下强制 `L0 + E0`，即"preserve the source lighting, highlight placement, exposure, white balance"；只有用户选择 `relight-and-skin` 才授权改光。

## 四、C 类：材质

### 判定
- 衣料：放大看有没有织纹/纤维方向；褶皱是不是只有明暗没有结构
- 发丝：是"根根分明"还是"成块抹平"；发梢是否糊进背景
- 配饰：金属有没有高光形状，边缘有没有穿模

### 处理
材质真实感靠**结构**，不靠"高级"：
- 织纹可见 + 褶皱有方向 + 边缘有细微磨损
- 发丝分区：发根密、发梢虚、边缘有碎发
- 金属高光呈条状，不是一片

## 五、D 类：渲染残留

### 判定
- 缩到 25% 看：整张像"渲染图"而不是照片
- 放大看边缘：有一圈亮边（锐化光晕）
- 暗部：完全无噪点（真实照片暗部一定有噪点）

### 处理
1. 提示词里去掉 `8K`、`超写实`、`HDR`、`极致细节`
2. 加"细节随对焦衰减，不要全脸同等锐化"
3. 仍不改善 → 可选后处理（见 `post-process.md`），但**颗粒只能掩盖过锐，不能制造质感**

## 六、E 类：结构缺陷

**提示词改不了。** 判定即分流：

| 缺陷 | 处理 |
| --- | --- |
| 手指数量/关节错 | 局部重绘该区域，或裁掉/遮挡 |
| 牙齿粘连/数量错 | 局部重绘嘴部，或换闭合嘴型 |
| 耳朵变形/耳环穿模 | 局部重绘单侧，对齐另一侧 |
| 瞳孔变形/双眼不对称 | 局部重绘眼部 |
| 肢体穿模、多人肢体归属错 | 结构性问题，通常弃图 |

上游的做法是"选结构缺陷最少的那张，而不是最好看的那张"，且结构缺陷优先局部 inpaint，不重写提示词。

> 依据：photorealistic-skill「Step 3 — Review and fix」：local defect → inpaint only that region；global defect → rewrite the prompt；以及 defects.md 的 Fix 列。

## 七、强度分档

同一张图，改动强度不同，风险不同。**默认从"轻"开始**：

| 档位 | 皮肤 | 材质 | 适用 |
| --- | --- | --- | --- |
| **轻** | 只收高光边界、恢复鼻翼毛孔 | 只补织纹 | 已经不错、只差一口气 |
| **中**（默认） | 区域性微细节 + 哑光化 | 织纹+褶皱方向 | 明显塑料感 |
| **重** | 重建皮肤响应（高风险） | 材质重建 | 整张像渲染图，且接受重绘风险 |

**重档的风险**：越接近"重建"，越容易顺手把脸也重建了。做重档时必须只涂材质区域，不要整图。

## 八、诊断输出格式

诊断完先给用户一句话结论，再给方案，不要直接甩提示词：

```
诊断：A 类（磨皮型）+ C 类（衣料无色块纹理）
范围：L1 质感，不动光、不动构图
方案：整图编辑（画框锁）+ 皮肤段与材质段重写
风险：面颊毛孔可能被写成噪点，验收时重点看这一项
```
