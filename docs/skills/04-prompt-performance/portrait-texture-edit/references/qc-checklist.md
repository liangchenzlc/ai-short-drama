# 验收清单：先查越界，再查质感

顺序不能反。**改坏了但变好看了，依然是失败。**

## 一、越界四项（任一不过 = 弃图）

| # | 检查 | 怎么查 | 判定 |
| --- | --- | --- | --- |
| 1 | **同一个人** | 原图与结果并排，核：痣/疤位置、耳形、发际线形状、眼距、下颌角 | 任一处对不上即失败 |
| 2 | **画框没变** | 叠图对比构图；核宽高比 | 比例漂移 > 5% 即失败 |
| 3 | **背景没重画** | 看背景里的小物件、文字、反光位置 | 有新增/消失/变形即失败 |
| 4 | **光向没变** | 看阴影落在哪一侧、高光在哪个面 | 阴影换边即失败 |

> 依据：xxg-portrait-rebuild-light「Preserve the Frame」与「Preserve the Identity Signature」；比例容忍 ≤5%。
> 身份六组：脸型轮廓与比例 / 五官间距形状 / 发际线与发量 / 皮肤固有标记 / 妆容配饰 / 年龄与表情。

**这一关不过，不要进入质感检查。** 质感再好也不能用。

## 二、质感三项

| # | 检查 | 合格标准 | 不合格表现 |
| --- | --- | --- | --- |
| 1 | **毛孔** | 100% 放大能看见，且**分布不均**——面颊柔、鼻翼略清 | 看不见（还在磨皮）/ 全脸一样密（变成噪点） |
| 2 | **反光** | 只出现在朝向主光的平面，有边界 | 全脸一层油 / 完全无高光（死板） |
| 3 | **材质** | 衣料有织纹与褶皱方向；发丝不成块；金属高光呈条状 | 色块 / 抹平 / 一片反光 |

> 依据：xxg-portrait-rebuild-light「Apply Optical Skin Realism」三点——clean continuous tone、bounded specular、region-specific microdetail。

## 三、副作用清单（出现即返修）

| 副作用 | 长什么样 | 原因 |
| --- | --- | --- |
| 过度锐化 | 边缘有亮边、毛孔像沙粒 | 提示词里有 `8K/超写实/极致细节`，或后处理锐化过头 |
| 磨皮回潮 | 比原图还滑 | 提示词里出现"细腻/光滑/无瑕" |
| 色偏 | 整体偏黄/偏青，或只有脸变色 | 多轮编辑累积；或白平衡被顺手改了 |
| 接缝 | 局部重绘区域边缘有一圈 | 遮罩边界太贴、内外锐度不一致 |
| 蜡感 | 有反光但反光均匀铺满 | 高光没写"有边界" |
| 贴片感 | 人物像贴上去的 | 光向或色温与背景脱节（超出 L1 范围，需用户授权） |
| 假细节 | 满脸雀斑/颗粒，比原图脏 | 违反了"不造脏"原则 |

## 四、评分与决策

四项越界 + 三项质感，每项 0/1 计分：

- **7 分**：通过
- **越界项有 0**：直接弃图，不要试图"修回来"
- **越界全过、质感缺 1–2 项**：只针对缺的那项重跑一轮，不要重写整段提示词

> 依据：xxg-portrait-rebuild-light「Validate the Result」——先看正常尺寸下的整体读感，再验身份/姿态/光学/画框是否稳定；"If a result is nearly unchanged, strengthen one observable target"，即只加强一个目标，不追加指令。

## 五、多轮编辑的额外检查

做到第二轮以上，加查两项：

- [ ] 肤色是否比原图更黄/更灰（累积色偏）
- [ ] 暗部是否越来越干净（累积降噪，真实照片暗部一定有噪点）

出现任一项，就换回**最初原图**作为基准重来，不要在当前结果上继续叠。

> 依据：xxg-portrait-rebuild-light `multi-round-repair`——"use the latest accepted edit as the target and the first root base as the stable identity/geometry/color reference"。

## 六、交付说明该写什么

给用户的结论只写三句：

1. 做了哪一级（L1 质感 / L2 影调 / L3 光效）
2. 越界四项是否全部通过
3. 还差什么（例如"面颊毛孔仍偏均匀，建议只对颊部再做一次局部重绘"）

不要用"质感大幅提升"这类无法验证的话。
