# 可选补强：渲染残留处理

**这不是默认步骤。** 先确认模型侧已经把提示词做到位，再考虑这里。

## 一、什么时候才用

只在三种情况下用，其余情况跳过：

1. 模型输出的画面**全画面同等锐利**，边缘有明显锐化光晕
2. 暗部**完全无噪点**，看起来像 3D 渲染
3. 提示词已经改到第三轮，质感都对，只差"降渲染感"这一口气

不适合用的场景：
- 皮肤还假 → 回提示词层，不要用滤镜掩盖
- 结构有问题 → 局部重绘，滤镜救不了
- 有贴片感 → 是光向问题，超出质感范围

## 二、三条硬限制

| 限制 | 原因 |
| --- | --- |
| **不得裁切、缩放、旋转、扩图** | 会改变景别与构图，直接违反画框锁 |
| **不得改变输出尺寸与宽高比** | 上游对本技能链路的容忍阈值是漂移 ≤5% |
| **不得用颗粒"制造质感"** | 上游明确禁止用 uniform grain 制造真实感；颗粒只能掩盖过锐，不能当质感来源 |

> 依据：xxg-portrait-rebuild-light "Do not manufacture realism with … uniform grain"；`Preserve the Frame` 要求保持 aspect ratio 与 subject-to-frame scale。
> 另注：xxg 原技能严格禁止用 Pillow/OpenCV/FFmpeg 产出最终图，只允许做只读审计。本技能放宽为"允许保守补强"，**风险由此引入**，所以限制写得比上游更死。

## 三、只做两个动作

### 动作一：降锐化（首选，也常常是唯一需要的）

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| Camera Raw / Lightroom | Texture −15 ~ −20 | 只压中间频率，不动边缘 |
| 同上 | Clarity −10 ~ −15 | 压局部对比，去"精修感" |
| FFmpeg | `unsharp=5:5:-0.5:5:5:0` | **负值 = 柔化**，这是 ffmpeg 里少数能降锐的写法 |

### 动作二：轻压对比（可选，仅当画面发"硬"）

| 工具 | 参数 |
| --- | --- |
| Camera Raw | Contrast −5、Dehaze −5 |
| FFmpeg | `eq=contrast=0.98:saturation=0.98` |

## 四、FFmpeg 参考命令（尺寸不变）

```bash
ffmpeg -y -i in.png -vf "eq=contrast=0.98:saturation=0.98,unsharp=5:5:-0.5:5:5:0" -q:v 2 out.jpg
```

- 不加 `scale`、不加 `crop`、不加 `pad`
- `-q:v 2` 是高质量 JPEG；要无损就用 PNG 输出
- 处理前先记下原图分辨率，处理后核对一致

## 五、颗粒：能不加就不加

如果你确实要加（例如交付要求"胶片感"），守住三条：

- 强度低于肉眼可辨：`noise=alls=5:allf=t` 起步，不要超过 8
- 只在**最终交付尺寸**上加，不要在放大前的母版上加
- 加完必须重跑越界检查：颗粒会让画面看起来"脏"，一旦超过阈值就是新的假

**注意**：本技能的目标是"提升质感"，不是"做胶片风"。颗粒属于风格化，超出 L1 范围，需要用户明确要求。

## 六、处理完的必查项

- [ ] 尺寸、宽高比与原图完全一致
- [ ] 叠图对比无位移（没有裁切或缩放）
- [ ] 五官边缘没有变虚（降锐化降过头会糊眼睛）
- [ ] 暗部没有被压死（对比降过头会发灰）

任一项不过，回退到未处理版本。

## 七、如果只做一件事

`Texture −20`（或 ffmpeg `unsharp=5:5:-0.6:5:5:0`），别的都不动。

这一步能去掉大半"精修感"，且几乎不会破坏身份与构图——风险最低、收益最稳。
