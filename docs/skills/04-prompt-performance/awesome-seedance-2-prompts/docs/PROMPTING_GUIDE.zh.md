## 一、基础公式（三类参考生视频任务）

参考生视频可细分为三类任务，按任务类型选择基础公式即可快速上手。

### 1. 多模态参考

从素材中提取部分元素（主体、风格、场景、音效），生成一个**全新**视频。
**适用场景**：动作迁移、主体复用、氛围借鉴等。

| 参考类型 | 推荐句式 |
|---|---|
| 图片参考 | `参考<图片N>中的<主体N>，生成……` |
| 视频参考 | `参考<视频N>中的<动作/运镜/风格/音效>，生成……` |
| 音频参考 | `参考<音频N>中的音色，生成……` |

### 2. 编辑视频

在原视频基础上做局部或全局修改，**未提及的部分默认保持不变**。
**适用场景**：局部替换、主体抹除、属性修改等。

- **增加元素**：清晰描述 `<元素特征> + <出现时机> + <出现位置>`
- **修改元素**：`严格编辑<视频N>，将其中的<原特征>修改为<新特征>`
- **删除元素**：点明需要删除的元素；对要保持不变的元素也在提示词中加以强调，表现更佳。

### 3. 延长视频

在时间维度上延续原视频，要求音视频风格、主体与叙事保持一致。
**适用场景**：续写剧情、延展动作、补全片段等。

- **延长视频**：`向前/向后延长<视频N>，生成……`
- **轨道补全**：`<视频1> + <过渡画面描述> + 接<视频2> + <过渡画面描述> + 接<视频3>`

### 4. 组合任务

上述三类任务可组合使用（例如：参考某个素材，去编辑另一个素材）。
**推荐句式**：`参考<图片/视频N>的[参考维度]，严格编辑<视频X>，[具体编辑内容]`

> ⚠️ **关键区分**：编辑 / 延长视频任务，直接用 `<视频N>` 指代视频，**请勿写成 `参考<视频N>`**，否则会被误判为「参考」任务。

## 二、进阶公式（多模态导演思维）

Seedance 2.0 本质是一个**多模态 AI 导演**：同时读取文字提示词、图片、视频、音频，并在内部拆成两个维度理解与生成——
- **空间层**：画面里有什么；
- **时间层**：事情如何随时间变化。

因此好的提示词不是「文案型形容」，而是「工程型指令」：**谁、在什么场景、做什么动作、镜头如何运动、按怎样的时间顺序发生**，分别投递给空间层和时间层。

```text
进阶公式 = 精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

一句话：先锁定「谁」在「干什么」，再交代「在哪」「什么氛围」，然后告诉模型「怎么拍」，最后用风格、画质、约束条件把结果收紧。

### 1. 定义主体

一张图里往往有多个主体，为精准引用特定对象，**必须做明确的主体定义**。主体可以是人物、道具、场景等。

**基本定义方式**
- 推荐句式：`将<图片/视频N>中的[主体核心特征]定义为<主体N>`
- 核心特征要求：用 **2–3 个清晰、稳定的静态特征**（服饰、发型、外观、类别）描述，确保唯一可识别。
- 示例：
  - `将图片1中穿红色连衣裙、戴草帽的女人定义为主体1`
  - `将图片1中穿红色连衣裙、戴草帽的女人定义为张红`

**多素材同主体**（多个素材指向同一主体时统一绑定）
- 推荐句式：`将图片1中的[…]、图片2中的[…]定义为<主体N>`

**多主体场景**（画面存在多个主体时分别定义，用唯一稳定的标签区分，后续持续使用对应标签）
- 推荐句式：`将<图片/视频N>中的[主体1核心特征]定义为<主体1>，将<图片/视频N>中的[主体2核心特征]定义为<主体2>……`
- 示例：`将视频1中的高个子男人定义为警察，将另一个矮个子男人定义为小偷。场景设定为拥挤的白天集市……小偷在拥挤的集市人群中惊慌失措地向前狂奔，警察在后方紧随其后全速追赶……手持镜头向前快速跟拍，画面带有轻微真实的晃动感。`

**主体指代的两种用法**
1. **未提前定义**的简单场景：每次提到主体都用 `<主体N>@<图片N>`，强调主体与素材的绑定，例如 `张三@图片1`。
2. **已提前定义**的场景：每次提到主体都用**同一标签**（如始终用「警察」「小偷」指代对应角色）。

**注意事项**
- 使用素材库（Asset ID）时，仍需用 `<图片/视频N>` 指代主体——模型无法直接把 Asset ID 关联到参考内容，**不得用 Asset ID 替代 `<图片/视频N>`**。
- 描述尽量简洁，避免冗余，避免语义冲突（同一主体不要出现矛盾特征）。
- 空间关系建议**优先用参考图**表达，减少复杂文字描述。

### 2. 使用分镜时序

模型内部对空间和时间是**解耦**建模的。因此复杂视频最理想的提示词形态是**时间轴化分镜**：把视频拆成几个镜头，按事件发生顺序动态描述每个镜头——**谁 + 在哪 + 做什么 + 镜头怎么动**。

**实操建议**：用「镜头1 / 镜头2 / 镜头3」为每段写一个简单分镜，再合并成完整提示词。

- ❌ 反面案例：`男人在街头紧张地奔跑，画面很有电影感。`
- ✅ 正面案例：
  - `镜头1：街巷侧拍，男人缓慢起跑，带有急促的呼吸感。`
  - `镜头2：男人撞翻水果摊，镜头快速摇动并给到男人惊恐的特写。`
  - `镜头3：男人翻过矮墙消失，镜头缓慢拉远定格在空荡的街道。`

**具体规则**
- 用「镜头1、镜头2、镜头3」标识，按事件发生顺序（先主后次）组织内容。
- 不强制限制每段时长，优先让模型根据剧情自然生成节奏。
- ⚠️ 模型对**精确时间**（如 0–3 秒）支持不稳定，强行限制时长可能导致结果异常。
- 每个镜头推荐按以下逻辑组织：
  1. **运镜或镜头切换方式**：如「全景缓慢推近」「固定机位」「镜头切至……」；
  2. **主体动作与表情**：核心角色 / 物体的关键动作、神态变化；
  3. **位置或空间变化**：主体所处场景、位置或空间关系；
  4. **音频信息**：对应镜头的音效、人声或背景音乐。

### 3. 动作描述要求

**① 肢体细化 + 程度量化**
动作要具体到手、腿、头部、肩背等部位，并补充**幅度、速度、力度**。
示例：缓慢抬手、快速转头、用力蹬地、微微低头。

**② 优先低缓、连续、细微动作**
尽量规避狂奔、大跳、剧烈翻滚等高爆发、大动态动作。
示例：缓慢行走、轻轻抬手、微微低头、顺势坐下。

**③ 补充动作过渡衔接**
写明前后动作的惯性与承接关系，保证画面连贯自然。
示例：借着转身惯性顺势抬手、从停顿状态自然过渡到举手。

**④ 情绪具象外化**（用身体细节替代「很悲伤」「非常愤怒」这类抽象词）

| 抽象情绪 | 外化为动作与细节 |
|---|---|
| 悲伤 | 低头、肩膀微微颤抖、眼眶泛红、手指无意识地攥紧衣角、泪水在眼眶里打转但没有落下 |
| 喜悦 | 嘴角抑制不住地上扬、眉眼舒展、脚步变得轻快、下意识地哼起小曲、忍不住原地转个圈 |
| 紧张 / 焦虑 | 频繁地看手表、手指不停敲击桌面、呼吸急促、眼神闪躲、无意识地啃咬指甲 |
| 愤怒 | 双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀般锐利、从牙缝里挤出话语 |
| 释然 | 长长地舒了一口气、紧绷的肩膀完全放松下来、脸上露出久违的淡淡微笑、抬头望向远方 |

### 4. 运镜写法

模型对运镜词理解力很强，直接使用**标准运镜术语**即可，例如「中景、特写、全景、缓慢推镜、平稳横移、固定镜头」。

> ⚠️ 一个镜头里尽量**只指定 1 种运镜方式**，不要同时要求推、拉、摇、移，否则会增加画面不稳定性。

### 5. 画质、风格与约束词

三者是把控成片效果的关键：划定创作边界、统一画质与美术调性，并规避画面瑕疵与随机偏差。

- **画质**（清晰度、细节纹理、光影质感）
  示例：`高清，细节丰富，电影质感，色彩自然，光影柔和`
- **风格**（整体美术画风与视觉调性）
  示例：`赛博朋克冷蓝紫色调`、`复古胶片`、`日系清新`
- **约束词**（规避瑕疵、畸形崩坏、不合理元素，约束生成边界与稳定性）
  - 避免字幕：`保持无字幕`、`避免生成任何文字或字幕`
  - 避免 Logo：`不要生成Logo`
  - 避免水印：`不要生成水印`

## 三、特殊符号规范

合理使用符号有助于模型准确区分不同信息类型：

| 信息类型 | 符号 | 示例 |
|---|---|---|
| 音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 台词 | `{}` | `{你好，世界}`。台词若为小语种（非中英文）需标注语种，如：`用日语说道{こんにちは}` |
| 字幕 | `【】` | `【第一章：启程】` |

**语言规范**：台词语言需统一，避免中英文混用（专有名词除外）。

## 四、实战案例

### 示例1：宿舍情感短剧（偏文戏 / 对话）

**素材准备**
- `@图片1`：女主半身照
- `@图片2`：宿舍场景参考图
- `@视频1`：室内对话运镜参考（中景推拉或轻微摇移）
- `@音频1`：室内环境声或轻音乐

**提示词**
```text
@图片1 中的女孩作为主角，@图片2 作为宿舍场景风格参考，参考 @视频1 的运镜方式。
镜头1：傍晚时分，女孩 @图片1 脚步轻快地走到宿舍门口 @图片2，镜头中景平稳跟拍，暖黄色日光从窗外洒进走廊，她在门口停顿一下，深呼吸，表情略带紧张。
镜头2：女孩 @图片1 推开门走进宿舍，镜头切到室内中景，舍友们一边整理书本一边抬头看向她，其中一人笑着问 {考得怎么样呀，过了吗}，镜头在几人之间缓慢切换半身特写。
镜头3：女孩 @图片1 先低头露出落寞表情，镜头给到她的近景，随后她抬头憋不住笑意，哈哈大笑说 {骗你们的}，舍友们追着打闹起来，镜头缓慢拉远，定格在宿舍内一片欢声笑语的全景画面。
全程画面高清电影纪实风，色调温暖，光影柔和；人物面部稳定不变形，动作自然流畅，无卡顿无闪烁；环境音效与 @音频1 自然融合。
```

### 示例2：古风悬崖对手戏（偏动作 / 氛围）

**素材准备**
- `@图片1`：红衣女主
- `@图片2`：黑衣刺客（对手）
- `@图片3`：悬崖竹林场景图
- `@视频1`：武打对决运镜参考
- `@音频1`：紧凑的鼓点或打斗音效

**提示词**
```text
@图片1 的红衣女子作为女主，@图片2 的黑衣女子作为对手，场景参考 @图片3 的悬崖竹林环境，整体运镜和动作节奏参考 @视频1，背景音效与 @音频1 同步。
镜头1：傍晚，镜头从红衣女子 @图片1 侧面中景缓慢推进，她站在悬崖边拿起酒壶喝酒，衣袂在山风中轻轻摆动，镜头环绕她半圈，从正面推到背影，远处隐约可见竹林中的黑衣人影。
镜头2：镜头变焦渐隐到远景，无人机视角俯瞰整片悬崖和竹林，两人分立山崖两端，山风卷起衣摆和尘土，节奏随鼓点略微加快。
镜头3：镜头切回地面近景，二人缓慢拔剑对峙，红衣女子 @图片1 神情从漫不经心转为冷冽，黑衣女子 @图片2 目光坚毅，剑尖微微颤动，镜头平稳跟随两人绕圈移动，最后定格在两剑相交前一瞬间的特写。
整体画面烟雨江湖电影感，冷调低饱和，电影胶片质感，光影层次丰富；人物面部和身体比例稳定不变形，动作连贯自然，不僵硬，无穿模无卡顿。
```

## 五、其他实用技巧

### 文字生成
Seedance 2.0 支持生成常用文字，能根据情境自动匹配风格与颜色，也支持在提示词中指定文字的颜色、风格、出现方式、出现时机、出现位置。**优先使用常用字，避免生僻字与特殊符号**。当前支持广告语、字幕、气泡等场景（详见「案例库 - 文字生成」）。

### 视频延长 vs 分段拼接
- **连续长镜头（视频延长）**：适用于单一场景内的「文戏」——长对话、情绪递进、单一路径移动，实现沉浸式、连贯的一镜到底。
- **场景 / 动作转折（分段拼接）**：适用于剧情转折或复杂快速的「武戏」——追逐、打斗、蒙太奇，独立生成片段再剪辑组合，保证节奏与视觉冲击力。
- 实际制作常**结合两者**：先用延长生成连贯对话，再拼接空镜或转场片段，兼顾沉浸感与节奏变化。

### 素材配置策略
通常把素材分成四种「功能角色」：

| 功能角色 | 作用 |
|---|---|
| 角色锚定 | 锁定角色外观 |
| 场景定调 | 锁定环境与风格 |
| 运镜参考 | 锁定镜头语言与动作节奏 |
| 节奏氛围 | 用音频控制情绪、音色 |

**推荐配置（总计 4–5 个素材）**：角色图 1–2 张（面部特写 / 全身）+ 场景图 1 张 + 运镜视频 1 段 + 音频 1 段。

> ⚠️ **不建议用满素材上限**。素材过多会让模型难以判断特征优先级，易出现风格冲突、主体识别模糊、生成效果偏离预期等问题。

## 六、常见问题与避坑清单

> 说明：字幕、水印、双胞胎等问题目前**无法 100% 规避**，以下方法用于**降低出现概率、提升抽卡成功率**。

| # | 典型现象 | 解决方案要点 |
|---|---|---|
| 1 | **人物 ID 漂移**（角色与参考图不一致 / 中途「换脸」，甚至撞脸明星被审核拦截） | 额外准备**独立人脸特写大头照**（仅面部、无表情最佳、少干扰）；主体定义写清 `<主体1>的面部特征参考图片1（大头照），妆造参考图片2（全身照）`；**越需精准参考的素材越往提示词前面放**；用大头照+全身照即可，**不要用人物多视图**（易被识别成多个主体）。 |
| 2 | **无端出现字幕** | 加约束 `保持无字幕`/`避免生成任何文字或字幕`；参考素材里的非必要文字先用工具去除；业务允许时**优先横屏**（横屏出字幕概率明显低于竖屏），后期再裁成竖屏。 |
| 3 | **出现 Logo / 水印** | 加约束 `不要生成水印`、`不要生成Logo`。 |
| 4 | **风格漂移**（想要 2D/3D 动漫却漂成真人写实） | 加明确风格约束词，如 `2D日漫风格`、`3D国风漫画`；需更精准时，**先把参考图转成目标风格再生视频**。 |
| 5 | **延长视频衔接处跳变 / 回退** | 用剪映等对齐关键帧：每个拼接点把**前一段末尾删 6 帧、后一段开头删 1 帧**；续写时尽量**以转场切镜的时刻结尾**，下一段以切镜后的新场景为起始。 |
| 6 | **双胞胎**（同画面出现两个完全相同的人） | 清晰定义每个角色并标注对应参考图（`张三（对应图片1）……李四（对应图片2）`）；结尾加全局约束「禁止出现外形/着装/配饰完全一致的人物，禁止同款分身、双胞胎，同一画面仅保留单个对应人物」；用**单人独立照**而非多视图；**精简提示词**，勿直接塞完整剧本。 |
| 7 | **延长视频画质劣化**（多次续写叠加、人脸出现斑驳色块） | 先把原视频经 Seedance 2.0 **转为白模视频**再作续写输入（参考词：`将视频转为白色3D模型，人物统一为纯白3D模型，无色彩、无纹理、无阴影，纯白背景，结构稳定、运动流畅`）；优先用高清素材；**控制续写次数**，避免多次叠加。 |
| 8 | **特效不符预期**（如倒计时数字乱跳） | 改用**参考视频定义特效**，例如 `数字"2999"出场方式参考视频1`，让模型精准理解特效形态与运动逻辑。 |
| 9 | **参考人物过多（>4 人）**（人数不符 / 人物重复） | **分组分步生成**：先把人物分组（每组 ≤4 人）分别生成图片，再用这些分组图片作参考素材图生视频。 |
| 10 | **视频结尾有噪音**（旁白片尾咔哒声 / 截断杂音） | 重新生成，或用剪映对片尾音轨做**音量包络线淡出**（末尾音量关键点下拉至 0）。 |
| 11 | **中文发音不准**（多音字、生僻字、形近字读错） | 把易读错的字替换为**发音一致的常用同音字**，如「螭龙山」→「吃龙山」。 |
| 12 | **音色参考不准**（与参考音频音色偏差大） | 在提示词中**补充细致的音色特征描述**；保持台词的语气、表述风格与参考音频相近。例：`使用@音频1低厚温润带细碎颗粒感中年男声的音色说……`。 |

## 七、提示词案例库

> 以下为各场景的代表性提示词原文，便于对照学习指代控制与文字生成写法。使用多图 / 多视频时若对顺序有要求，应**按顺序上传**，并在提示词中用「图片1、图片2……」「视频1、视频2……」精准指代。

### 文字生成

**广告语（Slogan）模板**：`「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征（颜色、风格）」`
- 示例：`手绘漫画风格，三个人围坐在一起吃图片1中的炸鸡，气氛友好愉悦，后画面逐渐模糊，画面中部显示文字"快乐尽在 Seedance"。`

**字幕模板**：`画面底部出现字幕，字幕内容为"……"，字幕需与音频节奏完全同步。`
- 示例：`生成带有画外音的视频。一个深沉、平静的男声说："在宏大的宇宙中，我们的世界不过是一个短暂的瞬间。然而，在其中，生命不顾一切地繁荣。"场景应从夜晚缓慢过渡到黎明，星星逐渐消失，太阳从山后升起。画面底部按照台词出现字幕。`

**气泡台词模板**：`「角色」说："……"，角色说话时周围出现气泡，气泡里写着台词。`
- 示例：`图片1中的两人穿着运动服在学校的操场跑步，女孩看向男孩，自信地笑着说："We can definitely do it!"镜头切到男孩的近景，他犹豫地回答："Are you sure?"镜头切回女孩的中近景，她语气轻快地说："Yes!"说话的角色周边出现气泡，气泡里是对应台词。`

### 图片参考

**主体多视角参考**
- 3C 数码：`提取图片1、图片2、图片3的相机，把背景换成白色，相机在一个白色桌子上，镜头以特写的形式聚焦相机，然后以相机为主体缓慢旋转，清晰展示相机的正面侧面以及背面。`
- 家居物品：`背景为暖调居家场景，中景呈现参考图中的保温杯，镜头平稳推近至保温杯近景，镜头外一只手自然入镜轻握杯身拿起保温杯，镜头跟拍手部微微旋转动作展示。`
- 角色：`参考图片1、图片2、图片3中的女子形象，生成她在一家咖啡店吃蛋糕的画面。`

**多图参考**
- Logo 参考：`背景是霓虹闪烁的未来都市空中廊道，飞行器与全息广告交织，参考图片2中的女孩，先用中景展示女孩放飞带有全息投影的银色悬浮灯，再镜头拉远展现漫天悬浮灯，画面逐渐模糊，后出现图片1的 Logo，整体风格为 3D 赛博朋克科幻动画风格。`
- 多主体参考：`参考图片中的猫猫和狗狗，在一个温馨的公寓里，狗狗在趴着吃狗粮，猫猫走过来，伸出爪子碰了碰狗狗，狗狗看到猫猫后停下吃饭，猫猫依偎在狗狗身边。画面采用暖色调。`
- 多元素参考：`场景设定在图片4中的餐厅内，店内人来人往。图片1里的女孩身着图片2中的服装，正在整理柜台上的物品。图片3中的男孩是一位顾客，他走上前，想要向女孩索要联系方式。图片5中的标识始终显示在画面的右下角。`
- 多宫格分镜图：`参考图片中的分镜图，生成打斗激烈的打斗场面。图片中的各个分镜构图要按照顺序出现，之后二人激烈打斗。`

### 视频参考

**动作参考**
- 影视：`参考视频1的人物动作和镜头语言，生成图片2和图片1的打斗场面，图片2是左边人物，图片1是右边人物。有激烈的背景音乐。`
- 营销：`参考视频1中马的奔跑形态，生成一匹金色的骏马在草原上奔跑，随即定格其奔跑的华丽姿态，变成一个马形的金吊坠。`

**运镜参考**
- `参考视频1的运镜，做一个科技园区的概念视频，以图片1中的高楼为视觉中心，同为第一视角俯冲，体现出图片1中园区的科技感。`

**特效参考**
- 影视：`参考视频1的金色粒子特效，让图片2中的人物吹笛子的同时，身边环绕一样的粒子特效。`
- 玩法特效：`参考视频1的特效，让图片1中的女生长出相同的翅膀，翅膀生成轨迹一致。`

### 视频编辑

**元素增删改**
- 增加：`在视频1的台面上添加炸鸡、披萨等小吃。`
- 删除：`清除视频1桌面上的其他零件和工具，保持桌面整洁干净，桌面上只有他俩手里的。`
- 修改：`将视频1中的香水替换成图片1中的面霜，动作和运镜不变。`

**视频延长**（模型自动截取衔接部分合成，输入视频原有片段不会重复生成）
- 向后延长：`生成视频1之后的内容，迟到的两个男士跑向他们，五个人终于见面，友好聊天。`
- 向前延长：`向前延长视频1，给白衣男子过肩镜头，白衣男子说："It's not that bad. You're just stressed. Everyone goes through this, you just need to keep going."`

**轨道补齐**（最多支持 3 段视频输入，总时长 ≤ 15 秒；自动截取首尾衔接部分，仅保留必要片段合成）
- `视频1，树叶落地的瞬间，激起金色粒子特效，一阵风吹过，接视频2。`
