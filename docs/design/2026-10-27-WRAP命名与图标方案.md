# 项目命名与图标方案（WRAP STUDIO）

日期：2026-10-27。范围：同类平台命名调研 → 项目命名 → 图标设计。图标成品见 [`docs/data/brand/`](../data/brand/README.md)。

## 结论

- **项目名：WRAP STUDIO**（WRAP 读作 /ræp/）。影视行业的收工口令「That's a wrap」；中文对应**杀青**。
- **图标**：青绿渐变底上一个月白 W。底色就是名字里的那个"青"。

## 一、命名：为什么是 WRAP

### 候选被逐一排除的原因

这一轮取名最大的成本不是想名字，是查占用。同赛道（AI 短剧 / AI 视频）里以下都已被占，全部排除：

| 词 | 撞到谁 |
| --- | --- |
| Scena | scena.ai，AI 视频平台 |
| Auteur | theauteur.top，AI 影视创作工作台，剧本→分镜→一致性生成 |
| Lychee | lychee.video，AI Video Studio |
| Troupe | maxgfr/troupe，开源浏览器视频工作台 |
| Oner | T1 打野选手 ID，中文语境干扰 |
| Frame / Final Cut / Reel | Frame.io / Apple / ReelShort |
| 有戏 | 有戏AI（风平智能），百万用户级短剧平台 |

由此得出一条这个赛道的取名口径：**同赛道占用一票否决，跨行业占用可以接受**（比如 Peach 撞了一家支付公司，不影响）。

### 选定 WRAP 的三条理由

1. **它本来就是影视行业的口令。** 片子拍完，导演喊「That's a wrap」，全组收工。不需要解释。
2. **它对应中文的「杀青」，而杀青比 wrap 更老。** 汉代著书用竹简，新竹含水易蠹，要先架火把青竹片烘干，这道工序叫**杀青**（也叫汗青）。烤干，稿子才算定。文天祥「留取丹心照汗青」的汗青，就是史册。
3. **这个词横跨了产品的整条路径。** 杀青先是"文字定稿"，后来才是"影片拍完"。本项目的流程正是从剧本定稿走到成片杀青——名字自带这条线。

四个字母、一个音节，也不撞上面任何一家。

### 为什么后面加一个 STUDIO

`WRAP` 单独做名字有一个问题：它是一个词，不是一个产品名。加后缀是用户定的方向——**只加不承载含义的后缀**，不做"Wrap Day / Wrap Party"那类有语义的组合。

在 Studio / Labs / AI 三个里选 **Studio**：

- **它落在产品形态上。** 这个产品本来就是"一个人 + 一整套班底"的工作室，Studio 不是凑字。
- **比 Labs 准。** Labs 暗示在训模型、做研究；本项目是应用层，不训模型。
- **比 AI 耐旧。** AI 现在就已经开始显旧，三五年后大概率要摘掉，届时要改一次名。
- **视觉上它天然是注脚。** 主字 WRAP 与副字 STUDIO 的大小比可以做到 3:1 以上，后缀永远不抢主字。

## 二、图标：为什么只有一块青和一个 W

**概念一句话**：底色就是名字里的"青"——**杀青**要烤掉的那层青。

**为什么是青**：

- 这个赛道被用烂的五个符号（镜头、光圈、播放三角、场记板、胶片齿孔）一个都没用。
- 名字 WRAP 的中文对应是杀青，而"青"本身就是一个颜色。用青做底，等于让色彩直接承担词义，不必再画一根具象的竹子。
- 从青玉、青瓷到青绿山水，青在中国是**唯一一个横跨器物与绘画的颜色**，做品牌底色不会落进"科技蓝"那一堆。

**为什么最后只有一个 W，没有印面**：

最初做的是"朱印盖在暗场"，但红色一撤，印面就失去了语义——红才是印。而且月白印面占到 68% 面积，整枚图标会被读成"白底青边的方块"，青反而成了边框。

所以砍掉印面，只留 W：**一块青，一个字母**。笔画端头仍是斜切——那是刻出来的刀口，不是字库里的现成字母。

**几何**：W 包围盒 620 × 476，居中；笔画 112；五顶点
`202,274 → 409.7,750 → 512,464.4 → 614.3,750 → 822,274`。
渐变 `#0C3A4B → #2E8073`，135°，`gradientUnits="userSpaceOnUse"` 铺满整块画布——所以缩放到任何尺寸，W 与背景的明暗关系都不变。

**色彩**：只有青绿一族（196° → 171°）+ 一个月白 `#EFEDE4`。没有红色。

## 三、过程与验证

定形走了四轮，前三轮都在 256px 灰度稿上做：

1. **字母直排**（W 三档粗细、W 负形、方环、竹简条）。只有 `W 负形`（方块挖 W）立住，其余像 UI 图标。
2. **白文印 / 收卷 / 螺旋**。收卷读成钥匙，螺旋读成 @；白文印胜出，带边栏和崩角的两个变体都读成"坏了"。
3. **印面上色**。骨白字 > 墨字（墨字压在红上会糊）；印面 800 太满，收到 700 才读得出"盖在纸上"。
4. **改青绿之后重做构图**。红一撤，印面失去语义；试过月白瓷牌、同色系瓷牌、无牌三种——月白牌把图标压成"白底青边"，青牌在大尺寸成立、32px 却消失，最终选无牌。

已渲染验证：1024 / 512 / 96 / 48 / 32 / 16 六级缩放、圆角遮罩、纯色版、单色版。
