# 标准模式创作流程设计（确认版）

本文件保留小说改编、素材生成、分镜制作三个页面的确认设计。设计阶段交付为可离线打开的静态 HTML 原型；应用实施与实际验证单独记录，不改变画布模式。

原型入口：[打开 HTML](standard-creation-workflow/index.html)。双击文件可直接使用；本机预览服务运行时可访问 <http://127.0.0.1:8093/>。可用 `#source`、`#assets`、`#storyboard` 直接进入对应阶段。所有文字、状态与任务均为演示；图库图片并非真实生成结果。刷新页面会重置演示输入。

## 共用工作区

```text
┌ 项目 / 分集 ─────────────────────── 保存状态 · AI 助手 ┐
├ 01 小说改编 ─ 02 素材生成 ─ 03 分镜制作 ─ 04 成片合成 ┤
│ 单列大图卡片 │ ┌────────── 当前对象 ──────────────┐ │
│ 搜索 / 分类  │ │                                 │ │
│ ┌ 缩略图 ┐   │ │       大图 / 视频       │对象信息│ │
│ └ 名称 类型┘ │ │                        │参考图片│ │
│      ↕       │ │                        │提示词  │ │
│ 独立滚动     │ │ 采用反馈               │参数/生成│ │
│              │ └─────────────────────────────────┘ │
└───────────────────────────────────────────────────────┘
```

顶部保留成片步骤以维持完整流程，但本次不设计成片页面。步骤序号表示顺序，状态使用“剧本已确认”“已采用数”等真实业务概念，不把进入页面视为完成。后续实现应按服务端作品状态计算；原型按演示对象计算。

1440px 桌面下，卡片列约 250px，主面板内部的设置区约 324px，预览占剩余空间。助手打开时新增约 320px 的右列，主面板自适应收缩；宽屏下各侧栏适度增加。设置区与预览区共用外边框，以细分隔线区分。收起设置只扩展面板内部的预览。

对象列表、预览、设置与助手各自保持滚动范围，固定标题和主要操作。图片使用完整预览，提供缩放、适合窗口和放大查看，不因卡片滚动改变中央位置。常驻界面只显示必要状态，采用影响和历史权限放到相应弹窗内说明。

不提供“下一步”按钮或重复的阶段标题，阶段切换通过顶部步骤完成。工作台填满剩余屏幕高度。设置内容按“对象信息 → 参考图片 → 提示词与底部参数”连续排列，信息区到参考图片间距 16px，参考图片到输入框间距 12px；窗口较矮时整个设置内容区统一滚动，标题行固定。

列表标题栏承载新增、提取与导入；对象标题栏承载生成记录、设置展开入口及分镜前后切换；剧本标题栏承载导出与记录；项目顶栏承载助手入口和保存状态。原有整页右上角操作组不再重复占据一行，底部也不保留步骤操作条。

## 尺寸与响应式基准

以下取自确认 HTML，而非按历次“增宽／缩窄”比例重新计算。宽度为 CSS 像素；正式实现优先保持内容比例、独立滚动和操作可达。

| 窗口宽度 | 卡片列 | 小说设置列 | 素材／分镜设置区 | 助手列 | 卡片高度 |
| --- | --- | --- | --- | --- | --- |
| ≥1700px | 280px | 330px | 约 349px | 340px | 203px |
| 1440–1699px | 250px | 306px | 约 324px | 320px | 187px |
| 1280–1439px | 220px | 282px | 约 298px | 288px | 187px |
| 1100–1279px | 208px | 270px | 280px | 264px | 173px |
| 1000–1099px | 200px | 260px | 280px | 264px | 173px |
| 701–999px | 200px | 260px | 280px | 330px 右侧抽屉 | 173px |
| ≤700px | 列表与主区纵排 | 按需抽屉 | 按需抽屉 | 按需抽屉 | 171px |

桌面项目顶栏高 53px，横向步骤高 52px；普通工作区外边距为上下 12px、左右 20px，列间距 12px。宽屏列间距 16px，小桌面 10px。卡片名称行固定 38px，缩略图高度分别为 163／147／133／131px；选中、加载图片或出现待制作标签均不改变卡片高度。

主面板实际宽度小于“设置区宽度 + 402px”时，预览与设置改为面板内部上下排列。正式实现通过 ResizeObserver 读取主面板 `clientWidth`，设置区宽度为局部 `--creation-settings-base × 10 / 9`；打开助手也会触发重排，不能只按浏览器宽度判断或使用固定阈值。

手机顶栏高 51px、步骤高 48px，卡片列表区域高 332px，仍只在列表内部滚动。设置与助手同时只出现一个抽屉；素材／分镜设置抽屉宽为 `min(366.667px, 100vw)`，小说设置为 `min(440px, 100vw)`，助手为 `min(340px, 100vw)`。步骤仅在自身容器横向滚动，手机正文允许页面纵向滚动。

四类提示词内容区默认 180px、可拖动调整。素材和分镜在高度不超过 700px 的桌面窗口中默认 160px；小说改编要求仍保持 180px。外框底部模型与发送控件另占高度，不把整个输入组件误设成 180px。

## 自动保存与作品确认

素材名称、素材类型、素材描述、镜头名称、镜头脚本，以及提示词、参考图片、模型、画幅、分辨率、张数和视频时长均自动保存。生成设置标题行移除勾选图标及手动保存操作，只保留收起按钮。信息字段编辑完成后自动保存；提示词输入、参数选择和参考图片变更自动保存，不需要另点确认。

保存反馈统一使用顶部状态：正在保存、已保存、保存失败或版本冲突。后续产品实现须等待保存完成再生成或切换对象、阶段；失败保留草稿并提供就近重试，冲突等待明确核对，不静默覆盖。作品信息与个人生成参数分别保存，修改素材描述或镜头脚本不覆盖个人提示词。原型只演示保存状态与本次页面输入，刷新仍会重置，不代表真实持久化。

自动保存只保存编辑内容和参数。剧本确认及图片、视频采用仍由用户明确操作；生成完成不能自动替换当前作品。视频时长独立于脚本时长。

新追加的空白素材先作为界面草稿保留。名称未填或类型未选时禁用生成，补齐后恢复；空白镜头同样需要先填写名称。正式接入时须核对现有类型枚举、名称必填和保存契约，字段补齐前不按完整素材提交。原型允许空类型，不表示生产接口已支持空类型保存。

正式页面区分“本机草稿已保留”“正在保存到服务端”和“已保存”。本机空白草稿不能让顶部显示服务端保存成功。正式素材的类型修改、镜头名称、富文本格式与个人生成草稿均需要按实施文档补齐保存路径。共享信息修改如需引用影响确认，应暂停相关自动保存并就近提示，不在每次输入时重复弹框。

## 小说改编

左侧约 306px 的“剧本改编设置”先显示本集画幅与视觉风格，下方为圆角改编要求输入框，提示词内容区默认高度 180px。文本模型选择嵌入框内左下方，右下方为生成发送按钮；删除独立模型字段、原文摘要和底部整行生成按钮。DOM 与键盘顺序均先设置、后正文。

右侧使用实际 Quill 2.0.3 编辑器展示本集剧本，沿用冷黑主题和场次排版。工具栏只保留加粗、斜体、引用、撤销与重做，旁边显示字数、场次数和场次定位，导出放在正文标题栏。中文编辑触发自动保存示意，并将定稿状态恢复为待确认。仅在草稿待确认时展示“确认当前剧本”，已确认后收起该操作区。

点击正文时不出现编辑区域外框；点击改编要求、展开或选择文本模型时，不增加 outline、焦点阴影或外框高亮。改编要求保留常态圆角细边线，文本模型保留自身常态底色与细边线。该规则仅限这三个区域；其他按钮和表单继续使用现有焦点反馈。文字编辑保留插入光标、文本选区和可访问名称。

“查看原文”图标位于左侧设置标题栏，打开宽为 `min(500px, 100vw)` 的左侧全高抽屉，原文可查看、编辑及导入 TXT；抽屉与剧本独立，关闭不丢本次输入。正文使用 14px、1.95 行距、760px 居中阅读宽度。这样避免原文常驻占据半屏，也不必跳到另一页面核对。生成的新剧本先只读预览，通过“采用并编辑”进入当前稿，再单独确认定稿。

Quill 使用官方发行版和 Snow 样式，自定义为紧凑的深色工具栏。选择依据是独立于框架、支持基础富文本及历史操作、具有完整文档，且体积可控：本次内嵌 JS 为 209,241 字节，gzip 为 58,947 字节；CSS 为 24,565 字节，gzip 为 3,738 字节。版本固定为 2.0.3，BSD-3-Clause 许可全文保留在 HTML 中。库与样式内嵌，无 CDN 运行依赖，也没有修改项目依赖清单或锁文件。实现用法已核对 [官方 API](https://quilljs.com/docs/api)、[工具栏](https://quilljs.com/docs/modules/toolbar) 与 [历史模块](https://quilljs.com/docs/modules/history)，项目主页为 <https://quilljs.com/>。

确认设计时，应用仅保存字符串正文；现已按实施文档 C4 同时保存业务纯文本与受限 Quill Delta，二者使用同一事务与版本。格式恢复、旧客户端兼容及实际验证见实施验收记录。原型以 HTML 展示富文本，不表示生产接口已改成 HTML 或已有结构化场次 API。场次识别不能改写原正文；完整正文编辑优先，场次定位作为渐进增强。

## 素材生成

左列保留全部、角色、场景、道具分类与名称搜索。大图卡片固定高度，不因选中而展开；底部为一行，左侧名称、右侧类型，长名称省略并可悬停查看完整内容。隐藏“已采用”等状态文字，未制作对象在缩略图区左下方显示低干扰的“待制作”标签。名称行固定 38px，腾出的空间用于更大的缩略图。卡片封面只显示当前采用图片，生成完成不会自动改封面；图上勾选只表示当前选中对象。

新增、从剧本提取和导入素材三个图标直接放在列表标题栏，提供中文提示与可访问名称，不使用三点菜单。点击新增直接在列表末尾追加并选中空白卡片，不弹窗；清空搜索并滚动到新卡片。在“全部”下名称、类型、描述与提示词均为空，类型选择显示“选择类型”；在角色、场景或道具下沿用当前分类。补齐类型后“全部”分类保持不变，新卡片继续可见。桌面聚焦名称输入，手机先追加卡片，设置通过已有入口打开。

中央工作面板的标题与作品标签跨越预览和设置；面板内部左侧只展示大图与作品状态，不再常驻素材描述。右侧把素材信息与生成设置合并，不提供信息标签页；素材名称和类型同排，素材描述直接展示，不通过折叠或“显示”操作打开。修改信息无需打开覆盖整个工作区的详情弹层。设置收起时，预览在同一面板内部扩展，顶部保留展开入口；模型与输入草稿保留。删除“逐个打磨角色、场景与道具”等段落说明和重复的来源标签。

参考图片位于圆角提示词输入框上方，可添加及移除。画面要求就是输入框内容，底部同排提供图片模型、比例与分辨率组合按钮、1／2／4 张下拉及发送按钮；不提供使用范围和高级参数。提示词默认高度 180px，最小 160px、最大 360px，可拖动调整；高度不超过 700px 的桌面窗口默认 160px。底部操作随输入框保留，较矮窗口可通过设置区滚动访问。

从剧本提取只产生素材文字；提取与图库导入通过外露图标打开原有核对流程。当前对象标题只保留“生成记录”与设置开合；记录包含历史预览，默认不占用工作区。正式页面将上传图片、资产库选择、共享及移除放在记录底部的“素材操作”，执行时先关闭记录。新生成结果自动进入中央预览，显示一行“未采用”及“采用此结果”；确认采用后才更新当前作品与卡片封面。涉及共享素材时，采用确认说明引用影响。卡片隐藏采用文字不改变明确采用的操作与状态反馈。

## 分镜制作

左列按镜头顺序展示大图卡片；底部名称在左、景别在右，保持同一行。镜号与脚本时长留在缩略图角落，不单独增加信息行。隐藏“图已采用”“视频已采用”等文字，待制作标签与筛选按当前分镜图或分镜视频判断，避免图片完成后掩盖视频尚未制作。支持名称搜索。中央顶部固定当前镜头与前后镜头按钮。

列表标题栏直接显示新增、从剧本提取两个图标，移除三点菜单。新增直接在末尾追加空白镜头，镜号顺增，名称、镜头脚本和提示词为空，选中并滚动到新卡片；不会弹出创建窗口。保留现有待制作筛选，不新增原流程没有的导入分镜功能。

中央只保留“分镜图 / 分镜视频”两个作品标签，使用同一对象，不跳离本页。两种媒体的生成设置使用一致的“镜头名称”标签、名称输入框和镜头脚本表单，并自动保存；不使用原位无边框名称编辑，也不提供独立镜头信息标签。设置区删除景别、运镜、脚本时长和画面布局字段，作品标签行右侧也不再展示“全景 · 5 秒”等摘要；左侧卡片保留用于浏览的景别和时长。

分镜图的大图与生成设置同属主面板，参考图片放在提示词上方，圆角输入框和底部模型、比例与分辨率、张数、发送按钮沿用素材生成布局。分镜视频使用已采用的分镜图作参考，底部张数替换为视频时长；图片与视频分别保留提示词和清晰度。两种提示词输入区均使用 180px 默认高度与同样的调整范围，参考图片间距沿用共用设置区规则。

候选策略与素材相同：日常只看当前作品或最新结果，历史按需查看，明确采用后进入后续剪辑。图片与视频分别标识，不能用一个“完成”掩盖未制作的视频。没有采用分镜图时禁用视频生成并说明需要先采用分镜图。

正式分镜对象标题保留前后镜头、媒体生成记录、设置开合四个工具；批量、排序与归档位于“分镜生成记录”底部，沿用既有许可及核对。生成选项按原型七格比例与标题／关闭按钮排布，2:3、3:2 按当前私人草稿合同禁用；图片仅提供 1K／2K／4K／模型默认，视频仅提供 480p／720p／1080p／模型默认，并继续按真实模型能力禁用不支持项。关闭选项浮层后卸载内容，关闭按钮与 Escape 恢复入口焦点；手机底层设置保留。

镜头名称必须独立保存，不能用脚本第一行充当名称，也不能因改名改写脚本。景别只作为卡片元信息显示，没有数据时留空。删除景别、运镜、脚本时长、画面布局的可见控件不代表删除既有数据；编辑其余字段时保留未显示的值，视频生成时长仍由输入框底部设置独立控制。

## 助手、状态与窄屏

助手按需在独立右列打开，主面板让出空间；不会替换生成设置。素材和分镜仍是“左列表 / 主面板 / 助手”三块，主面板内包含预览与设置。小说页为“左设置 / 剧本 / 助手”。关闭助手后主面板恢复宽度，设置的开合与输入不受影响；切换选中对象时，助手的作品引用同步更新。助手只分析与建议，保留项目对话与当前作品引用，不替代生成、提取和采用入口。

正式页面在保存状态右侧提供助手入口，标准模式用局部样式实现 49px 标题栏、消息区顶部的可移除作品引用、贴底 84–180px 输入及同排模型／圆形发送按钮；附件与 Skill 保留在“附件与技能”展开入口，已有内容和错误继续展示。画布共用对话逻辑并保持自己的布局。真实分集切换、实际作品状态与局部状态色的维护约定见 [前端设计约定](../../frontend/DESIGN.md)，产品行为见 [产品范围](../../frontend/PRODUCT.md)。

原型顶部“状态演示”是评审工具，可查看加载、空、失败与冲突；正式产品不显示此工具。失败就近提示和重新加载；冲突保留输入、暂停生成与切换，提供下载草稿及明确载入服务端版本的确认。

主面板空间不足时，预览与生成设置在同一面板内改为上下排列，避免把画面挤成窄条。打开助手仍会收缩主区，设置按可用宽度调整排列。1000px 以下助手使用右侧抽屉；700px 以下卡片与主面板纵排，卡片区域保持单列和固定滚动高度，设置按需抽屉打开。手机设置与助手同时仅显示一个抽屉，输入各自保留。横向步骤在自身容器内滚动，正文与页面不出现横向滚动。保留键盘焦点、原生弹窗 Escape／焦点管理及减少动态效果偏好。

## 确认设计时与实际产品的差距

下表保留 2026-10-09 的设计背景，不作为当前未实现清单。已接入的契约、布局及验收结果以实施验收记录和维护接口说明为准。

| 提案 | 确认时依据 / 实施边界 |
| --- | --- |
| 横向流程、常驻对象详情 | 布局提案，实际应用仍使用左侧流程及现有编辑布局 |
| 正文、保存、候选、明确采用 | 基于现有标准模式业务；原型只模拟状态，不证明真实保存或生成 |
| Quill 富文本与场次定位 | 实际编辑器已用于原型；生产正文目前只有字符串，需要补格式保存与纯文本适配；本次尚未改变契约 |
| 直接追加空白素材／镜头 | 原型内的草稿交互；“全部”下空类型须在生成前补齐，正式实施需核对既有字段约束与草稿保存方式 |
| 已保存素材的类型修改 | 当前公开 `AssetPatch` 明确禁止修改 `kind`，需要同步接口、DTO 和服务端类型依赖校验 |
| 镜头名称与卡片景别 | 当前 `StoryboardShotRead`、`ShotRead` 与 `shot_scripts` 无独立名称、景别字段，需要契约与持久化补齐 |
| 自动保存 | 正文与镜头已有自动保存；素材仍有手动保存入口，需要在原版本保护上增加串行自动保存 |
| 个人生成草稿 | 已有个人模型偏好不等于对象级参数草稿；需要明确私人保存路径，不能直接写入共享对象字段 |
| 生成输入接入 | 素材图与分镜图支持最多 4000 字符的补充提示词；分镜图部分参数和视频输入须读取共享保存设置，需按实施文档 C5 扩展私人草稿引用，同时保留来源校验 |
| 模型和可选参数 | 原型值是示例，正式实现按个人模型能力显示，不承诺每个模型支持 4K 或具体时长 |
| 素材／分镜提取 | 原型演示核对入口；示例同名对象跳过，不连接服务 |
| 视频预览 | 仅播放器布局与播放状态示意，没有生成或加载真实视频 |
| 跨素材与视频批量制作 | 本轮不纳入主路径；现有未实现项不包装为可用功能 |
| 成片合成 | 只保留流程位置与范围说明，沿用现有页面 |

视觉变量延续 [现有设计约定](../../frontend/DESIGN.md)，产品事实参考 [产品范围](../../frontend/PRODUCT.md)、`SourceStage`、`AssetsStage`、`StoryboardStage` 和相关现有流程测试。图片来源见 [SOURCES.md](standard-creation-workflow/assets/SOURCES.md)。未对生产设计系统进行更改。
