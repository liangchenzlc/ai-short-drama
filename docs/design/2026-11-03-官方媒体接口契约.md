# 官方媒体接口契约

关联[配置模块实施方案](../plans/2026-11/2026-11-03-配置模块实施方案.md)。
2026-11-04 按公开官方文档核对。本文记录本轮实际接口范围，
既有协议继续保留，仅移除 RunningHub 图片工作流。

## 策略与适配器

图片以协议族为策略，不以每个型号建立一套调用代码。
`ai/adapters/image/contracts.py` 定义构造请求、解析结果、能力和轮询接口；
`registry.py` 注册 OpenAI、方舟、通义/万相、Gemini、Grok 五族，
`selection.py` 解析显式协议和可信官方域名。配置、准入、执行和结果解析复用同一注册表。

`ai/adapters/model_protocols.py` 是文本、图片、视频、音频公开接口及协议映射的唯一目录。
`ai/data/official_media_models.json` 是已核实官方型号和固定能力的唯一数据源，
由 `ai/official_models.py` 提供目录与能力读取，不新增数据库协议表。
新增协议时实现适配器并注册；已有协议沿原策略修改，不为兼容重复一套实现。
HTTP、存储、异步任务、幂等和归档继续复用现有网关及 Worker。

## 图片范围

| 接口 | 创建与返回 | 本轮边界 |
| --- | --- | --- |
| OpenAI Images | `/images/generations`；原图片编辑 multipart；`data[].url/b64_json` | 保留既有 GPT Image 调用，不因模型名称猜测新能力 |
| 方舟 Images | `/api/v3/images/generations`；`data[].url/b64_json` | Seedream 继续使用方舟原生协议，支持已授权参考图 |
| 通义/万相 Images | 原 DashScope 同步/异步端点与查询合同 | `qwen-image`、`dashscope-qwen-image` 复用一个适配器；保留已有模型 |
| Google Gemini Image | `/v1beta/models/{model}:generateContent`；`inlineData` | `x-goog-api-key`；参考图由服务端内联，多张复用现有单图任务分发 |
| Grok Image | `/images/generations`、JSON `/images/edits`；`data[].url/b64_json` | 编辑限单参考图，使用 `image.url`，不套用 OpenAI multipart |

方舟公开页面核实的型号是 `doubao-seedream-5-0-pro-260628`。
Google 官方 SDK 示例核实的图片型号是 `gemini-3.1-flash-lite-image`。
界面展示名称或 Nano Banana 等俗称不作为服务端型号 ID。
获取到的账号模型列表或用户输入的准确模型 ID 仍是实际调用依据。

参考图编码不进入 `resolved_parameters`，Gemini 的 `contents` 与其他正文一起排除。
未知图片网关必须明确选协议；官方域名自动匹配不等于供应商实际生成验收。

## 视频范围

| 接口 | 创建 | 查询 | 已实现输入 |
| --- | --- | --- | --- |
| 方舟 Seedance | `/api/v3/contents/generations/tasks` | 原任务 ID 对应端点 | 沿现有方舟策略与保存能力执行 |
| MiniMax H3 | `/v2/video_generation` | `/v2/query/video_generation/{task_id}` | 文本、首帧/尾帧、参考图片组 |
| 可灵 4 | `/text-to-video/kling-4.0`、`/image-to-video/kling-4.0` | `/tasks?task_ids=...` | 文本、首帧/尾帧 |
| 通义万相 | 既有 DashScope 创建端点 | 既有原任务查询 | 原已支持的 Wan 型号；未开放 Wan3 |
| OpenAI Videos、NewAPI、ModelHub | 保留原合同 | 保留原合同 | 不改变原已支持范围 |

MiniMax 使用 API Key Bearer、`content` 角色数组；创建只取 `task_id`，
查询以 `task.id/status/content.url/usage` 读取原任务。固定能力：

| 准确型号 | 时长 | 分辨率 |
| --- | --- | --- |
| `MiniMax-H3` | 4–15 秒 | 768p、2K |
| `MiniMax-H3-Highspeed` | 4–15 秒 | 480p、768p |
| `MiniMax-H3-Lite` | 4–15 秒 | 480p、768p |
| `MiniMax-H3-Max` | 5–15 秒 | 480p、768p |

参考组最多九图，与首尾帧分开使用。已授权图片转换为 Data URI，
沿官方每图 30 MiB 和 JSON 请求总量 64 MiB 边界处理。
参考视频、音频、音轨生成未对外开放，不因官方还有其他能力而放宽本轮准入。

可灵使用北京或新加坡官方主机及直接 API Key Bearer，
不使用旧版 AK/SK JWT；`settings` 保存时长/分辨率，
首尾帧使用 `contents[].type=first_frame|last_frame`。
图片原字节通过现有已授权存储读取器转 Base64。
`kling-4.0` 固定能力为 3–30 秒、720p/1080p。
创建取 `data.id`，查询从 `data.result` 中读取同一任务的 `outputs`；
本轮不接中间帧、多模态 Omni 或其他旧版可灵协议。

方舟公开文档出现的 Seedance ID 已登记到官方目录：
`doubao-seedance-1-0-lite-i2v-250428`、`doubao-seedance-1-0-pro-250528`、
`doubao-seedance-2-0-260128`、`doubao-seedance-2-5-260628`。
目录不是账号授权证据，各型号仍经过现有请求准入及实际供应商结果判断。
