# 分集创作流程视觉精修方案

日期：2026-10-20。状态：**用户已同意方案及第12节A–D，实现与本轮回归完成**。适用范围：标准模式分集详情的四阶段、阶段内浮层及共用 AI 创作助手。实际批次、验证结果与未覆盖边界见[实施记录](../plans/2026-10/2026-10-20-分集创作视觉精修实施记录.md)。

本次修订已纳入用户明确要求：**移除共用顶栏账号入口；页面内边距、功能区间距从紧控制；减少常驻说明，保持简洁**。以下逐页建议已按此同步调整，不再沿用原稿较宽松的留白建议。

## 1. 设计结论与范围

建议沿用现有的**中性炭黑创作工作台**：黑底、灰阶分层、白底深字主按钮、系统中文字体。通过操作层级、对齐、控件状态和局部间距获得精致感。作品本身是视觉中心，界面保持安静。

本方案保留 60px 单层顶栏、居中四步骤、剧本左设置右正文、素材与分镜左列表加预览和设置、成片剪辑台的既有骨架。提示词仍在原设置区，生成按钮保留圆形图标，素材与镜头卡片不展开、不增加常驻操作排。

方案初审以当时工作区源码和本机最近截图为依据；第2节保留该阶段的历史证据边界。用户同意后已进入实现，保留已有未提交修改，只调整相关标准创作界面；不修改无限画布的源布局与交互。

### 1.1 覆盖地图

| 区域 | 页面、子状态与浮层范围 |
| --- | --- |
| 共用顶栏 | 返回、分集选择、四步导航、保存详情与版本核对、助手开关、移除账号入口、旧稿恢复、会话失效重新登录 |
| 剧本创作 | 空稿来源选择、梗概输入、小说改编设置、当前正文、候选预览、原文抽屉、导入剧本、生成记录、任务详情 |
| 素材生成 | 搜索分类、草稿与素材卡、作品预览、名称类型描述、参考图、生成参数、生成记录、素材操作、提取核对、项目库导入 |
| 分镜制作 | 搜索筛选、镜头卡、图与视频、名称脚本、参数、参考图、原生对白条件入口、提取核对、媒体记录、分镜记录、批量、排序、归档 |
| 共用图片工具 | 大图预览、设主图、编辑、宫格切分、裁剪与局部编辑、标注、图片处理、单图修改历史；按实际入口显示可用工具 |
| 成片合成 | 素材区、播放器、剪辑工具、时间轴、导出栏、专注剪辑、同步、导出设置、导出记录、采用成片、结果回看 |
| 声音编辑 | 成片内原位展开的原声、字幕、配乐，以及关联候选、试听、参数、历史与反馈 |
| AI 创作助手 | 消息、输入、模型、引用、附件与技能、会话历史与管理、作品引用选择、只读历史创作记录 |

“每个控件都检查”不等于每个控件都改。下文使用五种判定：**保留**（已有设计合适）、**精修**（视觉或细节调整）、**修正**（反馈/可达性/说明不一致）、**移除**（用户已明确要求删除的入口或重复信息）、**已同意调整**（原需单独评审、现已获得同意的第12节A–D）。

### 1.2 本轮边界

- 不新增色系、字体依赖、装饰渐变、发光、背景纹理或大型说明区。
- 不调整桌面主分栏比例，不把提示词移到预览下方，不把单层顶栏改回双层。
- 不改自动保存、冲突处理、生成准入、权限、任务恢复和作品采用规则。
- 素材图、分镜图生成后直接保存完整图片组，第一张默认主图；剧本和视频仍使用各自的明确采用操作。
- 声音只从成片阶段进入；不在分镜阶段补“声音制作”按钮。不把不可达组件当作现有功能。
- 移除分集共用顶栏的账号头像/账号中心链接，桌面和窄屏均不保留替代占位；成片进入专注剪辑时也不重新出现账号入口。顶栏右侧仅保留保存状态和AI助手，四步继续几何居中。账号中心页面与认证、会话失效恢复行为不变。

## 3. 视觉方向和统一尺度

### 3.1 颜色与字体

下面六个核心色直接沿用现有变量，不引入新主色。

| 角色 | 现有值 | 用途 |
| --- | --- | --- |
| 工作区底色 | `#101010` / `--canvas` | 连续工作背景 |
| 面板底色 | `#181818` / `--surface` | 列表、设置、编辑面板 |
| 浮层底色 | `#1f1f20` / `--surface-raised` | 弹窗、下拉、悬浮工具条 |
| 悬停底色 | `#242424` / `--surface-hover` | 可操作对象的短暂反馈 |
| 主操作填充 | `#f5f5f5` / `--accent-fill` | 生成、采用、确认导出等当前主动作 |
| 正文文字 | `#f3f3f5` / `--ink` | 标题与主要内容 |

次级文字沿用 `--sub`，弱边线沿用 `--hair`，控件边线沿用 `--border-control`。错误、警告、成功继续使用现有语义色；同一创作页面统一取本地主题变量，避免一处用全局红色、另一处硬编码另一种红色。

字体保留 `Segoe UI / PingFang SC / Microsoft YaHei / sans-serif`。界面正文 13px，标签 12px，帮助文字 11–12px；阶段/对象标题按现有位置保持 16–21px。剧本正文保持 14px、约 1.95 行高、760px 最大阅读宽度。模型名称可省略，但完整名称在展开菜单和悬浮提示中可见。时间、镜号、尺寸使用等宽数字，不给普通中文标签加等宽字体或字间距。

### 3.2 间距规则：区分关系，不平均铺开

| 关系 | 推荐尺度 | 具体要求 |
| --- | --- | --- |
| 图标与文字、标签与值 | 4–6px | 一眼看出属于同一控件 |
| 标签与输入、同组按钮 | 6–8px | 不把一个操作拆成两段 |
| 相关字段组 | 8–10px | 名称/类型、参数组、历史条目内容 |
| 不同功能区 | 8–12px | 默认12px；强关联区域8px，不默认用16–24px撑开 |
| 页面外围内边距 | 桌面默认12px、最大16px；手机10px | 大屏也不扩大外围留白，列间距沿现有响应式规则 |
| 桌面面板内边距 | 默认12px | 标题、字段、正文共用垂直对齐线；嵌套区不重复叠padding，确需区分时最多16px |
| 普通浮层正文 | 默认16px；紧凑局部12px | 标题、内容、页脚共用左右基线，不默认使用20–22px |
| 浮层页脚 | 纵向12px、横向16px | 固定在正文滚动区外，按钮gap6–8px |
| 手机局部面板 | 10–12px | 保留操作热区，减少外围留白 |

正文只有一行、预览只有一张图时，作品区域的空余属于可编辑/可预览空间，不强行塞提示卡，也不把整个工作台缩成短卡。真正要收敛的是重复标题、嵌套边框、同组操作之间的散落间距和不必要的固定高度。

16px以上间隔不作为默认值；只有正文阅读、触控命中、必要的操作分隔等具体理由才保留。普通设置区、历史列表、空状态与弹窗都遵循本节紧凑规格，不能每页再单独放大一档。

### 3.3 保留的容器几何

| 项目 | 当前基线与方案 |
| --- | --- |
| 共用顶栏 | 保留 60px、四步几何居中、当前步骤编号白底；不增加进度计数 |
| 页面内边距 | 桌面以12px为默认，最多16px；手机10px。收紧现有20/28px等外围留白，不改变主分栏结构 |
| 1440px 素材/分镜 | 列表 250px，设置约 324px，列距 12px；助手 320px，按现有规则让出空间 |
| 1440px 剧本 | 左设置 306px；正文居中，阅读宽度最多 760px |
| 对象标题与作品标签 | 标题行约 56px，标签行约 41px；只调内部对齐，不额外加说明行 |
| 素材/分镜卡片 | 1440px 档总高 187px、名称行 38px、圆角 8px；其他断点沿用现有 token，不套旧 V2 的 150px |
| 提示词 | 内容区默认 180px，可调 160–360px；低矮桌面素材/分镜为 160px。小说桌面组合框约241px保留；手机按D改为约253px，详见第5节 |
| 自适应 | 保留现有 ResizeObserver 阈值及上下预览/设置重排；上下重排不人为扩大预览固定高度 |
| 手机 | 顶栏 60px，列表约 332px 内滚动，主面板与设置/助手抽屉沿现有断点；不新增整页横向滚动 |

当前局部 `--creation-*` 变量已承担列宽与卡高，应继续复用，不能通过全局 Ant Design token 一次性改变所有工作台页面。

### 3.4 按钮、输入与下拉的统一状态

| 控件 | 精修规则 |
| --- | --- |
| 常规文字按钮 | 桌面沿用 34px；同一操作组等高。宽度由文字与左右 12–13px 内边距决定，不按容器等分铺满 |
| 图标按钮 | 普通对象工具保持 32×32px；边界清楚、图标居中。24/27px 的小工具仅在原有紧凑位置使用，需核验热区 |
| 生成按钮 | 桌面保持原有 30×30px 圆形白按钮，loading 图标居中；禁止新增金色或带文字大按钮 |
| 触控 | 已同意D：手机生成、模型及参数操作行采用可见44px高度，圆形发送为44×44px；允许为此重排底栏。素材/分镜在组合框可用宽度不足320px时模型独占第一行，参数与发送第二行；小说保持176px模型与44px发送同排。助手标题工具沿用40px，不将所有小工具一律放大 |
| 主次层级 | 一个局部任务只强调一个主动作；关闭/取消为次按钮，删除/共享影响独立分组，不把所有按钮都刷白 |
| 悬停 | 背景与边线明度改变，120–160ms；不缩放、不抬起、不改变边框宽度、宽高或文字位置 |
| 按下/选中 | 按下色短暂变化；选中使用持续灰底与边线，不能和 hover 相同 |
| 键盘焦点 | 保留 2px 可见焦点；小说正文/创作要求/框内模型现有“不加聚焦外框”例外保留，其他入口不可被全局 `outline:none` 清掉 |
| 禁用 | 明确区分只读、缺条件、执行中；必须在临近位置说明原因，禁用按钮不可成为唯一解释入口 |
| 输入框 | 普通单行保持 34px；标签常驻，不能全靠 placeholder；错误在字段下方，保留输入，不引起整个表单跳动 |
| 多行输入 | 根据用途自适应；短描述不强占 180px，提示词保留既有可调范围；底部操作不会压住末行文本 |
| Select / AutoComplete | 收起时单行省略，菜单可更宽；长模型选项可用“名称 / 型号与状态”两行，建议菜单 280–360px 并受视口约束；普通枚举保持单行 |
| 下拉条目 | 普通行 32–34px；双行模型项 44–48px；菜单不留大片空白。不支持的比例/清晰度保留禁用原因 |
| Tooltip | 只补充图标含义、完整名称或原因，建议延时 300–500ms；不能承载唯一操作说明，触屏不依赖 hover |

### 3.5 “更多”菜单的使用原则

同属一个对象、低频、不是当前步骤必经的操作可以放在同一个更多菜单。菜单最多一级，按“导入/替换”“共享”“移除/归档”等真实业务关系分组，危险项放底部并有分隔线。低风险动作点击即可，影响共享作品或移除对象仍沿用原核对/确认。

不收起：生成、采用、选择、上一镜/下一镜、播放、分割、撤销/重做、主要导出入口。不能把不同对象的动作塞进一个全页更多，不能为了页面整齐增加必经点击。

| 操作组 | 决策 |
| --- | --- |
| 素材列表新增/提取/导入 | 保留标题栏三个入口；统一 32px 图标工具及 tooltip |
| 素材上传/资产库选择/共享/从本集移除 | 已同意C：保留生成记录底部“素材操作”，主面板新增同一组操作的更多图标快捷入口；不把每个动作常驻铺开 |
| 分镜列表新增/提取 | 保留直达；不与排序、批量混在标题栏 |
| 分镜批量/排序/归档 | 已同意C：历史底部与主面板更多入口复用原回调及权限、边界判断；归档危险项独立分组 |
| 单张图片工具 | 已同意B：保留预览与条件设主图，使用“编辑图片”和“更多图片操作”两个一级菜单，具体分组见第8节 |
| 剪辑工具 | 高频工具保留；用6px组内距、分隔线和8–12px组间距收敛，不先隐藏 |
| 助手会话管理 | 当前已有新对话快捷入口与历史管理；沿用，不因旧文档描述而擅自删除入口 |

### 3.6 页面说明与文案减量

默认界面只保留定位、输入、作品和操作，不新增阶段副标题、使用教程卡或大段能力介绍。精简的是界面说明，不删用户创作的正文、素材描述、台词或提示词。

| 信息 | 处理规则 |
| --- | --- |
| 已有标题/按钮能表达的说明 | 删除重复内容，例如“可在这里编辑/通过AI生成/内容会自动保存”等常驻介绍；无需每页再解释一次流程 |
| 一般用法、低频技巧、技术细节 | 图标Tooltip或按需details，不默认展开；保存细节、任务编号、版本技术信息放对应详情 |
| 空状态 | 最多一行原因+一个主要行动；不叠加欢迎语、长说明和大型占位卡 |
| 字段 | 保留短标签；格式/大小/数量限制就近短写，不新增整段帮助文字 |
| 正常保存/来源 | 保留状态图标或简短来源，不常驻多行解释；涉及共享影响时才显示必要说明 |
| 候选、权限与能力 | 保留“未采用”“只读”“缺少主图”等最短必要状态；同一状态避免在标题、预览、页脚重复多次 |
| 错误、冲突、受理不明 | 条件出现，简短说明问题和下一步；不能为了简洁藏掉恢复入口 |
| 删除/共享/费用/旧输入重生 | 只在对应操作前后就近提示必要后果，不写成页面常驻说明；原核对与确认条件保留 |
| 隐私 | 保留简短的“仅你可见”等必要边界，不重复铺陈实现机制 |

## 4. 共用顶栏与状态层

| 元素/入口 | 判定 | 方案 |
| --- | --- | --- |
| 返回、项目名、分集入口 | 精修 | 保留当前位置和单行省略；同一垂直中心线；返回按钮不挤压当前分集名称 |
| 四步导航 | 保留 | 只显示编号和名称。hover 提亮，当前步骤稳定，不把圆圈做成完成勾选 |
| 分集选择浮层 | 精修 | 当前集灰底+文字标识；集号、标题对齐；长标题省略且可看全；保留每页20条、继续加载、失败重试、空态；切换不增加保存确认 |
| 保存图标/异常计数 | 精修 | 保持正常状态安静；保存超过800ms才展示文字；异常计数与图标对齐，别用连续闪烁吸引注意 |
| 保存详情 Popover | 精修 | 当前最大约352px宽、560px/70dvh高；按资源分组，标题+状态+动作，不堆成长按钮串；正文内部滚动 |

| 搜索/筛选/换页 | 搜索框尺寸稳定；无结果和“本集还没有内容”区别表达；过滤不悄悄丢掉选中对象或草稿 |
| 阶段与分集切换 | 保留已有会话与后台保存机制，不补“未保存，是否离开”日常确认；刷新保护规则保持现状 |
| 专注剪辑 | 清楚显示退出入口与保存反馈，Escape按原规则退出；不让额外浮层遮住唯一出口 |

### 11.3 每个数据区域必须覆盖的状态

| 状态 | 表达要求 |
| --- | --- |
| 首次载入 | 主要骨架与真实区域等尺寸，避免加载前后版式大跳动；局部操作可用局部loading |
| 空数据 | 一个短说明和真实下一步，不加大插画。未选对象与没有对象分开表达 |
| 执行中 | 触发按钮loading防重复提交，显示真实状态；关闭观察窗口不等于取消后台任务 |
| 失败 | 就近说明失败操作与恢复办法，保留已有作品和输入；重试loading不能误导为新任务已成功 |
| 来源变化/冲突 | 解释版本与影响；保留当前草稿、核对与重载路径；不能靠换成红色边线代替说明 |
| unknown/受理不明 | 显示正在核对和原请求入口，不能给一个会重复收费的“再次生成”主按钮 |
| 只读/权限不足 | 浏览内容仍可读，编辑和提交正确禁用；共享图与私人任务、参数、对话边界不变 |
| 长内容 | 长中文名称、长模型名、多行错误、0/1/20/80条列表、多参考图不撑破容器；数字ID始终是字符串 |

### 11.4 动效与无障碍

仅保留状态回应：颜色/边线120–160ms、浮层约180ms，不增加页面入场编舞。减少动态效果时关闭位移动画。所有图标入口有名称，表单有标签，选中项不只靠颜色，Tab顺序沿视觉顺序；关闭弹窗、删除条目和切换对象后焦点落在仍存在的合理位置。
