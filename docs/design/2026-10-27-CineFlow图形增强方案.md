# CineFlow 图形增强方案

日期：2026-10-27。用户针对 `cineflow-mark-light.svg` 提出单独字母 C 偏单调，希望增加设计元素。本轮保留品牌名称、字标、蓝绿背景色和画框轮廓，增强独立图形。

## 选定方案：C＋F

在画框式 C 内加入 F，分别对应 **Cine** 和 **Flow**。F 的两条横笔采用斜切端点，与 C 的开口形成呼应。图形由两个填充路径组成，保持单色可用。

为容纳 F，C 的内侧上边从 84 调整至 78、下边从 172 调整至 178；外轮廓和 256 × 256 源画布不变。F 使用较窄的横笔与独立竖笔，保留左右及底部间隙。定稿前修正了初稿横笔过长、竖笔过短造成的 E 字母误读倾向。

六个主 SVG、两档应用图标 PNG、横向组合标志 PNG 及总预览均同步更新；用户指定的 [cineflow-mark-light.svg](../data/brand/cineflow/cineflow-mark-light.svg) 是当前 CF 主版。原始单字母 C 保存在[归档文件](../data/brand/cineflow/archive/cineflow-mark-light-v1.svg)。

## 比较过的方向

| 方向 | 表达 | 本轮处理 |
| --- | --- | --- |
| C＋F | 名称两个构词部分的首字母，与品牌直接关联 | 选为主版 |
| C＋流线 | 影像与创作流程向外延伸，流动感较强 | 保留独立备选 SVG |

[方向对照图](../data/brand/cineflow/cineflow-mark-comparison.png) 包含原稿与三个增强方向，以及深色、渐变背景和 16–64px 实际尺寸。

## 验证与范围

- 使用 Skia Path2D 绘制 C、F、播放符号及流线轮廓，交付保持为原生 SVG。
- 8 个当前 SVG（6 个主版、2 个备选）分别在关闭系统字体加载的情况下渲染为 16、24、32、48、96、256、512px 宽度，共 56 次；另检查总预览中的 16–128px 图标与深浅背景组合标志。
- 目视检查 F 的横笔、竖笔和内侧间隙；建议图标使用宽度至少 24px。16px 可用作紧凑图标，细节辨识度较低。
- XML 结构、SVG 的 viewBox、非矢量节点和本次文档的本地链接另行检查。
- 仅修改设计资产及说明，未修改业务代码或应用内品牌入口，未执行业务功能测试。
