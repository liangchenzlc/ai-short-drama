# 整个创作流程提示信息清单

日期：2026-10-20。范围：标准模式分集详情的剧本创作、素材生成、分镜制作、成片合成，以及共用顶栏、AI 助手、生成记录、图片工具和相关弹窗。

本文保留实施前审计记录。公共反馈及各阶段迁移后的维护约定见 [标准创作流程反馈规则](创作反馈规则.md)，后续开发以该规则和当前源码为准。

本清单基于当前源码静态核对。相同组件的重复提示合并记录；任务等业务 DTO 携带的错误及部分本机异常为动态文本，按实际显示出口归类，不将其视为有限的固定字符串；普通 HTTP 错误经客户端统一映射，不直接显示服务端原始 message。本轮仅整理清单与展示建议，没有修改界面，也没有逐一触发浏览器异常验收。

## 1. 对工作台尺寸的影响与统一建议

| 标记 | 当前表现 | 建议 |
| --- | --- | --- |
| 挤压 | 在正常文档流新增 Alert、段落或任务块；减少定高容器中的编辑、预览和列表空间，或增加滚动；窄屏时可能继续向下推高页面 | 移到原有按钮、保存状态、模型选择器或任务入口的锚定浮层，不新增提示行 |
| 换行风险 | 已在工具栏或状态行中，但文本变长可增高或挤占相邻按钮宽度 | 固定入口尺寸，摘要单行截断；完整内容通过鼠标悬浮、点击和键盘聚焦打开 |
| 原区替换 | 加载、空态或失败替代原有列表、编辑器、图位或播放器内容 | 保持该区域原有尺寸，在区域内部替换或覆盖 |
| 已为浮层 | 位于下拉、Popover、Dialog、Drawer 或播放器绝对定位层 | 保留浮层承载；长内容在浮层内部滚动，不传导到工作台 |

| 信息性质 | 统一承载方式 | 必须保留的内容 |
| --- | --- | --- |
| 正常读取、核对模型能力、提交中 | 原按钮或选择器 loading；必要说明放其浮层 | 禁止重复点击、可访问的加载状态 |
| 成功、已复制、提交成功 | 固定定位短通知；原按钮结束 loading | 生成结果和任务记录仍可回查 |
| 普通操作失败 | 对应操作的锚定错误浮层；无内容可用时使用原区错误态 | 完整原因、重试；同一故障避免多处重复横幅 |
| 网络中断、轮询断连 | 原保存或任务入口显示紧凑异常状态；详情浮层保留重连 | 后台是否继续、最近状态、重试方式；不能一律称为生成失败 |
| 版本冲突、恢复记录损坏、请求受理不明 | 既有状态入口保留持久异常标记，点击进入 Popover、Drawer 或核对 Dialog | 下载、双版本核对、重试原请求、明确清除等全部恢复动作 |
| 字段不合法、缺模型、参数不支持 | 控件错误态与锚定反馈；禁用原因应可点击或键盘访问 | 具体字段、限制值、修改方式 |
| 静态帮助 | 既有标题、字段或工具按钮的帮助浮层 | 单位、约束及必要操作说明；不能隐藏业务确认控件 |
| 付费、清除记录等操作确认 | 保留确认弹窗 | 风险说明和明确确认操作 |

不为这些提示新增侧栏、状态大横条或空白预留区；不恢复此前已删除的“已生图”“结果未采用”等预览标签。浮层需限制在视口范围内，不产生页面横向滚动，支持键盘、焦点回归及 `alert/status` 通知。
