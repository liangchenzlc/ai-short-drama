## 1. 目标与范围

创作工作台在同一套流程中支持单剧和多集作品。用户不需要选择或切换作品类型：新作品默认有一集，需要时添加分集，只有多集时才展示分集选择器。作品级资产共享，剧本、分镜和成片数据按集隔离。

本次设计覆盖剧本创作、资产生成、分镜制作，以及它们需要的后台模型、生成流程和接口边界。成片预览节点的页面和交互不在本次设计范围内；为避免多集串用，成片数据及既有取数入口需要按集对接。

开发顺序是硬约束：

1. 先完成前端交互和视觉验收；这一阶段不改后端业务、数据库或正式接口。
2. 用户确认前端后，按照稳定的页面交互实施后端、更新契约并联调。
3. 前端验证中的模拟数据只用于可见的开发预览，不冒充真实保存或真实生成；后端接通后撤掉模拟入口，不保留两套正式业务流程。

## 2. 现状与改造重点

- 现有项目只能有一份已确认剧本，编辑稿和剧本、分镜版本都以项目为范围；分镜顺序也在项目内唯一。这些边界需要下移到分集。
- 现有资产属于项目，符合全剧共享的方向；素材信息目前主要是名称和通用描述，角色画像需要结构化。
- 资产、分镜列表已有宫格与列表切换。分镜已有批量任务与预检基础，资产生图具备批量后端能力但工作台尚未接入。改造重点是统一中间工作区与批量操作，不重新造任务引擎。
- 现有图片组已有图位、主图和历史，可复用。当前新组的第一张可能自动成为主图，本方案改为：只有原本没有主图时才自动设置，重新生成不会自动替换已有主图。
- 当前分镜视频单项和批量流程都要求分镜图。支持不生成分镜图直接生成视频，需要改变前后端请求契约和模型能力判断。
- 当前资产标签会进入生图上下文，资产更新也会使素材变为待确认。既然标签只用于查找，应从生图和分镜上下文中移除标签的创作语义。

## 3. 工作台与分集

保留现有四个主阶段和可展开的 AI 创作助手。资产库面向整个作品；剧本正文和分镜面向当前分集。多集时，顶部在集级工作区域显示当前分集与选择入口。

~~~text
┌──────────┬─────────────────────────────────────────────────────────┐
│ 剧本创作 │ 作品名称        第 01 集 · 初遇 ▾          AI 助手       │
│ 资产生成 │─────────────────────────────────────────────────────────│
│ 分镜制作 │ [大纲] [剧本]                                           │
│ 成片预览 │                                                         │
└──────────┴─────────────────────────────────────────────────────────┘
~~~

- 新作品创建一个默认分集；单集时不展示“第 1 集”与分集选择器。
- 添加第二集后显示选择器，原剧本、镜头和关联媒体仍属于原来的第一集，不搬迁或重建。
- 分集按顺序显示，可新增、改名、排序和删除；删除操作明确提示会移除该集的概要、剧本、分镜和成片数据，共享资产保留。至少保留一集。
- 切换分集时，保存或保留当前编辑，再载入目标集；后台运行中的任务继续属于提交时的集与对象。批量勾选不跨集沿用。
- 删除至只剩一集后隐藏分集选择器；剩余集的数据保持原样。

### 3.1 视觉与动效

沿用当前工作台的深色主题、字体、图标与间距体系，以标题、布局与状态区分层级。左侧资源导航保持稳定，主工作区内的资料、预览与提示词对齐；长内容各自在所属区域滚动，AI 助手展开后仍可读、可编辑。表单保留必要标签与可访问名称，不增加常驻教学段落。

视图切换、选择、缩略图切换及分镜图输入区展开使用短促、连续的过渡，避免大幅位移和操作卡顿；加载中的图片和卡片保持占位尺寸，减少布局跳动。遵循减少动态效果的系统设置，键盘焦点与选中状态始终可见。

## 4. 剧本创作

### 4.1 大纲

原“选题”并入大纲，不设单独步骤。项目级大纲包含题材、故事核心和故事大纲；多集时在其后展示分集概要。大纲视图面向整个作品，剧本视图编辑当前集。

~~~text
[大纲] [剧本]                                      ＋ 添加分集

题材       悬疑 / 都市
故事核心   林夏收到一封匿名信……
故事大纲   ……

分集概要
01  初遇            林夏收到第一封信……
02  未寄出的信      林夏发现信封上的旧地址……
03  重逢            ……
~~~

只有一集时只展示故事大纲，不展示多余的分集概要列表。已有故事设定的题材、核心和梗概分别承载这些内容；故事层面的人物关系可写在大纲中，角色的正式结构化画像以资产页为准。后端实施时将现有非空人物小传并入大纲正文，再移除重复的故事设定字段，不丢弃原文。

分集可手动逐集添加，也可输入生成数量，由 AI 一次产生可编辑的分集概要。采用前显示将填写和新增的集数；默认第一集概要为空时先填入它，其余结果追加新集。已有概要不自动覆盖。用户可取消结果或编辑后采用。

### 4.2 剧本

单集直接显示完整剧本；多集一次编辑一集，通过顶部选择器切换。剧本编辑沿用现有编辑器、自动保存、选区改写和生成输入方式。同一集的剧本候选与修改记录属于这一集，不与分集列表混用。

~~~text
[大纲] [剧本]                         第 01 集 · 初遇 ▾

第一场  咖啡馆·日·内

林夏推门进来，将一封信放到桌上。
……
~~~

## 5. 资产生成

### 5.1 视图与单卡

资产页是全剧共享库。左侧沿用现有资产库列表、分类、搜索、创建、更多操作以及原有列表／宫格切换；标签精确筛选和新的单卡、宫格、列表切换位于中间工作区，两处展示方式独立。左侧资源导航用于选择对象，单卡不出现“上一个 / 下一个”。

~~~text
资产导航        资产信息                         图片与生成
                ┌──────────────────────┬─────────────────────────┐
角色            │ 姓名   林夏           │        当前预览图片       │
场景            │ 定位   主角           │                         │
道具            │ 性别   女  年龄 28    │ [① 主图] [②] [③]  全部 │
                │ 身份   记者           ├─────────────────────────┤
                │ 外貌   ……             │ 图片提示词               │
                │ 性格   ……             │                         │
                │ 标签 [第 01 集] [+]   │ 模型 / 参数            ↑│
                └──────────────────────┴─────────────────────────┘
~~~

角色字段为名称、定位、性别、年龄、身份、外貌、性格。定位支持主角、配角、群演和未填写；年龄使用可编辑文本，允许“28 岁”或“二十多岁”。字段可留空，AI 从剧本提取时没有依据的信息留空。场景和道具继续使用适合自身的名称与描述，不套用角色字段。

角色资料是创作信息，图片提示词是本次生图要求：生成时由角色资料、用户输入及所选参考组合上下文，不自动维护一份重复的角色总描述。沿用现有图片提示词组件、模型选择、参数和参考能力。

### 5.2 图片组与主图

- 一张图时直接预览；多张图时展示当前预览及缩略图条，“全部”展开同组图片以便比较。
- 点击缩略图只切换查看；“设为主图”才改变默认主图。当前预览和主图分别标识。
- 无主图时第一张成功的结果自动设为主图；已有主图时，新组作为新结果展示，用户选择后才替换。若正在查看的组不含当前主图，提供当前主图入口。
- 图片组的每个图位各自显示生成中、完成或失败；失败项可重试。生成历史可查看和采用旧图。
- 一次返回多张独立图片是一组多个图位；一张九宫格图片仍是一张图，可沿用现有图片工具切分。
- 图片按原比例完整显示，预览区限制高度，点击可放大，不能把下方大提示词输入框挤出主要工作区域。

### 5.3 分集标签

分集是普通文本标签，只用于查找与筛选，不建立资产与分集的归属关系。一个资产可有多个分集标签；不标记时仍可供任意一集使用。标记或移除由用户主动操作，不根据分镜引用自动增删。

沿用资产已有标签字段与搜索能力，增加标签编辑和精确筛选。标签筛选和批量选择必须使用相同范围；“第 01 集”只匹配该标签。现有每资产 20 个标签的限制应放宽，使同一资产能标记作品中的全部分集。

标签是文字：分集改名、删除或调整顺序时，标签不自动同步；用户按需修改。更新标签只影响检索，不能改变已采用图片的确认状态，也不应改变生图提示词、分镜上下文或使已有结果失效。普通素材标签统一采用这一检索语义。

## 6. 分镜制作

### 6.1 单卡

每集独立维护镜头。左侧沿用现有分镜表、搜索、待制作筛选、创建、更多操作以及原有列表／宫格切换；中间工作区的三种展示方式独立。中间单卡左侧编辑镜头信息与分镜图，右侧始终展示视频预览和现有的大提示词输入框；不出现“上一个 / 下一个”。

~~~text
分镜导航        镜头信息                         视频与生成
                ┌──────────────────────┬─────────────────────────┐
镜头 01         │ 镜头 03               │        视频预览          │
镜头 02         │ 景别 中景  时长 4 秒  │                         │
镜头 03         │ 镜头描述：画面、对白… ├─────────────────────────┤
                │                      │ 参考图                   │
                │ 分镜图 [缩略图] 1/4  │ [林夏 ×] [咖啡馆 ×] [+]  │
                │ [生成分镜图 ▾]        ├─────────────────────────┤
                │ ┌ 图片提示词 ──────┐ │ 视频提示词               │
                │ │ 模型 / 参数    ↑ │ │                         │
                │ └──────────────────┘ │ 模型 / 参数            ↑│
                └──────────────────────┴─────────────────────────┘
~~~

点击“生成分镜图”在左侧展开独立的图片提示词输入框、模型与参数，再点击生成。收起时保留输入；图片和视频提示词各自保存。已有分镜图使用缩略图及图片组查看方式，支持选择图片并“用于视频”。

镜头描述是一份可编辑文本，承载画面、动作、运镜和对白；景别、时长使用现有镜头字段，不再复制一套平行描述。

### 6.2 两条视频生成路径

~~~text
镜头描述 + 已选角色 / 场景参考图 ──────────────────→ 生成视频
镜头描述 + 已选角色 / 场景参考图 + 选入的分镜图 ──→ 生成视频
~~~

- 默认选入该镜头关联角色和场景的当前主图，明确显示在视频提示词附近；用户可逐个移除或重新加入。
- 移除仅影响当前镜头的视频生成参考，不删除素材、分镜图或镜头与资产的引用。选择随该镜头的视频草稿保存，不因刷新或切换自动恢复被移除项。
- 分镜图需要用户明确选入视频参考；生成分镜图本身不自动改变视频参考。
- 关联资产没有主图时仍可使用文字资料，参考区标明缺图；已选资产引用在新一次生成时使用该资产的当前主图，更换主图会更新参考区缩略图，不会重选已被移除的资产。已生成视频和历史来源保持原样。
- 参考图不是默认首帧。根据模型真实能力选择参考图输入；模型不支持所选参考或数量超限时，显示原因并允许换模型或移除参考。
- 不选任何图片时才是纯文字生成视频。视频提示词为空时，以已保存的镜头描述作为生成依据。
- 镜头尚无视频时，首个可用结果成为当前视频；已有视频时，新结果保留为候选，在生成历史中明确采用后才替换。

## 7. 宫格、列表与批量生成

资产和分镜的三种视图操作同一批对象。宫格用于比较画面，列表突出名称、描述和状态，单卡用于编辑；切换视图保留筛选和批量勾选。点击卡片进入该对象单卡，批量选择通过复选框完成。

~~~text
[单卡] [宫格] [列表]    搜索 / 类型 / 标签

☑ 全选筛选结果        已选 3 项                [批量生成]
┌─────────┐  ┌─────────┐  ┌─────────┐
│ ☑ 画面  │  │ ☑ 画面  │  │ ☑ 画面  │
│ 林夏    │  │ 咖啡馆  │  │ 信封    │
│ 已生成  │  │ 生成中  │  │ 待生成  │
└─────────┘  └─────────┘  └─────────┘
~~~

- 资产批量生成图片；分镜批量生成分镜图或视频。镜头的批量范围为当前集，资产范围为当前作品的筛选结果。
- “全选筛选结果”包含所有匹配数据，不仅是已加载到页面的卡片。超过现有单批 100 项时，按现有批次上限拆分提交；当前页面汇总进度，每个批次在任务历史可查。
- 提交前展示所选数量、可执行数量和跳过原因。默认只生成缺失项；重新生成已完成项由用户明确选择。
- 本次批量统一选择生成模型；资产图可统一本次输出参数，分镜图和视频沿用各镜头保存的画幅、时长、描述、提示词和参考图选择。
- 每项显示排队、生成中、完成或失败，可查看原因并重试失败项。部分失败不隐藏已完成结果；已有主图或视频不因重新生成而悄悄替换。

## 8. 后端数据与接口设计

### 8.1 数据归属

~~~text
作品
├─ 项目级故事设定与大纲
├─ 共享资产（角色 / 场景 / 道具）
│  └─ 图片组、图位、主图、历史；普通文本标签
└─ 分集
   ├─ 分集概要、剧本及剧本版本
   ├─ 分镜 → 图片组 / 视频 / 镜头资产引用
   └─ 成片草稿及成片媒体
~~~

| 对象 | 目标设计 |
| --- | --- |
| 项目与大纲 | 项目保留名称、工作台模式与作品级大纲；故事大纲使用现有故事设定模型统一承载，不新增单剧 / 剧集类型字段。 |
| 分集 | 新增分集记录，包含稳定 ID、项目 ID、排序、标题、概要及集级版本；项目至少一集，新增与重排使用稳定 ID。 |
| 剧本 | 剧本候选和修改记录归属分集；同一集最多一份已确认剧本。现有项目级编辑剧本指针和正文版本改为集级。 |
| 分镜 | 镜头归属分集，排序在该集内唯一；分镜集合版本改为集级。镜头引用仍指向作品共享资产。 |
| 资产 | 角色、场景、道具仍归属项目；角色新增结构化画像，名称复用资产名称，其他字段由角色资料统一提供。图片组及主图沿用现有结构。 |
| 标签 | 沿用资产普通文本标签，不新增资产—分集关系表；精确标签筛选供列表和批量范围共同使用。 |
| 成片与声音 | 每集有自己的成片草稿和时间线；跟随成片的声音数据自然隔离，角色声音等项目级共享配置继续共享。 |
| 生成 | 保留现有任务、批次、图片组和媒体模型；资产生成冻结项目与目标资产，镜头生成冻结项目、分集与目标镜头，均记录版本、提示词及实际参考媒体。 |

角色画像作为资产的结构化资料，包含定位、性别、年龄、身份、外貌和性格。角色生图和分镜上下文读取同一份画像；场景和道具继续使用自己的描述。更新标签仍推进必要的编辑版本，但不改变素材确认状态、角色创作内容摘要或分镜生成上下文；在途生图只因标签变化时仍可正常采用，生成来源核对依据实际创作内容，不单凭资产编辑版本变化判定内容失效。

采用一次新的数据结构与接口，不保留单集和多集两套业务逻辑。实施后端时按项目规范同步 ORM、数据库变更、完整建表 SQL、接口文档及测试；已存在开发数据的处理通过明确迁移完成，不因“无需兼容”直接清空数据。

### 8.2 接口与上下文边界

以下为目标接口划分，正式字段在前端验收后与实现同步确定；实际接口统一使用项目现有的 API 前缀、鉴权、版本和错误约定。

| 范围 | 接口职责 |
| --- | --- |
| 作品 | 读取与保存项目级故事设定、大纲和共享资产；资产列表支持精确标签筛选。 |
| 分集 | 项目下创建、列出、修改、排序与删除分集；生成分集概要后明确采用。 |
| 集级创作 | 在项目及分集范围内读取、保存剧本和修改记录，列出、创建、修改和排序分镜。 |
| 生成与批量 | 沿用生成及批次入口；集级来源携带分集和对象身份，预检使用相同的分集、标签和选择范围。 |
| 视频参考 | 视频请求支持零张或多张参考图；前端显式传入已选来源，后端按模型能力校验并冻结实际媒体。 |
| 成片对接 | 既有成片读取和保存使用当前分集，页面内部布局不调整。 |
| AI 助手 | 项目、当前分集和当前对象成为明确上下文；项目级资产操作与集级剧本、分镜操作各自使用正确范围。 |

视频参考选择属于每个用户、每个镜头的视频生成草稿，可复用现有私人生成草稿机制。草稿中的参考列表区分“资产引用”和“选中的分镜图片”：前者保存资产 ID，在生成时解析当前主图；后者保存用户选中的图片媒体 ID。首次创建草稿或新增镜头资产引用时加入默认资产项；用户移除后持续保留选择，不因重新进入页面再次加入。已保存的空列表表示不使用参考图。提交时冻结实际媒体 ID；参考列表是否为空决定实际输入方式，不重复维护一份模式字段。

## 9. 分阶段实施与验收

### 第一阶段：前端先行

使用开发专用的可交互示例数据，覆盖单集、多集、空状态、图片组、生成中、成功和失败。预览入口挂载与正式工作台相同的页面组件；示例只在数据边界注入，明确标识为演示，不调用真实模型，不写真实项目，不把模拟成功当成已保存；示例修改只保留在当前预览会话，刷新后重置。后端实施并接通后删除预览入口与模拟数据。

1. **工作台与剧本**：呈现单集、多集切换、大纲和剧本页面。最小验收：默认单集无分集选择器；添加第二集后，第一集正文仍在，两个分集可独立编辑。
2. **资产工作区**：完成单卡、宫格、列表、角色资料、标签、图片组和大提示词。最小验收：一张和多张图片均能查看；查看其他图片不改变主图；标签筛选不改变资产使用。
3. **分镜工作区**：完成镜头信息、左侧分镜图生成面板、右侧视频与参考区。最小验收：展开图片提示词后才能生成分镜图；有无分镜图都能演示视频生成；关联角色与场景参考可移除。
4. **批量与状态**：完成选择、筛选、预检、进度和失败呈现。最小验收：在宫格选择后切换列表仍保留选择，部分成功和失败可同时查看。
5. **前端完整验收**：在桌面最小内容宽度 1280 CSS px 及常用桌面宽度检查，分别检查 AI 助手展开和收起；使用真实浏览器多轮截图打磨布局、文本、图片比例和动效，并检查键盘操作、保存反馈及空状态。

前端验收确认前，后端结构和接口不实施；若页面调整导致交互或契约变化，先修订本文，再进入后端阶段。

### 第二阶段：后端与联调

1. **分集与写作**：建立分集、项目大纲和集级剧本边界。最小验收：两集可分别保存和确认剧本，原单集内容在添加第二集后不移动。
2. **资产与标签**：实现结构化角色画像、标签检索语义和共享资产。最小验收：同一角色可被两集引用；只改标签不改变主图及生成状态。
3. **分镜、参考与批量**：按集隔离分镜与任务，打通两种视频生成路径。最小验收：第一集任务运行时切到第二集，结果仍归第一集；去掉分镜图后仍可按模型能力生成视频。
4. **成片数据及接口**：按集对接现有成片数据，不调整成片预览页面布局。最小验收：两集成片草稿及时间线互不串用。
5. **完整验收**：从大纲创建两集，编写剧本，复用角色，分别生成分镜图和直接生成视频，切换视图批量查看，并验证标签筛选、结果采用、失败重试和跨集隔离。按项目测试映射运行前端、后端、数据库及必要的真实浏览器检查。
