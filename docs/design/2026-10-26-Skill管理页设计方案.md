## 一、确定的设计决策

本页采用 **Operate（操作型）** 模式，面向管理短剧创作方法的用户。主要任务是找到方法、检查文件、导入或更新，以及控制它在哪种创作模式中可用。

| 项目 | 本版决定 |
| --- | --- |
| 入口 | 保留独立页面「Skill 管理」，路由 `/skills`，侧栏位于「资产库」下方 |
| 页面 | 我的 Skill / 内置 Skill 两个页签，紧凑卡片，单一主按钮「导入 Skill」；卡片不展示文件数量 |
| 触发方式 | 从目标数据模型、接口、导入导出和所有界面中移除；不再记录自动或手动，由任务中的实际使用决定 |
| 标签 | 保留 `tags` 数据及导入导出能力；所有界面均不展示、不填写、不筛选 |
| 适用模式 | **三段式单选开关：通用 / 创作 / 画布，新增导入默认通用** |
| 录入方式 | 通过 Markdown 或 ZIP 导入；名称、用途、正文和资料从文件解析，界面只读 |
| 多文件 | 用一个 ZIP 保留目录和相对引用；所有预览统一为左侧目录树、右侧只读编辑区，按本地查看文件的方式切换；复用 Ant Design DirectoryTree / Splitter 与 CodeMirror 6 |
| 脚本 | 本期不接受脚本资源；发现脚本拒绝整个包，不提供忽略后继续或仅禁用执行的选项 |
| 更新方式 | 「更新文件」重新导入完整包，预览通过后整体替换；不在系统内逐文件编辑 |
| 简洁要求 | 无页头副标题、常驻使用说明、标签墙、版本号或重复状态文案；帮助按需打开，问题发生时再显示 |
| 旧页面退役 | 从 AI 配置页删除 Skill 页签、旧视图及重复入口；旧链接仅做路由兼容，新功能只在独立页面提供 |

本期不提供空白新建、可写正文编辑器、资料上传表单、脚本编辑、直接复制创建、批量导入、批量启停或新的排序控件。只读编辑区仅用于查看、定位和复制内容。内置方法可查看、启停和导出；需要修改时在本地编辑文件，再导入为个人 Skill。

## 二、设计方向与信息取舍

### 2.1 沿用工作台，收紧信息层级

沿用项目的中性炭黑、中文无衬线字体和紧凑控件。视觉重点落在**方法名称与可核对的文件内容**：列表便于找方法，弹窗便于确认文件包。

列表保留紧凑卡片，预览采用独立的文件浏览结构：摘要与模式放在顶部，目录树和只读编辑区在下方并排。目录树在桌面预览中始终可见，点击文件立即切换右侧内容，不再设置「方法正文 / 文件」页签，也不保留常驻的摘要侧栏。

| 原方案中的负担 | 本版处理 |
| --- | --- |
| 页头说明、页脚生命周期说明反复解释功能 | 删除常驻段落，必要后果只在操作详情或删除确认中出现 |
| 卡片同时显示标签、调用方式、多个模式名和资料数 | 收为名称、两行用途、一个模式名和启停，不显示文件数量 |
| 新建与导入两个并列入口 | 只保留「导入 Skill」 |
| 解析后还要进入编辑表单 | 在同一个弹窗中检查并确认导入 |
| 左栏按字段铺满多个说明块 | 摘要移至顶部，左侧只放目录树，右侧只读查看当前文件；边界与来源按需查看 |
| 每张卡片放分类图标、状态徽章、查看按钮 | 删除装饰图标和重复按钮；状态只表达一次 |

### 2.2 视觉基线

下列颜色均来自现有 `frontend/src/app/tokens.css`，不新增色板。

| 角色 | Token / 色值 | 用法 |
| --- | --- | --- |
| 页面底 | `--canvas` / `#101010` | 工作区背景 |
| 内容表面 | `--surface` / `#181818` | 卡片、正文区域 |
| 正文 | `--ink` / `#f3f3f5` | 标题、主要内容 |
| 次要文字 | `--sub` / `#b4b4bc` | 用途、路径和元信息 |
| 结构边线 | `--hair` / `#2d2d2d` | 分区；控件边线和焦点另用现有对应 token |
| 主操作 | `--accent-fill` / `#f5f5f5` | 导入按钮；文字使用现有 `--on-accent` |

- 字体沿用 `"Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。标题 26px，弹窗标题 17px，卡片名称 14px/600，正文 13px，元信息 12px；完整正文行高约 1.7。
- 文本、名称和操作组左对齐，页头主操作靠右。用途说明控制在约 65–75ch；只读编辑区按文件原始换行显示，长行在区内横向滚动，不撑宽弹窗。
- 卡片圆角 12px、控件 7px；卡片无投影，浮层复用统一 Dialog 的阴影。
- 选中态沿用浅灰强调色；成功、警告和错误使用现有语义色。启用开关复用项目现有组件，不能为了醒目另建颜色。
- 不加横幅、统计面板、渐变、分类色块或逐卡入场动画。反馈发生在用户操作的位置。

## 三、页面结构

### 3.1 入口与层级

```text
Skill 管理                                              [导入 Skill]

我的 Skill 6     内置 Skill 12
────────────────────────────────────────────────────────────────
[搜索名称或用途                         ] [全部状态 ▾] [全部模式 ▾]

┌──────────────────────┐ ┌──────────────────────┐ ┌──────────────────────┐
│ 竖屏短剧钩子开场  [开]│ │ 分镜规划         [开]│ │ 角色口播语气校准 [关]│
│ 将开头三秒改为有冲突的│ │ 根据剧情组织镜头顺序│ │ 根据角色与情绪调整  │
│ 开场，保留人物关系。  │ │ 与景别。            │ │ 台词语气。          │
│ 通用                 │ │ 创作                │ │ 通用                │
└──────────────────────┘ └──────────────────────┘ └──────────────────────┘
```

线框中的名称、数量只演示布局，界面必须使用实际数据。

- 页面标题下直接进入页签，不放功能介绍。
- 「导入 Skill」在两个页签中保持同一位置，新增结果都进入「我的 Skill」。
- AI 配置页删除 Skill 页签、旧视图和「前往 Skill 管理」等重复入口；独立页由主导航进入。旧地址 `/ai_config?section=skills` 只做路由级替换跳转到 `/skills`，不渲染旧页面。
- 保留现有应用导航布局，不为增加入口硬编码一套新的移动导航列数。

### 3.2 搜索、筛选与数量

| 控件 | 规则 |
| --- | --- |
| 来源页签 | 我的 Skill / 内置 Skill；计数表示各来源总数，不跟随搜索变化 |
| 搜索 | 占位文案「搜索名称或用途」；只匹配可见的名称与用途，不匹配隐藏标签 |
| 状态 | 全部状态 / 已启用 / 已停用；不再给每个选项附加计数 |
| 模式筛选 | 全部模式 / 创作可用 / 画布可用；后两项都包含通用 Skill |
| 分页 | 沿用分页加载，不把当前页数量当作总数；超过一页才显示分页 |
| 无结果 | 「没有匹配的 Skill」与「清除筛选」；保留工具栏 |
| 空库 | 「还没有 Skill」与「导入 Skill」；我的空库可另给轻量文字入口「查看内置 Skill」 |

模式筛选回答“在哪个工作区能用”，与导入时三选一的适用模式设置区分。通用不是“全部模式”筛选的同义词。

搜索防抖 300ms，清空立即生效；新查询重置页码，旧响应不得覆盖新结果。切页签保留搜索与筛选。状态进入 URL，例如：

```text
/skills?tab=mine&q=钩子&status=enabled&mode=standard
```

URL 不再保留调用方式或标签参数，旧参数进入新页时忽略。筛选生效时才补充一处结果数量；无筛选时不重复展示“共 N 个”。

## 四、卡片

### 4.1 只保留四类信息

| 信息 | 展示 |
| --- | --- |
| 名称 | 首行，超长省略；完整名称可在详情读取 |
| 用途 | 两行，保留真实内容；不额外生成宣传性摘要 |
| 适用模式 | 页脚左侧，只显示「通用」「创作」或「画布」 |
| 启停 | 右上角二态开关；可访问名称带 Skill 名称及当前状态 |

卡片不显示文件数量、标签、触发方式、版本、ID、校验和、更新时间、内部工具名称或单独的「查看详情」按钮；不为文件数保留空位、图标或悬浮提示。文件结构在打开预览后通过目录树查看。

### 4.2 状态与点击

- 卡片名称是详情入口，可扩大鼠标命中区；开关独立命中，点击开关不打开详情。不得将整个含开关的卡片包在一个按钮中。
- 名称保持可读，不因停用而把整卡降透明度。开关旁的短状态在「已启用 / 已停用 / 不可用」中择一显示，不再叠加同义徽章。
- 不可用时，在用途区域内给一条具体原因，最多两行；完整问题在详情中查看。阻止重新启用，但已经启用的不可用项仍允许停用。
- 保存中只让对应开关 loading，保留用途和模式。错误通过统一反馈入口呈现，不替换整行元信息。
- 单卡最小高度约 148px，内距 16px，允许随字号和内容增高；不固定裁切高度。

## 五、适用模式：三段式单选开关

```text
适用模式    [ 通用 | 创作 | 画布 ]
```

这是一个三选一的分段控件，同一时间只有一个选中值；独立启停仍使用二态 Switch。两者不能共用字段或交互语义。

| 用户选项 | 含义 | 沿用的 `modes` 数据 |
| --- | --- | --- |
| 通用 | 在创作和画布中都可用 | `["standard", "infinite_canvas"]` |
| 创作 | 仅创作模式可用 | `["standard"]` |
| 画布 | 仅无限画布可用 | `["infinite_canvas"]` |

- 新增导入初始选中「通用」。包内已有的模式声明不自动改变这个初始选择；最终保存用户在预览中确认的选项。
- 更新既有个人 Skill 时初始回显它当前的模式，保留原设置；用户可在确认更新前修改。
- 个人详情中可直接修改适用模式，按现有内容版本约束保存。内置 Skill 的范围由平台维护，详情只读显示模式名，不增加个人范围覆盖字段。
- 未选择和多选都是非法状态；不提供清空按钮。存储仍使用现有数组，不再并存一个容易失同步的 `common` 字段。
- 「通用」不代表获得所有能力。服务端仍须检查包依赖与选定模式的兼容性，失败时给具体原因，不能靠切换选项绕过校验。
- 正常情况下不在控件下常驻解释句；可聚焦帮助入口按需显示「通用适用于创作和画布」。
- 视觉上是三段开关，可访问语义使用单选组；左右方向键切换、Space 选中，不能给三选一控件错误标注 `role="switch"`。

## 六、导入流程

### 6.1 单一入口，同一弹窗完成

```text
选择文件 → 检查文件 → 预览内容并选择模式 → 导入 Skill
```

不展示常驻步骤条，不进入第二张表单，也不打开可写编辑器。只接受一次一个 Skill：单个 Markdown，或一个包含多个文件的 ZIP。

**尚未选择文件：**

```text
导入 Skill                                                   [关闭]

┌──────────────────────────────────────────────────────────────┐
│                                                              │
│                   拖入 ZIP 或 Markdown                       │
│                       [选择文件]                             │
│                                                              │
│              ZIP 需包含 SKILL.md，暂不支持脚本                 │
└──────────────────────────────────────────────────────────────┘

[格式要求]
```

选择区只保留一条必要说明。体积、数量、格式和打包范例在「格式要求」中按需查看，不把限制清单铺在空弹窗中。

**检查通过后的预览：**

```text
导入 Skill                                                   [关闭]
竖屏钩子.zip                                               [重新选择]
竖屏短剧钩子开场                         [ 通用 | 创作 | 画布 ]
将开头三秒改为有冲突的开场，保留人物关系与因果。
────────────────────────────────────────────────────────────────
文件                        │ SKILL.md                 [只读]
  SKILL.md（选中）           │ ────────────────────────────────
▾ references                │ 1  ## 目标
    节奏规则.md             │ 2  ...
    示例.csv                │ 3
▸ assets                    │ 4  ## 步骤
                            │ 5  ...
────────────────────────────────────────────────────────────────
                                         [取消] [导入 Skill]
```

- 弹窗最大宽度约 1100px；顶部放精简摘要与模式，下面左侧目录树约 220–260px，右侧只读编辑区占据剩余宽度。两区各自滚动，不形成三栏布局。
- 名称与用途是文件解析结果，不是输入框；不另重复「名称」「用途」字段标题。
- 用途默认最多两行，过长时提供「展开」；不让长摘要把文件区挤出首屏。
- 默认选中目录树里的 `SKILL.md`，右侧显示主指令正文的只读源码，不展示 YAML 元数据。目录树与内容同时可见。
- 点击目录展开或折叠，点击文件在右侧打开；导入、更新和详情复用同一个只读文件浏览器，完整行为见第七节。
- 唯一需要用户决定的字段是适用模式。新导入通过校验后默认启用，之后可在卡片上停用；不再增加一个“创建后立即启用”表单项。
- 不显示标签、触发方式、slug、内部版本、原始解析 JSON 或“已准备好”等重复成功说明。

### 6.2 校验与提交

| 阶段 | 行为 |
| --- | --- |
| 选择 | 客户端先检查空文件、扩展名和上传体积；服务端进行完整检查 |
| 检查中 | 原选择区显示「正在检查文件…」，不给虚构进度百分比；允许取消，忽略被取消请求的迟到响应 |
| 检查通过 | 允许预览与确认导入；切换模式需重新核对兼容性 |
| 检查未通过 | 在原内容区显示问题摘要及相关路径；主操作不可用，保留「重新选择」 |
| 确认导入 | 按所选模式再次校验，并提交完整包；按钮为「正在导入…」，防止重复提交 |
| 成功 | 关闭弹窗，进入我的 Skill；若旧筛选会隐藏新项则清除对应筛选，定位新增条目 |
| 明确失败 | 保留已解析内容与模式选择，提供重试；不让用户重新填写字段 |
| 结果不明 | 保存原请求身份，显示「核对导入结果」；核对前不创建第二个请求 |

预览只是检查，不代表已经持久化。正式写入必须重复执行包规则，不能信任浏览器传回的“校验通过”。

成功时最多一条「已导入「名称」」短提示，卡片可短暂描边，不自动再次打开详情。同一次提交的重试复用原幂等键，不产生两条记录。

### 6.3 多文件规则与格式要求

本期沿用现有容量边界，不因采用 ZIP 导入就承诺无限文件。

| 内容 | 本版规则 |
| --- | --- |
| 主文件 | ZIP 内必须且只能有一个 `SKILL.md`，位于根目录或一个共同外层目录 |
| 单文件导入 | 支持 `.md`，作为主文件；有本地资料引用时必须改用包含这些文件的 ZIP |
| 元数据 | 主文件提供名称与用途；缺失或格式错误时在本地修正，不回退到网页填写 |
| 文本资料 | `.md`、`.txt`、`.json`、`.csv`、`.yaml`、`.yml`，保留相对路径 |
| 图片资料 | `.png`、`.jpg`、`.jpeg`、`.webp`，沿用现有图片检查与只读预览 |
| 上传体积 | 非空且不超过 4 MiB |
| 展开后体积 | 整包不超过 1 MiB；最多 32 个文件，包含主文件，即最多 31 个附加文件 |
| 单文件与正文 | 单文件不超过 128 KiB；主指令正文不超过 64 KiB |
| 目录 | 保留子目录；移除合法的共同外层目录后，引用仍必须能定位到原文件 |
| 本地引用 | 检查正文及文本资料中的本地文件引用；缺失则阻止导入，不静默忽略 |
| 外部资源 | 不自动抓取链接，不以远程下载补齐缺失文件 |
| 归档异常 | 继续拒绝越界路径、重复路径、加密条目、符号链接和嵌套压缩包 |

一个有效的目录示例，仅在「格式要求」中展示：

```text
竖屏钩子/
├── SKILL.md
├── references/
│   ├── 节奏规则.md
│   └── 示例.csv
└── assets/
    ├── 输出模板.md
    └── 镜头示例.png
```

**脚本边界必须在正式写入端落实：**

- 文件白名单不包含脚本或可执行文件；`.py`、`.js`、`.ts`、`.sh`、`.ps1`、`.sql`、`.bat`、`.cmd` 等均不可导入。
- 位于 `scripts/` 中的文件、显式声明为 `script` 的资源同样阻止导入；不得改成 reference 类型后绕过。
- 一个文件不支持即拒绝整包。不能静默删掉脚本、遗漏不支持的文件，或给「忽略并导入」按钮。
- 文档中的代码示例仅作为文本显示，不产生脚本资源，不执行、不安装依赖。
- 校验面向资源格式与引用，不承诺理解任意自然语言指令的全部运行依赖；包内容不能扩大平台实际提供的能力。

### 6.4 导入问题的短文案

| 问题 | 显示内容 | 可做的操作 |
| --- | --- | --- |
| 主文件缺失 | 「未找到 SKILL.md」 | 重新选择；格式要求 |
| 包含脚本 | 「暂不支持脚本：scripts/check.py」 | 重新选择 |
| 缺少资料 | 「缺少文件：references/节奏规则.md」 | 重新选择 |
| 元数据不完整 | 「SKILL.md 缺少用途」 | 重新选择 |
| 文件过多 | 「包含 38 个文件，最多支持 32 个」 | 重新选择 |
| 不兼容 | 例如「所选模式不支持这个方法需要的能力」 | 查看具体问题；调整模式或重新选择 |
| 上传失败 | 「文件上传失败」 | 重试上传 |
| 导入结果未知 | 「导入结果待核对」 | 核对导入结果 |

问题较多时显示「3 个问题」及首项，可展开全部；路径可换行并复制，不展示服务器堆栈、工具内部标识或标签值。修复方式是在本地调整文件后重新选择，界面不提供补正文、补资料或删除引用的编辑入口。

### 6.5 同名、关闭与恢复

- 从页头导入始终创建个人条目，不按名称或 slug 自动覆盖。存在同名项时，仅显示一次「已有同名 Skill，将新增一份」，允许继续。
- 更新已有条目必须从它的详情进入「更新文件」，目标由 ID 确定。
- 确认导入前关闭直接退出，原文件仍在本地，不为临时预览增加草稿确认弹窗；再次打开可重新选择文件。
- 提交期间短暂阻止重复操作；网络超时后进入可恢复的待核对状态，不无限锁住弹窗。
- 允许带着待核对记录关闭，页面保留一个紧凑的恢复入口；账号隔离，继续使用原请求核对，不显示原始 JSON。
- 历史在线编辑草稿与未决请求不得随入口退役被删除：已有请求继续核对；未提交草稿提供恢复下载，再由用户整理为可导入文件，不重新暴露在线编辑器。

## 七、详情与只读文件浏览器

预览采用本地查看文件的交互：**左侧目录树选文件，右侧只读编辑区显示该文件**。导入预览、更新预览、个人详情与内置详情使用同一结构，不再用「正文 / 文件」页签切换，也不提供可编辑版本。

### 7.1 顶部摘要与操作

头部放名称、来源身份和启停；用途与适用模式在文件区上方紧凑排列，长用途按需展开。文件区获得主要空间。

| 区域 | 我的 Skill | 内置 Skill |
| --- | --- | --- |
| 用途 | 只读，两行后可展开全文 | 只读，两行后可展开全文 |
| 适用模式 | 三段式单选，可修改 | 显示实际模式名，只读 |
| 启停 | 可修改个人设置 | 可修改个人设置 |
| 主操作 | 更新文件 | 导出 ZIP |
| 更多操作 | 导出 ZIP、删除 | 无重复菜单 |
| 正文与文件 | 目录树 + 只读编辑区 | 目录树 + 只读编辑区 |

- 来源身份只出现一次。适用边界与来源许可仅在有内容时提供折叠入口，不显示空占位或常驻提示。
- 适用模式和启停是独立的管理设置，允许按第五节与第八节保存；它们不使文件编辑区变成可写。

### 7.2 目录树

- 始终包含根主文件 `SKILL.md` 和所有附加文件，依据实际相对路径构造层级；不显示总文件数或分类计数。
- 初次打开选中 `SKILL.md`；主文件固定在最上方，其余目录优先，同层按名称稳定排序。
- 单击文件立即在右侧打开；单击目录箭头展开/折叠，选择目录不清空已打开的文件。双击文件不会进入编辑或弹出第二层窗口。
- 一次选中一个文件，选中态与右侧路径一致；切换文件后保留其他目录的展开状态，返回已读文件恢复其滚动位置。
- 显示真实文件名和层级，不另造标题。树节点过长时省略，焦点或悬停可查看完整路径；右侧标题栏始终提供完整相对路径的查看与复制。
- 支持上下键移动、左右键展开/折叠、Enter 打开，清楚区分键盘焦点与当前打开文件。
- 不提供新建、重命名、删除、拖动排序、移动目录、右键写入菜单或逐文件上传。

### 7.3 只读编辑区

| 文件 | 右侧显示 |
| --- | --- |
| `SKILL.md` | 主指令正文源码，保留 Markdown 标记与原有换行；frontmatter 和隐藏元数据不展示 |
| 其他文本文件 | UTF-8 原文与行号，保留缩进，不自动格式化、不把 JSON/CSV 转成编辑表单 |
| 图片 | 同一内容区域内按比例预览，保持目录树可用，不另开大弹窗 |

- 标题栏仅保留当前相对路径、一个短「只读」标记及复制内容操作；图片不显示复制文本按钮。没有保存、撤销、格式化或编写/预览切换按钮。
- 允许文本选择、复制、滚动与键盘定位；禁止输入、粘贴覆盖、剪切删除、拖入文本和任何内容写回。只读状态不能用 `disabled` 代替，否则无法正常选取和复制。
- 文本使用 CodeMirror 6 的只读编辑能力，通过 `@uiw/react-codemirror` 接入 React；行号、文本选区、滚动和键盘处理复用库能力，不自行编写编辑器内核。主题沿用工作台，不引入完整 IDE、终端或脚本执行环境。
- `SKILL.md` 行号以所展示正文为准；其他文本按文件原文行号显示。隐藏元数据只影响展示，不修改导出包；标签仍按第九节保存。
- 只读区域按纯文本转义显示，不执行 HTML、脚本或嵌入内容。Markdown 默认展示源码，不增加第二套渲染模式。
- 查看与切换文件不产生修改标记，不触发自动保存或写请求，关闭预览不出现「未保存内容」确认；已有导入待核对操作按第六节单独处理。

### 7.4 内容读取与失败恢复

- 先呈现列表已有摘要，再读取目录与主文件。已保存的主文件使用详情中的 `instructions`，附加文件沿用版本化资源读取接口；导入预览读取本次解析结果。
- 当前选中文件加载中只替换右侧内容区域；读取失败在同一区域显示「读取失败」及「重试」，目录仍可操作，不显示其他文件的内容冒充当前文件。
- 以账号、Skill/本次导入包身份、内容版本和路径区分缓存，核对资源校验值；切换文件取消或忽略旧请求，迟到响应不得覆盖当前选择。
- 重新选择包、更新完成或切换账号后不沿用旧包内容缓存；只读查看不改变服务端版本。
- 单个主文件的包也保留同一树形结构；空文本文件显示空内容，加载失败不伪装成空文件。

### 7.5 组件选型与复用边界

本期采用 **Ant Design `Tree.DirectoryTree` + `Splitter` + CodeMirror 6（`@uiw/react-codemirror`）**。目录树与分栏沿用宿主已有组件；只读编辑区复用成熟编辑器，只开发 Skill 数据与界面的连接逻辑。

调研基于 2026-10-26 获取的官方文档、公开仓库索引和 npm 包声明。仓库内已确认：宿主使用 Ant Design `^5.29.3`；画布子包已声明 `@uiw/react-codemirror` `4.25.11` 与 `@codemirror/lang-json` `6.0.2`。画布存在依赖声明不等于宿主已经安装，也不代表这次只读交互已通过验收。

**目录树与分栏配置：**

- 使用受控选中项和展开项，单选、无复选框、关闭拖动；目录只负责展开与折叠，文件选择才触发右侧内容读取。
- `DirectoryTree` 的 `expandAction` 可设为 `false`，按既定规则通过箭头展开；复用树组件键盘行为，不再手写一套方向键导航。
- 分栏使用现有 [Ant Design Splitter](https://5x.ant.design/components/splitter/)，该组件自 5.21.0 提供，项目当前版本已覆盖。默认目录宽约 240px，保持现有窄屏切换规则；分隔条操作使用组件能力，不手写拖拽实现。
- 图标、选中态和行高通过现有主题与局部样式适配，不修改第三方源码。

**CodeMirror 只读配置：**

- 遵循 [CodeMirror 官方只读示例](https://codemirror.net/examples/readonly/)：启用 `readOnly`，关闭 `editable`，并通过 `contentAttributes` 添加 `tabindex`，使不可编辑内容仍能获得键盘焦点。
- React 封装使用对应的 `readOnly` / `editable` 属性；关闭 Tab 缩进，让 Tab 正常移到下一个控件。禁止将编辑器更新回调连接到保存接口；切换文件只更新展示内容。
- 按需保留行号、文本选择和必要快捷键；关闭自动补全、修改历史及其他与只读查看无关的编辑扩展。
- Markdown、JSON、YAML 只按需加载对应语言扩展；TXT、CSV 可直接显示纯文本。文本高亮不代表接受或执行脚本，后端文件白名单继续独立生效。
- 使用项目中性炭黑 token 定义编辑器主题，隐藏标签与元数据的规则不变；不直接采用与页面冲突的整套编辑器主题。
- 编辑器和语言扩展随文件预览按需加载，不阻塞卡片列表。图片继续走现有图片预览，不交给代码编辑器。

**应用层仍需实现的部分：** 相对路径转目录节点、当前文件与版本绑定、内容读取及取消、滚动位置恢复、图片分流、隐藏元数据、账号隔离和错误反馈。这些属于 Skill 业务；树导航、文本选区、行号、编辑器布局和分栏拖动由第三方组件承担。

**依赖边界：** 后续在 `frontend/package.json` 与宿主锁文件中明确添加所需 CodeMirror 依赖，优先使用画布已声明的兼容版本；不得从 `frontend/canvas/node_modules` 深层导入，也不依赖间接依赖碰巧存在。不为本次改动升级 Ant Design 主版本或改动画布代码；如确需调整共同声明的包版本，须按项目规则同步两边声明与锁文件。

## 八、更新文件与日常设置

### 8.1 更新文件

```text
个人详情 → 更新文件 → 选择完整包 → 检查与预览 → 确认更新
```

1. 在同一操作层切换到更新视图，标题「更新 Skill」，保留返回原详情的入口，不叠加第二个大型弹窗。
2. 目标对象固定为原 Skill；选错文件可重新选择，不因包内同名信息改变目标。
3. 回显当前适用模式、保留启停状态；名称、用途、正文和资料以新包为准。
4. 仅在有变化时显示一行「新增 2 个文件，替换 3 个，移除 1 个」，可展开路径清单；名称变化时明确显示新旧名称。用户核对后点击「确认更新」，不再弹一次重复确认。
5. 完整包整体替换当前内容，缺席文件视为移除，不偷偷保留旧资料。历史冻结版本继续保留。
6. 校验失败、保存失败或内容冲突时，旧 Skill 保持可用，新包与用户选择保留在当前流程。

内置 Skill 不提供更新入口。导出内置包后在本地修改、重新导入，会成为个人 Skill。

### 8.2 启停、模式与冲突

| 情况 | 处理 |
| --- | --- |
| 启停 | 只保存个人启停设置，不附带触发方式或重新写入内容 |
| 个人模式修改 | 只提交模式变化及内容并发版本，串行保存；保存期间该控件 loading |
| 保存成功 | 控件状态即反馈，不额外弹自动保存成功消息 |
| 明确失败 | 回到最近确认状态，保留本次选择及重试入口 |
| 结果未知 | 显示待核对状态，读取服务端后确认；不能把未知当作未保存并盲目重发 |
| 409 冲突 | 保留双方状态，显示「你的选择 / 当前设置」，由用户保留当前设置或按最新版本重新应用 |
| 删除 | 确认一次，写明对象与后果；执行中防重复提交 |

启停和模式变化影响后续加载；已受理任务继续使用冻结版本，不由管理页回写任务状态。这个规则放在按需帮助或必要确认里，不在列表底部常驻。

删除确认文案：「删除「名称」？后续任务将无法使用，已加载的任务不受影响。」

反馈复用 `StudioFeedback`、`useStudioMessage` 和统一 Dialog。沿用公共位置与时长，不另建底部提示系统。关闭短提示不能清除问题和恢复入口，也不能让页面或弹窗高度跳动。

## 九、目标数据约定与现状差异

本节面向后续实现，**不表示本次已修改契约或数据**。

### 9.1 保留、隐藏与移除

| 字段或概念 | 目标处理 |
| --- | --- |
| `name` / `description` | 从包解析；列表和详情展示；通过更新文件修改 |
| `instructions` / `resources` | 包内容整体导入或更新，按需只读预览 |
| `modes` | 保留现有两种运行模式数组，映射为 UI 的通用 / 创作 / 画布 |
| `enabled` | 保留，属于个人使用设置；与模式和调用方式无关 |
| `tags` | 保留存储、校验、导入与导出；界面没有输入、列表、详情、筛选或搜索入口 |
| `exclusions` / `source` | 从包读取，有内容时在详情折叠展示 |
| `required_tools` | 保留内部兼容检查，不把内部名称列成用户设置 |
| `invocation_mode` | 从新目标模型和契约中删除，不再用隐藏字段或默认 `auto` 继续记录 |
| 版本、校验和、ID、slug | 保留内部身份、并发和完整性用途；不当作用户表单字段 |
| `script` 资源类型 | 不再属于新导入、更新、创建的可接受内容；不能仅设置为不执行 |

隐藏标签的保留规则：

- 新导入有合法标签则保留，没有则用空数组；不自动生成标签，也不要求用户补充。
- 整包更新显式带有标签字段时按包更新；未提供时保留原标签，显式空数组才清空。预览与确认必须保留“未提供”和“空数组”的区别，不能因界面隐藏而意外清空。
- 启停、模式调整及重试都不能重写标签。导出文件可包含这些元数据，但网页不展示原始元数据。
- 标签校验失败通过文件元数据问题返回，修复发生在本地，不引入标签表单。

触发方式的退役规则：

- 新增、更新、设置、列表、详情、筛选、运行时检索与导出均不再依赖 `invocation_mode`。
- 导入旧包遇到旧触发声明时忽略，不另存为隐式设置；导出不再生成该字段。
- 旧库字段需要后续迁移移除，不能只从页面隐藏，也不能统一写入 `auto` 来模拟“移除”。
- 用户显式选择或任务按需使用由任务上下文决定；任务的真实使用轨迹可继续记录，但不回写为 Skill 的固定触发类型。
- 历史任务快照保留可追溯性，不批量改写历史记录。

历史已存包保留原文件及版本引用，兼容读取维持既有只读边界，不增加执行能力。个人项后续更新必须使用无脚本完整包，内置项由平台维护；新建与更新都不能绕过相同检查。本期不自动删除旧包或改写历史任务。

### 9.2 已有能力与必须改造的部分

当前源码已经具备导入预览、完整包保存、资源读取、导出、设置版本和待核对操作；**它仍支持在线编辑、触发字段与只读脚本，因此本版不是纯视觉换皮**。

接口前缀统一为 `/api/v1/agent`：

| 能力 | 既有入口 | 后续要求 |
| --- | --- | --- |
| 列表 | `GET /skills` | 去除触发筛选，搜索不匹配隐藏标签；模式筛选保持成员匹配 |
| 详情 | `GET /skills/{skill_id}` | 供正文、文件树与只读摘要使用，响应不再包含触发方式 |
| 导入预览 | `POST /skills/imports/preview` | 完整检查多文件包，拒绝脚本，返回可定位的阻断问题；保留标签是否提供的信息 |
| 确认导入 | `POST /skills` | 提交解析后的完整内容与所选模式，复用 `Idempotency-Key`；正式写入重新校验 |
| 更新文件 / 个人模式 | `PATCH /skills/{skill_id}` | 使用内容并发版本；文件更新整体替换，模式调整只提交变化字段 |
| 启停 | `PATCH /skills/{skill_id}/settings` | 保留设置并发版本，仅更新 `enabled`；删除触发字段及必填约束 |
| 文件读取 | `GET /skills/{skill_id}/versions/{content_version}/resources` | 保留版本身份和分段读取；支持已有文本、图片预览 |
| 导出 | `GET /skills/{skill_id}/export` | 导出完整当前包与保留的标签，不生成触发字段 |
| 旧直传 / 复制入口 | `POST /skills/uploads`、`POST /skills/{skill_id}/copy` | 新页面不暴露；若其他调用仍保留，也须遵守无脚本写入规则 |

说明：

- 不新增“标签管理”“触发配置”接口，也不为一个三段控件增加第三种运行模式。
- 来源计数可复用分页响应的真实 `total`；本期不要求新增 facets 接口或一组状态统计。
- 当前预览解析器会给缺失字段补默认值，实施时须处理名称/用途缺失、隐藏标签是否提供和默认模式选择，不能原样采用旧编辑草稿。
- 导入、更新和保留的其他写入入口使用同一服务端包规则；只修改浏览器文件选择器不满足本方案。
- 从单页设置移除触发字段时，需同步个人设置、内置默认、助手检索/选择与运行时加载，避免另一入口仍按旧开关过滤。

## 十、响应式与可访问性

### 10.1 结构适配

按主内容区实际可用宽度决定卡片列数，不按屏幕宽度假设侧栏已经收起。

| 可用内容宽度 | 卡片 |
| --- | --- |
| ≥1248px | 4 列 |
| 932–1247px | 3 列 |
| 616–931px | 2 列 |
| <616px | 1 列 |

卡片目标最小宽度 300px，间距 16px；极窄屏随容器缩小，不制造横向滚动。

- 工具栏空间不足时搜索独占一行，两个筛选等宽并排；不额外引入筛选抽屉。
- 桌面预览保留目录树与只读编辑区；不足以容纳双栏时只显示当前文件，通过「目录」按钮在同一操作层切换到树，选中文件后返回内容。摘要与模式仍在上方，手机使用全屏 Dialog，标题与操作区固定。
- 窄屏在目录与内容之间切换时保留选中项、展开状态和各文件滚动位置，不另外叠加弹窗，不让长行产生整页横向滚动。
- 手机主操作、文件行和开关热区至少 44px；固定底部操作区考虑安全区域。

### 10.2 可访问性与状态

- 启停为 `switch`，适用模式为单选组，文件目录采用树形语义；只读编辑区可聚焦且可选取文本，有当前文件名称与只读状态，复用组件的键盘行为。
- 卡片、开关、帮助、文件行和恢复入口均有可见焦点与明确名称。帮助不能只在鼠标悬停时可见。
- 弹窗焦点循环，背景不可交互；Escape 先关闭上层菜单再关闭弹窗，关闭后回焦原入口。
- 保持普通文本至少 4.5:1、交互边界与焦点至少 3:1 的对比目标；不得为追求清淡使用低对比文字。
- 不仅用颜色表达启停、不可用或错误；用短状态、图标或可访问状态同步表达。
- 200% 缩放、长名称、长文件路径和多行错误下，控件不重叠、不裁切操作。
- 加载用对应区域骨架或原按钮 loading；局部失败在原区域给重试，不能冒充空库。
- 控件切换约 150–180ms；尊重 `prefers-reduced-motion`，不做页面入场编排。
