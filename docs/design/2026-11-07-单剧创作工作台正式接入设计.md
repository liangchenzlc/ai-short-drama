# 单剧创作工作台正式接入设计

2026-11-07 用户确认单剧预览。本设计以实际预览及其后续反馈为准，覆盖此前多集方案中与本设计冲突的部分。暂不引入剧集、分集选择或分集标签，也不改造成片预览节点。

## 交互与范围

```text
剧本：现有「故事设定 / 剧本正文」与其保存、恢复、改写流程
资产：现有素材列表 │ 批量操作与单卡 / 宫格 / 列表
                  │ 资料                       图片组、参考图、生成输入
分镜：现有分镜列表 │ 批量操作与单卡 / 宫格 / 列表
                  │ 镜头资料、分镜图和图参考   视频、视频参考、生成输入
```

保留正式页面原有新建、删除、搜索、排序、模型与参数、私有草稿、编辑冲突恢复、图片组、声音、素材采用和助手。三种视图共用正式数据和操作，单卡没有上一个／下一个按钮。批量操作展示每项状态，超过 100 项拆成多批，失败项可重试；已有作品不被重新生成的结果覆盖，结果须可查看并主动采用。保持已确认预览的视觉比例、桌面最小宽度 1280px 和原左侧列表。

## 素材资料与版本

素材维持一个稳定的作品资料对象，角色包含定位、性别、年龄、身份、外貌、性格；场景包含类型、地点、光线、环境布置、氛围；道具包含类型、材质、颜色、尺寸、状态、外观、用途。场景时间继续使用已有 `scene_time`，界面映射到时间输入，不再保存第二份时间。名称、描述和已有标签仍是原字段。切换素材类型时经确认清空类型专属资料并按现有约束检查关联和角色版本。

类型专属资料随作品版本和生成上下文冻结，资料改变要参与角色不可变版本和生成结果过期判断。历史角色快照与其摘要不能原地改写；新增版本需要保证原快照依旧可校验、可复制。资料通过既有资产 CRUD 和编辑会话保存，不将私人提示词写入共享作品。

## 分镜与对白

镜头新增机位、运镜和声音设想，和名称、景别、时长、镜头描述一起保存并进入图片、视频生成上下文。预览中的自由文本对白属于镜头创作设想，不直接当作已审核配音稿；现有 `ShotDialogue` 按角色、顺序和审核状态管理实际原生对白与声音，保持为生产对白的唯一来源。两者在界面和数据中明确区分，不能自动互相覆盖。保持原声音功能及角色关联校验。

分镜关联素材用于分镜图参考。每次新增关联角色或场景时，其当前主图默认加入本人的视频参考；用户可分别移除视频参考或分镜图参考。主动选择分镜图后才将该图作为视频参考。视频参考保存资产身份或选定的分镜图片身份，真正提交时读取并冻结可访问的当前媒体；未创建草稿的默认值和用户主动清空的空列表必须区分。视频模型的输入能力及参考数量由真实模型能力判断。

## 生成与采用

共用现有图片组、草稿、模型配置、任务、批次和媒体库。两条视频路径均有效：无图片时由镜头文本生成；有参考时依据已选择的资产主图／分镜图生成。提交前保存草稿，检查资源归属、版本和真实模型能力，冻结提示词、参考媒体及相关内容；候选和任务重试保留原有冲突、幂等与受理不确定处理。结果与参考选择、原生对白和实际来源一起记录，图片或视频变更后不应误采用过期任务。原有作品保留，新的生成结果由用户明确采用。

## 数据与接口边界

沿用项目、素材、镜头和私人生成草稿，不新增集表或按集归属字段。扩展现有资产、镜头和草稿接口与持久化，相关列表、编辑会话、助手读写、复制、内容哈希、任务预检和媒体采用使用同一份资料。数据库变更同时更新 ORM、增量迁移、全量建表及测试库验证；不得用全量建表覆盖现有库。正式页面只接真实数据，预览夹具仍用于隔离视觉回归。

## 验收

覆盖刷新后资料和参考选择恢复、角色历史版本、草稿空参考、两条视频生成路径、关联素材变化、图片组、原声对白、已有作品不被覆盖、跨视图勾选、101 项分批和失败重试。验证冲突、未知受理、删除与权限边界，并使用 1280 / 1440 / 1920 宽度及助手开关截图复核正式路由。真实模型或外部供应商未调用时须明确记录。
