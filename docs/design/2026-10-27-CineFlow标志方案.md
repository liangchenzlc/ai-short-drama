## 设计目标

产品服务于从小说／剧本、素材和分镜到生成与成片的个人影像创作流程，同时提供无限画布和 AI 创作助手。标志保持简约、清晰，既能作为工作台中的小图标，也能完整呈现 `CineFlow` 名称。

## 图形与字标

主图形为**开放银幕 C**：用圆角画框建立 C 的轮廓，右侧上下两端作斜切，形成向外展开的开口。最终图形由一个连续填充路径构成；画框与开口共同表达影像和故事的展开过程，呼应 Flow 所强调的创作流程。

内部比较了较圆的 C、画框式 C 与弧形 C，选择画框式方案。它在小尺寸下保留矩形留白与清晰开口，能够兼顾首字母和影像创作空间的联想。

字标采用 `CineFlow` 的确切大小写。`Cine` 使用较实的字重，`Flow` 使用较轻字重，同字号、同基线，并按新名称重新计算字距和整体宽度；以 Bahnschrift 绘制后转换为轮廓路径，确保 SVG 的显示不依赖本机字体。

## 色彩与布局

主图标延续此前设计交流中的蓝绿渐变方向：深蓝 `#123E67` → 蓝青 `#126B80` → 青绿 `#249282`，搭配月白 `#F5F9F8` 的图形。另提供炭黑 `#101010` 与月白的透明单色版，用于现有工作台的深浅背景。

应用图标为 256 × 256 源画布，背景圆角 56；横向标志为 603 × 160，图形在左、字标在右。渐变采用 `userSpaceOnUse` 固定在各自源画布上。预览页中的英文短句仅为展示说明，不属于 Logo 路径。

## 交付

包括主应用图标、彩色背景完整 Logo、透明背景深浅组合标志，以及透明背景深浅独立图形，共 6 个 SVG。另提供 512px、1024px 应用图标 PNG、1600px 宽透明组合标志 PNG 与完整预览。

全部文件及使用建议见 [CineFlow 品牌资产](../data/brand/cineflow/README.md)。本轮仅交付标志设计，产品页面名称、侧栏和 favicon 的接入不包含在本次改动中。

- 使用 Skia／`@napi-rs/canvas` 的 Path2D 与 SVG 绘图表面绘制、简化轮廓并导出原生矢量。
- 使用 resvg，在关闭系统字体加载的条件下，将 6 个 SVG 分别渲染为 16、24、32、48、96、256、512px 宽度，共 42 次，检查矢量解析和裁切。
- 预览页展示主图标的 16、24、32、48、64、96、128px 实际尺寸，以及深浅背景组合标志；已目视检查 C 的开口、内侧留白、渐变及字标大小写。

- 对 SVG 执行 XML 结构检查，确认无 `text`、`image`、`script` 或 `foreignObject` 节点；字符均为路径，SVG 无外部字体依赖。
