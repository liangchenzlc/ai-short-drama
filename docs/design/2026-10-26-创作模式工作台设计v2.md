## 0. 一句话结论

四个页面现在都是「左列表 + 右面板」，能干活，但每页都在回答两个问题：**看哪个** 和 **改什么**。
v2 把每页收敛成一个问题：**素材页锁一致性、分镜页排镜头、成片页对时间**，并用同一套「左序列 / 中工作面 / 右检查器」骨架承载。

| 页面 | 现在回答 | v2 只回答 | 关键新增 |
| --- | --- | --- | --- |
| 剧本创作 | 写什么、AI 怎么改 | 这场戏能不能拍 | 场次与素材状态打通、明确的下一步 |
| 素材生成 | 选哪张图、怎么生成 | 这个角色的基准定没定 | 三视图资产、一致性锚点、资产引用计数 |
| 分镜制作 | 这个镜头生成没生成 | 12 个镜头排得顺不顺 | 分镜表网格、引用资产、图→视频一条流水线 |
| 成片合成 | 片段放哪、参数多少 | 成片还差什么 | 从分镜同步、未同步汇总、导出前置 |

## 1. 市场：四类产品的做法

### 1.1 素材/资产（天工短剧工作台、LibTV、Storyboarder.ai、Arcloop）

| 做法 | 具体形态 | 出处 |
| --- | --- | --- |
| 角色多视图 | 一张参考图推正/侧/背/面部特写，存为项目资产，一次生成多次调用 | 天工短剧工作台、LibTV |
| 一致性锚点 | 脸型、发型轮廓、外套剪裁、耳饰等 3–5 个硬锚点，写成"禁改项" | Arcloop 一致性手册 |
| 场景基准 | 全景图统一门牌、走廊宽度、光源方向 | 小云雀实践、CSDN 实操 |
| 资产即引用 | 分镜写「引用 林夏-v03 / 旧公寓-夜-v02」，而不是重写外貌 | 分镜交接表实践 |
| 状态与版本 | 资产有 v01/v02/v03，换装分层存，不覆盖旧版 | LibTV |

**共性**：素材页不是"生成图片"的地方，是**建立可复用资产**的地方。判断标准是"能不能被下游引用"，不是"这张图好不好看"。

### 1.2 分镜（Boords、Storyboarder、Wonder Unit、天工）

| 做法 | 具体形态 |
| --- | --- |
| 多视图切换 | Global 缩略图墙 / Grid 网格 / Shot list 镜头表 / Script view 文本视图 / Frame editor 单帧编辑（Boords） |
| 镜头卡 | 画面 + 镜号 + 时长 + 台词/备注 + 状态，一卡一镜 |
| 分镜表即交接 | 镜号 / 景别运镜 / 画面动作 / 时长 / 引用资产 / 验收点（天工、Boords shot list） |
| 顺序可拖 | 网格与列表都支持拖拽调整镜序，镜号自动重排 |
| 帧→视频 | 静态帧一键转动态（Storyboarder.ai Video 2.0），animatic 预览 |

**共性**：分镜页的主视图是**全部镜头**，不是"当前镜头"。详情是次要的。

### 1.3 成片（剪映专业版、LibTV 画布轨道、小云雀 3D 导演台）

| 做法 | 具体形态 |
| --- | --- |
| 四区 | 素材箱 / 监视器 / 检查器 / 多轨时间轴 |
| 一键成片 | 按分镜顺序铺轨，缺口与未同步单独标 |
| 片段级返工 | 只重做问题片段，不整片重跑 |
| 多画幅导出 | 竖屏 / 横屏 / 海外版一次配置 |

**共性**：成片页的专业结构已经固定（NLE），差异在**"从哪来"和"还差什么"**：来源是否自动同步、缺口是否可视。

## 2. 现状诊断（基于当前实现）

### 2.1 剧本创作（已按 v2 落地）

- 结构：左结构 292 + 正文；创作台按钮唤出。**保留**。
- 缺两处：场次里的人有没有建素材看不到；底栏没有明确出口。
- v2 微调：结构栏加一行「素材已建 4 / 6 人 · 去素材」；底栏右侧加「下一步：素材生成 →」。

### 2.2 素材生成

现在：左列表（搜索 + 分类 + 187px 封面卡）+ 右面板（预览图 + 名称/类型/描述/参考图/提示词/模型/参数）。
问题：

1. **没有"资产"概念**：只有单图与图片组，没有三视图/多角度，"角色一致性"没有承载物。
2. **状态不可扫**：已生成、未生成、待更新三种状态混在封面卡里，只能逐个点开确认。
3. **预览被设置挤压**：预览与设置同在一个主面板，1440 以下图片很小。
4. **没有批量**：12 个素材要逐个生成；"从剧本提取 6 个"是弹窗流程，不在列表上。
5. **引用关系不可见**：素材被哪些镜头引用，只在删除时报错。

### 2.3 分镜制作

现在：左单列镜头卡（媒体 + 镜号 + 时长 + 名称 + 景别）+ 右面板（图/视频分段 + 预览 + 设置）。
问题：

1. **看不到全局**：一次只能看 3–4 个镜头，12 个镜头排得顺不顺全靠记忆。
2. **图/视频被拆成两个模式**：生成视频要先切 tab，一条流水线变成两套状态。
3. **引用不可见**：镜头引用了哪个角色/场景版本，只在设置里。
4. **没有进度与批量**：不知道还有几个待生成，也不能一次生成多个。

### 2.4 成片合成

现在：素材箱 + 监视器 + 检查器 + 多轨时间轴，导出在标题栏图标，"同步分镜"在工具栏。
问题：

1. **进来是空时间轴**：没有"从分镜一键铺轨"的引导。
2. **跨镜头状态不可见**：哪些片段的分镜改过了、需要重新同步，没有汇总。
3. **导出不是主操作**：藏在图标里，和"保存"同级。

## 3. 设计方案

### 3.1 统一骨架

| 区域 | 宽度 | 职责 |
| --- | --- | --- |
| 左 · 序列 | 230–260 | 这一页要处理的对象清单（场次/素材/镜头/片段），带状态点与计数 |
| 中 · 工作面 | 自适应 | 当前对象的编辑或浏览面（正文 / 资产画布 / 分镜表 / 监视器+时间轴） |
| 右 · 检查器 | 270–320 | 当前对象的设置与生成，可收起；与剧本页"AI 创作台"同一套开合逻辑 |

两条通用规则：

1. **状态用点，详情用字**：列表里只用 6px 圆点表达（实心=已生成、空心=待生成、琥珀=待更新），进详情才出现文字状态。
2. **引用用 chip，带版本**：`林晚 v3`、`沈氏顶层 v2`，点击可跳到资产；改资产版本时，引用它的镜头会被标"待更新"。

### 3.2 素材生成（图 11）

三栏：素材清单 258 / 资产画布 / 生成设置 320。

- **清单**：分类 tab 带计数（全部 12 / 角色 6 / 场景 4 / 道具 2）；每行 42px 缩略图 + 名称 + 「角色 · 4 视图 · 被 8 个镜头引用」+ 状态点。底部常驻「从剧本提取 · 6 个待建」。
- **资产画布**：主图 300×400（3:4 定妆照）；下方**视图条**：正面 / 侧面 / 背面 / 面部特写 / 表情服装 + 「补视图」；再下方**一致性锚点** chips（短发、深色风衣、银色耳钉），可编辑。
- **生成设置**：人设描述 → 参考图（最多 4）→ 生成提示词（框内模型 + 发送）→ 提示"生成会同时产出三视图并存为基准"→ 最近生成两条（可对比）。
- 交互：点「补视图」只补缺失角度；主图右上「主图 · 正面」标出当前基准；素材被引用后，画布底部显示"角色基准会被所有引用镜头继承"。

### 3.3 分镜制作（图 12）

三栏：镜头序列 230 / 分镜表 / 镜头详情 306。

- **镜头序列**：筛选 全部 12 / 待生成 3 / 已完成 9；每行 44×26 缩略图 + `S01 · 民政局大厅` + 景别·时长 + 状态点；底部总时长 1'58"。
- **分镜表**：默认 4 列网格（12 镜 3 行看完），右上可切表格视图；每卡：画面（角标镜号、右上状态点、右下时长、左下场景）→ 一句画面描述 → 景别·运镜；末尾「＋ 新增镜头」。
- **镜头详情**：预览（16:9，带播放）→ 分镜图 / 分镜视频 分段（同一条流水线，不换页）→ 引用资产 chips → 画面描述 → 提示词（模型 + 发送）→ 提示"换图保留旧视频；视频成功自动成为成片来源"。
- 批量：表头「3 个镜头待生成」+「批量生成 3 个」，选中多卡后底部浮条确认。

### 3.4 成片合成（图 13）

四区：素材箱 172 / 监视器 + 时间轴 / 检查器 272。

- **顶部**：`12 片段 · 1'58" · 2 个未同步` + 「从分镜同步」+「剪辑工具」+ **「导出成片」主按钮**。
- **监视器**：16:9 居中，左上时间码，安全区虚线，底部播放控制，左下当前片段名。
- **时间轴**：V1 画面 + A1 原声 / A2 对白 / A3 字幕 / A4 配乐 / A5 音效；轨道标签固定、波形与字幕块按真实内容；播放头浅色。
- **检查器**：画面 / 声音 / 字幕三 tab；画面给构图、缩放、位置、来源（含"已同步"）。
- **底部状态条**：总时长 · 片段数 · **"S05、S10 分镜已更新，待同步"** · 自动保存时间。
- 空态（未画）：时间轴为空时给「从分镜一键成片」大按钮 + 「手动导入素材」次级入口。

### 3.5 视觉规范（四页共用）

| 项 | 规则 |
| --- | --- |
| 背景 | 画布 `#101010`，面板 `#181818`，工作面（画布/监视器）`#0b0b0c`–`#0e0e0f` |
| 描边 | 面板 `#282828`，分区 `#222`，控件 `#333` |
| 文本 | 主 `#f3f3f5`，次 `#b4b4bc`，弱 `#6f6f79` |
| 语义 | 已生成 `#8be1ac`、待生成 空心灰、待更新 `#f1c376`、错误 `#fa9898` |
| 数字 | 时长/镜号/时间码统一等宽（Consolas） |
| 密度 | 列表行 46–50px；卡片间距 8px；面板内距 10px |
| 圆角 | 面板 10、卡片 8、控件 6–7、状态点 50% |
| 触控 | 手机断点下所有可点区域 ≥44px；桌面保持紧凑 |

## 4. 与现状的差异清单

1. 素材页从「列表 + 单图」升级为「清单 + 资产画布（三视图/锚点）+ 设置」，新增状态点与引用计数。
2. 分镜页从「单列卡片 + 详情」升级为「序列 + 分镜表（网格/表格）+ 详情」，新增批量生成与引用资产。
3. 成片页新增「未同步汇总」与「导出成片」主按钮，明示"从分镜同步"。
4. 四页统一三栏骨架与右栏开合逻辑，右栏都能收起。
5. 状态点、引用 chip、等宽数字成为跨页的通用语言。

## 5. 落地顺序

**P0（不改接口）**：素材列表状态点与引用计数（读现有 `reference_count`）、分镜网格视图（纯展示）、成片未同步提示（已有 storyboard_version 比对）、剧本页两处微调。

**P1（需要接口）**：素材三视图与锚点（新表或 asset 扩展字段 + 生成参数）、分镜引用资产 chip、批量生成、成片一键铺轨。

**P2**：表格视图、拖拽排序与镜号重排、多画幅导出配置。

## 6. 风险

- 三视图会让素材生成成本×3，需要"按需补视图"而不是默认全量。
- 分镜网格在 12 个镜头以上会滚动；表格视图是必要补充。
- 成片"未同步"依赖分镜版本对比，需明确"同步会覆盖哪些剪辑决定"。
