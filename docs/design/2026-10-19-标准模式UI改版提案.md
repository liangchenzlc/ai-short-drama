## 1. 背景与目标

标准模式分集页由四个阶段组成：剧本创作、素材生成、分镜制作、成片合成，前三步共用「左列表 + 主面板 + 右侧设置」，成片为独立剪辑台。

本次改版**不新增业务功能，不改业务规则**，只解决三个具体问题：

1. 头部占 105px（项目栏 53 + 步骤栏 52），且四步靠左排列，视线要来回横移；
2. 每一步后面都挂着一串状态（剧本待确认 / 已有主图 12/17 / 图 2/6 视频 2/6 / 待合成），量纲不同、字号又小，读不出重点；
3. 生成输入区的边界、字号与内边距缺少收敛，长提示词读起来偏紧。

## 3. 改版原则

**原则一：一层头部，四步居中。**
项目身份、四步轨道、已保存、助手收进 60px 单层。左右两侧各占等宽弹性空间，中间轨道自然居中——不是"靠右挤一挤"，是几何居中。

**原则二：状态回到对象身上。**
步骤只回答"我在第几步"，不回答"做完多少"。剧本待确认、已采用数、已出图数、成片状态一律回到各自页面的对象栏或底栏，那里才有上下文。

**原则三：骨架不动，只收敛细节。**
「左列表 / 中间画面 / 右侧设置」不动；生成输入仍在设置栏底部；生成按钮仍是圆形图标。改版只碰尺寸、间距、字号、字重、边框与对齐。

**原则四：颜色只做语义。**
中性灰承担全部结构；绿色只表示已完成/已保存，黄色只表示待确认，红色只表示失败与冲突。不新增强调色。

## 5. S1 剧本创作

- **左列 300px「剧本设置」**：本集画幅 / 视觉风格（并排）→ 分隔 → 来源素材（`小说原文 · 12.4 万字`，右侧"查看"）→ 分隔 → 创作要求（200px 输入区 + 底部：模型选择 / 30px 圆形发送）。列内不放下游引用与底部提示，到创作要求为止。
- **右面板**：对象栏（`第 01 集 · 剧本` / `雨夜来信` / `待确认` / `生成记录` `导出` `确认剧本`）；格式工具栏（B I 引用 撤销 重做 ＋ 336 字 · 3 场 ＋ 场次定位）；正文 700px 居中、14px / 1.95，一直延伸到面板底部。

**为什么这样改**

| 改动 | 理由 |
| --- | --- |
| 头部合并 + 四步居中 | 105px 里有近 40px 是重复信息；居中后视线只走一条中线，不必从左上角横移到右侧再回到正文 |
| 步骤去状态 | 四步状态是四种量纲（确认状态 / 张数 / 图与视频两组计数 / 阶段名），并列时无法比较；移到各自页面后，状态与对象在一起，可读性反而更高 |
| 生成按钮不改 | 圆形图标 + 白底深箭头在深色面板上辨识度足够，且与右侧"发送"语义一致；换文字按钮会让左栏高度失衡 |
| 输入框只调字号与边框 | 长提示词的主要问题是行高与字重，不是位置；11.5px / 20 行高 + 去描边同色底块，视觉更稳，也不改变已有交互 |
| 不设底部状态条 | 保存状态在顶栏、字数与场次在工具栏，底部再加一条只会重复；删掉后正文与对象栏直接相接，纵向更干净 |

## 6. S2 素材生成

- **左列 300px**：标题"素材 8" + `+ 新增` + `⋯`；搜索；分类（全部/角色/场景/道具）；4 张通栏卡片（选中卡白描边、未生成卡虚线占位），列表到卡片为止，不加计数脚注。
- **主面板**：对象栏（`素材 · 场景` / `雾夜街道` / `已采用` / `生成记录` 设置 ⋯）→ 画面（contain 居中）→ 画面脚注（`1 / 1 张` + 缩放/全屏）。
- **设置列 300px**：「生成设置」头 + ×；素材名称 / 素材类型；素材描述；参考图片（2/16，132×74 网格 + 添加）；**生成要求**（178px 无边框同色底块 + 底部：模型 · 比例分辨率 / 30px 圆形发送）。底部不放"共享到项目 / 移出本集"。

**为什么这样改**

| 改动 | 理由 |
| --- | --- |
| 设置列 324 → 300 | 画面宽度基本不变的前提下，把省下的 24px 让给左侧卡片列，卡片才撑得起 276px 通栏 |
| 生成要求容器去掉描边 | 设置列里已有 4 层边线（面板、字段、参考图、输入框），再描一圈会显得碎；改用比面板亮一档的底块（`#17171A`）分层次更安静 |
| 字号 12 → 11.5 + 行高 20 | 提示词以短句为主，适度缩小字号换行距，三行内能读完一段，不压迫右侧 300px 的宽度 |
| 新增画面脚注 | 张数与缩放/全屏原本浮在画面内（`creation-preview-tools` 绝对定位），会压住构图底部；移出画面外只占 40px，画面更干净 |
| 卡片 226×187 → 274×150 | 卡片功能是"看画面"；加宽后一屏能完整看到 4 张，代价是图高 147→110、更接近宽银幕比例 |
| 列表不加计数脚注 | 「已采用 5/8」这类计数与顶栏、卡片重复；去掉后列表只呈现卡片本身，滚动区也多出一行 |

## 7. S3 分镜制作

- **左列 300px**：标题"分镜 8" + `+ 新增`；搜索；筛选（全部镜头 / · 待制作）；4 张镜头卡（画面左上角镜号角标、底部"名称 + 等宽时长"），不加计数脚注。
- **主面板**：对象栏（`镜头 01 · 全景 · 5.0 秒` / 标题 / `图已采用` / `分镜图 | 分镜视频` / `生成记录` ⋯）→ **图片组 2×2**（第一张"1 主图"角标，每张右下角 `1672 × 941`）→ 画面脚注（`4 / 4 张` + 缩放/全屏）。
- **设置列**：镜头名称、镜头脚本、参考图片（1/16）、视频参考状态行、生成要求（同 S2），到生成要求为止。

**为什么这样改**

| 改动 | 理由 |
| --- | --- |
| 图片组保持 2×2，但补角标 | 现有宫格已经能一次看全 4 张，缺的是"哪张是主图、每张多大"；补角标后不必悬停或进全屏即可判断 |
| 单图操作仍保留 hover 工具条 | 不改变现有交互；角标只是补足"不悬停也能掌握的信息" |
| 镜头信息并到对象栏一行 | 「镜头 01 · 全景 · 5.0 秒」是身份信息，出现一次即可；原来左侧卡片与顶部摘要各一份，滚动时会分裂 |
| 图/视频切换放对象栏右端 | 与左侧"待制作"筛选语义不同（一个是产物类型，一个是进度筛选），分开后不再互相干扰 |
| 参考图与脚本保持原位 | 镜头的脚本是共享内容，写在设置栏里符合"编辑共享信息"的位置预期 |

## 8. S4 成片合成

- **左 232px 素材仓**：`分镜视频 6` + "拖入轨道"；缩略图 84×48 + 镜号 + 时长。
- **中监视器**：`剪辑预览 | 成片回看` + 右端 `合成预览`；16:9 画面；传输条（时间、播放、总时长、音量、全屏）。
- **顶部工具条 40px**：撤销 / 重做 ┃ 分割 / 删除片段 ┃ 片段静音 …… 右端时间码 + `专注剪辑`。
- **时间轴 208px**：标尺 00:00–00:20；片段宽度即真实时长（5.0s=252 / 4.0s=201 / 3.0s=151 / 6.0s=302）；播放头贯穿全高；脚注"剪辑已自动保存 · 4 个片段 18.0 秒" + `缩放 100%`。

**为什么这样改**

| 改动 | 理由 |
| --- | --- |
| 三区固定（左仓 / 中监视器 / 下时间轴） | 与前三步同方位，切步骤不用重新建立空间记忆 |
| 与前三步共用同一头部 | 原来成片页头部仍是"项目 + 四步 + 状态"，合并后四页一致，也省出 45px 给监视器 |
| 工具按改 / 删 / 声分组 | 原工具条 9 个按钮等权平铺，「删除片段」紧邻「前移」，误触成本高 |
| 片段与标尺同一比例 | 时间轴的核心语义是比例；两者坐标系不一致时，"看起来 10 秒、实际 18 秒"会误导剪辑判断 |

## 9. 交互状态表

| 状态 | 触发 | 页面表现 |
| --- | --- | --- |
| 无剧本 / 未开始 | 新分集 | 画面显示占位；对象栏状态为「草稿中」或空 |
| 生成中 | 提交生成 | 圆形按钮原位切换为进度态（同尺寸）；画面保留上一张，不跳位 |
| 候选未采用 | 返回结果 | 图片组按 1/2/4 呈现，第一张默认主图；采用入口就近显示 |
| 已采用 | 明确采用 | 对象栏状态变绿；左侧卡片封面同步；其余图片仍在组内 |
| 保存中 / 已保存 | 自动保存 | 顶栏 `● 已保存`；编辑区不闪烁、不夺焦 |
| 保存失败 / 冲突 | 网络失败 / 409 | 就近提示 + 保留草稿 + 重试 / 下载 / 核对，不自动覆盖 |
| 受理不明 | 超时 | 只核对原请求，不重发；按钮回到可用并提示"上次结果未知" |
| 窄屏 | ≤1000px | 助手改抽屉；设置与助手互斥，各自输入保留 |

## 13. 埋点与验收

**埋点**：`creation_header_step_click{step, from}`、`generation_submit{stage, model, count}`、`image_group_primary{stage, index}`、`card_scroll_depth{stage}`。

**关注指标**：进入页面到首次提交的时长；图片组"设为主图"的触发率（判断角标是否真的降低了寻找成本）；提示词输入框聚焦时长。

**验收清单**

1. 四屏头部：四步在 1440 / 1280 / 1024 下均几何居中，无状态文字，无勾选；
2. 生成按钮：30px 圆形、白底深箭头，与现状像素一致；
3. 设置列：生成输入在栏内底部，300px 宽下文字不溢出，模型/比例/发送同一行不换行；
4. 素材页：4 张卡片完整可见，未生成卡显示占位；
5. 分镜页：2×2 图片组 + 主图角标 + 像素角标，不遮挡画面主体；
6. 成片页：片段宽度与标尺同比例（5.0s 片段宽 / 标尺总宽 ≈ 5/20）。

## 14. 未覆盖与风险
