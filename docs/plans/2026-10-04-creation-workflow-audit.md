# 分集创作流程审查与优先级修改方案

日期：2026-10-04。状态：审查完成。后续三批修复已实施，当前结果见[实施与验收记录](2026-10-04-creation-flow-fixes-verification.md)。

审查阶段按“小说改编与剧本定稿 → 素材准备 → 分镜制作 → 成片合成”的操作顺序，核对界面、编辑会话、前端 DTO、HTTP 路由、Service、数据权限与异步任务。Agent 作为前三阶段的创作入口单独核对。当时没有修改业务代码、现有配置或业务数据，没有提交代码；开始时的 75 个未提交条目均保留。以下问题表保留审查时的证据等级，后续修复与新增复现不回写为审查阶段已经验收。

本报告基于当前工作树，包含上一轮已经完成的 Agent 改造，不把能力验证门槛、讨论/生成切换和旧的跨对象历史混用重新列为当前问题。上一轮交付边界见 [Agent 完善方案](2026-10-04-agent-creation-refinement.md)。

## 1. 结论与证据等级

当前基本制作链路已经具备候选、手动采用、作者隔离、来源冻结、版本校验、串行保存和异步恢复。优先补齐请求不确定时的恢复、对象切换后的状态一致性，以及必须前置完成的审核入口，然后提升大量素材和镜头的审核效率。保留冷黑、紧凑的中文工作台风格。

未发现足够证据判定新增 P0。这不是对整个系统安全性或真实供应商质量的完整验收。

| 标识 | 含义 |
| --- | --- |
| 已复现 | 本轮隔离脚手架执行并复现当前问题行为；使用替身时明确标明，不能视作现场浏览器或供应商验收 |
| 代码确认 | 调用链、状态与分支能确认缺口；尚未完成该故障的现场或数据库复现 |
| 待验证 | 静态链路存在风险，须先补对应验证，再决定修复细节 |
| 增强建议 | 当前行为符合已有范围，建议改善效率、可理解性或可恢复性 |

| 优先级 | 判断标准 |
| --- | --- |
| P0 | 已证实的权限泄露、不可恢复破坏或核心链路普遍不可用；本次没有确认项 |
| P1 | 高风险重复制作、高频流程断点、关键审核或恢复入口缺失 |
| P2 | 有绕路的状态缺口、错误反馈、分页/定位、媒体恢复与契约一致性 |
| P3 | 视觉细节、维护说明和超出现有范围的能力扩展 |
