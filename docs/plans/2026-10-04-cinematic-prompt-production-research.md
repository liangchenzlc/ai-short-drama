# 提示词优化方案：沿用当前制作流程

日期：2026-10-04。第三版，按用户对参考图和分镜提示词的要求修订。

**完整提示词与填好的示例见 [提示词审核稿](2026-10-04-prompt-templates-review.md)。两份文档均待审核，尚未替换运行模板。**

## 1. 这版的核心

继续用当前小说、剧本、素材、分镜、图片、视频和合成流程。现有风格框、生成按钮、候选与采用操作继续沿用。

重点改为：**提取分镜时，就一次写好每镜的脚本、图片提示词和视频提示词。** 后续生图和生视频使用已经写好的对应正文，再补实际参考图、当前布局、画幅和实际视频时长。

生成素材图、分镜图和视频时，提示词只包含有用的自然语言，不整包传素材或分镜业务 JSON。内部 JSON 快照、版本和历史重试继续保留；文本提取的 JSON 输出也继续保留。

## 2. 最重要的五项改进

| 优先级 | 怎么改 | 解决什么问题 |
| --- | --- | --- |
| 1 | 分镜提取一次产出脚本、完整图片正文、完整视频正文，三份内容核对一致 | 避免后续模型各自猜动作、重设计镜头，减少图片和视频对不上 |
| 2 | 按实际上传顺序写“角色/场景/道具：图片N＋名称”，明确每张图的用途 | 减少人物串脸、道具错配、照搬参考板姿势和布局 |
| 3 | 图片写确定时刻；视频写起点、动作过程、相机路径、节奏和终点 | 减少静态图挤入多个动作、视频动作乱跳或提前出现结果 |
| 4 | 打斗写清距离与攻防；特效写来源和作用；大场面写地标、尺度和主次 | 用具体画面设计提高表现力，减少只堆“震撼、电影级”等词 |
| 5 | 选中风格自动加入对应模块，素材设计与分镜表现保持协调 | 同一套结构适用写实、二维、水墨、水彩和三维，不全部套写实 CG |

打斗、特效和大场面的规则直接内置在模板，剧情涉及时才使用。没有新增 Skill 选择、摄影设置、提示词编辑保存或额外确认步骤。

## 3. 参考图说明怎么写

假设分镜图实际上传顺序是林夏、张小鸣、树林、倚天剑：

```text
角色：【图片1】林夏；【图片2】张小鸣
场景：【图片3·场景图】树林
道具：【图片4·道具图】倚天剑
```

随后说明人物图保留身份与造型、场景图保留空间、道具图保留形制；人物站位、姿势、持物和视线按本镜正文。

图例和实际附件必须来自同一个去重后的列表。没有附图就没有图号，用途不明的上传图不猜身份。提取分镜时先写素材名称，生成请求时再补真实图号。

**当前视频只收到一张已采用分镜图**，因此写：

```text
综合分镜参考：【图片1】
图内人物：林夏、张小鸣
图内场景：树林
图内道具：倚天剑
```

图内说明仅用于确实可辨认的内容；这不是另外附上四张素材图。继续使用现有全能参考，不锁首尾帧，不因参考图是宫格就强制切镜。

## 4. 六个阶段怎样衔接

| 现有阶段 | 新提示词的责任 |
| --- | --- |
| 小说生成剧本 | 将心理转成可见行动，保留因果、对白和结果 |
| 剧本提取素材 | 定好可复用的身份、单一状态、外观与空间，把选中风格写进素材 prompt |
| 生成素材图 | 根据保存的设计和真实参考生成，保留人物/道具参考板、场景单图版式 |
| 剧本提取分镜 | 设计每镜作用、空间、起点、动作和终点，同时写完整图片与视频正文 |
| 生成分镜图 | 单图画起点；宫格把同镜已有阶段展开成静态画面，不扩展剧情 |
| 生成视频 | 用已写好的动态正文，执行本镜动作、运镜与结果，按实际时长安排节奏 |

三份分镜内容暂放在现有 `script` 字符串中，用“【分镜脚本】”“【分镜图提示词】”“【分镜视频提示词】”区分。当前 JSON 六字段与采用流程保持不变。

后台需要配套取段：图片只取图片正文，宫格再补同镜已有阶段，并明确起点限制只约束第一格；视频优先用现有用户视频稿，否则取视频正文。旧分镜和手动分镜没有新标题时，图片使用原有起点与动作阶段的自然语言回退，视频回退原有默认稿。不能只改模板后仍将混合的整段脚本发给媒体模型。

## 5. 风格和调研依据

继续按当前风格框读取都市写实、电影质感、国风水墨、清透水彩、日系动画、三维动画与自定义输入。只拼选中的模块，不将六种混在一起，不新增风格确认。

在现有风格框更换风格后，分镜图片和视频按当前选择覆盖正文或参考图中的旧画风，只调整表现，保留人物身份和剧情事实。没有选择风格时沿用已有明确表现。

素材独立生图没有本集风格字段，所以提取时将风格写进已有素材 prompt，独立出图沿用保存稿；共享素材不会随另一个分集风格自动重做。

已阅读五个项目的相关 Skill：Huobao Drama、waoowaoo、Toonflow、Seedance2-Storyboard-Generator、drama-skills。本轮进一步核对 drama-skills 的图片/视频模板、waoowaoo 的素材与场景模板，以及 ViMax 的静态起终点与动作分解模板。

审核稿提供固定提交的原文链接和具体借鉴。drama-skills 与 Seedance2 已是项目既有参考。本次取用专业写法，不带入外部项目的审批、Agent 工具或新增制作步骤。
