这是一份整个项目的修改方案，以下是我对这个项目的修改要求，请根据我提出的要点进行修改并验证：
1. project页面修改内容：
分集列表中的分集的“编辑分集”，“删除”按钮放在item上面，不单独放在item外面
2. episodes页面修改内容：
左边的流程栏提供向左收起来的功能，在“创作流程”这几个字的右边提供一个按钮，点击之后可以向左收起来
把小说改编流程和剧本定稿流程放在一个步骤
3. 小说改编页面（把剧本定稿的页面加到这里来）
右边的“AI剧本改编”区域放在左边，布局调整成这样子
| 流程栏  | AI剧本改编栏（AI模型功能栏） |  小说内容创作区域    |
|        |                         |                   |
下面的候选剧本不要在下方展示。
本集小说支持文件txt导入
AI模型功能栏提供本集画幅，视觉风格两个选择框选择
4. 素材准备页面
点击新建角色按钮出现的弹窗替换成右侧出现的抽屉栏
素材提取结果的弹窗不要出现原文依据，甚至后端提取的接口也不需要原文依据
素材提取结果的弹窗中每个item不要直接展示出图片生成提示词的内容，可以在人物名/场景名/道具名 右边
提供一个图标按钮，点击之后出现一个文字提示（可以利用ant design组件）
编辑素材页（右边抽屉框）的宽度更大一点，占到屏幕的一半，里面的内容重新布局，把“本次补充要求”这个输
入框给删掉，这里的生成记录只做一个跳转（跳转到任务管理页对应的生成任务详情），这里不要展示其具体的
请求参数那一堆
“参考图片”这几个字替换成“生成图片”
在“生成图片”这个区域下提供一个增加“参考图片”，可以用缩略图展示已经上传的图片
5. 分镜制作页面
删掉归档功能，下载草稿
同样的，这个页面改成
   | 流程栏  | AI模型功能栏 |  分镜创作区域    |
   |        |            |                |
AI 模型功能栏主要提供选择文本模型，分镜生图模型，平均镜头时长，分镜要求描述这几个选项
然后提供“生成分镜脚本”按钮，把“刷新任务”的按钮删掉，同样，在这个区域提供“生成记录”按钮
点击“生成记录”按钮会弹出一个弹窗，在里面可以查看往期生成的记录，对于每条记录可以查看
往期的分镜记录，只展示镜号，分镜脚本，且这里需要支持懒加载列表，先加载展示出来的分镜列表，
往下划才会加载其他的列表，然后可以点击采用按钮
采用之后，分镜就会出现在分镜创作区域，同样是懒加载机制，且只先展示分镜号和分镜脚本（一行展示，
多出的分镜脚本可以省略），然后点击分镜item，下方会展示分镜生图区域，
这里展示分镜脚本，关联素材（区分角色，道具，场景），同样有个生成图片区域
生成图片区域有参考图片可以上传，图片清晰度，图片比例，图片布局，图片数量，然后点击生成图片按钮
同样，生成的记录可以用弹窗展示，不要在下方展示太多内容
6. 对于任务管理页(tasks)的修改
任务列表可以展示id，展示哪一个项目，哪一集，哪一个主题生成的，可以用“项目/集/主题” 来展示
任务详情页的输入与参数不要展示整个请求参数，只展示提示词部分
