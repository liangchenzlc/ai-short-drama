## 设计方向

Operate 模式，沿用已有工作台，重点让正文和镜头占据主要空间。颜色：主操作青绿 #087f75、底色 #f4f7f7、侧栏 #edf2f2、正文 #203235、次要文字 #5d7073、编辑面 #ffffff。沿用 Segoe UI / PingFang SC / Microsoft YaHei，14px 正文、16–20px 分组标题，所有编辑内容左对齐。

桌面：`可收起流程栏 | 模型与生成控制 | 正文 / 镜头创作区`。窄屏收为单列，流程栏可收起，生成设置与正文依次排列，抽屉占满屏幕。历史任务只在用户打开时展开，镜头列表滚动分页加载，默认一行摘要、选择后展开编辑。复核：不改为通用仪表盘，不新增统计卡片或装饰性标题；保留当前视觉身份，把设计调整集中在创作工作区结构。

## 问题与处理

- impeccable context 启动器无法在用户目录创建引擎缓存；按技能回退流程直接读取 PRODUCT.md / DESIGN.md，继续执行。
- 当前 `npm test` 使用 `node --test tests`，Node 22/Windows 将目录作为模块读取而失败。修正为明确的测试文件匹配后验证。

- 浏览器连接器没有可用浏览器，改用项目内无界面 Playwright；Windows 沙箱清理 Vite 子进程受限，提升权限运行测试后正常退出。
