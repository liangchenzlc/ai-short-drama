# AI 创作助手 Harness 重构实施

状态：已完成。日期：2026-10-26。

## 已确认范围

采用 LangGraph 控制执行流程，LangChain 驱动 Agent 决策与 function calling。
图片与 Skill 共享轻引用、按需水合和深层资料递进加载机制，保留 MySQL 上的 L1–L5
记忆分层。工具由 Agent 自主选择，服务端继续校验归属、任务范围、版本、模型能力及预算。
本期不迁移旧停止、改向和恢复中断系统，不引入多 Agent、向量库或任意脚本执行器。

## 目录归属

`agent/harness/` 管执行图和状态；`agent/resources/` 管资源协议与水合；
`agent/context/` 管装配、预算和压缩；`agent/gateway/` 管 LangChain 模型与协议；
`agent/tools/` 管注册及执行；`agent/skill/` 继续管理不可变方法包；
`agent/memory/` 保留现有记忆和后台整理；`ai/prompts/assistant/` 保存版本化提示。
checkpoint 通过 Service → DAO → ORM 保存，业务工具复用现有 Service 与操作账本。

## 验收约束

- 持久化历史、请求快照、checkpoint 与 pending writes 中媒体实体为零。
- 图片只在明确请求读取的单次模型调用内水合；冻结原件和衍生对象仍由 MinIO 保存。
- Skill 首次加载保存正文，重复加载不复制正文；压缩后仍需使用的方法保留完整正文。
- 当前状态不逐轮追加完整快照；L2/L4 水位线和 L5 作用域、遗忘规则保持有效。
- 业务工具与模型调用恢复复用持久回执；受理不明不自动重发付费请求。
- 测试替身、真实基础设施和真实供应商验收分别记录，不互相替代。
