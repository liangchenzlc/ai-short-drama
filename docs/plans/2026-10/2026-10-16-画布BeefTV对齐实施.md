编制日期：2026-10-16。实施复选框表示当前工作树已有对应实现；每项验收情形另见[实施与验证记录](2026-10-16-画布BeefTV对齐验收.md)，不将代码完成等同于全部真实对照通过。[逐项复核](2026-10-16-画布BeefTV对齐审计.md)发现第 3、11 项细节未补完整，现已修复；17 项仍未全部完成真实运行验收。

## 目标与范围

对照 BeefTV v1.7.23（`c596a342244ceeb674633b6a9bf974ef860310f6`），按体验影响、开发投入和行为一致性排序，补齐以下 17 项，并核实另外三组实现差异。原迁移基线 `4ca2a65a7780a8dfcaaa86c33679f84fb04e055c` 保留；新版来源另行注明。

- 排除导演台／3D 预演、MiniMax H3 新版细参数、画布 AI 创作助手和 BeefTV 未开放功能。
- 标准模式保持现有行为。复用 Python、MySQL、MinIO、宿主客户端、账号权限和任务系统，不恢复已删除的 BeefAPI。
- 保留已有未提交改动及测试重组；不自动提交、暂存或还原其他任务。
- 来源画风按用户确认补完整快照，包括画布专用的设置、持久化与同步。
- 估算按熟悉项目的一名全栈开发者计算，包含相关测试联调，外部服务部署与供应商等待另计。

## 第一批：P1

### 1. F050：生成中节点删除（1–3 人日）

- [x] 实施：统一所有删除入口，识别节点、框内子节点及批次中的活跃任务；按源显示费用确认。确认后先发起取消，再删除节点；失败仍删并提示未取消任务可能继续，阻止后续批次派发。切换账号／画布时关闭旧确认框。
- 原因：避免节点消失造成任务已经停止的误解。
- 验收：普通删除、取消确认、多选、框内节点、批次等待／运行、取消失败、重复点击和完成竞态；撤销不重提任务，不承诺删除终止供应商计费。

### 2. F017：滚轮与触控板手势（0.5–1.5 人日）

- [x] 实施：接入新版手势意图判断及约 200ms 锁定，沿用滚轮步长、双轴触控板、修饰键和缩放锚点处理。
- 原因：平移缩放是最高频操作，误判持续影响体验。
- 验收：连续事件、手势结束、双轴及修饰键测试；鼠标、触控板及实际设备对照，输入区滚动符合源行为。

### 3. F096／F097：历史刷新与插入反馈（0.5–1 人日）

- [x] 实施：弹窗打开时约每 5 秒刷新，关闭停止；保留已有详情刷新、防重复提交及作用域保护，补选择中的条目和加载反馈。
- 原因：让新结果及时出现，并说明插入正在进行。
- 验收：自动出现新结果、关闭停止、重复点击仅插入一次、失败恢复、旧响应不跨账号／画布插入。F097 详情刷新和防重复已存在，不重复开发。

### 4. F257／F258：视频与音频字幕入口（0.5–1 人日）

- [x] 实施：补视频工具栏字幕按钮，字幕命令支持音频，统一节点、资源、时长及草稿上下文。
- 原因：将已有字幕能力接到直接可达入口。
- 验收：视频／音频打开、编辑、保存、重开、刷新恢复，不同节点不串草稿，图片不显示命令。

### 5. F249：H.264 兼容播放（2–4 人日）

- [x] 实施：统一视频来源，原视频播放失败时异步准备 H.264/AAC 副本；复用 FFmpeg 和任务设施。按资源版本去重，记录状态及稳定定位值；沿源间隔和上限轮询，关闭播放器停止观察。保留原文件及下载。
- 原因：兼容问题会阻断结果查看与后续编辑；常用素材已无法播放时提升至第 1～2 位。
- 验收：H.264 直接播放、真实 HEVC 回退、转码失败、超时、重复打开、刷新、越权、Range／HEAD、定位和音画同步；临时 URL 过期可重新读取。

### 6. F271／F273：字幕自动转写（1.5–3 人日，依赖 4）

- [x] 实施：字幕弹窗接通现有 Whisper API、任务观察及结果解析；呈现提交／运行／失败／完成，成功替换当前草稿，沿用原保存动作。绑定账号、画布、节点及资源，旧结果不覆盖其他上下文。
- 原因：显著减少手工字幕录入。
- 验收：已知对白音视频、无语音、服务未就绪、任务失败、重复提交、关闭重开及资源切换。文案说明宿主服务端执行，不宣称音视频不出本机。

### 7. F116：生成交付进度（1–2 人日）

- [x] 实施：用真实任务与资源状态区分生成、下载／取回、处理及就绪，补停滞反馈；无真实百分比时使用不确定进度。恢复重试遵守服务端许可。
- 原因：避免交付等待被当作卡死和重复生成。
- 验收：生成完成但资源未就绪、慢取回、失败、恢复、刷新和终态竞态；不提前显示可用，不重复付费提交。

## 第二批：P2 素材与预览

### 8. F079／F080：上传确认与文件管理（1–2 人日）

- [x] 实施：统一上传弹窗，提供文件选择／拖入、待上传列表、预览、移除及确认；复用现有上传和节点插入，保留范围与幂等身份。
- 原因：减少批量误传后的返工。
- 验收：多类型、移除、取消、格式不支持、部分失败、重复确认；资源与节点不重复，临时预览释放。

### 9. F087：多类型素材托盘（1–2 人日）

- [x] 实施：查询、搜索、预览及插入支持图片、视频、音频和文本，保留完整分页、草稿合并与账号校验；文本不伪装成媒体文件。
- 原因：减少素材选择绕路。
- 验收：四类素材、多页、空态、失败、已删缓存清理、账号切换和刷新后引用。

### 10. F081：媒体 URL 导入（1–2 人日，依赖 8）

- [x] 实施：上传弹窗补 HTTPS 链接与媒体类型入口，复用现有服务端 URL 导入校验、幂等及持久化资源插入。
- 原因：省去先下载再上传。
- 验收：三种媒体、无效／不可访问链接、重定向失败、类型不符、超时、重复提交及画布切换。

### 11. F098：历史悬停视频预览（0.5–1 人日，依赖 5）

- [x] 实施：历史卡片复用兼容视频来源，沿源实现悬停播放、移出暂停和加载／失败反馈，卸载释放资源。
- 原因：减少比较结果时逐个插入的操作。
- 验收：快速悬停、多卡切换、列表滚动、HEVC、准备失败、不后台持续播放，插入只执行一次。

### 12. F051：视频右键删除（0.25–0.5 人日，依赖 1）

- [x] 实施：补视频专用菜单删除项，复用统一删除链。
- 原因：对齐常用菜单入口。
- 验收：普通／生成中视频、多选、确认、撤销及事件传播。

## 第三批：P2 风格与云端转写

### 13. F202：来源完整风格快照（3–5 人日）

- [x] 实施：新增画布专用来源风格持久化，按来源项目保存完整快照和并发版本；侧栏复用风格选择器设置、保存及同步。文字画风仅作初始化，完整快照与个人原件分离；同步创建或更新风格节点，不自动重写既有作品。
- 原因：完整保留提示词、负向提示词、选项和资源绑定。
- 验收：内置／自定义完整风格、旧文字画风、无快照、资源失效、并发和重登；个人原件变更不影响共享快照，资源经过项目权限检查，标准模式不变。

### 14. F211：个人风格跨设备持久化（2–4 人日）

- [x] 实施：账号级风格 CRUD、收藏和最近使用，只调整风格存储适配；旧本机风格由用户明确选择幂等导入，同名不静默覆盖，不切换全局工作区模式。
- 原因：换设备仍可使用本人风格。
- 验收：两个独立会话、账号隔离、修改／删除同步、冲突、网络失败和重复导入；删除个人原件不损坏作品快照。

### 15. F272：云端转写模型（3–5 人日，依赖 6）

- 原因：提供 Whisper 服务之外的模型选择。
- 验收：无模型、刷新、配置失效、不支持、供应商失败、不确定提交及账号切换；未知提交不自动重发，失败不自动切换其他付费模型，真实供应商单列验收。

## 数据、接口与验证规则

- 兼容副本：增加准备与状态接口及文件 variant=playback 读取，按原资源版本和编码配置去重，原资源身份不变。
- 来源风格：既有来源概览增加快照与版本，来源路径增加 /style 写入，持久化独立于标准模式文字画风；预期版本冲突保留输入。
- 个人风格：实现账号归属的风格接口、收藏与最近使用；作品快照不受个人原件修改影响。
- 云端转写：现有创建合同增加可选 model_config_id，省略保持 Whisper，模型列表支持刷新。
- ID 和并发版本对外为十进制字符串；凭据不进浏览器存储、日志或快照；媒体持久化稳定身份。
- 数据库改动必须同步 ORM、真实目标库 DDL、完整 SQL、增量迁移和说明，记录库名与语句；应用不自动建表。
- 修改测试或辅助文件同步 test-map.json，执行 --check，并更新 --inventory。现有工作树含其他任务，使用 --feature 明确本轮范围。
- 普通逻辑执行 fast；数据库追加 mysql；交互追加 browser；队列／存储追加 infra；live 独立选择，不自动开供应商开关。
- 前端批次执行 npm run build（frontend/）及 npm run source:check（frontend/canvas/）；后端执行相关功能测试与 Ruff 检查、格式检查。
- 来源适配、API、数据库和运行说明随实际改动更新。构建、哈希、夹具通过均不代表真实媒体或供应商验收。
