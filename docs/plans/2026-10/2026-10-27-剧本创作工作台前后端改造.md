# 剧本创作工作台前后端改造

状态：已完成。范围：标准创作模式的剧本节点；AI 创作助手保持现状。

> 后续验收调整：左侧仅保留三个一级文档入口，已移除场头／地点二级目录及提示，正文统一为整篇连续文本。本文下方的场头导航描述保留初次方案记录，当前行为以[产品范围](../../../frontend/PRODUCT.md)为准。

## 产品边界

工作台以一份可直接修改、自动保存的当前剧本为中心。生成成功即成为当前正文，供素材提取和分镜使用。保留小说原文、故事大纲和剧本正文三个文档，左侧场头从正文解析，仅用于跳转。大纲可手写或由小说、想法生成，也可以跳过大纲直接生成剧本。

移除右侧 AI 创作台、候选对比、手动采用/确认、版本和草稿入口，以及场次、动作、对白、OS、VO 插入工具、独立节拍/人物小传/一句话故事表单。不建立可手动管理的场次实体。

## 前端设计与交互

使用 impeccable 的 Operate 模式与 frontend-design，沿用现有冷黑工作台和系统中文字体。画布 #101010、面板 #181818、悬停 #242424、正文 #f3f3f5、次级文字 #b4b4bc、边界 #2d2d2d。240px 左侧目录，8px 区间距，正文阅读宽度约 840px，16px/1.9 连续编辑。宽度按实际容器响应：不足 1000px 时目录进入抽屉，兼容已有助手占宽。

默认打开剧本。小说支持 TXT 导入；大纲和剧本可手写或打开紧凑生成对话框。默认来源依次选择非空大纲、小说、想法；小说内“从小说改编”固定预选小说。只保留来源、可选创作要求和模型，想法来源必须填写想法。正文支持 TXT 导入导出，UTF-8 上限 1 MiB。

选中剧本文字出现一个“AI 修改”入口，Ctrl/Cmd+K 同样可打开指令浮层。完成中文输入法合成、保存成功后冻结选区和版本；服务端仅替换选区，自动保存。浮层使用 portal，窄屏为底部面板，Escape 仅关闭界面。成功替换是一笔撤销事务；撤销通过常规保存生效。浏览器重载不保存撤销历史。

生成期间锁定目标文档，其他文档可编辑，页面退出不取消任务。可主动停止。刷新通过 writing 的活动任务恢复状态，任务结束后重新读取正文；保留其他文档未保存输入，仅在服务端基线未变时安全续接版本。409 保留用户输入并提供恢复操作。旧浏览器本地大纲仅在服务端为空时提示一次导入，不静默覆盖。

## 数据与保存

新增 project_story_outlines：雪花 ID、唯一 project_id、MEDIUMTEXT 正文及创建/修改审计；复用项目权限、项目级 content_version 和事务锁。小说与剧本继续使用现有表；剧本原位更新，首次保存创建记录。新生成不新增候选或 NovelScriptRecord。

所有当前剧本非空保存发布并设置内部 confirmed；空正文取消可用状态，不回退到旧确认剧本。切换内部唯一确认前先释放旧确认。未采用的 Agent 候选保护不变。纯文本为权威，AI 写入清空旧 editor_document。保留旧 novel_script 任务和兼容接口。

## 接口与异步任务

- GET /projects/{id}/writing 增加 outline、active_writing_tasks（任务、目标、操作、状态）。
- PUT /projects/{id}/outline：content/content_version；响应 outline/content_version。正文均限制 UTF-8 1 MiB。
- PUT /projects/{id}/script 返回准确 confirmed_script_id。
- POST /ai/generations/text 增加 story_outline（novel/idea）、script_generate（outline/novel/idea）、script_rewrite。局部修改提供当前 script_id、start/end 和 selected_text，偏移使用 Unicode 码点半开区间；浏览器显式转换 UTF-16。

复用现有模型、MySQL、RabbitMQ、Celery、幂等键、取消和结果恢复。入队在项目锁下检查目标活动任务、读取来源并冻结目标标识/哈希。所有目标保存和切换路径遵守相同锁。模型调用不占数据库事务；先持久化原始输出，再将正文、版本、业务回执与任务完成原子提交。失败、空输出、截断、取消和过期目标均不覆盖正文。保存重试复用原始输出；恢复历史失败任务必须重新检查锁和目标指纹。

改写上下文仅包含选中文本、前后各最多 2000 码点及已保存大纲，提示词只要求返回替换正文。服务器按原始索引拼接前缀/结果/后缀，重复文字和 emoji 不产生错替换。素材与分镜读取最新当前正文，生成中禁止启动相关下游生成；已存在素材和分镜不自动重建。

## 实施与验证

1. 模型、增量 DDL、writing 契约、自动确认和目标互斥；验证读写、归属、空正文、旧候选保护。
2. 三类文本任务的来源冻结、提示词与原子回写；验证幂等、Unicode、失败/取消/恢复及并发。
3. 编辑会话加入大纲和安全刷新，替换两栏界面并接入真实接口；验证输入法、撤销、导航、任务恢复、容器响应。
4. 执行加法迁移、导出完整 schema，同步接口、数据库、产品、架构与测试索引。先查看 changed dry-run，再执行 writing/generation 与受影响下游测试、类型检查、生产构建、check-docs 和 check-quality。

上线需先排空旧小说改编任务，协同更新 API、文本 Worker 和前端。迁移只规范已有已发布的当前剧本，非空稿直接可用、空稿取消可用状态，保留历史与私人候选。

三文档工作台、自动保存与直接生效、选区 AI 修改及撤销已对接后端；生成沿用真实异步队列，目标互斥、幂等回执、取消与原输出恢复已落地。本机 `short_drama` 已执行迁移，重入 0 项状态变更；全量 schema 为 120 表。

相关快速回归 716 项通过（API 16、后端单元 554、前端 Node 146），浏览器 19 项通过；真实 MySQL 并发／迁移及 RabbitMQ、Celery 文本 Worker 联调分两次共 10 项通过。双包类型检查与生产构建、26 个相关 Python 文件的 Ruff 检查、测试映射、文档与结构门禁及差异空白检查均通过。模型联调使用本地 HTTP 替身，尚未进行真实供应商生成效果验收。完整证据和部署说明见[验收记录](../../reviews/2026-10-27-剧本创作工作台验收.md)。
