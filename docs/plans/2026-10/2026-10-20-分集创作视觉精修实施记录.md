## 3. 共用接口与样式约定

本次只增加可选局部表现参数，不改变HTTP契约或数据库结构。

| 接口/标记 | 用途 |
| --- | --- |
| `ConfigSelect.optionLayout?: 'single' \| 'detailed'` | 标准创作模型菜单分名称、型号与状态两行；48px条目，菜单宽度受视口限制 |
| `ConfigSelect.presentation?: 'standard-creation'` | 为标准模式下拉增加局部样式，不改变未传参调用方 |
| `ConfigSelect.feedbackContainer?: HTMLElement \| null` | 将目录、偏好与未选模型反馈放到指定整行容器，保留原重试与选择逻辑 |
| `GenerationComposer.feedbackRef?: React.Ref<HTMLDivElement>` | 在组合框后提供整行反馈容器，空容器不占空间；`SourceStage`连接小说模型，媒体生成按同一模式连接 |
| `EpisodeModelSelect`同名可选参数 | 透传上述表现与反馈参数，保留分集模型偏好及字符串ID |
| `ImagePicker.purpose` | `candidate`、`artwork`、`reference`、`generation-input`区分候选、作品替换、私人参考与生成输入说明；原选择/复制流程不因文案变化 |
| `ImagePicker`、`ImagePreview`等的`presentation` | 标准入口显式传递局部外观；公共默认调用保持原表现 |
| `standard-creation-dialog` / `standard-creation-popup` / `standard-creation-drawer` | 标准分集浮层作用域；原生Dialog内下拉继续挂在当前可交互层，不统一强挂body |
| `PLAYWRIGHT_OUTPUT_DIR` | 可为并行验证指定独立产物目录；未设置时保留原默认，避免多个测试进程清理同一输出目录 |

图片生成后直接保存完整图片组、第一张默认主图；剧本和视频保留明确采用。私人参数、任务、凭据、生成历史和对话按本人隔离，现有权限检查不变。助手旧“历史创作记录”仍为只读消息与原工作台提示，不在该窗增加候选采用或任务继续能力。
