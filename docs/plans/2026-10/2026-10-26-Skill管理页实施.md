# Skill 管理页实施

- 日期：2026-10-26
- 状态：已完成
- 依据：[Skill 管理页设计方案](../../design/2026-10-26-Skill管理页设计方案.md)

将 Skill 从 AI 配置迁入独立管理页，统一为导入、整包更新与只读文件浏览。沿用 Agent API、不可变版本、账号隔离和既有事务边界，复用 Ant Design DirectoryTree／Splitter 与 CodeMirror 6。

## 范围

- 包含：独立入口、来源／名称用途／启停／模式检索、紧凑卡片、三段模式、Markdown／ZIP 导入、整包更新、只读预览、前后端契约、数据库迁移及旧界面删除。
- 不包含：在线编辑、脚本录入或执行、批量管理、无关的 Agent 架构调整。

## 实施与验证

- [x] 统一契约：删除 Skill 触发设置与筛选；`tags` 隐藏保留，PATCH 省略保留、`[]` 清空。模式沿用 `modes`，默认通用，更新保留原模式及启停。
- [x] 改造导入发布：前后端均限制文件类型、路径、文件／目录冲突、引用及体积；脚本与未知格式整包拒绝。预览和直接请求均校验，上传前检查兼容性，发布仍使用不可变版本和短事务。
- [x] 完成迁移：删除 `agent_skill_settings.invocation_mode`，保留版本 CHECK 和其余设置。隔离库覆盖正迁移与恢复；本机已备份并执行，设置／历史版本／任务引用摘要一致。
- [x] 改造运行时：移除按触发偏好过滤，继续按启停、模式和兼容性选择方法；保留任务实际激活来源审计。
- [x] 新建 `pages/skills/` 与 `features/skills/`，接入路由和侧栏；卡片只显示名称、用途、模式与启停，问题在对应位置反馈。
- [x] 共用只读文件浏览器：默认 SKILL.md 正文，目录树、行号、复制、图片、缓存、请求取消、迟到响应隔离、局部重试与窄屏切换；没有内容写入入口。
- [x] 接通导入更新会话：完整包移除确认、同名新增、幂等回执核对、版本冲突后明确确认、旧草稿与旧受理记录下载，按账号隔离。
- [x] 删除 AI 配置旧 Skill 页签、管理／编辑／资料组件及专属样式；旧 URL replace 到 `/skills`，保留模型类别、助手设置和安全画布返回。助手选择器仅选择、只读预览及进入统一管理页。
- [x] 完成相关 fast／MySQL／浏览器测试、两包构建、静态检查和两轮批量视觉验收；如实记录替身边界及已有过期回归。
- [x] 同步 API、数据库、架构、代码地图与测试映射，通过文档和结构门禁，记录[验收结果](../../reviews/2026-10-26-Skill管理页验收.md)。

本机使用 [Skill 管理迁移](../../database/migrations/2026-10-26-skill-management/README.md)；完整库、设置原值及 25 份资源备份保留于 `.runtime/skill-implementation/20261026T114331Z/`。迁移时无活动任务，API、scheduler 和 Agent Worker 已停止并在迁移后以新版启动。

其他环境发布前独立预检、备份并协调前端／API／Worker 同版切换，不由应用启动隐式迁移。不回填历史快照，不删除已冻结资源；恢复时按设置身份补回旧列，不覆盖迁移后的启停或版本。
