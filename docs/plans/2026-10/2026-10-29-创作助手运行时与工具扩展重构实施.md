**技术栈（Tech Stack）：** Python 3.12+、FastAPI、Pydantic 2、SQLAlchemy 2、MySQL 8、Celery / RabbitMQ、MinIO、LangChain 1.x、LangGraph 1.x、Deep Agents 必要中间件、FastMCP、OpenSandbox + Docker；React 19、TypeScript strict、Ant Design。

**设计依据（Spec）：** [已确认的重构设计](../../design/2026-10-29-创作助手运行时与工具扩展重构设计.md)。执行者必须同时阅读设计和本计划。

## 一、全局约束与完成边界

- 单一通用助手，不新增助手预设、角色选择、子 Conversation 或子会话聊天入口；子任务仅在主会话展开。
- 框架控制完整循环；删除强制 reviewer、completion contract 和项目自研 continuation，主 Agent 根据提示词 / Skill 判断交付完成。
- 生成提交立即返回任务身份；显式等待未完成的业务结果、`ask_user` 等待必要用户输入时持久 interrupt。普通工具、代码执行和委派开始本身不 interrupt，不为每次业务写入强加审批。
- 子 Agent 同步交付，同轮可并行，首版一层、最多 **3** 个并发，共享父 Run 预算；不引入后台子任务调度或 Agent Protocol 服务。
- 对外 MCP **长期只提供工作台业务工具**；不开放助手完整任务委托、聊天、运行控制、记忆、Skill 加载、`task` 或任意沙箱执行。
- MCP 账号令牌必须有名称；有效期、IP 白名单可选；支持创建、列表、删除；完整密钥只展示一次。初始化、发现、调用及后续协议请求都必须认证。
- 外部 MCP / 本机 stdio 工具的接入、配置、测试、启停仅保留设计；本次不增加连接页面、API、连接表、MCP 客户端依赖或空适配层。
- OpenSandbox + Docker，自部署；只保证 Python **3.12**、Node.js **24.x LTS**、pip / npm；支持公网联网、在线安装依赖、下载公开资料和脚本访问外部 API。
- 沙箱按执行范围隔离；持久工作区恢复文件，持久等待可销毁容器并保留卷；不承诺恢复进程内存。FFmpeg / 数据媒体包批量预装不在本次交付。
- 业务数据继续以 MySQL / MinIO 为准；不引入 Redis、PostgreSQL、Kubernetes 或新的 Agent 常驻服务。
- 数据库事务不得跨模型请求、沙箱命令或网络调用；SQLAlchemy Session 不跨线程共享；checkpoint 不存凭据、SDK 对象、媒体字节或签名 URL。
- 同一 Run 的恢复固定提示词 / 工具 / Skill 版本、模型额度与子并发配置；账号权限、媒体生成总开关、停止请求、MCP 令牌撤销在执行边界实时生效。
- 前端展示模型实际提供的思考文本 / 摘要、工具、Skill、子任务、沙箱日志与等待；未提供思考时不伪造。支持 SSE 去重、断线恢复、刷新回看。
- 项目尚未正式上线，不保留旧新两套运行时、兼容工具别名或新旧 checkpoint 双读；会话、作品、已有生成任务和成果须保留。
- 中文文档与回复；ID / 版本对外使用十进制字符串；桌面浏览器最低内容视口 **1280 CSS px**；Node 开发运行环境沿用项目要求。
- 全部实施后真实文本模型验收已获授权，不限费用额度；仅使用第 5.3 节指定模型与主备站，凭据进程内注入。图片、视频及其他非文本生成仅 mock 供应商，禁止真实调用；受控模型、SDK 替身不能冒称真实模型或 OpenSandbox 验收。

执行状态映射沿用现有产品词：活跃运行是 Run.running / Task.running，根图持久等待生成是 Run.waiting_generation / Task.waiting_media，用户停止是 Run.cancelled / Task.stopped，正常完成是双方 succeeded。预算耗尽用 Run.failed + `agent_budget_exhausted` 和 Task.paused_budget；新普通消息才能获得新 Run 预算。子任务仍运行时根运行保持 running，仅在所有可执行分支都已结束或等待时转等待。其他失败用 Run.failed / Task.paused_error，不在 Run 中发明未经迁移的 paused_budget 状态。

```python
from langgraph.checkpoint.base import BaseCheckpointSaver
from short_drama.core.exceptions import Conflict


class MySQLCheckpointSaver(BaseCheckpointSaver):
    def __init__(self, service):
        super().__init__(serde=JsonPlusSerializer(pickle_fallback=False))
        self.service = service
        self.thread_id = f"owner:{service.owner_id}:run:{service.run_id}"

    def put(self, config, checkpoint, metadata, new_versions):
        values = config["configurable"]
        if values["thread_id"] != self.thread_id:
            raise Conflict("执行图不能跨账号或 Run 访问")
        namespace = values.get("checkpoint_ns", "")
        codec, payload = self.serde.dumps_typed(checkpoint)
        self.service.put(
            namespace=namespace,
            namespace_hash=namespace_key(namespace),
            checkpoint_id=checkpoint["id"],
            parent_id=values.get("checkpoint_id"),
            codec=codec,
            payload=payload,
            metadata=metadata,
        )
        return {"configurable": {
            **values,
            "checkpoint_ns": namespace,
            "checkpoint_id": checkpoint["id"],
        }}
```

```python
from langgraph.types import Command


async def stream_run(graph, *, claim, context, config, snapshot, initial_messages,
                     waits, events):
    resume_values = waits.resume_values(claim, snapshot)
    graph_input = (
        {"messages": initial_messages} if snapshot is None
        else Command(resume=resume_values) if resume_values
        else None
    )
    async for event in graph.astream(
        graph_input,
        config,
        context=context,
        stream_mode=["messages", "updates", "custom"],
        subgraphs=True,
        durability="sync",
    ):
        await events.accept(event, claim)
    saved = await graph.aget_state(config, subgraphs=True)
    await waits.bind_snapshot(saved, claim)
    return saved
```

```python
# agent/tools/media_generation/wait_generation.py
from langchain.tools import ToolRuntime, tool
from langgraph.types import interrupt


@tool
def runtime__wait_generation(task_ids: list[str], runtime: ToolRuntime) -> dict:
    """下一步需要生成结果时等待；已完成任务立即返回，不重新提交。"""
    context = runtime.context
    wait = context.waits.inspect_and_register(
        run_id=context.run_id,
        scope_id=context.scope_id,
        tool_call_id=runtime.tool_call_id,
        task_ids=task_ids,
        fence=context.fence,
    )
    if wait.satisfied_without_interrupt:
        return wait.result
    interrupt({
        "kind": "generation",
        "wait_operation_id": str(wait.operation_id),
    })
    return context.waits.read_result(wait.operation_id, fence=context.fence)
```

```python
execution_scope: ContextVar[int | None] = ContextVar("execution_scope", default=None)


class TaskScopeMiddleware(AgentMiddleware):
    async def awrap_tool_call(self, request, handler):
        if request.tool_call["name"] != "task":
            return await handler(request)
        context = request.runtime.context

            context.run_id,
            context.scope_id,
            request.tool_call["id"],
            fence=context.fence,

        async with context.subtask_slots:
            token = execution_scope.set(scope_id)
            try:
                return await handler(request)
            finally:
                execution_scope.reset(token)
```

```python
from starlette.responses import JSONResponse
from short_drama.core.exceptions import BusinessError


class McpBearerAuth:
    def __init__(self, app, *, authenticate):
        self.app = app
        self.authenticate = authenticate

    async def __call__(self, scope, receive, send):
        if scope["type"] != "http":
            return await self.app(scope, receive, send)
        try:
            principal = await self.authenticate(Request(scope))
        except BusinessError as error:
            headers = {"WWW-Authenticate": "Bearer"} if error.status_code == 401 else {}
            response = JSONResponse(
                {"code": error.code, "message": error.message},
                status_code=error.status_code,
                headers=headers,
            )
            return await response(scope, receive, send)
        scope.setdefault("state", {})["mcp_principal"] = principal
        await self.app(scope, receive, send)
```

```typescript
// features/assistant/runtime/assistant-trace-state.ts
import { addDelta } from '@host/features/assistant/runtime/agent-events';
import type { DeltaChunk } from '@host/types/assistant/runtime/agent-events';
import type { TraceDeltaEvent } from '@host/types/assistant/runtime/trace';

export function applyTraceDelta(
  state: Record<string, DeltaChunk[]>,
  event: TraceDeltaEvent,
): Record<string, DeltaChunk[]> {
  const { block_id, channel, offset, delta } = event.payload;
  const key = `${block_id}:${channel}`;
  return {
    ...state,
    [key]: addDelta(state[key] ?? [], {
      ...event,
      payload: { turn_id: block_id, offset, delta },
    }),
  };
}
```
