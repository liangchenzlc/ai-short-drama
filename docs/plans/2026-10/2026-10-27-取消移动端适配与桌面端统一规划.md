# 取消移动端适配与桌面端统一规划

> 日期：2026-10-27  
> 状态：已完成  
> 已确认：项目只面向桌面浏览器，最低支持内容区域宽度为 **1280 CSS px**。  
> 执行进度：桌面默认布局、移动分支清理、测试迁移及长期规范已落实；验证存在既有失败，详见文末执行记录与验收文档。

项目将统一为桌面创作工作台，移除现有为手机和平板单独维护的布局、交互分支及验收要求，并将“后续页面无需移动端适配”写入长期协作与设计规范。实施先确定桌面默认布局，再分模块清理，最后迁移测试和核对文档，避免仅靠增加最小宽度掩盖仍存在的移动端实现。

## 一、目标与范围

| 项目 | 约定 |
| --- | --- |
| 支持对象 | 桌面浏览器，键盘、鼠标及触控板操作；宿主工作台与无限画布均纳入 |
| 最低宽度 | 浏览器内容区域宽度 ≥1280 CSS px；以实际视口计，不以显示器物理分辨率或设备型号计 |
| 桌面布局 | 保留流式布局、多栏、可收起面板、拖动调宽、内部滚动及必要的桌面宽度档位；不把所有页面锁死为一张固定尺寸画布 |
| 高度 | 使用可用窗口高度；以 720px、768px 等较矮桌面窗口检查滚动和操作可达性，不新增硬性高度拦截 |
| 低于最低宽度 | 不再提供专属布局、手机抽屉或完整可用性承诺；沿用桌面最小宽度，必要时允许溢出。不新增设备识别、访问拦截页或“请使用电脑”提示系统 |
| 后续设计 | 页面、组件、原型及日常验收只覆盖桌面支持范围，不再要求手机稿、平板稿、触屏专属布局及移动端截图 |

**纳入范围：** 当前产品的全部前端入口，包括认证与账号、项目管理、四阶段创作、AI 创作助手、任务、媒体资产库、AI 配置、Skill 管理，以及无限画布、共用浮层和图片工具；同时清理相关状态、事件监听、样式、测试参数及维护文档。

**保持范围：** 业务流程、API、数据库、任务执行、保存恢复、权限、生成与成片输出保持原语义；本需求不需要后端接口或数据库迁移。9:16 竖屏视频、竖图、媒体比例和导出能力属于创作内容，不属于移动端页面适配。现有桌面视觉风格和无限画布业务交互继续保留。

### 清理判定规则

| 类型 | 处理方式 |
| --- | --- |
| 手机／平板专用布局 | 删除专用断点、分支、DOM、遮罩、状态、事件及失去调用方的代码，不仅设置为隐藏 |
| “基础样式为手机，断点后才是桌面” | 先把桌面样式提升为默认，再移除断点；尤其核对画布的 `hidden lg:flex`、`lg:hidden` 等成对实现 |
| 1280px 以上的窗口变化 | 保留有用途的列宽调整、内容换行、列表列数和面板调宽，不要求媒体查询数量归零 |
| 桌面内的小容器 | 保留按实际容器宽度工作的 `ResizeObserver`、`@container`、省略与内部滚动；助手打开后剩余编辑区可能小于 700px，不能据此认定为手机 |
| 输入与无障碍 | 保留 Pointer Events、触控板缩放、键盘焦点、快捷键、Dialog 焦点管理及 `prefers-reduced-motion`；删除已退役抽屉自己的焦点陷阱和 `inert`，不删除通用能力 |
| 触屏与视口细节 | 清理仅为手机增加的控件尺寸、触屏替代入口、软键盘避让和安全区补丁；`visualViewport`、`hover: none` 等逐项判断，桌面浮层防溢出或通用输入确有依赖的部分保留并说明理由 |
| 浏览器基础设施 | 正常的 viewport 元信息、媒体自适应、DPR 清晰度、文字换行和浮层边界约束不作为移动端适配批量删除 |
| 第三方与历史资产 | 不修改 `node_modules`、构建产物、第三方方法包或历史原型来凑“零命中”；纳入应用维护的画布源码仍须清理，历史文档按需补充现行范围说明 |

## 五、验证与验收

### 桌面矩阵

所有尺寸指浏览器内容视口。以下为建议执行矩阵，其中 1280px 最低宽度已确认；矮窗口尺寸用于发现遮挡，不是新增支持门槛。

| 场景 | 视口／操作 | 核对点 |
| --- | --- | --- |
| 最低支持宽度 | 1280×720、1280×900 | 全部主路由可操作；助手与设置同时打开；无手机替代导航、抽屉或意外页面级横向溢出 |
| 常见笔记本 | 1366×768 | 顶栏长名称、固定页脚、模型菜单、生成与导出动作可达 |
| 常规桌面 | 1440×900 | 主流程和共用浮层；助手调宽、设置开合、失败恢复 |
| 宽屏桌面 | 1920×1080 | 列宽与阅读宽度合理，媒体比例正常，无过度拉伸 |
| 局部空间变化 | 在支持宽度内连续调整窗口、助手宽度、成片轨道高度 | 无重挂载丢稿、焦点跳失或布局残留；允许局部滚动和面板内部重排 |
| 桌面缩放与键盘 | 浏览器缩放后实际内容宽度仍 ≥1280px；Tab、Escape、方向键及快捷键 | 浮层不遮挡关键动作，文字不截断到无法操作，键盘可达与降低动效偏好继续生效 |

不再将 320／375／390／768px 手机和平板视口列为常规验收要求。低于 1280px 的行为只需核对不会重新进入专用移动界面，不建立新的手机可用性测试套件。
