**Goal:** 在不修改后端的前提下，完成单剧与多集创作工作台的正式前端组件，并提供可交互、明确标识的开发预览供用户验收。

**Architecture:** 使用现有工作台外壳和可复用编辑组件，新增由数据和回调驱动的剧本、资产与分镜视图。独立 Vite 夹具只负责内存中的示例数据和模拟生成，正式页面组件不依赖夹具；前端验收后，下一阶段再以真实接口接入并删除夹具。

**Tech Stack:** React 19、TypeScript strict、Vite 7、Ant Design、原生 CSS、Playwright。

**Spec:** [创作工作台剧集与单剧设计](../../design/2026-11-06-创作工作台剧集与单剧设计.md)。

> 执行补充：资产与分镜左侧列表沿用原有结构、卡片、筛选、创建及列表／宫格切换；中间工作区的三种视图单独切换。前端单剧预览已获用户确认。

## Global Constraints

- 本计划只实施前端、开发预览和前端测试；不修改后端、数据库、正式 API 契约或成片预览节点页面。
- 最低桌面内容视口宽度为 1280 CSS px；不做移动端与触屏专属布局。
- 新增文件、目录、变量和 CSS 类名使用小驼峰；沿用现有 React、Ant Design、原生 CSS 与项目主题，不引入新框架。
- 不把模拟数据放进正式项目路由；预览中明确显示“演示数据”，不访问业务 API、真实模型、账号或真实项目，刷新后状态重置。
- 预览必须挂载放在 frontend/src 的目标工作台视图组件；不得另做一份只用于截图的静态页面。既有正式路由暂时继续使用现有服务，后端阶段再用目标视图替换旧容器，删除预览入口和模拟数据，不保留两套正式业务逻辑。
- 目标视图只通过 props 接收数据和动作，不直接调用 HTTP；可复用的现有组件如含网络操作，先抽出纯展示部分，再由正式适配层执行原请求。
- 资产、分镜单卡无“上一个 / 下一个”；左侧保留原有资源列表及操作，负责切换对象；中间视图切换不改变左侧展示方式。图片、视频各自保留现有提示词组件。
- 分集标签只是用户编辑的普通文本标签，精确筛选，不自动关联或解除镜头引用。
- 不新增单剧 / 剧集切换字段；默认一个分集，多集时才出现分集选择器。
- 不因编写计划而修改业务代码。执行时先检查工作区，保留用户已有未提交改动；各任务只处理列出的职责范围。

## 页面结构与数据流

~~~text
┌──────────┬─────────────────────────────────────────────────────────────┐
│ 阶段导航 │ 作品名称          当前分集（多集时）           AI 助手       │
│          ├──────────────┬──────────────────────────────────────────────┤
│ 剧本创作 │              │ 大纲 / 剧本                                  │
│ 资产生成 │ 资源导航     │ 资产资料        │ 图片组 + 图片提示词        │
│ 分镜制作 │              │ 镜头资料+分镜图 │ 视频 + 参考图 + 视频提示词 │
│ 成片预览 │              │ 单卡 / 宫格 / 列表                           │
└──────────┴──────────────┴──────────────────────────────────────────────┘
~~~

预览入口持有项目、大纲、分集、资产、镜头和模拟任务；视图只接收数据与事件回调。切换视图不重建数据；切换分集时剧本、镜头按稳定 ID 读取，资产仍从同一个共享数组读取。图片预览选择、主图采用、镜头关联资产、视频参考选择各自独立。

import { useEffect, useState } from 'react';

export function useBatchSelectionState(scope: string) {
  const [ids, setIds] = useState<string[]>([]);
  useEffect(() => {
    setIds([]);
  }, [scope]);

  const toggle = (id: string, checked: boolean) =>
    setIds((current) =>
      checked ? [...new Set([...current, id])] : current.filter((value) => value !== id),
    );

  return { ids, setIds, toggle };
}
