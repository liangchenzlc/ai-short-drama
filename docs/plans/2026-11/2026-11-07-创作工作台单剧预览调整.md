# 创作工作台单剧预览调整 Implementation Plan

**Goal:** 根据前端验收反馈调整单剧创作预览，保留原有左右资源列表和既有产品视觉。

**Architecture:** 沿用正式剧本编辑器的展示组件，并以受控数据提供隔离演示；资产、分镜仍使用现有预览组件及内存状态。移除新预览中分集模型，不修改后端或已有正式项目数据。

**Tech Stack:** React、TypeScript、Ant Design、原生 CSS、Playwright。

**Spec:** 本计划覆盖 2026-11-07 的用户验收反馈，优先于 [2026-11-06 多集方案](../../design/2026-11-06-创作工作台剧集与单剧设计.md) 中的前端分集设计。

```text
剧本：现有「故事设定 / 剧本正文」页面
资产：原列表 │ 批量图标 · 全选                 单卡 / 宫格 / 列表
             │ 资料                     适中图片 + 高提示词
分镜：原列表 │ 批量图 / 视频 · 全选            单卡 / 宫格 / 列表
             │ 镜头资料 + 常开分镜图     适中视频 + 高提示词
```

- [x] 单剧：移除预览分集选择、概要和分集标签，复用原剧本页面与内存数据。最小验收：原有两个标签可编辑，页面无分集入口、预览无业务 API 请求。
- [x] 资产：批量操作与视图切换同行，补全场景和道具资料，缩小图片预览、增大提示词并隐藏滚动条。最小验收：资料切换后保留，图片组与批量操作仍可用。
- [x] 分镜：批量操作同行，补充景别之外的机位、运镜、对白和声音；分镜图生成始终展开并缩小预览。最小验收：两种视频路径及手动参考选择仍可用。
- [x] 完整验收：检查 1280、1440、1920 桌面宽度与助手开关，批量和图片组弹窗留有内边距；运行预览、原剧本和工作台回归，类型检查及生产构建。

不新增或修改正式后端接口、数据库和成片预览节点；模拟数据刷新后重置，预览不提供 AI 选区改写。参考现有剧本与镜头编辑器，以及常见镜头表的景别、角度、运镜、动作、对白和声音字段。

2026-11-07 验收记录：预览、原工作台布局及原剧本相关浏览器回归共 50 项通过；预览类型检查、标准前端构建、测试映射与结构门禁通过。已检查上述桌面宽度与弹窗截图，等待用户验收预览。

后续预览反馈：调整剧本标签内边距，让资产图片、分镜视频及提示词区域对齐；放大分镜图并将参考素材移至分镜图下方，图片参考与视频参考可分别移除。保留用于批量生成的筛选结果全选操作。预览、原工作台与剧本浏览器回归 51 项通过；复核了 1280、1440、1920 宽度截图，类型检查和标准前端构建通过。

再次调整：加宽单卡资料区，放大资料与提示词文字，让右侧预览及输入区适应可用空间。已复核 1280、1440、1920 宽度和助手开关的截图；31 项预览浏览器回归、类型检查与标准前端构建通过。

2026-11-07 用户确认当前单剧预览；正式接入转入 [单剧创作工作台正式接入计划](2026-11-07-单剧创作工作台正式接入.md)。
