# FlowerLab · 品牌标识

## 风格定位

**用户选定风格：4 抽象标**（用户点名，非建议）。

FlowerLab 是 AI 短剧工作台，产品本体是"让一个故事按某种规律生长成片子"。黄金角螺旋是自然界的生长算法——植物不必被"设计"，只要按规则展开就长成该有的样子。AI 生成在这里是同一件事。这个隐喻是标识的全部来源。

## 设计说明

**概念一句话：五片花瓣按同一方向微微旋开，中心留一个孔。**

- **构图逻辑**：五片花瓣均分 72° 但整体同向偏转 18°，形成旋转动势而非静态放射对称。中心留 5.8% 半径的孔，既是花蕊，也是镜头入光孔、培养皿的俯视剖面——三个意象共用同一个圆形。花瓣之间的负空间由花瓣自身的宽度收窄自然形成，不靠描边或挖缝。
- **几何逻辑**：花瓣由极坐标曲线生成，根部在圆心汇聚、向外展宽、尖端收束。直径占画布 80%，四周留 10% 安全边距。
- **色彩逻辑**：深墨绿骨架承担形体，暖纸白花瓣建立明度层次，旧金只出现在中心孔一处。深底浅形，把标识从"花店"的语义拉到"暗房/标本"的语义。

## 色彩规范

| 角色 | HEX | RGB | HSL | 占比 | 用途 |
|------|-----|-----|-----|------|------|
| 骨架 Skeleton | `#1F2420` | 31, 36, 32 | 96° 8% 13% | 58% | 画布底、花瓣间隙 |
| 过渡 Transition | `#F1EDE2` | 241, 237, 226 | 43° 35% 92% | 37% | 花瓣主体 |
| 点睛 Accent | `#A38B3E` | 163, 139, 62 | 47° 45% 44% | 1% | 中心花蕊孔 |
| 深色模式 | `#F1EDE2` 反白 | — | — | — | 深底用浅色骨架 |

校验：骨架 L=13%（≤22%）、S=8%（≤45%）；点睛面积 1.04%（≤5%）、全场仅一处；色相总数 2 + 中性；骨架与花瓣明度差 79，花瓣与点睛差 48。

**禁用**：不描黑边、不加投影、不用纯白描边包主体、不在骨架上叠高饱和色。

## 缩放表现

| 尺寸 | 保留 | 舍弃 |
|------|------|------|
| 1024 / 512 | 全部：花瓣曲率、18° 旋势、金蕊 | 无 |
| 96 | 五瓣轮廓、中心孔 | 花瓣尖端的细微曲率变化 |
| 48 | 五瓣剪影、中心点 | 花瓣间缝隙约 1px，开始并拢 |
| 32 | "五瓣 + 中心点"的整体剪影 | 缝隙消失，退化为花形块 |

32px 以下不建议再单独使用图形，改用字标或加大留白。

## 使用

- 图标自带底色，直接使用即可，不要再叠底或加圆角遮罩（iOS 会自动裁圆角）。
- 安全边距已留 10%，裁切时不要切进花瓣尖端。
- 最小使用尺寸 32px；小于 32px 请改用字标。
