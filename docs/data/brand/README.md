# WRAP STUDIO · 图标交付

项目名：**WRAP STUDIO**　｜　画布：1024 × 1024　｜　构成：青绿渐变底 + 一个月白 W

## 名称写法

| 场景 | 写法 | 说明 |
| --- | --- | --- |
| 字标（logo lockup） | `WRAP` 大字 + `STUDIO` 小字 | 主副字号比 ≥ 3:1；`STUDIO` 字距拉开到 +0.18em，压在主字下方左对齐或居中对齐 |
| 正文/标题 | Wrap Studio | 两个词都首字母大写 |
| URL / 包名 / 代码标识 | `wrapstudio` 或 `wrap-studio` | 不加空格 |
| 图标 | 只有 W | **不做 WD 缩写**，会丢掉刚建立的识别度 |

后缀 `STUDIO` 不承载语义，只负责把 `WRAP` 从"一个词"变成"一个产品"。所以它的视觉权重要永远低于 WRAP——它是注脚，不是名字。

| 文件 | 用途 |

## 色彩规范

| 角色 | HEX | RGB | HSL | 用途 |
| --- | --- | --- | --- | --- |
| 青 · 起 | `#0C3A4B` | 12, 58, 75 | 196° 72% 17% | 渐变起点（左上） |
| 青 · 止 | `#2E8073` | 46, 128, 115 | 171° 47% 34% | 渐变终点（右下） |
| 月白 | `#EFEDE4` | 239, 237, 228 | 47° 24% 92% | W |
| 纯色版底 | `#1E5D5A` | 30, 93, 90 | 178° 51% 24% | 渐变中点，替代渐变时使用 |

- 渐变只有两个色标，色相从 196° 走到 171°（同一族内 25°），方向 135°（左上→右下）。
- 没有红色。整套色只落在青绿一族 + 一个月白。
- 青就是名字里的那个"青"——**杀青**，把青竹烤干定稿。底色不是在配一个好看的绿，它就是这个字本身。

## 几何

- 画布 1024 × 1024，满版渐变，不设内框。
- W：包围盒 620 × 476，居中；笔画粗 112；五顶点
  `202,274 → 409.7,750 → 512,464.4 → 614.3,750 → 822,274`。
- 笔画端头为斜切（butt），不做圆角——刻出来的切口是斜的。
- 渐变用 `gradientUnits="userSpaceOnUse"`，坐标铺满整块画布，所以缩放到任何尺寸，W 与背景的明暗始终一致。

## 使用说明

- **App 图标 / 头像 / favicon**：用主版。系统圆角遮罩只切四角，W 在安全区内。
- **不能使用渐变时**（单色印刷、极小的 favicon、某些系统限制）：用纯色版。
- **单色场景**：底纯黑 + W 纯白即可，轮廓不依赖青绿。
- 不得拉伸、加投影、加描边、改渐变方向或旋转角度。
- 16px 以下 W 会糊成一个亮块，这是可接受的降级；这个尺寸下识别靠色块形状，不靠字母。
