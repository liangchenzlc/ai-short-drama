# AI Short Drama

面向个人创作者的 AI 短剧工作台。每个项目就是一部作品，创作内容、流程素材、分镜及生成结果保存在服务端；AI 结果先成为候选，由用户明确采用。项目仅所有者可见。

## 当前能力

| 环节 | 已实现 | 当前边界 |
| --- | --- | --- |
| 账号与归属 | 邮箱验证、登录、找回密码、项目隔离、个人模型配置 | 成员、邀请及跨库共享已退役 |
| 项目 | 名称与模式创建、原位改名、搜索、分页、最近打开、版本冲突保稿 | 创作模式直接进入流程，不分集；无项目资料页及手动归档 |
| 小说与剧本 | 自动保存、候选剧本、切换编辑稿、确认、版本冲突处理 | 小说修改不会自动重写剧本 |
| 素材生成 | 剧本 AI 提取、候选审核、流程素材、图片组、生图、上传与采用 | 项目、全局及个人角色/场景/道具素材库已退役，媒体资产库保留 |
| 分镜制作 | AI 拆镜、原文依据、时长、编辑、排序、素材关联 | 宫格图片尚无切格制作流程 |
| 分镜图片 | 关联素材参考图、异步生成、候选预览、采用、过期提示 | 可用参数取决于模型适配能力 |
| 分镜视频 | 单图或宫格作为全能参考图、系统与用户提示词、候选播放与采用、来源过期提示 | 当前接入 ModelHub Mini 全能参考；不含批量制作，模型效果需实际联调 |
| Agent 创作 | 私有持续对话、模型能力约束下的附件理解、内置/个人 Skill、计划审核与明确采用 | 对话、候选和历史仅本人可见，采用后进入本人作品；默认开启，启动需账号认证、显式迁移和独立 Worker；真实模型兼容性需单独验收 |
| 通用生成 | 文本/图片/视频任务、取消、按条件恢复或重试、媒体资产库 | 模型可用参数取决于适配能力 |
| 成片 | 连续画面轨与原声、对白、字幕、配乐、音效辅助轨，分割裁剪、撤销重做、合成预览和 MP4 导出 | 不含多视频叠层、转场或变速；语音识别和模型效果需按配置单独验收 |

创作模式直接提供四步：**剧本创作 → 素材生成 → 分镜制作 → 成片合成**。顶部保留名称、阶段导航、保存状态、助手和返回；画幅只在成片导出设置中选择，默认跟随实际分镜视频。AI 创作助手以当前项目为会话主体，成果保存到该项目，创作模式与画布模式分别使用各自目标；已受理任务保持原目标。桌面创作助手支持拖动调宽，模型旁通过添加菜单和 Skill 列表选择附件与方法。回复时发送按钮切换为停止，停止后可直接发送补充或新方向，完成后开始新任务；`/` 选择的 Skill 在输入框内显示高亮块，用户消息下不再显示操作按钮，等待回复使用动态省略号，输入区不显示任务选择下拉框；任务、上下文及记忆管理入口已移除，记忆由后台自动维护。接口、页面和模型供应商支持范围分别说明，不将存在后台接口等同于页面已完成。

项目名称仅在 Enter 或失焦时提交，Escape 丢弃尚未提交的输入，版本冲突保留本机名称供核对。成片刷新媒体地址时释放旧音频缓存并保留预览位置；配乐压低区间合并显式区间与未静音的对白。声音、成片上传后的数据库操作失败时，先独立核查文件是否已被引用再补偿清理。Agent 优先收集已结束的生成任务，前面的运行中任务不会阻塞后续结果。

## 技术栈

- 前端：React 19、TypeScript、Vite、Ant Design、Axios、React Router。
- 后端：Python 3.12+、FastAPI、Pydantic、SQLAlchemy/PyMySQL。
- 数据与任务：MySQL 8.0.21+、RabbitMQ、Celery、MinIO。

## 开始开发

本机依赖可在仓库根目录执行 `docker compose up -d` 一键启动 MySQL、RabbitMQ 和 MinIO，并自动初始化新库和媒体存储桶。默认连接配置与维护命令见 [Docker 依赖指南](docs/instruction/Docker一键启动后端依赖.md)。

准备 Python、uv、Node.js 22.18+ 的 22.x 或 24.x LTS，以及 MySQL、RabbitMQ 和 MinIO。按[开发与运行指南](docs/instruction/开发运行与验证.md)配置环境、初始化数据库、启动 API/调度器/Worker 和前端。

**新库使用完整建表文件：[schema.mysql8.sql](docs/database/schema/schema.mysql8.sql)。** 当前包含 116 张表及延后建立的外键。旧分集/协作版本只按[创作模式离线切换说明](docs/instruction/创作模式维护说明.md)备份、预演并重建；本次不迁移旧作品。不要叠加历史协作增量脚本，应用不会自动迁移。
