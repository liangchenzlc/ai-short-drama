# AI Short Drama

本项目仅支持桌面浏览器，最低内容视口宽度为 **1280 CSS px**，以浏览器实际内容区域计。新增和修改页面无需手机、平板或触屏专属布局、原型及验收；保留桌面窗口变化、组件内部排布、键盘可访问性、降低动效与正常滚动。低于最低宽度沿用桌面最小宽度并允许溢出，不增加设备识别或访问拦截。9:16 等媒体内容比例与输出能力继续保留。

面向个人创作者的 AI 短剧工作台。每个项目就是一部作品，创作内容、流程素材、分镜及生成结果保存在服务端。剧本以单页正文编辑，AI 按选区改写并直接保存；素材提取、分镜等结构化候选继续由用户明确采用。项目仅所有者可见。

Skill 统一在侧栏的独立管理页导入和更新，支持 Markdown／ZIP；通过目录树和只读源码区查看文件，模式为通用／创作／画布，默认通用。标签隐藏保留，卡片不显示文件数量，不再记录触发方式，脚本整包拒绝。AI 配置仅保留模型与助手设置；旧 Skill 地址自动转到 `/skills`。旧部署先执行 [Skill 设置迁移](docs/database/migrations/2026-10-26-skill-management/README.md)。

Skill 卡片的启停开关位于右下角，搜索与筛选控件等高排列；详情仅保留用途、模式及操作，目录树和只读文件区占主要空间，不展示适用边界和来源说明。

> 2026-10-28：独立任务管理页面与全局入口已退役，旧 `/tasks/*` 地址回到项目列表。后台任务继续执行，创作场景内保留必要的进度、失败及恢复反馈。

主页资产库按“生成历史 / 创作模式 / 画布模式”和“全部 / 图片 / 视频 / 音频”两层筛选；名称搜索框与媒体类型按钮同行，高度为 32px。本人 AI 生成的产物按创建时间倒序排列，每页 24 项、每行六项，卡片宽高较原四列约缩小三成。点击直接预览图片、播放视频或试听音频；图片支持画布同款缩放、旋转与拖动，关闭播放器即停止播放。手动上传的输入媒体不进入该库。

| 后台异步生成 | 文本/图片/视频/音频任务、取消、按条件恢复或重试 | 独立任务管理已退役，生成反馈保留在创作场景内；模型参数取决于适配能力 |
| 主页资产库 | 本人 AI 图片/视频/音频、工作台与媒体分类、名称搜索、六列分页与直接预览 | 不收录手动上传；只提供预览，不提供编辑、采用或任务跳转 |
| 成片 | 连续画面轨与原声、对白、字幕、配乐、音效辅助轨，分割裁剪、撤销重做、合成预览和 MP4 导出 | 不含多视频叠层、转场或变速；语音识别和模型效果需按配置单独验收 |

剧本页标题为“剧本”，提供“故事设定 / 剧本正文”双标签，960px 居中编辑区与两侧统一为近黑背景（#181818），故事设定输入框采用稍浅的灰色（#202020），聚焦保持同色且无边框。故事设定包含一句话卖点、故事梗概、故事类型、人物小传，使用独立版本串行自动保存，冲突保留本机输入；旧小说和大纲不自动导入。正文自然滚动，无固定字数／撤销栏及导入／导出入口，保留 Ctrl/Cmd+Z 撤销与选区 AI 改写。改写任务期间正文只读，进度和停止放在标题行；空稿可直接编辑，AI 创作助手从顶部进入；剧本页已移除“让助手起草剧本”和“最近变更”按钮。资产库和分镜表支持列表／宫格切换，列表行及侧栏底部“＋ 创建”均高45px，已有提取历史继续可查。接口见[剧本工作台](docs/api/writing-workspace.md)，实施与验证见[布局调整验收](docs/reviews/2026-10-28-创作工作台布局与故事设定验收.md)。

错误与警告的恢复操作保留在保存状态或弹窗标题的提示详情内；短提示关闭后仍可重试，弹窗内的详情操作不受外壳裁剪。旧分集、跨库素材共享与触屏尺寸验证的清理见[旧用例核查](docs/reviews/2026-10-28-旧用例核查与后端重启验收.md)。

创作模式直接提供四步：**剧本创作 → 资产生成 → 分镜制作 → 成片预览**。左侧固定40px满高图标导航，悬停显示阶段名称；顶部保留名称、保存状态、助手和返回；画幅只在成片导出设置中选择，默认跟随实际分镜视频。AI 创作助手以当前项目为会话主体，成果保存到该项目，创作模式与画布模式分别使用各自目标；已受理任务保持原目标。桌面创作助手支持拖动调宽，模型旁通过添加菜单和 Skill 列表选择附件与方法。新 Harness 任务执行中可补充输入，错误或旧预算暂停后发送“继续”会接着原任务执行，完成后开始新任务；不设任务累计轮次、工具调用次数或活动时长上限，单次请求及上下文／媒体配额继续生效；新任务支持边界停止，停止及暂停后普通消息沿原 Task 创建新 Run；旧引擎保留原 resume 控制；`/` 选择的 Skill 在输入框内显示高亮块，用户消息下不再显示操作按钮，等待回复使用动态省略号，输入区显示当前任务目标，并可明确“开始新任务”；任务、上下文及记忆管理入口已移除，记忆由后台自动维护。接口、页面和模型供应商支持范围分别说明，不将存在后台接口等同于页面已完成。

助手的待发送素材在有限高度内滚动，短桌面窗口保留完整的移除与发送入口。未结束任务显示其实际运行模型，任务结束后可切换；`@` 按关键词过滤当前对象和画布节点。成功执行过程自动折叠，失败原因默认展开且分别保留；成果等待、成功与失败使用对应状态图标。

复杂任务可登记有用户原文来源的交付要求，候选最终答复须经过独立检查，核对实际保存数量、回读和媒体交付证据；缺项返回原 Agent 继续执行。关键观察可作为有来源的任务笔记跨压缩保留，写入等能力组按需启用。连续空转会给出诊断并暂停，已有成果保留，补充信息后可继续；这不限制正常长任务的累计执行量。运行规则见 [Harness 运行机制](docs/instruction/AI创作助手Harness运行机制.md)。

后台记忆维护在凭据或明确鉴权错误时直接结束；限流及已回执的无效抽取输出按三次发送退避，耗尽后跳过该抽取范围，受理不明不重发。已有库先升级[记忆作业状态约束](docs/database/migrations/2026-10-26-agent-memory-retry/README.md)。后台作业重试次数不限制创作任务长度。

项目名称仅在 Enter 或失焦时提交，Escape 丢弃尚未提交的输入，版本冲突保留本机名称供核对。成片刷新媒体地址时释放旧音频缓存并保留预览位置；配乐压低区间合并显式区间与未静音的对白。声音、成片上传后的数据库操作失败时，先独立核查文件是否已被引用再补偿清理。Agent 优先收集已结束的生成任务，前面的运行中任务不会阻塞后续结果。

## 技术栈

- 前端：React 19、TypeScript、Vite、Ant Design、Axios、React Router。
- 后端：Python 3.12+、FastAPI、Pydantic、SQLAlchemy/PyMySQL；助手使用 LangGraph／LangChain。
- 数据与任务：MySQL 8.0.21+、RabbitMQ、Celery、MinIO。

## 开始开发

本机依赖可在仓库根目录执行 `docker compose up -d` 一键启动 MySQL、RabbitMQ 和 MinIO，并自动初始化新库和媒体存储桶。默认连接配置与维护命令见 [Docker 依赖指南](docs/instruction/Docker一键启动后端依赖.md)。

准备 Python、uv、Node.js 22.18+ 的 22.x 或 24.x LTS，以及 MySQL、RabbitMQ 和 MinIO。按[开发与运行指南](docs/instruction/开发运行与验证.md)配置环境、初始化数据库、启动 API/调度器/Worker 和前端。

**新库使用完整建表文件：[schema.mysql8.sql](docs/database/schema/schema.mysql8.sql)。** 当前包含 119 张表及延后建立的外键。旧分集/协作版本只按[创作模式离线切换说明](docs/instruction/创作模式维护说明.md)备份、预演并重建；本次不迁移旧作品。现有单层项目升级须执行[剧本工作台加法迁移](docs/database/migrations/2026-10-27-writing-workspace/README.md)。还须执行[剧本变更恢复增量](docs/database/migrations/2026-10-27-script-revisions/README.md)。本次新增[独立故事设定表](docs/database/migrations/2026-10-28-story-settings/README.md)，已在当前配置库执行，不回填旧业务数据。不要叠加历史协作增量脚本，应用不会自动迁移。
